## 3. Insert gates

Insert runs only when `resolveP76RehearsalSidecarWriterMode() === "insert_only"` and `canInsert === true`:

| Gate | Required |
|------|----------|
| `ENABLED=1` | yes |
| `DRY_RUN=0` | yes |
| `ALLOW_DB_WRITE=1` | yes |
| `KILL_SWITCH=0` | yes |
| `ENVIRONMENT` | `dev` or `staging` |
| `NODE_ENV` | not `production` |
| `input.environment` | matches `writerEnv.normalizedEnvironment` |

Otherwise: `insertedCount=0`, `blockedCount` or early `disabled` / `blocked_production` result — **no create**.
