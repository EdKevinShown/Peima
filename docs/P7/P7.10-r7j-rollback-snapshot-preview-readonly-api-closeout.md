## 3. Endpoint 摘要

- **Method / path:** `GET /admin/p76/canonical-sidecar/:id/rollback-snapshot-preview`
- **Feature gate:** `PEIMA_P76_CANONICAL_SIDECAR_ADMIN_ENABLED=1`（否则 404）
- **RBAC:** `VIEW_P76_CANONICAL_REHEARSAL`（ADMIN / OPERATOR / DATA_ANALYST 可读；未认证/权限不足 → 401/403，由 JwtAuthGuard + RbacGuard 执行）
- **Sidecar 不存在:** 404
- **MatchResult 缺失:** 200 + `snapshotReady=false` + `blockedReasons` 含 `missing_current_match_result`
- **Apply preview `canApply=false`:** 200 + `snapshotReady=false` + `preview_not_ready`

## 4. Rollback snapshot preview response contract

- `schemaVersion`: `1`
- `sourceType`: `"p76_canonical_apply_rollback_snapshot"`
- `sourceVersion`: `"p7.10-r7g-rollback-snapshot-builder-v1"`
- `mode`: `"dry_run"`
- `snapshotReady`: boolean
- `blockedReasons`: string[]
- `before` / `proposedAfter`: baseline vs proposed 摘要
- `rollback.rollbackTokenPreview`: `"redacted"`
- `rollback.rollbackTokenHash`: `null`（或 omitted）
- `rollback.rollbackExpiresAt` / `rollback.rollbackScope`: dry-run 元数据
- `safety`: 六项均为 `false`

## 5. Web F 区更新

- 并行请求 `rollback-snapshot-preview`（不影响 apply-preview 主面板）
- 展示 Dry-run badge、`snapshotReady`、blocked reasons、before/proposedAfter、rollback token/expires/scope、snapshot safety
- API 401/403/404/网络错误 → 友好 unavailable 提示
- **无** Apply / Rollback / Promote 按钮

## 6. No-write safety

响应与 builder 保证：

| Flag | Value |
|------|-------|
| `writesDb` | `false` |
| `writesMatchResult` | `false` |
| `writesFinalScore` | `false` |
| `triggersWorker` | `false` |
| `changesPercent` | `false` |
| `productionRollout` | `false` |

服务层仅 `findUnique`；不 `update`/`create`/`delete` sidecar 或 MatchResult。

- 不包含 sidecar 行内 `rollbackToken` 明文
