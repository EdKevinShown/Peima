## 3. Writer purpose and non-goals

### 3.1 Purpose

1. Consume **`P76CanonicalWriterShadowPayloadV1`** rows produced by `buildP76CanonicalWriterShadowPayloadV1` ([`p76-canonical-writer-shadow-builder.ts`](../../apps/api/src/modules/matching/p76-canonical-writer-shadow-builder.ts)).
2. Map each shadow into a future **`P76CanonicalWriterRehearsalMeta`** insert (after migration).
3. Preserve rehearsal evidence for **Admin / Ops read-only** review ([r6d §9](./P7.10-r6d-dedicated-rehearsal-sidecar-schema-design.md)).
4. Keep **`appliedToMatchResult = false`** on every row and inside `shadowPayload`.
5. Stay **invisible** to GET / worker / FinalMatchPage unless a **future, separate** gated project says otherwise.

### 3.2 Non-goals

| Non-goal | Notes |
|----------|-------|
| Create / update / upsert `MatchResult` | Worker-owned baseline |
| Update `matchInsights` | Option C deferred ([r6c](./P7.10-r6c-canonical-writer-dual-write-rehearsal-design.md)) |
| Change `candidateUserId`, `finalScore`, `displayCandidateUserId` | Compare-only |
| Wire GET `/matching/result` | [r6e](./P7.10-r6e-rehearsal-sidecar-migration-design-review.md) |
| Worker / batch-match integration | No ranking input |
| Disable PreviewPool | [P7.10-r5](./P7.10-r5-legacy-pool-bridge-sunset-plan.md) separate |
| Canonical production write | r3+ program |
| Write `p76_allowlist_apply_meta` | Use existing `p76-allowlist-apply-writer` only |

## 5. Env gates

### 5.1 Environment variables

| Env | Default | Meaning |
|-----|---------|---------|
| `PEIMA_P76_REHEARSAL_SIDECAR_WRITER_ENABLED` | `0` | Master enable |
| `PEIMA_P76_REHEARSAL_SIDECAR_WRITER_DRY_RUN` | `1` | Build rows + summary; **no** `create` |
| `PEIMA_P76_REHEARSAL_SIDECAR_WRITER_ENVIRONMENT` | `dev` | Logical env label → must map to `dev` \| `staging` |
| `PEIMA_P76_REHEARSAL_SIDECAR_WRITER_ALLOW_DB_WRITE` | `0` | Second explicit insert gate |
| `PEIMA_P76_REHEARSAL_SIDECAR_WRITER_KILL_SWITCH` | `0` | `1` = hard stop (fail closed) |

**Related (read-only upstream, not writer):**

| Env | Role |
|-----|------|
| `PEIMA_P76_CANONICAL_WRITER_SHADOW_ENABLED` | Shadow **builder** ([`p76-canonical-writer-shadow-env.ts`](../../apps/api/src/modules/matching/p76-canonical-writer-shadow-env.ts)); writer should force `1` when loading rows via r6a path or reject `disabled` shadows |

### 5.2 Insert allowed only when (all true)

| # | Condition |
|---|-----------|
| 1 | `ENABLED=1` |
| 2 | `DRY_RUN=0` |
| 3 | `ALLOW_DB_WRITE=1` |
| 4 | `KILL_SWITCH=0` |
| 5 | `ENVIRONMENT` ∈ `{ dev, staging }` (after normalize) |
| 6 | `process.env.NODE_ENV !== 'production'` |
| 7 | Table `p76_canonical_writer_rehearsal_meta` exists (migration applied) |
| 8 | Optional: `_prisma_migrations` contains expected migration name ([r6e](./P7.10-r6e-rehearsal-sidecar-migration-design-review.md)) |

### 5.3 Production block (defense in depth)

Even if all env flags are wrong:

| Layer | Behavior |
|-------|----------|
| App | `resolveWriterMode()` → `blocked_production` if `ENVIRONMENT=production` or `NODE_ENV=production` |
| DB | `CHECK (environment IN ('dev','staging'))` ([r6e §6.2](./P7.10-r6e-rehearsal-sidecar-migration-design-review.md)) |
| Ops | Migration **not** deployed to prod until explicit approval |

## 7. Input contract

```ts
type P76CanonicalWriterRehearsalWriterInput = {
  auditRunId: string;
  environment: "dev" | "staging";
  readPathSourceVersion: string;
  rows: Array<{
    matchResultId: string;
    viewerUserId: string;
    allowlistApplyMetaId?: string | null;
    shadow: P76CanonicalWriterShadowPayloadV1;
  }>;
};
```

| Field | Rules |
|-------|-------|
| `auditRunId` | **Required**; non-empty; cuid/uuid; same for entire batch; writer may generate if CLI omits |
| `environment` | `dev` \| `staging` only |
| `readPathSourceVersion` | From `readP76ReadPathEnv().sourceVersion` (default `p7.6-r7j3-staging-cohort-v1`) |
| `rows[].matchResultId` | **Required** per [r6e](./P7.10-r6e-rehearsal-sidecar-migration-design-review.md) |
| `rows[].shadow` | Must pass builder invariants + privacy guard |

**Blocked row policy:** May **skip insert** for `shadow.guardrails.eligible === false` **or** insert with `eligible=false` — **recommend insert all rows** (including `rolled_back`, `missing_sidecar`) for audit fidelity; denormalized columns reflect guardrails.

## 10. Writer pipeline

```text
1. readP76CanonicalWriterRehearsalWriterEnv()
2. resolveWriterMode() → disabled | dry_run | insert_only | blocked_production | kill_switch
3. if not insert_only and not dry_run → return early result
4. validateInput(input) — auditRunId, environment, row shape
5. for each row:
     a. assertShadowInvariants(shadow) — mode=shadow, appliedToMatchResult=false
     b. assertPrivacySafe(shadow)
     c. mapToCreateInput(row)
6. if dry_run → write artifact JSON only; exit 0
7. assertPrismaSurfaceSafe(prisma) — no matchResult.update in client
8. for each createInput:
     try prisma.p76CanonicalWriterRehearsalMeta.create
     on P2002 unique → duplicateCount++
9. emit P76CanonicalWriterRehearsalWriterResultV1
```

**Data sources for CLI v1:**

| Source | Path |
|--------|------|
| Re-run r6a logic in-process | Reuse `loadP76CanonicalWriterShadowAuditRowInputs` from [`p710-r6a-canonical-writer-shadow-audit-runner.ts`](../../apps/api/src/dev-cli/p710-r6a-canonical-writer-shadow-audit-runner.ts) |
| Or read existing audit JSON | `artifacts/p76/r6c2a/canonical-writer-shadow-audit-targeted.json` → map `rows[]` |

Recommend **shared loader function** extracted in implementation (not in r6f).

## 13. Idempotency

| Mechanism | Detail |
|-----------|--------|
| DB unique | `@@unique([matchResultId, auditRunId, pipelineVersion])` ([r6e](./P7.10-r6e-rehearsal-sidecar-migration-design-review.md)) |
| Writer behavior | On Prisma `P2002`, count as **`duplicateCount`**, do not fail batch (unless `--strict`) |
| Same `auditRunId` | All rows in one CLI invocation share one id |
| Re-run | Second run with same ids → duplicates skipped or reported |

**CLI flags (future):**

- `--auditRunId=<id>` — required or auto-generate cuid
- `--strict` — fail on any duplicate
- `--skipDuplicates` — default true

## 14. Prisma surface safety

Mirror [allowlist writer `P76AllowlistApplyWriterPrisma`](../../apps/api/src/modules/matching/p76-allowlist-apply-writer.ts): **narrow type** passed to writer.

```ts
type P76CanonicalWriterRehearsalWriterPrisma = {
  p76CanonicalWriterRehearsalMeta: {
    create: (args: { data: Prisma.P76CanonicalWriterRehearsalMetaCreateInput }) => Promise<{ id: string }>;
    findUnique?: (args: { where: { matchResultId_auditRunId_pipelineVersion: ... } }) => Promise<...>;
  };
  matchResult?: {
    findUnique: (args: { where: { id: string }; select: { id: true } }) => Promise<{ id: string } | null>;
  };
};
```

**Explicitly omit** from type:

- `matchResult.update` / `create` / `upsert` / `delete`
- `p76AllowlistApplyMeta.update` (rehearsal does not mutate allowlist)
- Any `matchInsights` path

**Runtime guard (implementation):** If `prisma.matchResult?.update` is defined, optional dev assert — prefer compile-time narrow interface.
