## 4. Request / response contract

**Request:** path param `id` = `p76_canonical_match_result_meta.id`

**Response:** `P76CanonicalApplyPreviewPayloadV1`

| Field | Notes |
|-------|-------|
| `mode` | always `"preview"` |
| `canApply` | `true` only if **all** gates pass |
| `blockedReasons[]` | Failed gate codes (non-empty when blocked) |
| `sidecar` / `currentMatchResult` | Normalized snapshots |
| `proposedChange` | Diff flags from r7d |
| `gateResults` | Per-gate pass/fail |
| `rollbackPreview.rollbackTokenPreview` | `"redacted"` only — **never** plaintext token from DB |
| `safety.*` | All `false` |

**Missing MatchResult:** `200` with `currentMatchResult: null`, `canApply=false`, `missing_match_result` in `blockedReasons` (not 404).
