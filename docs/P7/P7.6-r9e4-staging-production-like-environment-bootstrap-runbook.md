## 3. 推荐 staging 架构

**最小合格组合（r9e3 reverify 必需）：**

| 组件 | 推荐选项 | 必须？ |
|------|----------|--------|
| **Postgres 16** | Supabase · Neon · Railway Postgres · AWS RDS · 阿里云 RDS | **是** |
| **API** | Render · Railway · Fly.io · ECS · EC2 + Docker | **是** |
| **Web** | Vercel · Netlify · Render static · Nginx + OSS | 可选（GET smoke 可 curl） |
| **Monitoring** | Grafana Cloud · CloudWatch · Datadog · Sentry + 日志 | **是**（dashboard + P0） |
| **Worker** | — | **否**（P7.6 read path 不依赖） |
| **Uploads** | 块存储 PVC 或 `UPLOAD_DIR` 持久卷 | 建议 |

**架构图与 provider 对照：** [artifacts/p76/r9e4/staging-architecture.md](../../artifacts/p76/r9e4/staging-architecture.md)

**原则：**

- staging **必须** non-localhost（DB host + API URL）
- staging 证据 **可** 用于 r9e3 **production-like reverify**，**不可** 标为 customer production
- **Worker 可暂不部署**；**Web 可选**；**API + DB + monitoring 必须有**

## 4. Staging env template

**权威模板：**

- [artifacts/p76/r9e4/staging-env-template.md](../../artifacts/p76/r9e4/staging-env-template.md)
- [docs/ops/peima-staging.env.example](../ops/peima-staging.env.example)

**冻结默认值（bootstrap 阶段）：**

```bash
DATABASE_URL=<staging-postgres-url>   # 非 localhost
NODE_ENV=production
API_PORT=3000
API_HOST=0.0.0.0
JWT_SECRET=<generate-strong-secret>   # 勿提交仓库
JWT_EXPIRES_IN=7d

PEIMA_P76_READ_PATH_ENABLED=0
PEIMA_P76_READ_PATH_VIEWER_IDS=
PEIMA_P76_READ_PATH_SOURCE_VERSION=p7.6-r7j3-staging-cohort-v1
PEIMA_P76_READ_PATH_REQUIRE_PM_SIGNOFF=1
PEIMA_P76_READ_PATH_REQUIRE_OPS_SIGNOFF=1
PEIMA_P76_READ_PATH_FALLBACK_LEGACY=1
PEIMA_P76_READ_PATH_STRICT_VIOLATION_BLOCK=1
PEIMA_P76_PRODUCTION_PERCENT_ENABLED=0
PEIMA_P76_PRODUCTION_PERCENT=0
PEIMA_P76_PRODUCTION_KILL_SWITCH=1

VITE_API_BASE_URL=https://api-staging.<your-domain>
```

**必须明确：**

| 规则 | 值 |
|------|-----|
| 不得提交真实 secrets | 仅 placeholder / Secret Manager |
| percent 默认 | **0** |
| read path 默认 | **off** (`ENABLED=0`) |
| kill switch 默认 | **on** (`=1`) |
| safe fallback (baseline display) | **on** (`=1`) |
