## 1. 一句话结论

P7.6-r2 定义 **Stage 1 PhotoVisual First Pool** 的 shadow contract：基于双方 `UserPreference.styleTags` 与 `detectionScoreJson.vision.photoVisualTags` 计算 **A→B / B→A / mutualPhotoVisualFit**，产出 **PhotoVisualCandidatePool** shadow（`PhotoFirstMutualMatchingShadowV1.stage1PhotoVisualPool`）。本轮只定义 contract、输入、输出、fallback、audit 与 old/new 对比规则；**不改**正式 pool、worker、`MatchResult` 或 `finalScore`。

## 3. Stage 1 目标

Stage 1 **只回答**：

| 问题 | 由 Stage 1 回答 |
|------|-----------------|
| A 是否喜欢 B 的照片风格？ | `AtoBPhotoVisualFit`（viewer `styleTags` ↔ candidate `photoVisualTags`） |
| B 是否也喜欢 A 的照片风格？ | `BtoAPhotoVisualFit`（candidate `styleTags` ↔ viewer `photoVisualTags`） |
| 双方视觉是否互相不排斥 / 有基础眼缘？ | `mutualPhotoVisualFit` |

**输出**：`PhotoVisualCandidatePool` shadow → `stage1PhotoVisualPool.selectedCandidateIds[]`

Stage 1 **不回答**：

- 20D 是否兼容（Stage 2）
- RRM 谁更适合推进（Stage 3）
- 最终 `MatchResult` 谁赢
- `finalScore` 是多少

## 5. Eligibility / Guardrails

### 5.1 Pair-level `eligible=true` 须全部满足

| # | 条件 |
|---|------|
| 1 | `viewerUserId` ≠ `candidateUserId`（非 self） |
| 2 | **性别 DB gate** 通过（与 onboarding `candidatePassesOppositeBinaryGate` 一致） |
| 3 | **Hard preference gate** 通过（`passesPreferenceHardGate`） |
| 4 | Candidate 首图（或选用图）`reviewStatus` 可用 — **非** `rejected` / **非** `needs_reupload` |
| 5 | Candidate `detectionStatus` 可用（与 onboarding 预览门控一致） |
| 6 | `visionStatus === "ok"` |
| 7 | `photoVisualTags` **非空**（归一化后至少 1 个封闭词表 tag） |
| 8 | Viewer 侧若参与 B→A：viewer 须有 usable vision + 非空 `photoVisualTags`（或 r3 定义 B→A 降级策略） |
| 9 | 用户状态：非 blocked / hidden；非已匹配 / 已忽略 / 已反馈不感兴趣（与产品 gate 对齐） |
| 10 | 必要画像字段不缺失（与 gated cohort 一致） |

### 5.2 明确禁止（与 P7.5-r7 / r7-e 一致）

- **不用** AI 判断 gender  
- **不**做人脸识别  
- **不**做颜值评分  
- **不**判断年龄 / 种族 / 身份  

### 5.3 Ineligible 处理

```text
eligible = false
ineligibleReasons[] = 枚举原因码
不进入 stage1PhotoVisualPool.selectedCandidateIds
pairs[] 仍可保留该行（audit），fit 字段为 null
```

**建议 `ineligibleReasons` 枚举**（r3 实现时对齐代码）：

| 码 | 含义 |
|----|------|
| `SELF` | viewer === candidate |
| `GENDER_GATE` | 性别门控失败 |
| `PREFERENCE_GATE` | hard preference 失败 |
| `REVIEW_BLOCKED` | reviewStatus 不可用 |
| `DETECTION_UNAVAILABLE` | detection 不可用 |
| `VISION_NOT_OK` | visionStatus ≠ ok |
| `EMPTY_PHOTO_VISUAL_TAGS` | 无 photoVisualTags |
| `VIEWER_VISION_MISSING` | B→A 需要但 viewer 无 vision |
| `USER_BLOCKED` | 用户状态拦截 |
| `MISSING_PROFILE` | 必要画像缺失 |

## 6. 分数定义

### 6.1 符号

```text
overlap(A, B) = 标签集合相似度（r3 选定具体公式，见 §6.4）
```

**产品语义**（contract 层）：

```text
AtoBPhotoVisualFit = overlap(viewer.styleTags, candidate.photoVisualTags)

BtoAPhotoVisualFit = overlap(candidate.styleTags, viewer.photoVisualTags)

visualImbalancePenalty = f(|AtoB - BtoA|)   // r3 定义，默认 0 或小常数

mutualPhotoVisualFit =
  0.5 * AtoBPhotoVisualFit
+ 0.5 * BtoAPhotoVisualFit
- visualImbalancePenalty
```

**可选保守版**：

```text
mutualPhotoVisualFit = harmonicMean(AtoBPhotoVisualFit, BtoAPhotoVisualFit)
```

### 6.2 进池排序（shadow）

对 **eligible** 的 pairs：

1. 按 `mutualPhotoVisualFit` **降序**  
2. 同分：按 `AtoBPhotoVisualFit` 降序  
3. 再同分：按 `candidateUserId` 稳定排序  

取 Top **N**（audit 默认 N=6 对齐 onboarding 槽位；可配置 `limit`）→ `selectedCandidateIds[]`。

### 6.3 公式锁定策略

| 阶段 | 决策 |
|------|------|
| **r2** | **只定义**两种 mutual 公式；**不锁定**生产公式 |
| **r3 / r4** | 实现 pure functions + audit 分布后选定 |
| **约束** | 分数**仅**用于 shadow；**不写**正式 pool / `finalScore` |

### 6.4 与现有代码对齐（r3 参考）

现有 `visual-ranking-shadow-scoring.ts` 使用：

- **`tagJaccard`** 作为 tag overlap  
- 可选 **`× confidence`**（candidate vision）  
- 单向 aesthetic：`viewerStyleTags` ↔ `candidate.photoVisualTags`  

P7.6 Stage 1 **新增**反向：`candidateStyleTags` ↔ `viewer.photoVisualTags`。r3 应复用 `tagJaccard` / `overlapTags`，避免第三套算法。

## 8. Source pool 决策

| 类型 | r2 范围 | 说明 |
|------|---------|------|
| **A — `onboarding_gated_cohort`** | **默认 · 必设计** | 复用 `collectGatedCandidates` 硬门控；**不影响 worker**；最安全 audit 面 |
| **B — `onboarding_preview_pool_v1`** | **必设计 · 对比** | 读 active onboarding pool 6 `candidateUserId`；算 `wouldChangeOnboardingV1` |
| **C — `legacy_preview_pool`** | **仅 comparison · 不实现写** | 读 active `preview_pools` items；算 `wouldChangeLegacyPreviewPool`；**bridge 后置** |

**r2 结论**：

- **实现计划（r3）默认**：先 **A** 生成 shadow；同一 `viewerUserId` 上并行填 **B/C** 进 `comparisons`（只读）。  
- **不**在 r2/r3 修改 legacy `PreviewPool` 或 worker 读池逻辑。

## 9. 与 visualRankingShadow 的关系

| 维度 | visualRankingShadow（现有） | P7.6 Stage 1（r2） |
|------|----------------------------|-------------------|
| 目的 | onboarding 假设 6 槽 vs v1 baseline | 双向眼缘池 shadow |
| 方向 | 主单向 aesthetic + style_similar 槽 | **A→B 与 B→A 显式** |
| 存储 | `OnboardingPhotoPreviewPoolShadow` | `PhotoFirstMutualMatchingShadowV1`（新 contract） |
| 写池 | APPLY 时可能写 onboarding v2 | **`appliedToPool: false`** |

**关系**：

- **不替代** `visualRankingShadow`；两者可 **同一 viewer 并存** audit。  
- **复用**：`visual-ranking-shadow-vision-input.ts`（usable vision）、`sourceImageKey`、`tagJaccard`。  
- **对比字段**（§7.3）：`visualRankingShadowCandidateIds` vs `stage1SelectedCandidateIds`；`wouldChangeOnboardingV1` 可与 shadow 6 槽 shadow 侧对比。

**`wouldChangeOnboardingV1` 定义**（r2）：

```text
set(onboardingV1CandidateIds) !== set(stage1SelectedCandidateIds)
OR
同集合但顺序不同且产品认为顺序有意义（可选 strictOrder 标志）
```

## 10. 与 legacy PreviewPool 的关系

| 项 | r2 策略 |
|----|---------|
| legacy 池角色 | batch worker **唯一**上游（r1） |
| r2 改动 | **无** — 只读 items 填 `comparisons.legacyPreviewPoolCandidateIds` |
| `wouldChangeLegacyPreviewPool` | `set(legacyIds) !== set(stage1SelectedCandidateIds)`（或 rank 相关扩展） |
| 桥接 worker | **后置** — 单独里程碑；需新 ADR |

**可选扩展字段**（r5 audit 用，r2 预留于 reason 文本或 future schema）：

- `legacyRank: Record<candidateUserId, rankInPool>`  
- `stage1Rank: Record<candidateUserId, number>`

## 14. 风险

| 风险 | 说明 | 缓解 |
|------|------|------|
| **双池脱节** | shadow 在 onboarding 链；worker 读 legacy | r3 只 shadow；bridge 单独立项 |
| **与 visualRankingShadow 重复** | 两套 shadow 可能困惑 | 区分 schema；comparisons 显式对比 |
| **B→A 缺 candidate styleTags** | 候选无 preference → `BtoAPhotoVisualFit=0` | ineligible 或降级 + audit 计数 |
| **无 live vision** | 仅 rules/stub tags | `VISION_NOT_OK` / empty tags → ineligible |
| **tags 覆盖不足** | cohort 大量 ineligible | r7-e 已 PASS 小样本；扩 cohort 前再 audit |
| **过早改 onboarding pool** | 误开 APPLY | env 清单；`appliedToPool: false` |
| **过早桥接 worker** | 误改 `preview_pools` | r2 禁止；C 只 comparison |
| **误启 APPLY / percent** | 生产池被覆盖 | 与 P7.5-r5 相同闸门；r2 不启 |
