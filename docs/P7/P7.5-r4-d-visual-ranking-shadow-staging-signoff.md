## 6. readyForApplyToPoolDesign 与原因

本次 staging：**`false`**。

主要 `reasons`（与实现一致）：

- `shadowCoverageRate 0.000 < 0.8`
- `validShadowRows 0 < 50 — sample too small`
- `viewerVisionAvailableRate 0.000 < 0.6`
- `avgChangedSlots 0.000 outside [0.3, 2.5]`

**说明**：在 **无 shadow 样本** 或 **valid &lt; 50** 时 `readyForApplyToPoolDesign = false` **为预期门禁**，不代表 CLI 或 persist 实现错误。需在 SHADOW 开启且足够多用户完成 `generate` 后重跑 CLI 再评估 r5。
