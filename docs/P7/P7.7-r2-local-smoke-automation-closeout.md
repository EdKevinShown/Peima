## 3. One-command usage (Windows)

From repo root:

```powershell
pnpm --filter @peima/api run p77:r2:local-smoke
```

Or directly:

```powershell
cd apps/api
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/p77-r2-local-smoke-automation.ps1
```

### Parameters

| Param | Default | Purpose |
|-------|---------|---------|
| `-RepoRoot` | `../../` from `apps/api/scripts` | Monorepo root |
| `-DotenvPath` | `<RepoRoot>/.env` | `DOTENV_CONFIG_PATH` for DB steps |
| `-AuditLimit` | `20` | r6a `--limit` |
| `-AuditOutput` | `artifacts/p76/r7r2/canonical-writer-shadow-audit.json` | r6a JSON path (repo-relative) |
| `-SkipDbAudit` | off | Skip r6a + artifact check |
| `-SkipHttpSmoke` | off | Skip r9b contract smoke |
| `-Pretty` | off | r6a `--pretty` |
| `-ViewerUserId` | `""` | Optional r6a filter |
| `-BatchId` | `""` | Optional r6a `--batchId` |

Examples:

```powershell
# Jest + build only (no DATABASE_URL)
.\scripts\p77-r2-local-smoke-automation.ps1 -SkipDbAudit -SkipHttpSmoke

# Full run with pretty audit JSON
.\scripts\p77-r2-local-smoke-automation.ps1 -Pretty
```

## 4. Step order

1. **`pnpm --filter @peima/api run build`** — compiles Nest + dev-cli (r6a runner in `dist/`)
2. **Jest regression pack** — patterns: `p77-r1`, `result-state`, `matching-result-state`, `p710-r4a`, `p710-r6`, `p710-r6a`, `p76-read-path-env`, `p76-read-path-display-resolver`
3. **r9b HTTP smoke (opt-in contract)** — `P76_SMOKE_EXPECT_RESULT_STATE_CONTRACT=1`, `node -r dotenv/config scripts/p76-r9b-http-get-smoke.mjs`
4. **r6a canonical writer shadow audit** — `node -r dotenv/config dist/dev-cli/p710-r6a-canonical-writer-shadow-audit-runner.js`
5. **Artifact safety check** — `p77-r2-local-smoke-artifact-check.mjs` asserts `appliedToMatchResultCount === 0`, `sourceType` / `mode`, no sensitive keys

Steps 3–5 are **SKIPPED** (not failed) when `DATABASE_URL` is absent in `.env`, unless explicitly skipped via switches.
