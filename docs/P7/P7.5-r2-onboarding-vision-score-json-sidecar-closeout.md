# P7.5-r2 — Onboarding vision `detectionScoreJson.vision` sidecar Closeout

## 本轮目标

在 **上传检测完成后** 将 `OnboardingVisionProfileV1` 合并进 `UserImage.detectionScoreJson.vision`；默认 **不写**；失败 **不阻断** 上传；review / gate / pool / worker **不变**。

设计依据：`docs/P7/P7.5-onboarding-vision-design.md`

## 行为矩阵

| `PEIMA_ONBOARDING_VISION_ENABLED` | `PROVIDER` | DB `detectionScoreJson.vision` | `sourceVersion` |
|-----------------------------------|------------|--------------------------------|-----------------|
| `false`（默认） | — | **不写入** | — |
| `true` | `rules` | 写入 | `p7.5-r2-rules` |
| `true` | `stub` | 写入 | `p7.5-r2-stub` |
| `true` | `zhipu` | 写入 skipped | `p7.5-r2-zhipu-skipped` + warning `ONBOARDING_VISION_PROVIDER_UNSUPPORTED_IN_R2`（**无 HTTP**） |
| `true` + 构建异常 | — | 写入 skipped | `p7.5-r2-persist-failed` |

## 集成点

- **Hook**：`ImagesService.detectionScoreJsonForPersist` → `UserImageVisionSidecarService`（`createFromUpload` / `detectionAndReviewToCreateFields`）
- **Review**：仍基于 **原始** `detection.scoreJson`（不含 `vision`）
- **模块**：`ImagesModule` imports `OnboardingVisionModule`；**未** import 进 `OnboardingModule`
- **未改**：`user-image-detection.service.ts`、3+2+1 pool、worker、matching、旧 PreviewPool
