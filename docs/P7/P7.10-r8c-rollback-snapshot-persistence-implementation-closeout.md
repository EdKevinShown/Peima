## 5. Persistence service behavior

**`createP76CanonicalApplyRollbackSnapshotRecord(deps, input)`**

| Step | Behavior |
|------|----------|
| 1 | 若 `dryRunSnapshot.snapshotReady === false` → `{ ok: false, reason: 'snapshot_not_ready' }` · **no insert** |
| 2 | 校验 `safety.*` 全为 `false` · `rollbackTokenPreview === 'redacted'` |
| 3 | 拒绝 dry-run payload 上非 null 的 `rollback.rollbackTokenHash` |
| 4 | 映射 r7g `before` / `proposedAfter` / summary → Prisma `create` |
| 5 | 返回 `{ ok: true, persisted: summary }` |

**输入：** `dryRunSnapshot` (r7g) · optional `rollbackTokenHash` · `requestedBy` · `auditRunId` · `approvals` · `environment`

**不调用：** `matchResult.update` · `p76CanonicalMatchResultMeta.update` · worker
