## 4. RRM mutual 公式

```text
AtoBRrmFit  = clamp(rhythmScoreAtoB)
BtoARrmFit  = clamp(rhythmScoreBtoA)

mutualRrmFit = harmonicMean(AtoBRrmFit, BtoARrmFit)

harmonicMean(A, B) = (A > 0 && B > 0) ? 2 * A * B / (A + B) : 0
```

**排序（Top2 内 eligible 候选）：**

1. `mutualRrmFit` desc  
2. `riskFlagCount` asc  
3. `repairPotentialScore` desc  
4. `candidateUserId` asc

## 5. Shadow builder 输出

| 字段 | 说明 |
|------|------|
| `stage3Rrm.evaluatedCandidateIds` | Top2 内已评估 id（0–2） |
| `stage3Rrm.rankedCandidates` | 含 fit、flags、`repairPotentialScore`、`eligible` |
| `stage3Rrm.selectedByRrmCandidateId` | RRM 2 选 1 结果 |
| `stage3Rrm.wouldChange20DWinner` | RRM 选中 ≠ `selectedBy20DOnlyCandidateId` |
| `finalShadow.stage3SelectedCandidateId` | 与 RRM 选中一致（shadow 语义） |
| `applied` / `appliedToPool` / `appliedToFinalScore` / `appliedToMatchResult` / `appliedToWorkerRanking` | 全部为 **`false`** |

**行为摘要：**

| 场景 | 行为 |
|------|------|
| RRM winner ≠ 20D winner | `wouldChange20DWinner = true` |
| `RRM_INSUFFICIENT_SIGNAL`（双向完全并列等） | fallback `selectedBy20DOnlyCandidateId` · `wouldChange20DWinner = false` |
| `TOP2_NOT_AVAILABLE` | `selectedByRrmCandidateId = null` |
| viewer / candidate profile missing · invalid input | 不 throw；按 fallback 枚举处理 |
