# P7.4-r1d-c2 — Admin Photo Review 只读 API Closeout

## 本轮目标

在 **不改动** detection / review 写入规则、onboarding 门禁、worker、匹配链路的前提下，为运营/管理员提供照片审核 **只读** 列表与详情 API，并接入 RBAC 权限 `manage_photo_review`。

**未实现（留给 r1d-c3+）：** approve、reject、needs-reupload、reset、audit log、Admin 页面、reviewStatus 接入 onboarding nextStep。

## 新增接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/photo-review/items` | 审核队列列表（默认 `pending_review`） |
| GET | `/admin/photo-review/items/:imageId` | 单张详情（含完整 `detectionScoreJson`） |

## 权限设计

- 新增 `Permission.MANAGE_PHOTO_REVIEW = "manage_photo_review"`（`packages/shared/constants/p5-rbac.ts`）。
- **ADMIN**、**OPERATOR** 角色在 `ROLE_PERMISSIONS_MAP` 中授予该权限。
- 路由使用现有 `JwtAuthGuard` + `RbacGuard` + `@RequirePermission(Permission.MANAGE_PHOTO_REVIEW)`。
- 未登录：由 `JwtAuthGuard` 返回 **401**。
- 已登录但无权限：由 `RbacGuard` 返回 **403**。
- 权限解析仍走 `RbacService`（DB `role_permissions` + `ROLE_PERMISSIONS_MAP` + `PEIMA_*_USER_IDS` env），非仅 env 白名单。

## 查询参数（列表）

| 参数 | 说明 |
|------|------|
| `reviewStatus?` | 默认 `pending_review` |
| `detectionStatus?` | `pending` \| `passed` \| `failed` \| `skipped` |
| `reasonCode?` | 匹配 `detectionReasonCodes` 或 `reviewReasonCodes` |
| `hasWarnings?` | `true`：仅 `detectionScoreJson.warnings` 非空；`false`：无 warnings |
| `userId?` | 按用户过滤 |
| `createdAfter?` / `createdBefore?` | ISO8601 时间范围 |
| `limit?` | 默认 20，最大 100 |
| `cursor?` | `createdAt.toISOString()\|imageId`，按 `createdAt asc, id asc` 分页 |

**排序：** `createdAt` 升序（FIFO）。

**`hasWarnings` 限制：** Prisma 未对 JSON 数组做 DB 级过滤；当指定 `hasWarnings` 时，单次最多拉取 `min(limit×5, 100)` 行后在内存过滤，极端情况下可能漏页，运营列表可接受。

## 返回字段

### 列表 item

- `imageId`, `userId`, `imageUrl`
- `detectionStatus`, `detectionReasonCodes`, `detectionRulesVersion`, `detectedAt`
- `reviewStatus`, `reviewReasonCodes`, `reviewedAt`, `reviewedByUserId`, **`reviewNote`**
- `createdAt`, `updatedAt`
- `detectionSummary`（不含完整 `detectionScoreJson`）

### `detectionSummary`

从 `detectionScoreJson` 提炼：

- `faceCount`
- `warnings`
- `primaryFace`
- `quality`（`meanLuma`, `laplacianVariance`, `width`, `height`）

### 详情

列表字段 + 完整 `detectionScoreJson` + `user: { userId, nickname }`（不返回 email/phone）。

## 普通用户接口边界

- `/images` 等仍通过 `UserImagePublicDto` / `toUserImagePublicDto` **不暴露 `reviewNote`**（见 `user-image-review-status.spec.ts`）。
- 普通用户 **不能** 访问 `/admin/photo-review/*`（需 `manage_photo_review`）。
- 本轮 **无** 用户侧修改 `reviewStatus`、无申诉 API。

覆盖要点：

1. 列表默认 `pending_review`
2. `reviewStatus` / `detectionStatus` / `reasonCode` 过滤
3. 列表含 `detectionSummary`，无完整 JSON
4. 详情含完整 JSON + `reviewNote`
5. 404 / RBAC 403（guard 单测）
6. 公开 DTO 不暴露 `reviewNote`（既有 `user-image-review-status.spec.ts`）

Controller 集成测试通过 override `JwtAuthGuard` / `RbacGuard` 测委托；401 依赖全局 `JwtAuthGuard`（与 audit / suggestion-center 一致）。
