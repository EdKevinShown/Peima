## 5. 结果解释

| 观察 | 含义 |
|------|------|
| Runner 正常退出、stdout JSON 完整 | DB 读取、normalize、`buildPhotoFirstMutualMatchingShadowV1`、audit 包装均成功 |
| `scannedCandidates=20` | gated cohort 扫描达到 `--limit` |
| `eligibleCandidates=0` | 20 条候选在 eligibility 规则下**无一**通过 |
| `GENDER_GATE` (13) | 候选与 viewer 的**性别 DB gate**（异性二进制门控）未通过 |
| `VISION_NOT_OK` (9) | 候选 `user_images` 上 vision 缺失或 `visionStatus !== "ok"`（或未满足 passing + 非空 tags） |
| `selectedCandidateIds=[]` | 无 eligible pair，Stage1 无法选出 Top-N |

**结论**：这不是 CLI/runner 实现失败，而是**当前本地数据集**在 Stage1 hard gates 下无法产生任何可选候选，故 r3b **不能**作为「Stage1 selection 行为已验证」的 signoff。
