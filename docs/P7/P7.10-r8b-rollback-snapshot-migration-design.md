model P76CanonicalApplyRollbackSnapshot {

  sidecarId     String @map("sidecar_id")

  baselineFingerprint          String    @map("baseline_fingerprint")

  proposedCandidateUserId String   @map("proposed_candidate_user_id")
  proposedFinalScore      Float?   @map("proposed_final_score")
  proposedReasonSummary   String?  @map("proposed_reason_summary")
  proposedSourceVersion   String?  @map("proposed_source_version")

  rollbackTokenHash  String?   @map("rollback_token_hash")
  rollbackExpiresAt  DateTime? @map("rollback_expires_at")
  rollbackUsedAt     DateTime? @map("rollback_used_at")
  rolledBack         Boolean   @default(false) @map("rolled_back")
  rolledBackAt       DateTime? @map("rolled_back_at")
  rollbackReason     String?   @map("rollback_reason")

  applyAuditRunId         String? @map("apply_audit_run_id")
  appliedBy               String? @map("applied_by")
  approvedByPm            String? @map("approved_by_pm")
  approvedByOps           String? @map("approved_by_ops")
  approvedByEngineering   String? @map("approved_by_engineering")

  sourceType    String @map("source_type")
  sourceVersion String @map("source_version")

  @@index([sidecarId])
  @@index([matchResultId])
  @@index([viewerUserId])
  @@index([rollbackExpiresAt])
  @@index([rolledBack])
  @@index([promotionStatus])

### 3.4 Relations / indexes

| Index / constraint | Purpose |
|--------------------|---------|
| `@@unique([snapshotId])` | Idempotent create by public id |
| `@@index([sidecarId])` | Admin UI / audit by sidecar |
| `@@index([matchResultId])` | Apply / rollback validation |
| `@@index([viewerUserId])` | Ops queries |
| `@@index([rollbackExpiresAt])` | Expiry sweeps |
| `@@index([rolledBack])` | Active snapshot filters |
| `@@index([promotionStatus])` | Lifecycle reporting |
| **Optional partial unique** | `@@unique([sidecarId, matchResultId, proposedSourceVersion])` **only** for rows where `promotionStatus IN ('snapshot_created','apply_pending')` — requires partial index in raw SQL review ([r8b1](./P7.10-r8b1-rollback-snapshot-migration-sql-review.md) optional); else enforce in application layer |

**Sidecar pointer（未来 r8c，非本 migration）：** `P76CanonicalMatchResultMeta.previousSnapshotHash` ← `baselineFingerprint`；`rollbackToken` 列应迁移为 **hash** 或弃用明文（见 [r7e §5](./P7.10-r7e-canonical-apply-rollback-snapshot-design.md)）。

**禁止：** 在 snapshot 表存完整 `P76CanonicalApplyRollbackSnapshotV1` JSON blob 作为唯一来源（可选 `payloadDigest` 列未来再加；r8b **不** 要求 JSONB payload 列以降低 secret 泄漏面）。

## 4. Redaction / storage policy

| Rule | Requirement |
|------|-------------|
| Rollback token | **No plaintext** in DB · logs · artifacts · API list/export |
| DB storage | **`rollbackTokenHash` only** |
| Secrets | **No** `DATABASE_URL` · `JWT_SECRET` · API keys · admin bearer tokens |
| Raw prompt / profile | **Not stored** |
| `matchInsights` | **Summary + checksum only** (`beforeMatchInsightsSummaryJson` + `beforeMatchInsightsChecksum`) |
| Artifacts | **No** real token; use `redacted` / ticket refs |
| Logs | Structured logs **must not** print token or hash preimage |
| Operator id | `appliedBy` = opaque admin id — **not** email in exports |

Align with [r7g §5](./P7.10-r7g-canonical-apply-rollback-snapshot-builder-closeout.md) and [P7.7-r4.1](./P7.7-r4.1-canonical-sidecar-admin-readonly-api-implementation-closeout.md) sanitization lists.

## 5. Token hash design

| Rule | Detail |
|------|--------|
| Mint | `crypto.randomBytes(32)` → base64url; returned **once** in future `POST create-rollback-snapshot` response |
| Storage | `rollbackTokenHash = HMAC-SHA256(pepper, canonicalInput)` or bcrypt — pepper from `PEIMA_P76_ROLLBACK_TOKEN_PEPPER` |
| Hash input binding | `snapshotId` + `matchResultId` + `sidecarId` + token plaintext (see [r7e §6](./P7.10-r7e-canonical-apply-rollback-snapshot-design.md)) |
| Expiry | `rollbackExpiresAt` — default **72h** staging · **24h** production-like |
| Single-use | First successful rollback sets `rolledBack=true`, `rollbackUsedAt=now()` |
| Reuse | Second attempt → `already_rolled_back` / idempotent **no-op** (no double MR write) |
| Expired | `now >= rollbackExpiresAt` → `rollback_token_expired` · **no** MR mutation |
| Preview APIs | `rollbackTokenPreview: "redacted"` only (r7j / r7f) |

**r8b:** defines policy only — **no** mint implementation.

## 6. Migration safety

Future **r8c** / **r8b-impl** migration **must**:

| Requirement | Detail |
|-------------|--------|
| Additive only | `CREATE TABLE` + indexes — **no** `DROP` / destructive `ALTER` on existing tables |
| MatchResult schema | **Unchanged** in snapshot migration — MR changes = **separate** reviewed migration |
| Data backfill | **Not required** — empty table at deploy |
| Triggers | **None** |
| Default Apply | **Not** enabled by migration |
| Rollback of migration | `DROP TABLE` safe if no production rows; staging review first |
| Prisma client | `db:generate` after schema edit; CI compile gate |
| Production migrate | **Separate** Ops approval — **not** in r8c without signoff |

**r8b:** **no** migration file created · **no** `prisma migrate` run.

## 7. Apply interaction

Future Apply (`r8d+`) **before** any `MatchResult` write **must** verify:

| # | Gate |
|---|------|
| 1 | Snapshot row exists for `snapshotId` |
| 2 | `baselineFingerprint` matches **current** live `MatchResult` |
| 3 | Sidecar eligible (`promotionStatus`, not `rolledBack`, not deleted) |
| 4 | Gate 12 / r8 milestone signoffs still valid |
| 5 | PM / Ops / Eng approval fields populated per tier |
| 6 | No active incident · no active worker deploy |
| 7 | P0/P1 clean · Grafana active |
| 8 | `PEIMA_P76_PRODUCTION_PERCENT=0` |
| 9 | Apply env gate enabled **dev/staging only** |
| 10 | `rollbackToken` verifies against `rollbackTokenHash` (if policy requires token before apply) |

**r8b:** documents gates only — **does not implement**.

## 8. Rollback interaction

Future Rollback (`r8e+`) **must**:

| # | Step |
|---|------|
| 1 | Load snapshot by `snapshotId` |
| 2 | Verify `rollbackTokenHash` against presented token |
| 3 | Reject if expired · already used · `rolledBack=true` |
| 4 | Confirm current `MatchResult` equals **proposedAfter** state |
| 5 | Restore **before** fields (`candidateUserId`, `finalScore`, `reasonSummary`, `matchInsights` from summary policy) |
| 6 | Set `rolledBack=true`, `rolledBackAt`, `rollbackUsedAt`, `promotionStatus=rollback_completed` |
| 7 | Write audit trail (separate audit log table future) |
| 8 | **No** worker trigger · **no** percent change |

Guards align with [r7e §7](./P7.10-r7e-canonical-apply-rollback-snapshot-design.md).

**r8b:** documents only — **does not implement**.
