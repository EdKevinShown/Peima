## 4. Env Runbook

### 4.1 默认关闭（生产 / staging 基线）

```env
PEIMA_ONBOARDING_VISION_APPLY_TO_POOL=0
PEIMA_ONBOARDING_VISION_APPLY_ALLOWLIST_USER_IDS=
PEIMA_ONBOARDING_VISION_APPLY_PERCENT=0
PEIMA_ONBOARDING_VISION_APPLY_SOURCE_VERSION=onboarding-photo-preview-v2-vision
PEIMA_ONBOARDING_VISION_SHADOW_ENABLED=1
```

**生产**：保持上述默认，**不得**在未完成审批的情况下改为 `APPLY_TO_POOL=1`。

### 4.2 Allowlist-only 开启（dev / staging / 受控生产）

```env
PEIMA_ONBOARDING_VISION_APPLY_TO_POOL=1
PEIMA_ONBOARDING_VISION_APPLY_ALLOWLIST_USER_IDS=<viewer cuid 1>,<viewer cuid 2>
PEIMA_ONBOARDING_VISION_APPLY_PERCENT=0
PEIMA_ONBOARDING_VISION_APPLY_SOURCE_VERSION=onboarding-photo-preview-v2-vision
PEIMA_ONBOARDING_VISION_SHADOW_ENABLED=1
```

### 4.3 规则（运维必读）

| 规则 | 说明 |
|------|------|
| 总闸 | **仅**字符串 `"1"` 为开（`"true"` **不算**） |
| Allowlist | **非空**；viewer **必须在列表内** 才可能 v2 |
| Percent | **不参与** c4 写池；`PERCENT=100` + 空 allowlist → 仍 **v1**（`allowlist_empty`） |
| 生效 | 修改 env 后 **必须重启 API** 或 **redeploy** |
| 范围 | **仅** onboarding photo preview **新生成** pool；**不**批量改历史 pool |
| 生产 | **默认关闭**；开启须单独审批且 **仍 allowlist-only** |

## 5. 允许操作与禁止操作

### 允许

- 在 **dev / staging** 对 **allowlist** 内 viewer 开启并验证
- **生产**如需开启：单独审批 + 极小 allowlist + §8 清单 + active audit
- 用 **active audit** 检查最新 **active** pool
- 用 **`sourceVersion`** 区分 v1 / v2
- 用 **关闸 + 再 generate** 回滚至 v1
- 运行 **c2 signoff runner** 做五案回归（非生产例行，可选）

### 禁止

- **percent 灰度**（归 **r5-d**，须单独设计评审）
- **非 allowlist** 或 **空 allowlist** 下期望全量 v2
- **默认开启生产** apply 总闸
- **批量 UPDATE** 历史 `onboarding_photo_preview_pools` / items
- 修改 **worker** / **`MatchResult`** / **`finalScore`**
- 修改旧 **`PreviewPool`**、正式匹配主链
- **云视觉 API**；**AI 美化 / AI 头像**
- **人脸比对** / 身份认证 / **颜值评分**
- **根据照片自动判断性别**
