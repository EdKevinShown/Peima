## 1. Runner 目标

单进程执行 **Case A–E** 五组 apply env，对真实 `OnboardingPhotoPreviewPoolService.generate()`：

- 临时覆盖 / 恢复 `process.env`（apply 四变量）
- 读取 active pool `sourceVersion` 与 6 items
- 读取 shadow `summary.applyDryRun` / `summary.applyResult` / 根 `appliedToPool`
- 调用 **r4-o2 active audit**
- 输出脱敏 JSON（`schemaVersion: p7.5-r5-c2-apply-writer-signoff-v1`）
- exit **0** 当且仅当 `summary.allPass === true`

**不**改 worker、`MatchResult`、`finalScore`、旧 `PreviewPool`、正式匹配主链。
