## 4. Endpoint contract

| Method | Route | Permission |
|--------|-------|------------|
| `POST` | `/admin/p76/canonical-sidecar/:sidecarId/apply` | `APPLY_P76_CANONICAL_REHEARSAL` |
| `POST` | `/admin/p76/canonical-sidecar/:sidecarId/rollback` | `ROLLBACK_P76_CANONICAL_WRITE` |

**Guards：** `JwtAuthGuard` + `RbacGuard`

**Apply body：** `snapshotId` · `matchResultId` · `requestedBy` · `environment` · `gateContext{ gate12Final, grafanaReady, pmSignoff, opsSignoff, engSignoff, activeIncident, activeWorkerDeploy, percent }`

**Rollback body：** 同上 + `rollbackTokenPlaintext`（仅传入 service 校验，**不** 返回）

---

## 5. Apply wiring behavior

1. Route env off → `404`
2. Route on → `applyP76CanonicalSidecarToMatchResult`（仍读 r8d service env）
3. `gateContext` boolean → r8d `P76CanonicalApplyGateContextV1` 字符串状态
4. Response 经 `sanitizeP76CanonicalApplyApiResponse`
5. r8d service env 默认 disabled → `mode=blocked` · `apply_execution_disabled`

---

## 6. Rollback wiring behavior

1. Route env off → `404`
2. Route on · token 空 → route `blocked` · `rollback_token_missing`（**不** 调 service）
3. Route on · token 有 → `rollbackP76CanonicalApply`（仍读 r8e service env + token hash gate）
4. Response 经 `sanitizeP76CanonicalRollbackApiResponse`
5. r8e service env 默认 disabled → `rollback_execution_disabled`
