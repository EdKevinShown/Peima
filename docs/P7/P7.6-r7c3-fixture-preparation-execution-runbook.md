## 9. Rollback 方案

**原则：** 从 `p76_r7c3_*_backup` 恢复；删除带 `dev-p76-r7c3-*` 前缀的新增行；rollback 后再跑 §8.2 确认 `recommendedForBatch` 回落。

### 9.1 恢复 `user_profile`

```sql
-- r7c3 rollback: user_profile from backup
UPDATE user_profile up SET
  "attachmentStyle" = b."attachmentStyle",
  "emotionalExpression" = b."emotionalExpression",
  "communicationStyle" = b."communicationStyle",
  "conflictHandling" = b."conflictHandling",
  "loveLanguage" = b."loveLanguage",
  "securityNeed" = b."securityNeed",
  "controlNeed" = b."controlNeed",
  "independence" = b."independence",
  "loyaltyView" = b."loyaltyView",
  "jealousyTendency" = b."jealousyTendency",
  "moneyAttitude" = b."moneyAttitude",
  "careerPriority" = b."careerPriority",
  "lifePace" = b."lifePace",
  "socialNeed" = b."socialNeed",
  "emotionalStability" = b."emotionalStability",
  "sexualValues" = b."sexualValues",
  "familyView" = b."familyView",
  "marriageExpectation" = b."marriageExpectation",
  "childrenIntent" = b."childrenIntent",
  "riskPreference" = b."riskPreference",
  "relationshipPace" = b."relationshipPace",
  "updatedAt" = NOW()
FROM p76_r7c3_user_profile_backup b
WHERE up."userId" = b."userId";
```

若 seed 前无 profile 行，rollback 改为 `DELETE FROM user_profile WHERE "userId" IN (SELECT "userId" FROM p76_r7c3_user_profile_backup WHERE /* 标记为 insert-only */);` — closeout 须注明 insert vs update。

### 9.2 删除新增 `user_preferences`

```sql
-- 仅删除 r7c3 写入的 preference 行
DELETE FROM user_preferences pref
WHERE pref.id LIKE 'dev-p76-r7c3-pref-%'
   OR pref."userId" IN (SELECT "userId" FROM p76_r7c3_user_preferences_backup);

-- 若 seed 前无行：从 backup 无法恢复 — 以 backup 为准 INSERT 还原（见 backup 表）
INSERT INTO user_preferences
SELECT id, "userId", "minAge", "maxAge", "preferredCities",
       "minHeight", "maxHeight", "educationPreferences", "occupationPreferences",
       "relationshipGoalPreferences", "styleTags", "createdAt", "updatedAt"
FROM p76_r7c3_user_preferences_backup
ON CONFLICT ("userId") DO NOTHING;
-- 注：执行前核对 backup 列与 live schema 一致（r4b1 §7）
```

### 9.3 恢复 / 删除 dev-only onboarding pool

```sql
-- 删除 r7c3 新建的 pool items + pool
DELETE FROM onboarding_photo_preview_pool_items oppi
WHERE oppi."poolId" IN (SELECT "id" FROM p76_r7c3_onboarding_pools_backup);

DELETE FROM onboarding_photo_preview_pools opp
WHERE opp."id" IN (SELECT "id" FROM p76_r7c3_onboarding_pools_backup);

-- 若修改了既有 pool：从 backup 还原
INSERT INTO onboarding_photo_preview_pools
SELECT * FROM p76_r7c3_onboarding_pools_backup
ON CONFLICT ("id") DO UPDATE SET
  "status" = EXCLUDED."status",
  "updatedAt" = EXCLUDED."updatedAt";
```
