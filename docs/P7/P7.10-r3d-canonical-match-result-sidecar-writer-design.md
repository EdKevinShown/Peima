## 5. Env gates

**Design-only env (extends [r3b §8](./P7.10-r3b-canonical-match-result-sidecar-schema-and-writer-design.md)):**

```bash
PEIMA_P76_CANONICAL_SIDECAR_WRITER_ENABLED=0
PEIMA_P76_CANONICAL_SIDECAR_WRITER_DRY_RUN=1
PEIMA_P76_CANONICAL_SIDECAR_WRITER_ALLOW_DB_WRITE=0
PEIMA_P76_CANONICAL_SIDECAR_WRITER_ENVIRONMENT=dev
PEIMA_P76_CANONICAL_SIDECAR_WRITER_ALLOWLIST_VIEWER_IDS=
PEIMA_P76_CANONICAL_SIDECAR_WRITER_SOURCE_VERSION=p7.10-r3d-canonical-sidecar-writer-v1
PEIMA_P76_CANONICAL_SIDECAR_WRITER_KILL_SWITCH=0
```

### 5.1 Insert allowed only when (all true)

| Gate | Value |
|------|-------|
| `ENABLED` | `1` |
| `DRY_RUN` | `0` |
| `ALLOW_DB_WRITE` | `1` |
| `KILL_SWITCH` | `0` |
| `ENVIRONMENT` | `dev` or `staging` (matches [r3c](./P7.10-r3c-canonical-match-result-sidecar-migration-design-review.md) CHECK) |
| `NODE_ENV` | **not** `production` |
| `input.environment` | matches writer normalized environment |
| Viewer | on `ALLOWLIST_VIEWER_IDS` (if non-empty) |
| Payload | `guardrails.eligible === true` |
| `sourceVersion` | payload matches `PEIMA_P76_CANONICAL_SIDECAR_WRITER_SOURCE_VERSION` (or documented cohort policy) |

Otherwise: **`insertedCount=0`** · increment `blockedCount` / `skippedCount` · **no** `create` — mirror [r6f2 §3](./P7.10-r6f2-rehearsal-writer-insert-only-implementation-closeout.md).

### 5.2 Mode resolution (mirror rehearsal)

| Resolved mode | Behavior |
|---------------|----------|
| `disabled` | No-op summary |
| `dry_run` | Map rows + artifact; **no** Prisma |
| `insert_only` | `create` when gates pass |

**Functions (future):** `readP76CanonicalMatchResultSidecarWriterEnv()` · `resolveP76CanonicalMatchResultSidecarWriterMode()` · `dryRunP76CanonicalMatchResultSidecarWriter()` · `insertOnlyP76CanonicalMatchResultSidecarWriter()`.

## 6. Writer input contract

### 6.1 Batch input shape (proposed)

```typescript
/** Design-only — P7.10-r3d */
type P76CanonicalMatchResultSidecarWriterInput = {
  auditRunId: string;
  environment: "dev" | "staging";
  sourceVersion: string; // writer cohort label
  rows: P76CanonicalMatchResultSidecarWriterRowInput[];
};

type P76CanonicalMatchResultSidecarWriterRowInput = {
  payload: P76CanonicalWriterDryRunPayloadV1;
  matchResultId?: string | null;
  pmSignoffStatus?: string;
  opsSignoffStatus?: string;
};
```

**Typical flow:** `buildP76CanonicalWriterDryRunPayloadV1(buildInput)` → attach to `rows[].payload` → pass to writer.

### 6.2 Per-row validation (before create)

| Rule | Reject code (suggested) |
|------|-------------------------|
| `payload.mode === "dry_run"` | `invalid_mode` |
| `payload.sourceType === "p76_canonical_writer"` | `invalid_source_type` |
| `payload.appliedToMatchResult === false` | `applied_flag_forbidden` |
| `payload.appliedToFinalScore === false` | same |
| `payload.appliedToWorkerRanking === false` | same |
| `payload.guardrails.eligible === true` | `guardrails_ineligible` |
| `payload.selectedCandidateId` non-empty | `missing_candidate` |
| `payload.score` finite **or** policy allows null with explicit waiver | `score_missing` |
| `auditRunId` non-empty | `missing_audit_run_id` |
| `environment` ∈ `dev` \| `staging` | `invalid_environment` |
| Privacy scan passes | `forbidden_payload_key` |
| `payload.viewerUserId` on allowlist | `not_allowlisted` |
| `payload.sourceVersion` matches writer cohort | `stale_source_version` |

**Assert helper (future):** `assertP76CanonicalWriterDryRunPayloadInsertEligible(payload)` — wraps r3a `assertCanonicalWriterDryRunNeverWritesMatchResult`.

## 9. Idempotency / duplicate handling

**Preferred unique key ([r3c §7](./P7.10-r3c-canonical-match-result-sidecar-migration-design-review.md)):**

```text
(auditRunId, viewerUserId, sourceVersion)
```

| Event | Behavior |
|-------|----------|
| `Prisma.P2002` on create | `duplicateCount++` · log row · **continue batch** |
| No `upsert` in v1 | Never overwrite existing sidecar |
| Re-run same `auditRunId` | Duplicates counted; no mutation |

**Helper (future):** `isP76CanonicalMatchResultSidecarWriterPrismaUniqueViolation(err)` — same as rehearsal `isP76RehearsalWriterPrismaUniqueViolation` (`code === "P2002"`).

**Active sidecar supersede:** Application may set `supersededAt` on older row before insert when cohort changes — **not** writer upsert; optional r3g ops tool.

## 10. Privacy / payload safety

**Reuse baseline:** `P76_REHEARSAL_WRITER_FORBIDDEN_JSON_KEYS` in `p76-canonical-writer-rehearsal-writer-privacy.ts` (includes `rawPrompt`, `transcript`, `imageFeatures`, `fullPrompt`, `rawImage`, etc.).

**Extend for canonical dry-run payload:**

| Additional deny (r3d) | Reason |
|-----------------------|--------|
| `rawVisionResponse` / `raw_vision_response` | Vision raw |
| `DATABASE_URL` | Secret |
| `secrets` | Generic |

**Behavior:**

| Case | Action |
|------|--------|
| Forbidden key in `stageSummary` / `dryRunPayload` | **Reject row** → `skippedCount++` · `reason=forbidden_payload_key` |
| Oversized JSON | Reject — cap e.g. 32KB per rehearsal precedent (`P76_REHEARSAL_WRITER_MAX_SHADOW_PAYLOAD_BYTES`) |
| Never persist | Strip not allowed in v1 — reject entire row |

**Scan target:** `dryRunPayload` + `stageSummary` before `create`.

## 13. Relationship to promotion

| Layer | Owner |
|-------|-------|
| Sidecar writer (r3d design) | Creates `mode=sidecar` · `promotionStatus=not_promoted` |
| Promotion (r3g+ / r7b) | Updates `MatchResult` + sidecar flags |

**Promotion preconditions ([r3b §10](./P7.10-r3b-canonical-match-result-sidecar-schema-and-writer-design.md)) — writer does not enforce:**

- Sidecar active · signoffs · `rollbackToken` · snapshot hash · r7 / r9e3 gates

**r3d does not implement promotion.**
