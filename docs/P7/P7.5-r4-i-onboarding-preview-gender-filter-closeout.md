# P7.5-r4-i — Onboarding preview gender gate (strict binary closeout)

## 本轮目标

在 **仅限** onboarding **photo preview pool** 生成路径与 **dev 候选人图导入** 中落实产品规则：**Viewer 与候选人的性别均为必填**；仅接受归一化后的 **male / female**；**不再**将 unknown / 空串用作「不过滤」或「补位」。不改 worker、正式匹配主链、旧 `PreviewPool`、`APPLY_TO_POOL`、`finalScore`、`MatchResult`。

## 产品规则（预览池）

- **Viewer**（`User.gender`，经 `normalizeUserGenderForPreview`）：
  - **male**：仅 **female** 候选人可进入 gated 集并参与 3+2+1、fallback、shadow 的 `gatedCandidates`。
  - **female**：仅 **male** 候选人。
  - **unknown / 空 / 无法识别**：`generate()` 直接 **`BadRequestException`**：`请先完善性别信息后再生成预览池。`  
    **不**归档旧池、**不**写 items、**不**跑 shadow（在 `archiveActiveOnboardingPoolsOnly` 之前就返回）。

- **Candidate**（`User.gender`）：仅当能归一为 **male** 或 **female** 时通过门闸；其它（空、`unknown`、乱码等）**丢弃**，**不补位**。

- **候选不足**：在 **异性** + 自排除 + 偏好硬门槛之后若 **&lt; 6**：沿用既有 **`BadRequestException`**；**不**放宽到未知性别、**不**用错误性别、**不**用 viewer 本人凑数。

不依照片、不用 AI、不接云 API。

## 实现文件

| 区域 | 文件 | 说明 |
|------|------|------|
| 归一化 + 门闸 | `onboarding-preview-gender.ts` | `isStrictBinaryPreviewGender`、`candidatePassesOppositeBinaryGate(viewerBinary, candidateRaw)`、`genderStorageFromBinary`（导入写库小写一致）。 |
| 预览池 | `onboarding-photo-preview-pool.service.ts` | `generate()` 在通过审美/照片检查后 **立即** 校验 viewer 性别；`collectGatedCandidates(..., viewerBinary: 'male'\|'female')` 在硬门槛后应用异性 + 二元候选过滤。 |
| 导入 plan | `p75-r4-h-candidate-image-import.plan.ts` | `PlannedImportGender = 'male'\|'female'\|'invalid'`；`parseMappingItemGender` 仅接受 male/female；**盘内未在 mapping 中出现的图片** 计为 **invalid**（无推断）。 |
| 导入服务 | `candidate-image-dev-import.service.ts` | invalid 行：**dryRun** 与 **write** 均跳过；摘要含 **`maleCandidates` / `femaleCandidates` / `invalidGenderCandidates` / `skippedInvalidGender`**。 |

## `mapping.json`

- 每项 **`gender` 必填语义**：仅 **`male`** / **`female`**（大小写不敏感）为有效。
- 缺省、`unknown`、其它字符串 → **invalid** → 导入跳过（**write** 不写 `User` / `UserImage`）；**dryRun** 计入 `invalidGenderCandidates` / `skippedInvalidGender`。
- **不**根据文件名或图片推断性别。

仓库示例：`dev-assets/test-user-images/mapping.json`（全部为 male/female）。

## 数据库字段（历史兼容）

- Prisma 中 `User.gender` 可能仍为 **`String` 且允许默认空串**：为 **历史兼容**、避免全站 migration 影响旧账号。
- **P7 onboarding preview `generate`** 在本轮在 **业务层** 将「空 / 非法」视为 **不可用**，不满足则拒绝生成。
- **建议**：在后续 **注册 / 资料完善（P7.x 或独立任务）** 中强制采集合法性别；**本轮不做** 全库纠偏 migration。
