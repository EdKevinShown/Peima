## 7. API 草案（设计级）

### 7.1 路由

```http
GET /admin/matching-observability/summary?limit=500&sinceDays=30
Authorization: Bearer <admin JWT>
```

### 7.2 响应形状（示意）

```json
{
  "sourceVersion": "p7.11-r1-matching-observability-summary-v1",
  "generatedAt": "2026-05-23T12:00:00.000Z",
  "window": { "sinceDays": 30, "since": "2026-04-23T00:00:00.000Z", "limit": 500 },
  "pairwise": { "total": 0, "byStatus": {}, "fallbackUsedRate": null, "failureDetailCodes": {} },
  "simulation": { "itemErrorCodes": {}, "schemaValidationCount": 0 },
  "finalize": { "frozenCount": 0, "wouldChangeStaticResultRate": null },
  "matchAndPool": { "matchResultsInWindow": 0, "previewPoolsInWindow": 0 }
}
```

- 字段名以实现为准，但 **必须** 与 CLI JSON 同构或文档化映射表。  
- **禁止** 返回 ID 数组、raw `meta`、prompt、transcript。

### 7.3 错误与边界

| 情况 | HTTP |
|------|------|
| 未登录 | `401` |
| 非 Admin | `403` |
| `limit` / `sinceDays` 越界 | `400`（与 CLI cap 一致） |
| DB 不可用 | `503` / `500`（Nest 惯例） |

## 8. 安全与隐私

- **只读**：单请求内 **零** `create` / `update` / `delete`。  
- **Admin-only**：复用 `assertIsAdminUserOrThrow`（或等价）。  
- **脱敏**：与 [M4.4 closure §4](../M4/M4.4-admin-observability-closure.md) 相同。  
- **日志**：API access log 可记 `adminUserId` + 参数，**不** log 完整聚合体若含敏感计数细节（按现有 admin 惯例）。  
- **产物**：`*.local.json` / `*.local.md` 继续 **gitignore**；closeout 仅提交 **脱敏** 快照。
