## 3. Runner usage

From repo root (after `pnpm --filter @peima/api run build`):

```bash
pnpm --filter @peima/api run p710:r6a:canonical-writer-shadow-audit -- --limit=20 --output=artifacts/p76/r6a/canonical-writer-shadow-audit.json
```

Optional flags:

- `--viewerUserId=<id>` — filter `MatchResult.userId`
- `--poolId=<batchId>` or `--batchId=<id>` — filter `MatchResult.batchId` (schema has `batchId`, not `poolId`)
- `--includeBlocked=false` — artifact `rows[]` only eligible; summary still counts all fetched rows
- `--pretty` — indented JSON
- `--dryRun=true` — label only (runner **always** read-only)

Requires `DATABASE_URL` (local/staging). **Read-only** Prisma (`findMany` / `findUnique` only). Writes **local JSON** under `artifacts/p76/r6a/`.

Sidecar linkage: **best-effort** `p76_allowlist_apply_meta` lookup by `@@unique([viewerUserId, sourceVersion])` where `sourceVersion` comes from `readP76ReadPathEnv()`.
