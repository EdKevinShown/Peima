# P7.2 — 照片 Onboarding 商业化收口（Closeout）

## 1. 本轮目标

- 将**照片上传**、**审美偏好选择题**、**3+2+1 onboarding 预览池**纳入真实用户主流程，与登录/问卷门禁一致。
- **不再**引导用户通过旧 **`/my-images`** 进入独立图片管理页（该路径重定向至 onboarding 上传页）。
- **不触碰**正式匹配主链（worker、旧 PreviewPool 生成、`MatchResult`、`finalScore` 等）。

## 2. 最终用户流程

```
login / register
  → /onboarding/photo-upload
  → /onboarding/photo-preference
  → /onboarding/photo-preview
  → /questionnaire
```

登录后首跳由 **`GET /onboarding/photo/status`** 的 `nextStep` 决定；直接访问 **`/questionnaire`** 时仍受 onboarding 门禁约束。

## 3. 已完成能力

| 能力 | 说明 |
|------|------|
| `GET /onboarding/photo/status` | 返回 `hasPhoto`、`hasPhotoPreference`（以 `onboardingPhotoAestheticCompletedAt` 为准，非仅 `styleTags`）、`nextStep` |
| `POST /onboarding/photo-preferences` | 保存审美标签并设置 `onboardingPhotoAestheticCompletedAt` |
| `GET /onboarding/photo-preferences/me` | 读取当前用户的 `styleTags` |
| `POST /onboarding/photo-preview-pool/generate` | 生成独立 onboarding 预览池（6 条 item），归档旧 onboarding active pool |
| `GET /onboarding/photo-preview-pool/me/latest` | 拉取当前用户最新 **active** onboarding 池；`hidden` 项不返回真实 `imageUrl` |
| `POST /onboarding/photo-preview-pool/acknowledge` | 写入 `onboardingPhotoPreviewCompletedAt`，用于问卷门禁 |
| `/my-images` | 前端路由 **`Navigate`（replace）** 至 **`/onboarding/photo-upload`**（带 `userId` 时原样附加 query） |
| 数据模型 | **`OnboardingPhotoPreviewPool`** / **`OnboardingPhotoPreviewPoolItem`**，与旧 `preview_pools` 物理隔离 |
| 3+2+1 结构 | **3** `aesthetic_fit` / `clear` · **2** `style_similar` / `blurred` · **1** `reflow` / `hidden` |

前端路由：`/onboarding/photo-upload`、`/onboarding/photo-preference`、`/onboarding/photo-preview`；首页主 CTA 与主导航与上述流程对齐。

## 4. 数据库变更

- **`User`**：`onboardingPhotoAestheticCompletedAt`、`onboardingPhotoPreviewCompletedAt`
- **新增** `OnboardingPhotoPreviewPool`（`userId`、`status`、`sourceVersion` 等）
- **新增** `OnboardingPhotoPreviewPoolItem`（`poolId`、`tier`、`displayMode`、`rankInPool`、`score`、`reasonTags` 等）
- **Migration 目录名**：`20260512120000_onboarding_photo_preview_pool_p7_2`

> 另：为修复 shadow DB 重放，可能对历史迁移 `20260423120000_profile_update_suggestions_p5_columns` 做过幂等化（`IF NOT EXISTS`）；与 P7 业务正交，部署时需按仓库实际 migration 历史执行。

## 5. 重要边界（未改动）

- 未修改 **worker** 主链
- 未修改 **`apps/worker/src/jobs/batch-match.processor.ts`**
- 未修改 **`apps/worker/src/jobs/matching-score.ts`**
- 未修改 **`MatchResult.candidateUserId`**
- 未修改 **`finalScore`**
- 未修改旧 **`PreviewPool` / `PreviewPoolItem`** 语义
- 未改旧 **`PreviewPoolService.generate`**
- **onboarding** 预览池**不写入** `preview_pools` 表

## 7. 当前限制

- 暂未做**真实人脸检测**
- 暂未做**照片清晰度检测**
- 暂未做**单人照检测**
- 暂未做**真实视觉 embedding** 相似度
- 暂未做**服务端强审核**
- 当前 **3+2+1** 仅为 **onboarding 第一印象预览**，**不**影响正式匹配 **`finalScore`**
