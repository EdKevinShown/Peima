## 4. Viewer 选择标准

### 4.1 优先纳入

| 条件 | 检查方式 |
|------|----------|
| Viewer 有 usable live vision | `photoVisualTags` / vision status（P7.5-r7） |
| Viewer 有 meaningful **20D** profile | `user_profiles` 关键维度非空 |
| Viewer 有 **user_preferences** | preference 行存在且可评分 |
| Candidate pool **≥ 6** 人 | onboarding_gated_cohort / preview 池 |
| Candidates 有 usable vision | r3b `eligible` / 非 `VISION_NOT_OK` |
| Candidates 有 20D profile + preference | r4b 无 mass `PROFILE_MISSING` |
| **Gender / preference gate 正常** | r3b 无异常 `GENDER_GATE` / `PREFERENCE_GATE` 拦截 |
| **Legacy 可对齐（加分）** | 存在 `MatchResult` 且 `userId = viewer` |

### 4.2 排除

| 条件 | 处理 |
|------|------|
| Viewer 缺 profile / preference | **不纳入** 首轮 batch |
| Candidates 全部被 gate 拦截 | 记 `blockedByGate` · 换 viewer |
| 大量缺 vision | 先 [vision backfill](./P7.5-r7-d-staging-cloud-vision-50-images-runbook.md) 或排除 |
| 大量缺 20D | 排除；避免「为跑通而 seed 整批」 |
| **需过多 dev-only seed 才能跑通** | 单独标记 `seedDependent` · 不计入 PM 统计分子（或降权） |

### 4.3 已知 signoff viewer（基线）

| `viewerUserId` | 角色 |
|----------------|------|
| `cmo7ksq8s00006znosryc9k0n` | **Batch 0 基线**（已 r3b–r6b · `legacy_mismatch`） |

后续 batch 应包含：**legacy 赢家在 P7.6 池内** 的 viewer（若存在），以区分 cohort 差异 vs 排序差异。

## 6. 每个 viewer 的执行流程

**前置：** `cd apps/api` · `pnpm exec nest build` · `DATABASE_URL` 已配置。

```text
viewer V:
  1. r3b  PhotoVisual First Pool audit
  2. 若 selectedCandidateIds 为空 → 诊断 vision / gate / styleTags（见 r3b1）
  3. r4b  20D Bidirectional Ranking audit（candidateUserIds = Stage1 输出）
  4. 若 top2CandidateIds 为空 → 诊断 profile / preference（见 r4b1）
  5. r5b  RRM Top2 Final Selector audit（top2 + selectedBy20DOnly）
  6. r6b  End-to-end old-new comparison（建议 --stage*AuditJsonPath）
  7. 填写 §7 记录表 + PM verdict
```

### 6.1 CLI 命令模板

**Stage 1 — r3b**

```powershell
pnpm run p76:r3b-photovisual-pool-shadow-audit -- `
  --viewerUserId=<V> `
  --sourcePoolType=onboarding_gated_cohort `
  --limit=12 --selectionLimit=6 `
  --dryRun=true `
  > artifacts/p76/r7b/<V>-r3b.json
```

**Stage 2 — r4b**（`candidateUserIds` 从 r3b JSON 提取）

```powershell
pnpm run p76:r4b-20d-bidirectional-ranking-shadow-audit -- `
  --viewerUserId=<V> `
  --candidateUserIds=<id1,id2,...> `
  --sourcePoolType=onboarding_gated_cohort `
  --topN=6 --dryRun=true `
  > artifacts/p76/r7b/<V>-r4b.json
```

**Stage 3 — r5b**

```powershell
pnpm run p76:r5b-rrm-top2-final-selector-shadow-audit -- `
  --viewerUserId=<V> `
  --top2CandidateIds=<t1,t2> `
  --selectedBy20DOnlyCandidateId=<20d-winner> `
  --sourcePoolType=onboarding_gated_cohort `
  --dryRun=true `
  > artifacts/p76/r7b/<V>-r5b.json
```

**Stage 4 — r6b**（推荐带 audit JSON 路径）

```powershell
pnpm run p76:r6-end-to-end-funnel-shadow-audit -- `
  --viewerUserId=<V> `
  --stage1AuditJsonPath=artifacts/p76/r7b/<V>-r3b.json `
  --stage2AuditJsonPath=artifacts/p76/r7b/<V>-r4b.json `
  --stage3AuditJsonPath=artifacts/p76/r7b/<V>-r5b.json `
  --compareLegacy=true --compareM6=true `
  --dryRun=true `
  > artifacts/p76/r7b/<V>-r6b.json
```

**所有命令必须 `--dryRun=true`。**

## 9. PM 判定标准

### 9.1 进入 r8 的**最低**条件

| # | 条件 |
|---|------|
| 1 | **≥ 3** runnable viewers（非 seed-only） |
| 2 | **P0 / P1 = 0** |
| 3 | gender / preference gate error = **0** |
| 4 | PM `better` + `acceptable` **≥ 80%**（of runnable） |
| 5 | PM `worse` = **0**，或有书面修复方案 |
| 6 | `differenceStage` **可解释**（文档化分布） |
| 7 | rollback 路径明确（shadow · `applied=false`） |
| 8 | 所有 `applied*` = **false** |

### 9.2 **推荐**进入 r8 条件

| # | 条件 |
|---|------|
| 1 | **5–10+** runnable viewers |
| 2 | PM `better` + `acceptable` **≥ 85%** |
| 3 | **P0 / P1 = 0** |
| 4 | `legacy_mismatch` 有归因（cohort vs 排序）且样本内可复现 |
| 5 | M6 差异可解释 |
| 6 | `seedDependent` viewers **≤ 20%** 或已排除在统计外 |

**满足后：** 更新 [r7 §9](./P7.6-r7-old-new-pm-audit-and-difference-review.md) 为 `PASS_TO_R8_ALLOWLIST_DESIGN` → **P7.6-r8**（仅 allowlist apply **设计**）。

## 10. BLOCK 条件

**任一**出现即 **BLOCK**（维持 `NEED_MORE_SAMPLES` 或 `BLOCK_*`）：

| # | 条件 |
|---|------|
| 1 | **P0 / P1** |
| 2 | gender gate 错误 |
| 3 | preference gate 错误 |
| 4 | Stage 1 大量错池 |
| 5 | Stage 2 Top2 系统性不合理 |
| 6 | RRM 不可解释反转（`wouldChange20DWinner` 高频且无 reason） |
| 7 | PM `worse` 占比高（例如 >20% runnable） |
| 8 | 多数样本**必须** seed 才能跑 |
| 9 | r6b comparison 字段大量缺失（legacy 全无） |
