## 4. 运行时契约（与代码一致）

### 4.1 HTTP

```http
GET /admin/matching-observability/summary?limit=500&sinceDays=30
Authorization: Bearer <JWT>
```

| Query | 默认 | 合法范围 |
|-------|------|----------|
| `limit` | `500` | `1` … `50000`（finalize meta 解析行上限） |
| `sinceDays` | `30` | `1` … `3650`（UTC 日界 `since`） |

| 响应 | 条件 |
|------|------|
| `200` + JSON 报告 | Admin 用户 + 有效 JWT |
| `401` | 未登录 |
| `403` | 不在 `PEIMA_ADMIN_USER_IDS` |
| `400` | `limit` / `sinceDays` 非法 |
| `500` `failed_to_build_matching_observability_summary` | 未预期 DB/服务错误（无连接串回显） |

### 4.2 `sourceVersion`

```text
m4.4-m1-admin-observability-summary-v1
```

CLI 与 Admin API **共用**（见 `MATCHING_OBSERVABILITY_SOURCE_VERSION`）。

### 4.3 报告段落（与 M4.4 §5 对齐）

| JSON 段 | 数据来源（Prisma） |
|---------|-------------------|
| `pairwise` | `ai_pairwise_decision_jobs` |
| `simulation` | `ai_simulation_v1_jobs` / `ai_simulation_v1_items` |
| `finalizeMeta` | `pairwise_pool_finalize_meta`（meta 仅安全字段聚合） |
| `matchAndPreview` | `match_results` / `preview_pools` + 只读 SQL 存在性计数 |
| `m42AlignmentHint` | 指向 `m4-2-batch-regression-report.mjs`（**不**在线算 M4.1 四源） |
