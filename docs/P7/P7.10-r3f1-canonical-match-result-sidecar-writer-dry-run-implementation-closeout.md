## 4. Writer behavior

- `dryRunP76CanonicalMatchResultSidecarWriter(input, writerEnv?)` maps eligible `P76CanonicalWriterDryRunPayloadV1` rows to plain `createInputLike` objects aligned with `P76CanonicalMatchResultMeta` (no Prisma types).
- `insertedCount` always `0`; `duplicateCount` always `0`; `appliedToMatchResultCount` / `appliedToFinalScoreCount` / `appliedToWorkerRankingCount` always `0`.
- Invalid rows are **skipped** (batch continues); programmer-invalid input (missing `auditRunId`, bad `environment`) **throws**.
- Privacy guard rejects forbidden keys (`rawPrompt`, `fullPrompt`, `transcript`, `imageFeatures`, `rawImage`, `rawVisionResponse`, `DATABASE_URL`, `secrets`) with `forbidden_payload_key` — no sanitize-and-write.
- Mapped rows: `mode=sidecar`, `promotionStatus=not_promoted`, all `appliedTo*=false`, `rolledBack=false`.
