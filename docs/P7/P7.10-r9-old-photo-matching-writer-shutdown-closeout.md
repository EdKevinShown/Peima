## 4. Env gate design

| Variable | Default | Purpose |
|----------|---------|---------|
| `PEIMA_P710_R9_OLD_PHOTO_MATCHING_WRITER_SHUTDOWN_ENABLED` | **`1`** | Master shutdown — blocks `MatchResult` create |
| `PEIMA_P710_R9_OLD_PHOTO_MATCHING_WRITER_ENABLED` | **`0`** | Legacy writer opt-in (dev rollback only) |
| `PEIMA_P710_R9_OLD_PHOTO_MATCHING_WRITER_ENVIRONMENT` | `dev` | Must be `dev` / `staging` / `production-like-staging` to allow writes |

**Write allowed only when:** `WRITER_ENABLED=1` **and** `SHUTDOWN_ENABLED=0` **and** non-production env **and** `PEIMA_P76_PRODUCTION_PERCENT=0` (and percent flag off).

**Emergency disable (production incident):**

```text
PEIMA_P710_R9_OLD_PHOTO_MATCHING_WRITER_SHUTDOWN_ENABLED=1
PEIMA_P710_R9_OLD_PHOTO_MATCHING_WRITER_ENABLED=0
PEIMA_P76_PRODUCTION_PERCENT=0
```

(Plus existing r8 mutation env all `0` — see [r8i signoff](./P7.10-r8i-pm-ops-apply-rollback-signoff.md).)

**Dev rollback (re-enable legacy writer writes — dev/test only):**

```text
PEIMA_P710_R9_OLD_PHOTO_MATCHING_WRITER_SHUTDOWN_ENABLED=0
PEIMA_P710_R9_OLD_PHOTO_MATCHING_WRITER_ENABLED=1
PEIMA_P710_R9_OLD_PHOTO_MATCHING_WRITER_ENVIRONMENT=dev
```

**Canonical Apply/Rollback:** separate `PEIMA_P710_R8_*` gates — unchanged by r9.
