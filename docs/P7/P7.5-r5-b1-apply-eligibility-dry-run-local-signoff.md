# P7.5-r5-b1 — APPLY_TO_POOL dry-run 本地签收

## 0. 边界与原则

- **仅文档签收**；§6 / §7 已由本机 **r5-b2 runner** 结果填毕并勾选通过。
- **不**进入 P7.5-r5-c 实现；**不**将 visual ranking **真正**写回 `OnboardingPhotoPreviewPoolItem`。

- **推荐**：五案验证使用 [§6.1](#61-使用-p75-r5-b2-runner-自动填-actual推荐) **r5-b2 runner**（单进程 env 覆盖，**无需**手工改 `.env` / 重启 API）。若走手工 §4 路径，仍须每次改 `.env` 并重启 API。

## 1. 签收目标

验证 **P7.5-r5-b** dry-run **仅**产生 `summary.applyDryRun` 等 eligibility metadata，**不改变**用户可见 onboarding photo preview pool（3+2+1）。

**须确认**

| # | 检查项 |
|---|--------|
| 1 | **Env 关**：`applyDryRun.reason === "env_disabled"`，`eligible === false` |
| 2 | **Allowlist 命中**：`eligible === true`，`reason === "ok"`，根字段 **`appliedToPool === false`**，`summary.applyToPoolIgnored === true` |
| 3 | **Percent 命中**（空 allowlist + percent=100）：`eligible === true`，`reason === "ok"`，**`appliedToPool` 仍为 false** |
| 4 | **Percent 未命中**（percent=0）：`reason === "percent_not_hit"` |
| 5 | **真实 pool**：`OnboardingPhotoPreviewPool.sourceVersion` 仍为 **`onboarding-photo-preview-v1`**；items 的 `candidateUserId` / `rankInPool` / `tier` / `displayMode` **与 v1 生成语义一致**，**未被** shadow 重排覆盖 |
| 6 | **Active audit**：无 self / gender / duplicate candidate / duplicate source image violation |

### 6.1 使用 P7.5-r5-b2 runner 自动填 actual（推荐）

新增 **dev-only** 脚本 **`p75:r5-b2-apply-dry-run-signoff`**：在 **单进程内** 对五组 apply env 做 **snapshot → 覆盖 → `generate()` → 读 DB shadow → active audit → 恢复 env**，stdout 输出 **`p7.5-r5-b2-apply-dry-run-signoff-v1`** JSON（`viewerIdMasked` / `poolIdMasked`，**无** raw `userId` / `poolId`、**无** phone / email / `reviewNote` / 完整 `detectionScoreJson` / 完整 image URL）。

**前置**

- 已 `pnpm --filter @peima/api run build`
- 根目录 `.env` 含有效 **`DATABASE_URL`**
- Shadow 可写（如 `PEIMA_ONBOARDING_VISION_SHADOW_ENABLED=1` 等，见 [P7.5-r4-e](../P7.5-r4-e-visual-ranking-shadow-sample-signoff.md)）
- 该 viewer 满足 `generate()` 门槛（审美完成、≥1 张图、偏好/关系画像、全局 ≥6 名门控候选等，与 r4-o3 一致）

**命令（仓库根，须能加载 `DATABASE_URL`）**

```bash
pnpm --filter @peima/api run p75:r5-b2-apply-dry-run-signoff -- --viewerUserId=cmp70ft7a001e6znksjb2jo03 --mappingPath=dev-assets/test-user-images/mapping.json
```

**注意**：`pnpm` script **仅** `node dist/...`，**不会**自动加载仓库根 `.env`。若未在 shell 中导出 `DATABASE_URL`，会出现 **`DATABASE_URL_missing`**，**不**视为 runner 逻辑失败。本机签收请优先使用 **dotenv-cli**（见下）。

**本机签收命令（已验证）**：在 `apps/api` 下执行：

```bash
cd C:\Users\34713\Desktop\peima\apps\api

npx dotenv-cli -e ../../.env -- node dist/dev-cli/p75-r5-b2-apply-dry-run-signoff-runner.js --viewerUserId=cmp70ft7a001e6znksjb2jo03 --mappingPath=../../dev-assets/test-user-images/mapping.json
```

**将结果填入 §6**

- 将 stdout JSON 中 `cases[]` / `summary` 与 §6 表对照即可（本机已填 §6）。
- **`summary.allPass === true` 且 exit code 0** 即五案自动化签收通过。

**说明**：每个 Case 会 **archive 旧 active pool 并生成新池**（与页面「重新生成」一致）。详见 [P7.5-r5-b2-apply-dry-run-signoff-closeout](./P7.5-r5-b2-apply-dry-run-signoff-closeout.md)。

## 7. 签收结论

**条件已满足**：§6 表格 **五案均为 PASS**；**real items changed?** 全为 **否**；根 **`appliedToPool`** 与 **`applyDryRun.appliedToPool`** **恒为 false**；**active audit** 各案均为 **true**；r5-b2 runner **`summary.allPass === true`**（见 [r5-b2 closeout](./P7.5-r5-b2-apply-dry-run-signoff-closeout.md)）。

**结论：P7.5-r5-b dry-run 本地签收通过。**

- eligibility metadata 能按 **env / allowlist / percent** 正确产生；
- **`appliedToPool` 恒为 `false`**（根与 dry-run 子字段一致）；
- 真实 **`OnboardingPhotoPreviewPoolItem` 未被 visual ranking 改写**（runner 校验 v1 `sourceVersion`、item 与 shadow baseline 一致）；
- **active audit 仍通过**（无 self / gender / duplicate candidate / duplicate source violation）。

- **签收日期**：2026-05-16（与本机 r5-b2 runner 执行记录一致；以实际执行日为准）  
- **执行方式**：`apps/api` + `dotenv-cli -e ../../.env`（见 §6.1）

若后续任 **FAIL**：在 issue / PR 中记录 Case、脱敏 `payload_json.summary` 与 audit 输出，并 **撤销** 本节「通过」表述。
