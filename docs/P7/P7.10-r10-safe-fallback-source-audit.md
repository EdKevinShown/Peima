## 1. GET `/matching/result` fallback order

Entry: `MatchingService.getLatestResultForUser` → `buildMatchResultViewerPayload` or no-row contract.

| Step | Condition | Outcome tier |
|------|-----------|--------------|
| 1 | No `MatchResult` row + contract **off** | HTTP 404 (unchanged legacy) |
| 2 | No row + contract **on** | `deriveNoRowResultState` → `matching_pending` or `no_result`; r10 enrich when r9 writer blocked |
| 3 | Row exists | `resolveMatchResultDisplay` core → P76 read overlay → projection |
| 3a | P76 sidecar eligible | **canonical_result** (`p76_allowlist_sidecar_readonly`) |
| 3b | RRM / pairwise / original | **stable_baseline** (`match_result_original`, RRM, finalize meta) |
| 3c | P76 enabled but ineligible | **stable_baseline** via `safe_fallback` + `baseline_display` |

**No step reads PreviewPool or calls batch-match worker.**

## 2. Canonical vs stable baseline

| Source | Tier | Notes |
|--------|------|-------|
| `p76_allowlist_sidecar_readonly` | canonical_result | Read-only sidecar overlay (not production Apply) |
