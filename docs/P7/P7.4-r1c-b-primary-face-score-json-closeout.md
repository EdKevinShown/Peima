# P7.4-r1c-b — primaryFace 写入 detectionScoreJson（Closeout）

> 前置：**P7.4-r1b** 人脸存在性检测 + **r1b-f1** 冷启动修复；**P7.4-r1c-a** 多人脸 warning only 策略与前端文案收口。  
> 本轮：仅增强 **`detectionScoreJson`**，不改变 **`detectionStatus`** 语义与 onboarding 门禁。

---

## 1. 本轮目标

- 在 **P7.4-r1b** 人脸存在检测基础上，为检测到的人脸计算 **`primaryFace`**。
- **只增强** `detectionScoreJson`，**不改变** `detectionStatus` 语义。
- **不改变**多人脸 **warning only** 策略（`MULTIPLE_FACES` 不进 `reasonCodes`、不 hard fail）。
- **不新增** DB 字段，**不写** migration，**不新增**依赖，**不改**前端 UI。

---

## 2. 已完成能力

- 新增 **`user-image-primary-face.ts`** 纯函数模块（主脸选择、指标计算）。
- 每张 `face.faces[]` 条目增加：
  - **`areaRatio`**
  - **`centerDistance`**
  - **`primaryScore`**
- **`faceCount === 1`**：写入 **`primaryFace`**，`index = 0`。
- **`faceCount > 1`**：写入 **`primaryFace`**，同时保留 **`warnings: ["MULTIPLE_FACES"]`**，`detectionStatus = passed`。
- **`faceCount === 0`**：不写 **`primaryFace`**，`failed` + `FACE_NOT_FOUND`。
- **`detectionRulesVersion`**：人脸管线完成时升级为 **`p7.4-r1c-v1`**。

## 4. primaryFace 计算公式

### areaRatio

```
areaRatio = (box.width × box.height) / (imageWidth × imageHeight)
```

使用**原图**尺寸（`UserImageQualityMetrics.width` / `height`），非 BlazeFace 采样分辨率。

### centerDistance

人脸框中心到图片中心的距离，除以「图中心到角点」距离，**clamp 到 `[0, 1]`**：

- **0** ≈ 人脸居中  
- **1** ≈ 人脸靠近边角  

### primaryScore

```
primaryScore = face.score × 0.5
             + areaRatio × 0.4
             + (1 - centerDistance) × 0.1
```

### 主脸选择

1. **`primaryScore` 最高**  
2. Tie-break：**`areaRatio` 更大**  
3. Tie-break：**`centerDistance` 更小**（更靠近中心）  
4. Tie-break：**`index` 更小**

## 5. detectionScoreJson 新结构

顶层字段（与 r1b 兼容扩展）：

| 字段 | 说明 |
|------|------|
| `quality` | r1a 画质摘要 |
| `face.faceCount` | 检测到的人脸数 |
| `face.faces[]` | 每张脸含 `score`、`box`、`areaRatio`、`centerDistance`、`primaryScore` |
| `face.primaryFace` | 主脸快照（含 `index`） |
| `warnings` | 如 `MULTIPLE_FACES`（非 `reasonCodes`） |
| `pipeline` | 如 `["quality","face"]` |
| `faceDetectionEnabled` | 本轮是否跑人脸 |

### 示例 JSON（双人脸 + warning）

```json
{
  "quality": {
    "meanLuma": 120,
    "laplacianVariance": 80,
    "width": 800,
    "height": 600
  },
  "face": {
    "faceCount": 2,
    "faces": [
      {
        "score": 0.5,
        "box": { "x": 0, "y": 0, "width": 40, "height": 40 },
        "areaRatio": 0.0033333333333333335,
        "centerDistance": 0.65,
        "primaryScore": 0.29
      },
      {
        "score": 0.95,
        "box": { "x": 280, "y": 180, "width": 220, "height": 240 },
        "areaRatio": 0.11,
        "centerDistance": 0.08,
        "primaryScore": 0.62
      }
    ],
    "primaryFace": {
      "index": 1,
      "score": 0.95,
      "box": { "x": 280, "y": 180, "width": 220, "height": 240 },
      "areaRatio": 0.11,
      "centerDistance": 0.08,
      "primaryScore": 0.62
    }
  },
  "warnings": ["MULTIPLE_FACES"],
  "pipeline": ["quality", "face"],
  "faceDetectionEnabled": true
}
```

单人脸时 `warnings` 为空数组或省略，`primaryFace.index === 0`。

## 6. detectionRulesVersion 策略

| 版本 | 何时写入 |
|------|----------|
| **`p7.4-r1c-v1`** | 人脸管线已执行：`passed`（含 `primaryFace`）、或 `failed` + `FACE_NOT_FOUND` |
| **`p7.4-r1a-v1`** | 仅画质检测；或 `FACE_DETECTION_ENABLED=0` 未跑人脸 |
| **`p7.4-r1b-v1`** | `skipped` 且未完成人脸 enrich（检测 load/infer 异常等） |

**`detectionStatus` 语义不变**：

| 条件 | status |
|------|--------|
| 无脸 | `failed` |
| 有脸 | `passed`（多人脸仍 warning only） |
| 检测异常 | `skipped` |
