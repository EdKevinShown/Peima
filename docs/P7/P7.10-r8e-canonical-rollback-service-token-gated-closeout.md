## 4. Rollback token gate 设计

| 项 | 说明 |
|----|------|
| 输入 | `rollbackTokenPlaintext`（仅内存比较，不落库） |
| 存储 | snapshot.`rollbackTokenHash`（HMAC-SHA256 hex） |
| Pepper | `PEIMA_P76_ROLLBACK_TOKEN_PEPPER`（未设则为空串） |
| 绑定 | `snapshotId` + `matchResultId` + `sidecarId` |
| 校验 | `verifyP76CanonicalRollbackTokenV1`（timing-safe compare） |

**禁止：** 明文 token 写入 DB · audit · 返回值 · closeout · artifacts · logs
