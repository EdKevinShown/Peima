## 4. Read Path 输入条件

未来 resolver **仅在下列条件全部满足**时，才可将 sidecar `selectedCandidateId` 用于用户可见 display（read-only overlay）：

| # | 条件 | 说明 |
|---|------|------|
| 1 | `PEIMA_P76_READ_PATH_ENABLED=1` | 总开关 · 默认 **0** |
| 2 | `PEIMA_P76_READ_PATH_DRY_RUN=0` | `1` = 仅 audit 不写 display；或未来显式 `DISPLAY_MODE=shadow` |
| 3 | `viewerUserId` ∈ allowlist | 与 Route C / env `VIEWER_IDS` 一致 |
| 4 | sidecar row **exists** | `p76_allowlist_apply_meta` 有当前 viewer + sourceVersion 行 |
| 5 | `sourceVersion` **允许** | 与 `PEIMA_P76_READ_PATH_SOURCE_VERSION` 或 cohort 默认一致 |
| 6 | `selectedCandidateId` **非空** | 字符串有效 user id |
| 7 | `productApplyStatus` = **approved**（或等价 gate） | **非** sidecar `applied=true`；须独立 **display read signoff**（r8h3 建议）· 当前 cohort 恒 `not_applied` → read path **blocked** |
| 8 | `pmSignoffStatus=approved` | 与 r8d writer signoff 对齐 |
| 9 | `opsSignoffStatus=approved` | 与 r8d writer signoff 对齐 |
| 10 | `rolledBack=false` | rollback 行禁止用于 display |
| 11 | `violationStatus=ok` | 含主链 flag · non-allowlist · stale version · artifact missing |
| 12 | `appliedToMatchResult=false` | 主链 guard |
| 13 | `appliedToFinalScore=false` | 主链 guard |
| 14 | `appliedToWorkerRanking=false` | 主链 guard |
| 15 | `appliedToDisplay=false` | 除非未来阶段**单独定义** display-applied 语义且经 signoff；r8h **默认要求 false** |
| 16 | artifact **exists** 或 sidecar 含足够 **stage summary** | `routeCArtifactPath` 可解析或 `stageSummary` 已 denormalized |
| 17 | **无 active P0/P1** | violation SQL · monitoring 无未关闭 P0 |

**语义重申（[r8f](./P7.6-r8f-admin-review-and-read-path-guard-design.md)）：**

- DB `applied=true` + `dryRun=false` → **sidecar written** · **≠** `productApplyStatus=approved`
- Admin UI 已展示 **Sidecar written** / **Not product-applied** · 用户 read path **不得**绕过该语义

## 5. Env Gate 设计

### 5.1 建议环境变量

| 变量 | 默认 | 含义 |
|------|------|------|
| `PEIMA_P76_READ_PATH_ENABLED` | `0` | 总开关 |
| `PEIMA_P76_READ_PATH_VIEWER_IDS` | `` | 逗号分隔 allowlist；空 = 无 viewer 可走 read path |
| `PEIMA_P76_READ_PATH_SOURCE_VERSION` | `p7.6-r7j3-staging-cohort-v1` | 允许的 sidecar `sourceVersion` |
| `PEIMA_P76_READ_PATH_REQUIRE_PM_SIGNOFF` | `1` | 要求 `pmSignoffStatus=approved` |
| `PEIMA_P76_READ_PATH_REQUIRE_OPS_SIGNOFF` | `1` | 要求 `opsSignoffStatus=approved` |
| `PEIMA_P76_READ_PATH_FALLBACK_LEGACY` | `1` | 任一 guard 失败 → **safe fallback to baseline display**（deprecated env name; not photo matching） |
| `PEIMA_P76_READ_PATH_STRICT_VIOLATION_BLOCK` | `1` | `violationStatus !== ok` 硬阻断 |
| `PEIMA_P76_READ_PATH_DRY_RUN` | `1` | 实现阶段默认 dry-run：记录 audit 不改返回 display |

**可选（实现阶段）：**

| 变量 | 默认 | 含义 |
|------|------|------|
| `PEIMA_P76_READ_PATH_DISPLAY_SIGNOFF_TOKEN` | `` | 与 r8h3 PM/Ops display signoff 绑定 |
| `PEIMA_P76_READ_PATH_ENV` | `dev` | `dev` \| `staging` \| `production`（production 须额外 signoff） |

### 5.2 默认行为

```text
ENABLED=0
PEIMA_P76_READ_PATH_FALLBACK_LEGACY=1   # safe fallback to baseline display
→ 100% baseline display · 用户无感知变化
```

**禁止：** 在未设 `ENABLED=1` 且未完成 r8h2 smoke + r8h3 signoff 时，在 production 默认开启 read path。

## 6. Resolver 顺序设计

未来 **display resolver**（伪代码顺序 · 实现见 r8h1）：

```text
1.  Resolve baseline display as base (`resolveMatchResultDisplay`; P7.10: not photo matching)
      → legacyDisplayCandidateUserId  *(P7.10 rename target: baselineDisplayCandidateUserId)*
      → legacyDisplaySourceType  *(P7.10 rename target: baselineDisplaySourceType)*
      → legacyFinalScore (unchanged)
      → legacyWorkerWinner (unchanged)

2.  If PEIMA_P76_READ_PATH_ENABLED != 1
      → return legacy (fallbackReason: env_disabled)

3.  If viewerUserId NOT IN allowlist
      → return legacy (fallbackReason: not_allowlisted)
      → audit nonAllowlistAttemptCount++

4.  Load p76_allowlist_apply_meta
      WHERE viewerUserId = ? AND sourceVersion = cohortVersion
      ORDER BY createdAt DESC LIMIT 1

5.  If no row
      → return legacy (fallbackReason: missing_sidecar)

6.  Derive sidecarStatus / productApplyStatus / mainChainApplyStatus / violationStatus
      (reuse p76-admin-allowlist-apply-meta.derive logic)

7.  If rolledBack == true
      → return legacy (fallbackReason: rolled_back)
      → blockedByRollbackCount++

8.  If violationStatus != ok OR STRICT_VIOLATION_BLOCK
      → return legacy (fallbackReason: violation)
      → blockedByViolationCount++

9.  If any appliedToMatchResult|FinalScore|WorkerRanking|Display == true
      → return legacy + P0 audit (fallbackReason: main_chain_flag)

10. If selectedCandidateId missing / invalid
      → return legacy (fallbackReason: missing_candidate_id)

11. If productApplyStatus != approved OR display signoff missing
      → return legacy (fallbackReason: product_not_approved)

12. If pm/ops signoff not approved (when REQUIRE_* = 1)
      → return legacy (fallbackReason: signoff_pending)

13. If artifact missing AND stage summary insufficient
      → return legacy (fallbackReason: artifact_missing)

14. Load candidate user; if missing / blocked / deleted
      → return legacy (fallbackReason: candidate_unavailable)

15. SUCCESS (read path only):
      → displayCandidateUserId = sidecar.selectedCandidateId
      → displaySourceType = p76_allowlist_sidecar_readonly
      → finalScore UNCHANGED
      → worker winner UNCHANGED
      → MatchResult UNCHANGED
      → attach auditMeta { readPath: true, sidecarId, sourceVersion, fallbackReason: null }

16. catch (any Exception)
      → return legacy (fallbackReason: exception)
      → exceptionFallbackCount++
      → MUST NOT bubble to HTTP 500 for display path
```

## 7. Display Source Type

### 7.1 建议新增 `displaySourceType`

| 值 | 含义 |
|----|------|
| `legacy` | 现有照片匹配 / M6 / RRM 路径（默认） |
| `p76_allowlist_sidecar_readonly` | 展示候选来自 P7.6 sidecar · **read path only** · **不**改 `MatchResult` · **不**改 `finalScore` · 可 fallback |

### 7.2 禁止命名

以下名称**不得**用于用户可见或内部枚举（避免与 production rollout 混淆）：

- `production_apply`
- `final_replacement`
- `worker_winner`
- `percent_rollout`
- `p76_live` / `p76_production`

### 7.3 与 `displayCandidateUserId` 的关系

| 模式 | `displayCandidateUserId` | 持久化 |
|------|--------------------------|--------|
| baseline | 现有 resolver 输出 | 不变 |
| read path success | sidecar `selectedCandidateId` | **仅响应层 overlay** · **不**写回 `MatchResult` 行 |
| fallback | legacy 值 | 不变 |

**r8h 不定义**将 read path 结果写回 DB 主链；任何持久化变更属于 **r9+** 且须独立 signoff。

## 8. Fallback 规则

### 8.1 必须 safe fallback (baseline display) 的条件

| # | 条件 | `fallbackReason`（建议） |
|---|------|--------------------------|
| 1 | env disabled | `env_disabled` |
| 2 | viewer not allowlisted | `not_allowlisted` |
| 3 | no sidecar row | `missing_sidecar` |
| 4 | `rolledBack=true` | `rolled_back` |
| 5 | `violationStatus !== ok` | `violation` |
| 6 | stale `sourceVersion` | `stale_source_version` |
| 7 | `selectedCandidateId` missing | `missing_candidate_id` |
| 8 | candidate user not found / blocked | `candidate_unavailable` |
| 9 | PM/Ops signoff not approved | `signoff_pending` |
| 10 | `productApplyStatus` not approved | `product_not_approved` |
| 11 | exception thrown | `exception` |
| 12 | non-dev/staging without production display signoff | `production_signoff_missing` |
| 13 | 任一主链 `appliedTo*` true（意外） | `main_chain_flag` |

### 8.2 Fallback 输出契约

| 字段 | 行为 |
|------|------|
| `displayCandidateUserId` | 恢复为 **legacy** 值 |
| `displaySourceType` | `legacy` |
| `finalScore` | **不变** |
| worker winner | **不变** |
| `fallbackReason` | 写入 **audit / metrics only** |
| HTTP / UI | **无**用户可见错误 · **无**「匹配失败」toast |

## 9. UI / FinalMatchPage 设计边界

**r8h 不改 UI、不改 FinalMatchPage 代码。**

未来若 **r8h2+** 接入，须遵守：

| 规则 | 说明 |
|------|------|
| 用户文案 | **不**宣传为「新正式匹配」· **不**展示「已上线」· **不**展示 P7.6 internal stage IDs |
| 普通用户 | 仅看到**正常**匹配结果（候选人与 legacy 一致或 allowlist 下由 read path 替换） |
| Debug / admin | 可选 **subtle technical badge**（仅 allowlist · dev/staging · 需 debug flag） |
| sidecar internals | **不**暴露 `stage1SelectedCandidateIds` 等给普通用户 |
| FinalMatchPage | 通过统一 **display resolver** 消费结果 · 页面**不**直接查 `p76_allowlist_apply_meta` |
