| # | Question | UI section |

| 6 | Gate 12 / Grafana / PM·Ops / incident / percent / worker 是否 blocking？ | Gate results (E) + status labels |
| 7 | 是否仍保持 **no-write** safety？ | Safety block (G) |

## 6. UI 区块

Wireframe order (top → bottom):

### A. Safety banner (sticky)

| Line | Copy (EN primary) |
|------|-------------------|
| 1 | `PREVIEW ONLY — NO MATCHRESULT WRITE` |
| 2 | Apply **blocked** until Gate 12 PASS, Grafana import, and PM/Ops signoff. |
| 3 | This page does not change user-visible matching results. |

Status chips (see §8): `Preview only` · `Promotion blocked` · `No-write verified` (when safety flags all false).

### B. Sidecar summary

From detail API `row` + apply-preview `sidecar`:

| Field | Display |
|-------|---------|
| `sidecarId` | Monospace id |
| `viewerUserId` | Admin-only (authenticated) |
| `selectedCandidateId` | Proposed candidate |
| `sourceVersion` | Cohort key |
| `mode` | e.g. `sidecar` |
| `promotionStatus` | Badge |
| `rolledBack` | Warning if true |
| `appliedToMatchResult` / `appliedToFinalScore` / `appliedToWorkerRanking` | Red if any true |

Link back: `/admin/p76/canonical-sidecar` · detail `/:id`.

### C. Current MatchResult snapshot

From apply-preview `currentMatchResult`:

| Field | Display |
|-------|---------|
| `candidateUserId` | Baseline candidate |
| `finalScore` | Formatted number |
| `reasonSummary` | Truncated text (no expand to raw JSON) |
| `updatedAt` | If exposed via future API field; else “from preview capture time” |

**No** full `matchInsights` JSON — only `hasMatchInsights` flag from preview if present.

### D. Proposed change

From apply-preview `proposedChange`:

| Flag | UI |
|------|-----|
| `candidateWouldChange` | Yes/No + arrow old → new ids |
| `scoreWouldChange` | Yes/No + delta |
| `reasonSummaryWouldChange` | Yes/No |
| `displayWouldChange` | Highlight if true |

### E. Gate results

Table: `gateResults[]` from preview + human labels.

| `blockedReason` | Label |
|-----------------|-------|
| `gate12_not_final` | Blocked by Gate 12 |
| `grafana_blocked` | Grafana pending |
| `production_write_blocked` | Production write blocked |
| `incident_active` | Incident active |
| `percent_rollout_active` | Percent rollout active |
| `worker_deploy_active` | Worker deploy active |
| `sidecar_already_promoted` | Already promoted |
| `sidecar_rolled_back` | Sidecar rolled back |
| `missing_match_result` | MatchResult missing |
| … | Map all [r7d](./P7.10-r7d-admin-apply-preview-payload-builder-closeout.md) codes |

Show `canApply` summary: green **Ready for future apply** only when true **and** ops context explicitly PASS (r7h still **no button**).

### F. Rollback preview

From apply-preview `rollbackPreview` + future snapshot API:

| Field | Display |
|-------|---------|
| `snapshotAvailable` | Yes/No |
| `rollbackTokenRequired` | Yes/No |
| `rollbackTokenPreview` | Always show **`redacted`** — never input/copy real token |
| `rollbackExpiresAt` | From snapshot when API exists; else “—” |
| `rollbackScope` | `match_result_baseline_v1` |
| `snapshotReady` (r7g) | When snapshot API wired |
| `before.baselineFingerprint` | Truncated hash + copy for ops ticket |

Sub-panel **Rollback snapshot dry-run** (when optional `GET …/rollback-snapshot-preview` exists):

- `before.candidateUserId` / `finalScore` / `matchInsightsSummary` (summary only)  
- `proposedAfter.*`  
- `blockedReasons` if `snapshotReady=false`

### G. No-write safety

Read-only checklist from preview `safety` (and snapshot `safety` when shown):

```
writesDb=false · writesMatchResult=false · writesFinalScore=false
triggersWorker=false · changesPercent=false · productionRollout=false
```

All must show ✓ in r7h review; any true → **P0 design violation** banner.

### H. Decision panel

| State | UI |
|-------|-----|
| `canApply=false` | Disabled **Apply** placeholder (grey) + “Blocked” + top `blockedReasons` |
| `canApply=true` | Still **no** enabled Apply in r7h — label: *Apply control hidden until P7.10-r8 + signoff* |
| Rollback | **Absent** — no button, no link to POST rollback |

Optional: “Copy review summary” exports redacted JSON (no tokens, no raw matchInsights).

## 11. Redaction

### Do not display

| Class | Rule |
|-------|------|
| Rollback token plaintext | Only `redacted` / `rollbackTokenPresent` boolean from detail API |
| `JWT_SECRET` / `DATABASE_URL` | Never |

| Data | Notes |
|------|-------|

| `sidecarId` / `matchResultId` | Required for tickets |
| Truncated `baselineFingerprint` | Hash only |
