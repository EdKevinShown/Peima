# P7.5-r4-n2 — Demo mapping / `demo-r4h` safe users (closeout)

## 1. 根因

映射里若 `userId` 指向 **库里已存在的用户**，且 **`phone` 不是 `demo-r4h*` 前缀**，则会命中 `non_demo_user_blocked`，**不写** gender / `UserProfile` / `UserImage`。

- **第一轮（r4-n2 初期）**：`mapping.json` 第 **7–12** 行的 `cmfemn*` / `cmfam*` id 在非 demo 用户上落库，已通过替换为 **`cmr4hf*` / `cmr4hm*`** 专用 id 解除。
- **第二轮（r4-n2 补充）**：第 **1–6** 行仍为历史 **`cmoc1…`** id；在用户环境中这些账号同样 **非 demo-r4h 手机**，`--debugBlockedRows=true` 下可见 `mappingLine1Based` 1–6 被挡。**本轮将 1–6 行同样替换为 demo 专用 `userId`**，与安全策略保持一致。

## 2. Blocked 原因与处理方式

| 阶段 | mapping 范围 | 问题 | 处理 |
|------|----------------|------|------|
| 第一轮 | items 7–12 | 非 demo 用户 | `cmfemn*` / `cmfam*` → `cmr4hf*` / `cmr4hm*`（`000716`…`001216` 段） |
| 第二轮 | items 1–6 | 非 demo 用户 | `cmoc1…*` → `cmr4hf*` / `cmr4hm*`（`010016`…`010066` 段，与 7–12 不重复） |

- **不改动** import：`isDemoR4hSeedPhone` / `non_demo_user_blocked` 规则不变。
- **排查**：`--debugBlockedRows=true` → `debug.nonDemoBlockedRows`（行号、`file`、`gender`、masked `userId`、`reasonCode`），无 phone/email。

## 3. Mapping 结构与 gender 数量（当前）

文件：`dev-assets/test-user-images/mapping.json`  

- **12 条** items：**female 6、male 6**（次序仍为 F,M,F,M,F,M,F,M,F,M,F,M）。
- 每条保留：**`file`、`userId`、`gender`、`nickname`、`styleTags`**；**性别仅来自映射字段**，不用图片/AI。
- `_devNote_r4n2`：说明 **12 条** 均应使用 **`cmr4hf*` / `cmr4hm*demo*`** 类 id，勿复用线上海量 `cmoc*` 账号。
