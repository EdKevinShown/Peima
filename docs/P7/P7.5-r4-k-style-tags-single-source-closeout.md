# P7.5-r4-k：Account 与 Onboarding 照片偏好「风格标签」单一数据源（closeout）

## 问题

- `/account` 曾展示「风格标签 / 照片风格偏好」多选（封闭词表）。
- `/onboarding/photo-preference` 有「整体气质」「照片感觉」「优先关注」三组 chip。
- 前二者与同一 **`UserPreference.styleTags`** 重叠，需在数据与编辑入口上统一，避免重复与误覆盖。

## 统一后的单一数据源

- **`UserPreference.styleTags`**（`user_preferences` 与用户一一对应，无第二套风格数组）。
- **白名单**：`ACCOUNT_STYLE_TAG_WHITELIST`（`@peima/shared/constants`）。
- **Onboarding 写入子集**：「整体气质 + 照片感觉」12 项池 `ONBOARDING_PHOTO_STYLE_TAG_POOL`（同义 `PHOTO_VISUAL_TAGS`）。

## 编辑入口（P7.5-r4-k1 产品调整）

- **唯一 UI 编辑入口**：**`/onboarding/photo-preference`**（整体气质 + 照片感觉 → `styleTags`）。
- **`/account`**：**不再展示、不编辑** `styleTags`；保存匹配偏好时 **不传** `styleTags`，依赖 **patch-like** upsert **不覆盖**已有 `styleTags`（见 r4-k1 与 `PreferencesService` 测试）。

## 哪些标签进入 `styleTags`

- **整体气质**（6）+ **照片感觉**（6）：`POST /onboarding/photo-preferences` 仅允许此池 + 白名单；并与账户侧**扩展**白名单标签（仅存在于 `ACCOUNT_STYLE_TAG_WHITELIST`、不在 onboarding 池内者）**合并**保存，见 `OnboardingService.savePhotoPreferences`。

## 哪些标签不进入 `styleTags`

- **优先关注**：`PHOTO_FOCUS_TAG_OPTIONS`；**不 POST**、不混入 `styleTags`；无 DB 新列（见 r4-k 说明）。

## Onboarding 保存逻辑（服务端）

- `OnboardingService.savePhotoPreferences`：池校验、合并、`onboardingPhotoAestheticCompletedAt`；**本轮 r4-k1 未改此逻辑**。

## Account（r4-k1）

- 已移除「照片风格偏好」标题、辅助说明及全部 `styleTags` chip。
- `PUT` 偏好 body **不含** `styleTags`。

## Onboarding 文案与 UI

- 仍分三组：**整体气质 / 照片感觉 / 优先关注**；前两组写入 `styleTags`；第三组仅本页状态。

## 修改文件（累计：r4-k + r4-k1）

- r4-k：`packages/shared/constants/p75-r4-j-account-form.ts`、`index.ts`，`apps/api/src/modules/onboarding/onboarding.service.ts`，`OnboardingPhotoPreferencePage.jsx`，相关 `onboarding.service` / `preferences` 测试等。
- r4-k1：`apps/web/src/pages/AccountPage.jsx`，`preferences.service.upsert-gate.spec.ts`（不传 `styleTags` 不覆盖），`docs/P7/P7.5-r4-k1-account-remove-style-tags-closeout.md`，本文档修订。
