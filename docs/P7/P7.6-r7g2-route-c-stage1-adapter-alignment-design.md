## 3. Root Cause

| # | 事实 |
|---|------|
| 1 | [r7g §4](./P7.6-r7g-route-c-staging-cohort-execution-runbook.md) / [r7j4](./P7.6-r7j4-route-cb-staging-cohort-execution-closeout.md) **readiness SQL** 已证明 **clean pool 存在** |
| 2 | [r3b](./P7.6-r3b-photovisual-first-pool-dev-cli-audit-closeout.md) runner 当前走 **`onboarding_gated_cohort`** 查询路径 |
| 3 | 该路径 **全库扫描** `users` + gate，**不读取** `onboarding_photo_preview_pool_items` |
| 4 | r7j4 clean pool 使用 **`sourceVersion=p7.6-r7j3-staging-cohort-v1`** · pool id `staging-p76-r7j4-pool-*` |
| 5 | 因此 r3b **native** `selectedCandidateIds` **为空**（与 pool 数据并存） |

**结论：** 问题是 **adapter / input mismatch**，**不是** 20D / RRM / r6b 算法失败；**不是** r7j4 cohort 未建好。

```text
r7j4 readiness SQL  ──►  pool items 存在  ──►  recommendedForRouteC=5
r3b native r3b      ──►  忽略 pool items ──►  selectedCandidateIds=[]
                              │
                              └──► 需要 route_c_clean_pool adapter
```

## 5. 推荐方案 — `route_c_clean_pool`

### 5.1 新增 `sourcePoolType`

```text
route_c_clean_pool
```

| 属性 | 值 |
|------|-----|
| 用途 | **仅** P7.6 Route C audit Stage1 |
| 读写 | **只读** |
| 与 production onboarding | **隔离**（audit-only） |

### 5.2 读取规则

| # | 规则 |
|---|------|
| 1 | `onboarding_photo_preview_pools.status = 'active'` |
| 2 | `onboarding_photo_preview_pools.sourceVersion = 'p7.6-r7j3-staging-cohort-v1'`（可 CLI 覆盖 · 默认此值） |
| 3 | `onboarding_photo_preview_pools.userId = viewerUserId` |
| 4 | 按 `onboarding_photo_preview_pool_items.rankInPool` **升序** 读取 `candidateUserId` |
| 5 | **排除** `candidateUserId = viewerUserId`（SELF） |
| 6 | pool id **不得** 匹配 `dev-p76-r7c5-%` / `dev-p76-r7c3-%`（与 r7g §4 `syntheticPool` 一致） |
| 7 | 对池内 candidate 做 **§7 eligibility** 校验；通过者进入 `selectedCandidateIds`（至多 `selectionLimit`） |

### 5.3 与 r7j4 对齐

| r7j4 字段 | adapter 使用 |
|-----------|--------------|
| `staging-p76-r7j4-pool-*` | `sourcePoolId` |
| 6× `candidateUserId` | `candidatePoolIds` → 过滤后 `selectedCandidateIds` |
| Cloud Vision / 20D / pref | §7 逐人验证（与 readiness 子集一致） |

## 7. Eligibility 口径

**原则：** adapter **不重新扩大池**；只校验 clean pool 中**已有** candidates。

| 检查 | 失败 reason | 动作 |
|------|-------------|------|
| `candidateUserId === viewerUserId` | `SELF` | **排除** |
| 无 passed image + usable vision JSON | `VISION_NOT_OK` / `VIEWER_VISION_MISSING`（viewer 同理） | **排除** |
| `photoVisualTags` 空 | `EMPTY_PHOTO_VISUAL_TAGS` | **排除** |
| `nonNull20DCount < 4` | `PROFILE_MISSING` | **排除** |
| 无 `user_preferences` | `PREFERENCE_MISSING` | **排除** |
| review / detection blocker | `REVIEW_BLOCKED` / `DETECTION_UNAVAILABLE` | **排除** |

**不建议**在 adapter 层重新执行**宽泛** gender/preference **全库搜索**；gender/preference gate 应在 [r7j3/r7j4](./P7.6-r7j4-route-cb-staging-cohort-execution-closeout.md) **pool 构建时**完成。

| 情况 | 处理 |
|------|------|
| pool 内 candidate 因 gate 与 native r3b 不一致 | 记 **`GATE_MISMATCH_WARNING`** · **不自动补候选** |
| 通过数 < 6 | `selectedCandidateIds` 为实际通过数 · closeout 标 **PARTIAL** · **不**从全库 pad |

**与 native r3b 差异（ intentional ）：**

| 项 | native r3b | route_c_clean_pool adapter |
|----|------------|----------------------------|
| 候选来源 | 全库 scan | **pool items only** |
| `MISSING_STYLE_TAGS` | 可拒 | **不用于 Route C**（以 vision `photoVisualTags` 为准） |
| `GENDER_GATE` / `PREFERENCE_GATE` | 扫描时硬拒 | **构建时已保证** · 仅 warning |

## 11. Route C Audit 更新方式

[r7g](./P7.6-r7g-route-c-staging-cohort-execution-runbook.md) 执行流更新为：

```text
FOR each viewer IN recommendedForRouteC (5):
  1. Stage1 — route_c_clean_pool adapter
       → artifacts/p76/r7g/<V>/r7g2-stage1.json
  2. Stage2 — r4b (--candidateUserIds from stage1)
       → r4b.json
  3. Stage3 — r5b (--top2 from r4b)
       → r5b.json
  4. Stage4 — r6b (stage JSON paths; compareLegacy/M6)
       → r6b.json
  5. PM evidence row
```

| 阶段 | 输入 | 产物 |
|------|------|------|
| **Stage1** | `route_c_clean_pool` adapter | `r7g2-stage1.json` |
| **Stage2** | `selectedCandidateIds` | `r4b.json` |
| **Stage3** | r4b top2 | `r5b.json` |
| **Stage4** | r7g2-stage1 + r4b + r5b paths | `r6b.json` |

**native r3b 产物：** 可保留作对照（`r3b-native-empty.json`），closeout 须注明 **native blocked · adapter used**。

**r6b stage1 路径：** 优先 `r7g2-stage1.json`；[r6b](./P7.6-r6b-end-to-end-funnel-shadow-live-audit-closeout.md) 解析器须接受 `schemaVersion=p7.6-r7g2-route-c-stage1-adapter-v1` 或 adapter 输出 **r3b-compatible shim**（r7g3 二选一 · 推荐 shim 以降低 r6b 改动）。
