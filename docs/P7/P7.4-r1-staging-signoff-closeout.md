## 3. 发现的问题

| 严重度 | 问题 | 处理 |
|--------|------|------|
| 低 | 手测种子图 `imageUrl` 为占位 URL，上传页缩略图显示「图片暂时无法显示」 | 不影响 gate / banner / redirect；可用真实 upload 图复测展示 |
| 低 | `pnpm --filter @peima/api run build` 在 **API dev 进程占用** 时出现 Prisma `EPERM` rename | 停 `pnpm dev:api` 后重跑即可；与业务逻辑无关 |
| 信息 | Admin 页面对无权限用户 **仍渲染筛选器**，列表区显示 permission denied | 符合现状；可选后续加路由级 guard（**非本轮回修**） |

**无 P0/P1 业务逻辑缺陷。**
