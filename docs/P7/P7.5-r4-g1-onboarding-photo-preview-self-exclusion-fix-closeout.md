# P7.5-r4-g1 — Onboarding photo preview pool self-exclusion fix (closeout)

## 1. 现象

在 `/onboarding/photo-preview` 中，“符合你审美的人”等区域出现 **当前 viewer 本人** 的照片；`imageUrl` 指向 viewer 自己的 `UserImage`。

## 2. 根因（归类）

产品在 `collectGatedCandidates` 已通过 Prisma `id: { not: viewerId }` 排除 viewer，但在以下情形下仍可能发生 **自检漏网**：

- ORM / 数据源异常或绕过 where 的假数据混入 `findMany` 结果；
- 历史或脏数据：`OnboardingPhotoPreviewPoolItem.candidateUserId === pool.userId`；
- `toViewerBundle` 仅以 `candidateUserId` 查 `UserImage`，若条目误指向 viewer，会把 **本人的首图 URL** 填进候选卡片。

本会话采用 **纵深防御**：生成路径再次过滤、gated 洗牌与写库前列校验、`toViewerBundle` 永远不解析 viewer 自己的图片 URL。

## 3. 修复点（摘要）

文件：`apps/api/src/modules/onboarding/onboarding-photo-preview-pool.service.ts`

1. **`isEligiblePreviewCandidate` / `buildSixNonSelfPreviewSlots`**（导出供单测）：在 **aesthetic_fit / style_similar / reflow** 全路径上仅从 `candidateUserId !== viewerUserId` 的池中取数；写入前逐项校验；
2. **`collectGatedCandidates`**：`push` 前 `continue` 若 `row.id === viewerId`；
3. **`generate`**：`gAll = gRaw.filter(isEligible)`；slots 仅用 `buildSixNonSelfPreviewSlots`；
4. **Shadow 输入**：`gatedCandidates` 再 `filter(isEligible)`；`baselineItems` 来自已落库的 items（无排序逻辑改动）；
5. **`computeShadow`** 调用：`Promise.resolve(...).catch(...)`，避免测试中 mock 未返回 Promise 时误崩；
6. **`toViewerBundle`**：`candidateIds` 排除 `candidateUserId === pool.userId`；`imageUrl` 仅用 `isEligiblePreviewCandidate` 为 true 的候选；Prisma `findMany` 结果容错 `Array.isArray`。

## 4. Self-exclusion 规则

- **生成**：任一 slot 的 `candidateUserId` 必须 **`!== viewerUserId`**，且不得在 `used` 集合中重复混入 viewer；
- **读**：`toViewerBundle` 不为 `candidateUserId === pool.userId` 的条目绑定 viewer 相册 URL；
- **可用性**：不改变“必须恰好 6 个 **他人** ”的产品口径（见下）。

## 5. 候选不足时行为（当前产品口径）

- **仍要求恰好 6 位互不相同的其他用户**。  
- **禁止**用 viewer 自己补缺；若 gated 池中有效他人 `< 6`，继续抛出原有 `BadRequestException`（“至少需要 6 位…” / “暂时无法分配…”），与上线契约一致。
- **无**降级为少于 6 条的池。

## 6. 测试

`apps/api/test/onboarding-photo-preview-pool.service.spec.ts`：

- polluted `findMany` 含 viewer id → create 条目仍无 viewer；
- 仅 viewer 一条候选宇宙 → `<6` 错误且不 `create`；
- `toViewerBundle` 遗留脏条目 `candidate === pool.owner` → 不返回 viewer `imageUrl`；
- helper：`buildSixNonSelfPreviewSlots` 跨三组 tier 不出现 viewer；
- 原有用例增补：`candidateUserId` 透传校验、shadow baseline / gatedCandidates 不含 viewer。
