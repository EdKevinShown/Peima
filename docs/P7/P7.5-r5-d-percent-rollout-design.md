## 6. Env 设计

延续现有四变量（名称以实现为准；与 [c4 §4](./P7.5-r5-c4-allowlist-apply-closeout-and-runbook.md) 一致）：

```env
PEIMA_ONBOARDING_VISION_APPLY_TO_POOL=1
PEIMA_ONBOARDING_VISION_APPLY_ALLOWLIST_USER_IDS=
PEIMA_ONBOARDING_VISION_APPLY_PERCENT=1
PEIMA_ONBOARDING_VISION_APPLY_SOURCE_VERSION=onboarding-photo-preview-v2-vision
PEIMA_ONBOARDING_VISION_SHADOW_ENABLED=1
```

### 6.1 设计规则（**实现后** 目标语义；**当前代码未实现**）

| 规则 | 说明 |
|------|------|
| 总闸 | `APPLY_TO_POOL` **仅**字符串 `"1"` 为开（`"true"` **不算**） |
| Allowlist 优先 | **allowlist 命中** → 进入 eligibility / guard；通过则 **v2**（与 c4 一致） |
| Allowlist 空 | **仅当** `ALLOWLIST_USER_IDS` **为空**（或等价 trim 后空）时，**percent** 才可决定非名单用户 |
| Allowlist 非空 + miss | viewer **不在** 非空 allowlist → **不 apply**（**即使** percent 命中） |
| Percent 范围 | **0–100** 整数；`percent=0` **等价关闭** percent 分支 |
| Percent=100 | **不允许** 直接用于 **生产**；须 **单独评审** 与签收 |
| 稳定 hash | `hash(viewerUserId)` 稳定；**同一 viewer** 在 **同一 percent** 下结果 **稳定** |
| 关闸 | `APPLY_TO_POOL=0` 或 percent=0（且 allowlist 空 / miss）→ 新 `generate()` **v1** |
| 生效 | 修改 env 后 **必须** restart API / redeploy |

### 6.2 与 r5-c（当前）差异对照

| 场景 | **r5-c 当前** | **r5-d 实现后（设计）** |
|------|---------------|-------------------------|
| allowlist hit | v2（若 guard ok） | **同左** |
| allowlist 非空 + miss | v1 · `not_in_allowlist` | **同左** |
| allowlist 空 + percent hit | v1 · `allowlist_empty` | **v2**（若 guard ok）· 新 reason 如 `percent_hit` |
| allowlist 空 + percent miss | v1 · `allowlist_empty` | v1 · 新 reason 如 `percent_miss` |
| env off | v1 · `env_disabled` | **同左** |

> **锁定**：在 **r5-d1 实现评审** 通过前，生产与 staging **仍执行 r5-c 左列**；不得仅改 env 期望右列生效。

### 6.3 推荐配置示例（**仅设计参考，禁止在未评审前用于生产**）

**D0 / 基线（与 c4 一致）**

```env
PEIMA_ONBOARDING_VISION_APPLY_TO_POOL=0
PEIMA_ONBOARDING_VISION_APPLY_ALLOWLIST_USER_IDS=
PEIMA_ONBOARDING_VISION_APPLY_PERCENT=0
```

**D1 staging percent 1%（allowlist 空，仅 staging）**

```env
PEIMA_ONBOARDING_VISION_APPLY_TO_POOL=1
PEIMA_ONBOARDING_VISION_APPLY_ALLOWLIST_USER_IDS=
PEIMA_ONBOARDING_VISION_APPLY_PERCENT=1
```

**受控生产：allowlist + percent 并存（allowlist 仍优先；percent 仅补空名单场景）**

```env
PEIMA_ONBOARDING_VISION_APPLY_TO_POOL=1
PEIMA_ONBOARDING_VISION_APPLY_ALLOWLIST_USER_IDS=<ops-approved cuids>
PEIMA_ONBOARDING_VISION_APPLY_PERCENT=0
```

生产 **小流量 percent** 时建议：**先清空或缩小 allowlist 仅用于 percent 轨道**，或 **保持 allowlist 非空且 percent=0** 直至 Ops 明确「空 allowlist + 低 percent」策略；**禁止** 未评审的「非空 allowlist + 高 percent」组合。

## 7. 灰度阶段

建议分阶段；**每阶段必须有停顿观察窗口**、**可回滚**、**不允许从 0 直接到 100**。

| 阶段 | percent | 范围 | 前置 |
|------|---------|------|------|
| **D0** | **0%** | 设计完成（**本文档**） | **不上线**；代码仍 allowlist-only |
| **D1** | **1%** | **staging only** | §5 门槛 + PM **50** pools 签收（staging） |
| **D2** | **1%** | **production limited** | D1 PASS + Ops **书面审批** |
| **D3** | **5%** | **production limited** | D2 运行 **24–48h** · **0** P0/P1 · audit 0 violation |
| **D4** | **10%** | **production limited** | D3 指标稳定（apply rate、error rate、投诉） |
| **D5** | **25%** | later | **单独评审**；不在 r5-d 默认批准 |

**阶段纪律**

- 阶段间 **至少 24h** 观察（D3→D4 建议 **48h**）。
- 任一 **P0/P1** 或 active audit violation → **立即回滚** 至上一阶段或 D0。
- **D2+** 每次升档须重复 §5.3 PM 抽样（可不重复 50 池全量，但须 **增量 ≥ 20** v2 pools）。

## 8. Apply decision 规则变化

### 8.1 当前 r5-c（已实现，不变）

```
env off                    → 不 apply（v1）
allowlist 空               → 不 apply（v1 · allowlist_empty）  // percent 不读
allowlist 非空 + miss      → 不 apply（v1 · not_in_allowlist）
allowlist hit + guard fail → 不 apply（v1 · 各 guard reason）
allowlist hit + guard ok   → apply（v2 · ok）
```

### 8.2 r5-d 后续实现才允许（设计口径）

```
env off                         → 不 apply
allowlist hit + guard ok        → apply（v2）
allowlist 非空 + miss           → 不 apply（percent 不覆盖名单外）
allowlist 空 + percent hit + guard ok   → apply（v2）
allowlist 空 + percent miss     → 不 apply（v1）
guard fail（任一路径）          → 不 apply（v1）
```

**判定顺序（建议实现）**

1. 总闸 `APPLY_TO_POOL !== "1"` → stop  
2. Parse allowlist → 若 **非空** 且 viewer **∈** list → eligibility / guard → apply or fallback  
3. 若 **非空** 且 viewer **∉** list → stop（`not_in_allowlist`）  
4. 若 allowlist **空** → `hash(viewerUserId) % 100 < PERCENT` → hit 则 eligibility / guard → apply or fallback；miss → `percent_miss`  
5. 所有 fallback 写 **v1** 与既有 `sourceVersion` 语义一致  

**本文档**：**只设计**，**不改** `onboarding-vision-apply-writer-decision.ts` 逻辑。

## 9. 监控指标

percent 灰度期（**实现后**）必须可统计、可告警、**不输出 PII**（viewer id 脱敏或聚合）。

### 9.1 核心指标

| 指标 | 说明 |
|------|------|
| `generated_pools_total` | `generate()` 成功创建 pool 次数 |
| `v1_count` / `v2_count` | 按 `OnboardingPhotoPreviewPool.sourceVersion` 分桶 |
| `apply_rate` | v2 / total（时间窗内） |
| `percent_hit_count` | allowlist 空且 hash 命中次数 |
| `fallback_to_v1_count` | 决策链最终 v1 次数 |
| `apply_result_reason_distribution` | `summary.applyResult.reason` 直方图（`ok` / `percent_hit` / `percent_miss` / `not_in_allowlist` / `allowlist_empty` / guard reasons / `env_disabled` 等） |
| `active_audit_violation_count` | duplicate candidate / duplicate source image / gender / self |
| `generate_error_rate` | generate 失败 / 总尝试 |
| `regenerate_success_rate` | 用户「重新生成」成功比例 |
| `pm_user_complaint_count` | 工单或定性标签（若有） |
| `rollback_executed_count` | 关闸操作次数（运维记录） |

### 9.2 与 r4-c shadow 指标对齐（持续）

- `shadowCoverageRate`、`validShadowRows`、`viewerVisionAvailableRate`
- `avgChangedSlots`、`changedSlots=6` 占比
- 各 tier `tierChangeRate`（reflow / aesthetic_fit / style_similar）

### 9.3 告警建议（实现阶段）

| 条件 | 动作 |
|------|------|
| 任一 active audit violation > 0 | **停止升档** + 排查 |
| `apply_rate` 偏离预期 percent **> 2×**（配置错误） | 告警 Ops |
| `generate_error_rate` 较基线 **> 2×** | 考虑回滚 |
| P0/P1 投诉 **≥ 1** | **立即回滚** D2+ |

## 13. 风险与缓解

| 风险 | 说明 | 缓解 |
|------|------|------|
| 低质量图片上浮 | 非 allowlist 用户进入 v2 后观感下降 | 小比例；§5.2 阈值；PM 50 pools；active audit |
| `sourceImageKey` 多样性不足 | 候选池受限 | [c2a](./P7.5-r5-c2a-shadow-source-image-dedup-fix-closeout.md) 已修 shadow；持续 audit duplicate image |
| 排序突变 | 用户感知「人选换了」 | 低 percent；`avgChangedSlots` 监控；保留 `sourceVersion` 可解释 |
| 性别资料与照片不一致 | DB gender 门控 vs 视觉观感 | **不**用 AI 判性别；PM P2/P3 记录；门控仍以 DB 为准 |
| percent 配置误开 | 环境变量错误 | 默认 0；D0→D1 分阶段；配置审计；`apply_rate` 告警 |
| 监控不足 | 升档后才发现 violation | §9 指标 + §10 CLI；升档前 **停顿窗口** |
| 生产回滚不及时 | 投诉或 audit 失败 | [c4 runbook](./P7.5-r5-c4-allowlist-apply-closeout-and-runbook.md)；Ops on-call；**不改主匹配链** |
