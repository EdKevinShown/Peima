## 3. 当前链路 vs 目标链路

### 3.1 当前（repo 事实 · 2026-05）

```text
Legacy PreviewPool / batch-match → MatchResult (candidateUserId, finalScore, matchInsights)

P7.6 shadow / sidecar (p76_allowlist_apply_meta) → read path overlay displayCandidateUserId
  (applyP76ReadPathDisplayOverlay in matching-result-display.ts — does NOT write MatchResult)

safe fallback → stable baseline (match_result_original / static_fallback) / matching_pending / no_result
  (matching-result-state.ts — NOT legacy photo matching)
```

| 组件 | 路径（搜索命中） | 写 `MatchResult`? |
|------|------------------|:---:|
| Legacy worker | `apps/worker/src/jobs/batch-match.processor.ts` L192 `previewPool.findFirst` | **Yes** |
| Style score | `apps/worker/src/jobs/matching-score.ts` `computeStyleScore` · `computeFinalScoreV1` | **Yes** (via worker) |
| Read overlay | `apps/api/src/modules/matching/p76-read-path-display-resolver.ts` | **No** |
| Display fusion | `apps/api/src/modules/matching/matching-result-display.ts` `resolveMatchResultDisplay` | **No** |
| Shadow / rehearsal | `p76-*-shadow*.ts` · `p76-canonical-writer-rehearsal-writer.ts` | **No** (`appliedToMatchResult: false`) |
| Allowlist apply writer | `p76-allowlist-apply-writer.ts`（r1） | **No** (forbidden) |

### 3.2 目标（full program）

```text
P7.6 canonical writer → MatchResult (+ matchInsights provenance)

P7.6 matchInsights → canonical evidence (stage1 / stage2 / stage3 / safeFallbackMeta)

GET /matching/result → 直接读 P7.6 canonical result（display 由 canonical 推导，非旧 overlay-only）

safe fallback → last stable P7.6 result / matching_pending / no_result

旧 photo matching writer → disabled (r4+) / removed (r6+)
```

| 过渡规则 | 行为 |
|----------|------|
| Canonical success | GET 读 P7.6 canonical `MatchResult` |
| Canonical missing | `matching_pending` 或 `no_result` |
| Canonical failed | Last stable P7.6 → else pending → else no_result |
| **禁止** | Fallback 到 PreviewPool / `computeStyleScore` / 旧照片池再生 |

## 4. Canonical writer 写入范围

### 4.1 `MatchResult`（Prisma `match_results` — 现有列）

| Field | Canonical writer | Notes |
|-------|:---:|-------|
| `userId` | Yes | Viewer |
| `candidateUserId` | Yes | P7.6 `selectedCandidateId` |
| `finalScore` | Yes | P7.6 score（**非** photo style score 语义）；可用 `scoreVersion` 区分 |
| `reasonSummary` | Yes | P7.6 决策摘要 |
| `matchInsights` | Yes | 含 `p76CanonicalWriterMeta`（§8） |
| `batchId` | Yes | 对齐现有 batch 语义 |
| `status` | Yes | 现有约定 |
| `createdAt` / `updatedAt` | Yes | 审计 |
| `sourceType` / `sourceVersion`（表列） | **No in r3** | 首期写入 `matchInsights` JSON；列扩展后续 |

**不建议**单独写 `displayCandidateUserId` 列 — schema **无**此列（搜索 `schema.prisma` `MatchResult` 模型）；display 由 read path 从 canonical `candidateUserId` + provenance **推导**。

### 4.2 `matchInsights`（canonical evidence）

| Block | Content |
|-------|---------|
| `p76CanonicalWriterMeta` | schemaVersion · sourceType · sourceVersion · mode · guardrails |
| Stage summaries | stage1 PhotoVisual · stage2 20D · stage3 RRM |
| `finalSelectedCandidateId` | 与 `candidateUserId` 一致 |
| `safeFallbackMeta` | policyVersion · reason · eligibility |
| Audit flags | eligible · violation · rolledBack · signoffs |
| `sourceVersion` / `schemaVersion` | Cohort freeze |

**迁移期：** 保留 worker 已写入的 JSON keys，直至 [r6 legacy removal](./P7.10-r1-legacy-photo-matching-dependency-audit-and-replacement-strategy.md) 门禁通过。

### 4.3 Display

| Item | Design |
|------|--------|
| `displayCandidateUserId` | **Derived** — 不直接写 DB 列 |
| `displaySourceType` | 来自 canonical provenance；**禁止** `production_apply` / `percent_rollout`（`p76-read-path-display-resolver.ts` `FORBIDDEN_DISPLAY_SOURCE_NAMES`） |
| Read overlay | 全量 canonical 后，overlay 可退化为 provenance 标注或只读审计 |

## 8. Writer output contract

**设计 payload（JSON 形态建议）：**

```json
{
  "schemaVersion": 1,
  "sourceType": "p76_canonical_writer",
  "sourceVersion": "p7.10-r3-canonical-writer-v1",
  "mode": "dry_run",
  "viewerUserId": "<viewer>",
  "selectedCandidateId": "<candidate>",
  "score": null,
  "reasonSummary": null,
  "stageSummary": {},
  "safeFallbackMeta": {},
  "appliedToMatchResult": false,
  "appliedToFinalScore": false,
  "appliedToWorkerRanking": false,
  "createdAt": "2026-05-19T00:00:00.000Z"
}
```

| `mode` | `appliedToMatchResult` | Persistence |
|--------|:---:|-------------|
| `dry_run` | **false** | Artifact / log only |
| `sidecar` | **false** | `p76_canonical_match_result_meta`（未来）或 rehearsal |
| `canonical` | **true** | `MatchResult` — **仅** signoff + [r7](./P7.10-r7-canonical-write-readiness-design.md) gates 通过后 |

**规则：**

- `dry_run`: `appliedToMatchResult=false`
- `sidecar`: `appliedToMatchResult=false`
- `canonical`: `appliedToMatchResult=true` only after later signoff
- **worker ranking 不在 r3 改**

**对齐现有 shadow（已实现 · 非 production writer）：** `p76-canonical-writer-shadow.types.ts` — `appliedToMatchResult: false` invariant；`p76-canonical-writer-shadow-builder.ts` asserts never `true`.

## 9. Safe fallback behavior after canonical writer

与 [P7.10-r2 §6](./P7.10-r2-legacy-terminology-replacement-and-safe-fallback-plan.md) 一致，canonical 落地后：

| Priority | Situation | GET / display |
|:---:|-----------|---------------|
| 1 | P7.6 canonical `MatchResult` exists + eligible | Read canonical (`resultState=ready`) |
| 2 | P7.6 approved sidecar allowed (过渡) | Sidecar overlay — 现有 read path |
| 3 | Last stable P7.6 / safe baseline | `safe_fallback` |
| 4 | Queued / not run | `matching_pending` |
| 5 | No row | `no_result` |

**P7.6 canonical success：** GET 读 canonical `MatchResult`。

**P7.6 canonical missing：** `matching_pending` 或 `no_result`（`matching-result-state.ts` 已定义类型）。

**P7.6 canonical failed：** last stable P7.6 → else `matching_pending` → else `no_result`。

**明确禁止：**

- fallback 到旧照片匹配 writer / PreviewPool / `computeStyleScore`
- 重新生成旧 photo matching result
- 产品文案称 safe fallback 为「旧照片匹配兜底」

**相关契约（已存在文档）：** [P7.10-r4 safe fallback API contract](./P7.10-r4-safe-fallback-api-contract.md) · [r4a](./P7.10-r4a-result-state-api-minimal-implementation-closeout.md).
