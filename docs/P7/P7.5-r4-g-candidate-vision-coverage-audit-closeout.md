# P7.5-r4-g — Candidate vision coverage audit (closeout)

## 1. 本轮目标

提供 **只读** 审计 CLI，从最近的 `OnboardingPhotoPreviewPool` + `items` 出发，汇总 **viewer / candidate** 用户在 `UserImage` 上的 **`detectionScoreJson.vision`（usable）** 缺口，解释为何 `visualRankingShadow` 审计中 `avgCandidatesWithVision` / `viewerVisionAvailableRate` 仍为 0。

**不**写入 DB、不改 pool、不改 3+2+1、不接云 API。

## 2. CLI 命令

**实现**：`apps/api/src/dev-cli/p75-r4-g-candidate-vision-coverage-audit-runner.ts`  
**pnpm**（需 `DATABASE_URL`）：

```text
pnpm --filter @peima/api run p75:r4-candidate-vision-audit -- --limit=100
```

**推荐（shell 无 DATABASE_URL）**：

```text
cd apps/api
npx dotenv-cli -e ../../.env -- node dist/dev-cli/p75-r4-g-candidate-vision-coverage-audit-runner.js --limit=100
```

**参数**：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--limit` | `100` | 最多扫描的 **pool** 数（按 `createdAt` desc） |
| `--userId` | — | 仅该 viewer 的 pools |
| `--poolId` | — | 单一 pool |
| `--since` / `--until` | — | `yyyy-mm-dd`（UTC），过滤 pool `createdAt` |
| `--includeArchived` | `false` | `false` 时仅 `status=active` |
| `--debugIds` | `false` | `true` 时输出最多 20 条 `debugCandidateUserIdsSample` |

默认 **不输出** candidate 明细 ID。

## 3. 审计对象

- **Pools**：满足过滤条件的 `OnboardingPhotoPreviewPool`，含 `items.candidateUserId`。
- **Viewer**：每个 pool 的 `userId`，去重后聚合其全部 `UserImage`。
- **Candidate**：所有 item 的 `candidateUserId` 去重，各自聚合 `UserImage`。

**纯函数模块**：`apps/api/src/modules/onboarding/vision/p75-r4-g-candidate-vision-coverage-audit.ts`（聚合、分类、推荐 heuristic）。

## 4. Usable vision 判断

与 shadow 路径一致，复用 **`extractUsableVisionFromDetectionScoreJson`** 等价条件（由 `firstUsableVisionByUserId` / `pickViewerPassingPhotoVision` 间接校验）：

- `detectionScoreJson` 可解析为 object
- 存在 `vision`，且 `visionStatus === "ok"`
- `photoVisualTags` 非空
- `reviewStatus` 不在 `rejected` / `needs_reupload` / `appealed` / `appeal_rejected`
- **不读** `reviewNote`

**Candidate 主因分类（互斥优先级）**：`usable_ok` → `missing_user_image` → `missing_detection_score_json` → `vision_skipped_present` → `blocked_review_present` → `missing_usable_vision`。

## 5. 输出指标

- **summary**：`poolsScanned`、`poolItemsScanned`、`uniqueCandidateUsers`、`viewerVisionAvailableRate`、`candidateUsableVisionRate`、`candidateDetectionCoverageRate`、`candidateImageCoverageRate`
- **viewerAggregate**：viewer 维度是否有图、hard gate passing、是否存在 detection JSON、`vision` 键、`usable`（经由 passing photo 选择与 shadow 对齐）、是否存在 vision blocking review
- **breakdown**：按上述互斥 bucket 计数
- **recommendation**：根据最大缺口桶给出下一步建议枚举

 stdout **不包含** `imageUrl`、`phone`、`email`、`reviewNote`、原始 `detectionScoreJson` 全文；运行时 `assertR4GVisionCoverageReportPrivacySafe` 断言 JSON 字符串。

## 7. 推荐下一步（映射用户判断表）

| 观测 | 建议 |
|------|------|
| `candidatesMissingUserImage` 高 | 测试数据补候选人上传 |
