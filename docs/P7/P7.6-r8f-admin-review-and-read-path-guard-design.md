## 3. 语义澄清

[r8e](./P7.6-r8e-allowlist-sidecar-live-closeout.md) 已暴露 **双轨 `applied` 语义**。后续 admin / read path **必须**显式区分，**禁止**把 sidecar 行 `applied=true` 展示为「已上线 / 已 production apply」。

### 3.1 三层语义

| 概念 | 含义 | r8e 当前值 |
|------|------|------------|
| **sidecarWritten** | `p76_allowlist_apply_meta` 行已写入审计元数据 | **5/5** 曾写入（1 行已 rollback） |
| **productApplied** | 真实产品路径（pool / display / 用户可见匹配）使用了 P7.6 结果 | **false**（全 cohort） |
| **mainChainApplied** | `appliedToMatchResult` / `appliedToFinalScore` / `appliedToWorkerRanking` / `appliedToDisplay` 任一为 true | **false**（全行） |

### 3.2 字段映射（DB → Admin 展示）

| DB / writer 字段 | Admin 语义 | 说明 |
|------------------|------------|------|
| `applied=true` + `dryRun=false` + `rolledBack=false` | `sidecarStatus: written` | sidecar 元数据已落库 · **≠** product apply |
| `dryRun=true` 或未写行 | `sidecarStatus: dry_run` | 仅 dry-run / 未写 sidecar |
| `rolledBack=true` | `sidecarStatus: rolled_back` | 已回滚 · read path **必须 ignore** |
| writer `result.applied` | `productApplyStatus: not_applied` | pipeline 级 · 始终 not_applied（直至未来 r9+ 单独 gate） |
| `appliedToMatchResult` 等 | `mainChainApplyStatus: none` | 全 false 时为 `none`；任一为 true → **P0** |

### 3.3 Admin UI 推荐枚举（避免裸 `applied` 文案）

```text
sidecarStatus:        written | dry_run | rolled_back
productApplyStatus:   not_applied | pending_signoff | applied   # 当前仅 not_applied
mainChainApplyStatus: none | partial | full                     # 当前仅 none
```

**禁止 UI 文案：**「已 Apply」「已上线」「已切换展示」—— 仅当 `productApplyStatus=applied` **且** 独立 r9 signoff 后才允许（本轮不存在）。

## 6. Read Path Guard 设计

**r8f 不接 read path** — 仅定义未来 guard（实现归属 **r8h** 或 **r9** 前独立设计）。

### 6.1 未来读取 sidecar 的前置条件（全部满足）

| # | Guard |
|---|--------|
| 1 | 独立文档：**r8h** read path / display resolver design **PASS** |
| 2 | 独立 PM/Ops signoff（**非** r8d · **非** r8e） |
| 3 | `PEIMA_P76_*` env gated · allowlist only |
| 4 | `productApplyStatus = applied`（未来字段 / 签核 · 当前不存在） |
| 5 | `violationStatus = ok` |
| 6 | `sidecarStatus = written` **且** `rolledBack = false` |
| 7 | `viewerUserId` ∈ allowlist |
| 8 | safe fallback (baseline display) 路径仍可用 |
| 9 | 异常 **不 bubble** 到用户请求 · 失败 → legacy |
| 10 | **不影响** `finalScore` · **不影响** worker ranking |

### 6.2 读取优先级（建议）

```text
if rolledBack or violation or not allowlist:
  → baseline display / MatchResult path only
else if productApplyStatus != applied:
  → legacy only (sidecar admin-visible only)
else if r8h guards pass:
  → optional P7.6-informed display (future)
```

## 8. Violation / Monitoring Guard

### 8.1 Admin 必须可见的指标

| 指标 | SQL / 来源 |
|------|------------|
| `violation_count` | `tmp/p76-r8c-violation-queries.sql` |
| `appliedToMatchResult=true` 行 | 同上 |
| `appliedToFinalScore=true` 行 | 同上 |
| `appliedToWorkerRanking=true` 行 | 同上 |
| `appliedToDisplay=true` 行 | 同上 |
| non-allowlist 行 | `viewerUserId NOT IN (Route C 5)` |
| `rolledBack=true` 行 | sidecar 表 |
| stale `sourceVersion` | 与当前 cohort 版本不一致 |
| artifact missing | `routeCArtifactPath` 指向文件不存在 |

### 8.2 红线（P0）

| # | 条件 |
|---|------|
| 1 | 任一主链 `appliedTo*` = true |
| 2 | non-allowlist viewer 出现在 display / product path |
| 3 | production percent 启用而无 r9 signoff |
| 4 | Admin 操作导致 `MatchResult` / `finalScore` / worker 变更 |

### 8.3 `violationStatus` 派生（建议）

| 状态 | 条件 |
|------|------|
| `ok` | violation_count=0 · 主链 flags 全 false · allowlist 内 |
| `p0_main_chain` | 任一 `appliedToMatchResult/FinalScore/WorkerRanking/Display=true` |
| `p0_non_allowlist` | allowlist 外行且 `applied=true` |
| `warn_rolled_back` | `rolledBack=true`（信息性 · 非 P0） |
| `warn_stale_version` | `sourceVersion` 与当前 cohort 不一致 |

## 9. Rollback Guard

| 条件 | 行为 |
|------|------|
| `rolledBack=true` | Admin 显示 **Rolled back** badge |
| future read path | **必须 ignore** 该行 |
| writer 重试 | `evaluateP76AllowlistApplyEligibility` 已有 `rolled_back` blocked reason · 须保持 |
| display | **safe fallback (baseline display)** |
| `MatchResult` 恢复 | **不需要**（主链未改） |

**r8e 证据：** `cmr4r7j4050025z64stag0001` rollback 后 `applied=false` · `dryRun=true` · `rolledBack=true` — admin 应展示为 `sidecarStatus: rolled_back`。
