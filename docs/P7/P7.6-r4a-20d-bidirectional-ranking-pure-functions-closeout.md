## 3. Pure function 实现摘要

| 函数 | 模块 |
|------|------|
| `computeAtoB20DFit` | scoring |
| `computeBtoA20DFit` | scoring |
| `harmonicMean20DFit` | scoring |
| `computeMutual20DFit` | scoring（默认 = harmonic） |
| `sortTwentyDRankedCandidates` | scoring |
| `buildTwentyDBidirectionalRankingShadowV1` | shadow |

**说明：**

- r4a 使用 **预计算分数**（`profileScoreAtoB` / `preferenceScoreAtoB` / `profileScoreBtoA` / `preferenceScoreBtoA`）
- **不**调用 `computeProfileScore` / `computePreferenceScore`（r4b DB adapter 负责）
- **不**调用 `computeFinalScoreV1`
- **不包含** PhotoVisual / `style` / preview pool / RRM 权重
- 常量：`TWENTY_D_WEIGHT_PROFILE = 0.4` · `TWENTY_D_WEIGHT_PREFERENCE = 0.6`

---

## 4. 20D 分数公式

```text
AtoB20DFit = 0.4 * profileScoreAtoB + 0.6 * preferenceScoreAtoB
BtoA20DFit = 0.4 * profileScoreBtoA + 0.6 * preferenceScoreBtoA

mutual20DFit = harmonicMean(AtoB20DFit, BtoA20DFit)

harmonicMean(A, B) = (A > 0 && B > 0) ? 2 * A * B / (A + B) : 0

imbalancePenalty = |AtoB20DFit - BtoA20DFit|   （仅审计，不参与 harmonic）
```

**排序**（eligible）：`mutual20DFit` desc → `AtoB20DFit` desc → `BtoA20DFit` desc → `candidateUserId` asc。

**profile 必填**：任一方向 `profileScore` 为 `null` → 该方向 fit 为 `null` → candidate 通常 `CANDIDATE_PROFILE_MISSING`。

## 6. Fallback / invalid 输入处理

| 条件 | 行为 |
|------|------|
| viewer 缺 profile（`viewerProfilePresent=false`） | `top2CandidateIds=[]` · 候选行含 `VIEWER_PROFILE_MISSING` |
| candidate 缺 profile | `eligible=false` · `CANDIDATE_PROFILE_MISSING` · fits `null` |
| `NaN` / 非有限分数 | `SCORE_INPUT_INVALID` · **不 throw** |
| 缺 preference | 按 `0` 计分；`missingSignals` 记录 `preference_*_missing` |
