## 6. Comparison 规则

### 6.1 `wouldChange*` 定义

```text
finalId = finalShadow.selectedCandidateId

wouldChange20DWinner =
  stage3.selectedByRrmCandidateId != null
  && stage2.selectedBy20DOnlyCandidateId != null
  && stage3.selectedByRrmCandidateId !== stage2.selectedBy20DOnlyCandidateId

wouldChangeLegacyMatchResult =
  finalId != null
  && legacyComparison.matchResultCandidateUserId != null
  && finalId !== legacyComparison.matchResultCandidateUserId

wouldChangeDisplayCandidate =
  finalId != null
  && legacyComparison.displayCandidateUserId != null
  && finalId !== legacyComparison.displayCandidateUserId

wouldChangeWorkerWinner =
  finalId != null
  && legacyComparison.workerWinnerCandidateUserId != null
  && finalId !== legacyComparison.workerWinnerCandidateUserId

wouldChangeM6Top2 =
  (set(stage2.top2CandidateIds) !== set(m6RrmTop2CandidateIds))
  OR (finalId != null && m6RrmSelectedCandidateId != null && finalId !== m6RrmSelectedCandidateId)
```

**null 处理：** 任一侧缺失 → 对应 `wouldChange*` = `false`，并在 `comparisonReasonSummary` 注明 `legacy_missing` / `stage_missing`。

### 6.2 `differenceStage` 枚举

```typescript
type DifferenceStageV1 =
  | "no_change"           // finalId matches all available legacy refs & 20D/RRM agree
  | "photo_pool"          // Stage1 set differs from legacy preview pool (informational)
  | "twenty_d_ranking"    // wouldChange20DWinner would be true if only 20D considered; or top2 ≠ worker top2
  | "rrm_selector"        // wouldChange20DWinner === true
  | "legacy_mismatch"     // finalId ≠ MatchResult/worker but 20D/RRM agree with each other
  | "unknown";
```

**推荐推导顺序（r6a 锁定）：**

1. 若 `wouldChange20DWinner` → `differenceStage = "rrm_selector"`  
2. Else 若 `wouldChangeLegacyMatchResult` 且 `!wouldChange20DWinner` → `differenceStage = "legacy_mismatch"` 或细分为 `twenty_d_ranking`（若 worker winner ∈ top2 但 ≠ finalId）  
3. Else 若 Stage1 集合与 `legacyPreviewPoolCandidateIds` 显著不同 → `photo_pool`（**仅标注**，不改变 finalId）  
4. Else → `no_change`  

### 6.3 `finalShadow.selectedCandidateId` 来源

```text
finalShadow.selectedCandidateId = stage3Rrm.selectedByRrmCandidateId
```

若 Stage 3 缺失 → fallback `stage2.selectedBy20DOnlyCandidateId`（并标记 `stage3_missing`）；仍 **不**写 DB。

## 10. 与 M6 RRM 的关系

| 维度 | M6 现有 | P7.6-r6 |
|------|---------|---------|
| **候选集** | 全 pool V2 scored | Stage 2 固定 Top2 |
| **Top2 来源** | `rrmV2Top2Selector` | `stage2TwentyD.top2CandidateIds` |
| **最终选择** | worker winner（主链）· shadow 不改 winner | `stage3Rrm.selectedByRrmCandidateId` |
