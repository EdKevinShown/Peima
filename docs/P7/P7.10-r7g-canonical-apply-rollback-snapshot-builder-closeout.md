## 4. Builder behavior

**Input:** `sidecar`, `currentMatchResult`, `previewPayload` (from r7d/r7f), `now`, `rollbackTtlHours`, `approvals`, `environment`.

**Guards (`evaluateP76CanonicalApplyRollbackSnapshotGuards`):**

`missing_sidecar` · `missing_sidecar_id` · `missing_current_match_result` · `viewer_mismatch` · `missing_selected_candidate` · `preview_not_ready` · `sidecar_already_promoted` · `sidecar_rolled_back` · `sidecar_deleted` · `sidecar_superseded` · `sidecar_applied_to_*`

Blocked inputs still return a snapshot object with `snapshotReady=false` (no throw).

**`baselineFingerprint`:** SHA-256 of canonical JSON slice per [r7e §4.2](./P7.10-r7e-canonical-apply-rollback-snapshot-design.md).

## 5. Redaction policy

| Rule | Implementation |
|------|----------------|
| No plaintext rollback token | `rollbackTokenHash: null`; preview `"redacted"` only |
| No raw `matchInsights` | `summarizeP76MatchInsightsForRollbackSnapshot` — keys + checksum only |
| Strip forbidden JSON keys | Same list as sidecar writer privacy |
| No secrets in JSON | Builder rejects serialized output with forbidden patterns |
