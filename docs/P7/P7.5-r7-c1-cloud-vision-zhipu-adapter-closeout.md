## 3. Adapter registry 变化

| `adapter` | 条件 |
|-----------|------|
| **mock** | r7-c0 任一 gate 未满足（与 c0 相同） |
| **real-zhipu** | gate 全满足且 `cloudVendor=zhipu` |
| **real-disabled** | gate 全满足但 vendor 非 zhipu/mock（如 `openai`） |

**legacy `provider=zhipu`** 仍走 **同一 gate**（`isOnboardingVisionCloudRoutedProvider`），**不能绕过**。

---

## 4. Live 调用条件（`real-zhipu`）

全部满足时 registry 返回 `real-zhipu`（仅 **async facade** 会发 HTTP）：

1. `PEIMA_ONBOARDING_VISION_ENABLED=true`
2. `PROVIDER=cloud` 或 `zhipu`
3. `CLOUD_DRY_RUN=false`
4. `CLOUD_HTTP_ENABLED=true`
5. `CLOUD_VENDOR=zhipu`（非 `mock`）
6. `API_KEY` 非空
7. `BASE_URL` 非空（adapter fail-closed）
8. allowlist 非空且 `imageId` 或 `userId` 命中
9. 调用方提供 **`imageRef`**（bytes 或 signedUrl）
10. 使用 **`runCloudVisionFacadeAsync`**（或直连 adapter + mock fetch）

**同步** `runCloudVisionFacade`（upload sidecar）：`real-zhipu` → **不发 HTTP** → `fallbackReason=cloud_live_requires_async` + rules tags。

---

## 5. Response parser 行为

- 只接受 **JSON object**（含 chat `choices[0].message.content` 内嵌 JSON）。
- 输出 `photoVisual` / `quality` / `scene` scored labels。
- invalid / missing / malformed → `parse_failure` → adapter refusal → facade **rules fallback**。
- **不保留** vendor 全文；`stripCloudVisionSensitiveFields` 剔除 beautyScore / genderGuess 等。

---

## 6. Prompt 安全边界

- 仅含 **taxonomyHints** + 安全说明 + 可选 **viewerStyleTags**（封闭审美标签）。
- **不传**：phone、email、userId、imageId、User.gender、reviewNote。
- 请求 body 中的 base64 **仅用于 HTTP**；**不写入** `detectionScoreJson.vision`。

---

## 7. Fallback rules 行为

| 场景 | `fallbackReason`（示例） |
|------|-------------------------|
| real-disabled vendor | `cloud_vendor_unsupported` |
| sync live path | `cloud_live_requires_async` |
| zhipu refusal / http / timeout / parse | `cloud_zhipu_<code>` |
| mock/normalizer empty | `cloud_empty_photo_tags` 等 |
| 任意未捕获异常 | `cloud_exception` |

一律 `fallbackUsed=true`，**不 throw** 到上传主链；`detectionStatus` / `reviewStatus` **不变**。
