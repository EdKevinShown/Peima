## 3. Staging env 配置

### 3.1 变量说明

| 变量 | 说明 |
|------|------|
| `PEIMA_ONBOARDING_VISION_APPLY_TO_POOL` | 总闸；**仅**字符串 `"1"` 为开（`"true"` **不算**） |
| `PEIMA_ONBOARDING_VISION_APPLY_ALLOWLIST_USER_IDS` | 逗号分隔 **viewer** cuid；**空** = 永不写 v2 |
| `PEIMA_ONBOARDING_VISION_APPLY_PERCENT` | c3 **固定为 0**；writer **不读** percent |
| `PEIMA_ONBOARDING_VISION_APPLY_SOURCE_VERSION` | v2 池版本，默认 `onboarding-photo-preview-v2-vision` |
| `PEIMA_ONBOARDING_VISION_SHADOW_ENABLED` | 须为 `1`（或等价），否则无 shadow → 无法写 v2 |

### 3.2 默认关闭（staging / 生产基线）

```env
PEIMA_ONBOARDING_VISION_APPLY_TO_POOL=0
PEIMA_ONBOARDING_VISION_APPLY_ALLOWLIST_USER_IDS=
PEIMA_ONBOARDING_VISION_APPLY_PERCENT=0
PEIMA_ONBOARDING_VISION_APPLY_SOURCE_VERSION=onboarding-photo-preview-v2-vision
```

**生产**：保持上述默认（或等价 secret）；**不得**在未完成 c3 + c4 前默认开启 apply。

### 3.3 allowlist 测试（仅 staging 小集）

```env
PEIMA_ONBOARDING_VISION_APPLY_TO_POOL=1
PEIMA_ONBOARDING_VISION_APPLY_ALLOWLIST_USER_IDS=<staging viewer cuid 1>,<staging viewer cuid 2>,...
PEIMA_ONBOARDING_VISION_APPLY_PERCENT=0
PEIMA_ONBOARDING_VISION_APPLY_SOURCE_VERSION=onboarding-photo-preview-v2-vision
PEIMA_ONBOARDING_VISION_SHADOW_ENABLED=1
```

### 3.4 锁定规则（与 c1 / c2 一致）

| 规则 | 说明 |
|------|------|
| **percent 不参与 c3** | 即使 env 中 `PERCENT=100`，allowlist 空仍 **v1** |
| **allowlist 空 → 无 v2** | `allowlist_empty` |
| **总闸** | 必须 `APPLY_TO_POOL="1"` 才可能 v2 |
| **改 env** | 必须 **重启 API** 或 **redeploy** staging 后才生效 |
| **staging 仅 allowlist-only** | 禁止在 c3 用 percent 模拟放量 |
| **生产默认关闭** | c3 通过 **不**等于生产开闸 |

## 8. PM Spot-check

**负责人**：PM / 产品（工程提供池列表与 audit 导出）。

**样本量**：至少 **20** 个 **active** preview pool（建议：allowlist 命中生成的 **v2** 为主，可含少量 v1 对照）。

**抽样建议**

- 来自 ≥ **3** 个 staging viewer（含 male / female）；
- 每 viewer 可多次 `generate()` 产生不同 pool id；
- 每个 pool 执行 active audit 后再做视觉检查。

### 8.1 记录表（复制 ≥ 20 行）

| Pool # | viewer | sourceVersion | 6 items visible | no duplicate candidate | no duplicate image | no self | gender gate ok | perceived quality | PM result | note |
|--------|--------|---------------|-----------------|------------------------|--------------------|---------|----------------|-------------------|-----------|------|
| 1 | | | ☐ | ☐ | ☐ | ☐ | ☐ | | PASS / FAIL | |
| 2 | | | ☐ | ☐ | ☐ | ☐ | ☐ | | | |
| … | | | | | | | | | | |
| 20 | | | ☐ | ☐ | ☐ | ☐ | ☐ | | | |

### 8.2 PM 检查项

- v2 排序是否比同 viewer 历史 v1 **更合理**（若可对比）；
- 是否出现明显 **低质图片上浮**；
- 是否出现 **重复图** / **重复人选**；
- 是否出现 **错性别**（与 DB gender 门控不一致的观感）；
- 是否出现 **viewer 自己** 的照片；
- **三组文案** / tier 展示（clear×3 / blurred×2 / hidden×1）是否符合预期；
- 用户是否能理解页面与「重新生成」行为。

### 8.3 通过标准

| 级别 | 标准 |
|------|------|
| **通过** | 20 池中 **0** 个 **P0/P1**；active audit **0** violation；PM 汇总 **PASS** |
| **P2/P3** | 可记录于 note，**不阻塞** c3，但须写入 **r5-c4 known issues** |
| **失败** | 任一 **P0/P1** 或 audit violation → c3 **FAIL** |

**严重级别（建议）**

| 级别 | 示例 |
|------|------|
| P0 | 自己入池、错性别门控失败、重复 candidate |
| P1 | 明显重复图源、6 items 缺失、v2 未生效但 env 为 hit |
| P2 | 排序主观不佳、轻微文案问题 |
| P3 | 审美分歧、demo 图与真人预期差 |
