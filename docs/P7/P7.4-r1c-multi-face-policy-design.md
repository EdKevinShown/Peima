# P7.4-r1c — 多人照 / 单人照策略设计（已确认）

> 状态：**策略已确认**；**P7.4-r1c-a** 落盘本文档并收口前端 warning 文案与展示位置。  
> 前置：**P7.4-r1b** 人脸存在性检测 + **r1b-f1** BlazeFace 冷启动修复。  
> 本轮 **r1c-a**：不改检测算法、不改 DB、不写 migration。

---

## 1. 一句话结论

**当前阶段维持温和策略：`faceCount > 1` 仅 `passed` + `warnings: ["MULTIPLE_FACES"]`、不 hard fail；上传页强提示「建议单人照」且不阻断 onboarding；`FACE_NOT_FOUND` 继续 hard fail；`detectionRulesVersion` 保持 `p7.4-r1b-v1` 直至 primaryFace 或策略收紧实现。**

---

## 2. 推荐多人照策略

| `faceCount` | `detectionStatus` | `detectionReasonCodes` | `warnings` | 进入 photo-preference |
|-------------|-------------------|------------------------|------------|------------------------|
| `0` | `failed` | `FACE_NOT_FOUND` | — | **否** |
| `1` | `passed` | `[]` | — | 是 |
| `>1` | `passed` | `[]` | `MULTIPLE_FACES` | **是**（warning only） |
| 检测异常 | `skipped` | `[]` | — | 是（兼容老用户） |

- **`MULTIPLE_FACES` 不写入 `detectionReasonCodes`。**
- **`hasPassingPhoto`**：`passed` 与 `skipped` 均视为可继续（含带 `MULTIPLE_FACES` 的 `passed`）。

### 未采纳：严格 hard fail

`faceCount > 1` → `failed` + `MULTIPLE_FACES`：**本轮不采用**。

### 分阶段预埋

onboarding **仅 warning**；正式展示降权 / 人工复核 → **P7.4-r1d / P7.5**（且受不改 `finalScore` / `MatchResult` / 3+2+1 **生成规则** 约束）。

---

## 3. 为什么当前不建议 hard fail

1. **误伤高**：合影、背景人像、海报、镜中脸、BlazeFace 误检等均可使 `faceCount > 1`。
2. **产品边界**：onboarding 是「有人脸即可做第一印象预览」，不是 KYC / 单人证照。
3. **转化**：hard fail 收窄漏斗，与「先完成预览闭环」目标冲突。
4. **r1b 已守住底线**：无脸仍 `FACE_NOT_FOUND` hard fail；多人脸属于**可解释性 / 准确性提示**层级。
5. **与已上线行为一致**：r1b 已 warning only，r1c 为策略确认与体验收口，非静默收紧。

---

## 4. 未来什么条件下才考虑 hard fail

| 条件 | 说明 | 建议阶段 |
|------|------|----------|
| `faceCount >= 3` 且无可靠主脸 | 降低双人合影误伤 | **P7.4-r1c-c** + 数据验证 |
| 主脸 `areaRatio` 过小 | 脸在图中过小 | **r1c-b** 写入指标；**hard fail 在 r1c-c** |
| 多脸面积接近、主脸不确定 | 需 `primaryFace` + 副脸面积比 | **r1c-b** / **r1c-c** |
| 用户连续多次多人照 | 行为策略 | **P7.4-r1d** 审核 |
| 运营审核升级 | 人工复核后再 fail | **P7.4-r1d** |

**P7.4-r1c-a 不实现**上述 hard fail。

## 7. 主脸 `primaryFace` 未来策略（P7.4-r1c-b）

当 `faceCount > 1` 时，在后端计算**主脸**（不裁剪、不生成头像）：

- 启发式：`detectionScore` + `areaRatio` + 距图中心距离综合得分。
- 写入 `detectionScoreJson.face.primaryFace`：`index`、`score`、`box`、`areaRatio`、`centerDistance`。
- 可选 `policy: { multiFacePolicy: "warning_only", shouldBlock: false }`。
- 升级 `detectionRulesVersion` 至 **`p7.4-r1c-v1`** 仅在 r1c-b 落地时。

用途：后续风格识别、审核、排序消费；**不**用于身份比对。

## 8. 前端 warning 体验（P7.4-r1c-a 收口）

### 固定文案

| 类型 | 文案 |
|------|------|
| **主文案** | 建议上传单人照片，避免影响匹配体验。 |
| **辅文案（可选展示）** | 如果照片中有其他人，系统可能无法准确判断你的照片风格。 |

### 行为

| 项 | 规则 |
|----|------|
| 性质 | **warning**（`role="status"`），非 error |
| 展示位置 | **仅** `/onboarding/photo-upload` |
| 阻断 preference | **否** |
| 重新上传 | 保留「选择照片 / 上传并继续」 |
| 继续 | `hasPassingPhoto` 为 true 时「继续选择审美偏好」可用 |
| preference / preview / questionnaire | **不展示** `MULTIPLE_FACES` |

### 与 `FACE_NOT_FOUND` 区分

- `FACE_NOT_FOUND`：红色 error，`role="alert"`，**阻断**跳转。
- `MULTIPLE_FACES`：琥珀色 info banner，**不阻断**。
