# P7.5-r3 — Visual ranking shadow (readonly) Closeout

## 本轮目标

基于 `UserImage.detectionScoreJson.vision`，生成只读 `VisualRankingShadowV1`，对比当前 3+2+1 baseline 与视觉标签 hypothetical 排序；**不改** pool items / tier / displayMode / rankInPool / 用户可见结果。

设计依据：`docs/P7/P7.5-onboarding-vision-design.md`

## VisualRankingShadowV1 schema

| 字段 | 说明 |
|------|------|
| `schemaVersion` | `visual-ranking-shadow-v1` |
| `sourceVersion` | `p7.5-r3-visual-ranking-shadow-v1` |
| `baselineSourceVersion` | `onboarding-photo-preview-v1` |
| `shadowSourceVersion` | `onboarding-photo-preview-v1-vision-shadow` |
| `appliedToPool` | 恒为 `false`（r3） |
| `slots[]` | 每槽 baseline vs shadow candidate、分数、reason、reasonTags |
| `summary` | changedSlots / changedTiers / vision 覆盖统计 |

## 打分逻辑（纯函数）

| Tier | Shadow 分 | Fallback |
|------|-----------|----------|
| **aesthetic_fit** | `jaccard(viewer.styleTags, candidate.photoVisualTags) × confidence` | `computeStyleScore` |
| **style_similar** | `jaccard(viewerPassingPhoto.tags, candidate.photoVisualTags) × confidence` | `computePreferenceScore` |
| **reflow** | 最旧注册优先；vision 仅极小 tie-break | `0.4` 探索基线 |

Hypothetical 池：按 tier 依次 pick（3+2+1），再与 baseline 逐槽对比 `wouldChange`。

## 接入点

- `OnboardingPhotoPreviewPoolService.generate()` 在 `create` 成功后 **void** 调用 `VisualRankingShadowService.computeShadow()`（失败吞掉，不阻断 generate）
- `generate()` 返回的 bundle **不变**（items / scores / tiers 同 r2）

## 是否写入 pool metadata

**否。** Prisma `OnboardingPhotoPreviewPool` **无** `metadataJson` 列（已核对 schema）。`persistVisualRankingShadowIfSupported` 返回 `{ persisted: false, reason: "no_metadata_field" }`。未做 migration。

## Env 与 APPLY_TO_POOL

| 变量 | r3 行为 |
|------|---------|
| `PEIMA_ONBOARDING_VISION_SHADOW_ENABLED=true` | 计算 shadow（默认 true） |
| `PEIMA_ONBOARDING_VISION_SHADOW_ENABLED=false` | 跳过 |
| `PEIMA_ONBOARDING_VISION_APPLY_TO_POOL=true` | **忽略** + `Logger.warn` + `summary.applyToPoolIgnored` |

## Fallback 策略

| 条件 | 行为 |
|------|------|
| candidate `visionStatus !== ok` 或 review blocked | 不计入 vision；aesthetic/style 走 baseline 分 |
| viewer 无 passing + ok vision | `viewerVisionAvailable=false`；style_similar 走 baseline |
| shadow 计算异常 | generate 不受影响（`.catch`） |

## 候选 / viewer vision 规则

- 候选：每用户 **首张** 图（createdAt asc）且 `visionStatus=ok`；`rejected` / `needs_reupload` / `appealed` / `appeal_rejected` 不用
- Viewer：最新 **passing** 图（`isUserImagePassingForOnboarding`）且 vision ok
- 不读 `reviewNote`；无外部请求
