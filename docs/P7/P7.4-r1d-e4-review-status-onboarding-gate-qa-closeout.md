## 4. reviewStatus 门禁规则表（当前生效）

### 4.1 单张 `isUserImagePassingForOnboarding`

| reviewStatus | detectionStatus | passing |
|--------------|-----------------|---------|
| **approved** / **appeal_approved** | * | **true** |
| **rejected** / **needs_reupload** / **appeal_rejected** / **appealed** | * | **false** |
| **pending_review** | passed / skipped | **true** |
| **pending_review** | failed / pending | **false** |
| **not_required** | passed / skipped | **true** |
| **not_required** | failed / pending | **false** |

### 4.2 用户维度

- **只要有 ≥1 张 passing photo** → `hasPassingPhoto = true`，可按审美 / preview / 问卷进度继续。
- **无 passing** → `nextStep = photo_upload`，并填充 `photoGateMessageKey` 等 gate 字段。
- **failed + 非 approved** → 该张不 passing；**failed + approved** → approved 覆盖机器结论。
