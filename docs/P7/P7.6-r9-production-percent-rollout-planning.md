## 9. Rollback plan

### 9.1 操作顺序（runbook 摘要）

1. 置 **`PEIMA_P76_PRODUCTION_KILL_SWITCH=1`**（或等价紧急开关）
2. **`PEIMA_P76_PRODUCTION_READ_PATH_ENABLED=0`**
3. **`PEIMA_P76_PRODUCTION_PERCENT=0`**
4. 清空或冻结 **`PEIMA_P76_PRODUCTION_ALLOWLIST_VIEWER_IDS`**
5. sidecar 读路径 **忽略**（display safe fallback (baseline display)）
6. 监控 `fallbackLegacyCount` 升至预期 · `p76DisplayCount` → 0
7. 记录 incident · postmortem 模板
8. **PM + Ops** 通知

### 9.2 必须证明（与 r8e / r8h 一致）

| 项 | 说明 |
|----|------|
| 不需恢复 `MatchResult` | 主链从未被 P7.6 read path 修改 |
| 不需恢复 `finalScore` | read path 仅 overlay display |
| 不影响 worker | ranking winner 未改 |
| legacy 路径完整 | 回滚后用户仍可见 legacy 匹配 |

### 9.3 Rollback drill（建议 r9f 前强制执行）

- staging：开启 read path → 验证 display → kill switch → 验证 100% legacy
- 记录耗时 · 负责人 · 失败项
