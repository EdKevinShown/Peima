## 4. Derived status 规则

| 字段 | 值 | 规则 |
|------|-----|------|
| `sidecarStatus` | `written` | `applied=true` · `dryRun=false` · `rolledBack=false` |
| | `dry_run` | 其他非 rollback |
| | `rolled_back` | `rolledBack=true` |
| `productApplyStatus` | `not_applied` | 默认 |
| | `blocked` | `auditNotes.productApplyBlocked=true` |
| | `future_enabled` | `auditNotes.productApplyEnabled=true` |
| `mainChainApplyStatus` | `violation_detected` | 任一 `appliedToMatchResult/FinalScore/WorkerRanking/Display=true` |
| | `none` | 全 false |
| `violationStatus` | `p0_main_chain_flag` | 主链 flag true |
| | `rolled_back` | `rolledBack=true`（非 P0） |
| | `stale_source_version` | `sourceVersion` ≠ `p7.6-r7j3-staging-cohort-v1` |
| | `artifact_missing` | `routeCArtifactPath` 在 repo 下不存在 |
| | `ok` | 以上皆否 |

**UI 禁止**将 DB `applied=true` 文案展示为「已上线」；`productApplyStatus` 当前恒为 `not_applied`（无 production apply）。

## 5. Aggregate / violation 规则

**Aggregate 字段：** `totalSidecarRows` · `writtenRows` · `dryRunRows` · `rolledBackRows` · `violationCount` · `mainChainViolationCount` · `nonAllowlistViolationCount` · `artifactMissingCount` · `staleSourceVersionCount` · `appliedToMatchResult/FinalScore/WorkerRanking/Display` true counts

**P0 violation（主链）：** 任一 `appliedToMatchResult` / `appliedToFinalScore` / `appliedToWorkerRanking` / `appliedToDisplay` = true

**`violationOnly=true`：** 过滤 `violationStatus !== ok`

**Privacy：** 响应经 `assertP76AdminResponsePrivacySafe` · 剥离 `imageUrl` / `detectionScoreJson` 等禁止键
