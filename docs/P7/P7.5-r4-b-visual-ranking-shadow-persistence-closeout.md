# P7.5-r4-b — VisualRankingShadow DB 持久化 Closeout

## 本轮目标

将 P7.5-r3 已计算的 `VisualRankingShadowV1` 写入独立表 `OnboardingPhotoPreviewPoolShadow`；**fire-and-forget**；**不**改变真实 3+2+1 items 与 viewer API。

设计依据：`docs/P7/P7.5-r4-a-visual-ranking-shadow-persist-design.md`

## 新增 Prisma model

`OnboardingPhotoPreviewPoolShadow`（`onboarding_photo_preview_pool_shadows`）：

| 字段 | 说明 |
|------|------|
| `poolId` / `userId` | FK，cascade delete |
| `shadowType` | 固定 `visual_ranking_shadow` |
| `sourceVersion` | 如 `p7.5-r3-visual-ranking-shadow-v1` |
| `payloadJson` | 完整 `VisualRankingShadowV1` |

`@@unique([poolId, shadowType, sourceVersion])`

## Migration

- **名称**：`20260516120000_p75_r4_onboarding_photo_preview_pool_shadow`
- **内容**：仅新表 + FK + unique + indexes
- **不回填**历史 pool

## Persist 行为

- `computeShadow()` 成功后调用 `persistVisualRankingShadow()` → Prisma `upsert`
- 重复同一 `poolId + shadowType + sourceVersion` → **update** `payloadJson` / `updatedAt`
- 失败 → `{ persisted: false, reason: "persist_error" }` + `Logger.warn`；**不**抛到 `generate()`

## Fire-and-forget

`generate()` 仍为：

```typescript
void this.visualRankingShadow.computeShadow(...).catch(() => {});
```

响应 bundle **不变**。

## Env

| 变量 | r4-b |
|------|------|
| `SHADOW_ENABLED=false` | 不计算、不写表 |
| `SHADOW_ENABLED=true` | 计算 + upsert |
| `APPLY_TO_POOL=true` | **硬忽略**；`appliedToPool=false`；`summary.applyToPoolIgnored` |

## Viewer API

- `POST .../generate`、`GET .../me/latest`、`toViewerBundle` **不含** shadow
- 旧 pool 无 shadow 行 → 读取正常
