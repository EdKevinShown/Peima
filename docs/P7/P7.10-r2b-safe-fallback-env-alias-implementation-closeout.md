## 3. Compatibility behavior

Parser: existing `parseTruthy` — accepts `1`/`true`/`yes`, `0`/`false`/`no`; empty → default for that branch.

**Priority:** If `PEIMA_P76_READ_PATH_SAFE_FALLBACK` is set (non-empty), it wins. Else if `PEIMA_P76_READ_PATH_FALLBACK_LEGACY` is set, use it and set `deprecatedAliasUsed: true`. Else both unset → **enabled `true`** (same as pre-r2b default).

| SAFE_FALLBACK | FALLBACK_LEGACY | `safeFallbackEnabled` | `deprecatedAliasUsed` |
|:---:|:---:|:---:|:---:|
| unset | unset | **true** | false |
| `1` | unset | true | false |
| unset | `1` | true | **true** |
| `0` | `1` | **false** (SAFE wins) | false |
| `1` | `0` | **true** (SAFE wins) | false |
| `0` | unset | false | false |
| unset | `0` | false | true |
