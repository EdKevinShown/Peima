# P7.5-r0 — `PEIMA_PREVIEW_VISUAL_ENHANCE_*` 配置审计

> **日期**：2026-05-15  
> **范围**：仓库内所有 `PEIMA_PREVIEW_VISUAL_ENHANCE_*` 引用；**不改代码**

---

## 1. 审计结论（摘要）

| 问题 | 结论 |
|------|------|
| 服务哪个池？ | **仅旧 `PreviewPool`**（`preview_pools` / `PreviewPoolService`） |
| 是否服务 onboarding 3+2+1？ | **否**（`onboarding-photo-preview-pool.service.ts` 无引用） |
| 默认是否开启？ | **否** — `PEIMA_PREVIEW_VISUAL_ENHANCE_ENABLED` 须显式 `1`/`true`/`yes` |
| 是否有真实外部 API 路径？ | **有**，但仅当 `ENABLED=1` **且** `PROVIDER=llm` **且** `LLM_BASE_URL`+`LLM_API_KEY` 已配置 |
| 是否影响 P7.4 / P7.5？ | **否**（正交能力） |
| 废弃 / 误导风险？ | **有** — 前缀像通用「预览视觉」，易与 P7.5 onboarding vision 混淆；**禁止扩展**，P7.5 用 `PEIMA_ONBOARDING_VISION_*` |

**当前仓库是否实际启用外部视觉 API？**  
- `.env.example` 中相关项均为 **注释**，默认 `ENABLED=0`。  
- 未读取用户本地 `.env`；按 example + 代码逻辑，**默认部署为关闭**；仅当运维显式开启且配置 LLM 密钥时才会 HTTP 调外部模型。

## 3. 运行时调用链（旧 PreviewPool only）

```
PreviewPoolService.generate(userId)
  → collectGatedCandidates(...)
  → if isPreviewVisualEnhanceEnabled()
       applyPreviewVisualEnhanceStubGAll(gAll, buildPreviewVisualEnhanceClient(), timeoutMs)
         → per candidate: client.enhance({ imageId, imageUrl })
         → parse → GatedCandidateForLayering.visualEnhance { visualTags, visualConfidence, visualSignalScore, visualReason }
  → assignLayeredSixUserIds(gAll, viewerPref)   // rank 1–2 视觉位可用 visualEnhance 加权
  → prisma.previewPool.create(...)
```

**文件**

| 文件 | 角色 |
|------|------|
| `apps/api/src/modules/preview-pool/preview-pool.service.ts` | **唯一** 业务入口（`generate` 内开关） |
| `apps/api/src/modules/preview-pool/visual-signal-enhance-stub.ts` | env 读取、stub/LLM client、cache、timeout |
| `apps/api/src/modules/preview-pool/preview-pool-layered-selection.ts` | 消费 `visualEnhance` 调整 rank 1–2 排序 |

**Onboarding 池（对比）**

| 文件 | 是否引用 PREVIEW_VISUAL |
|------|------------------------|
| `apps/api/src/modules/onboarding/onboarding-photo-preview-pool.service.ts` | **无** |

## 4. 外部 API 路径说明

| 条件 | 行为 |
|------|------|
| `ENABLED=0` | **不调用** enhance；纯 tag / preference 排序 |
| `ENABLED=1`, `PROVIDER=stub`（默认） | **无网络**；`StubPreviewVisualEnhanceClient` 由 `imageId` 确定性算分 |
| `ENABLED=1`, `PROVIDER=llm`, 缺 URL/key | 回退 **stub** |
| `ENABLED=1`, `PROVIDER=llm`, URL+key 齐全 | `LlmPreviewVisualEnhanceClient` — OpenAI 兼容 `chat/completions` + 图（URL 或本地文件） |

**输出形态**（与 P7.5 `OnboardingVisionProfileV1` **不同**）：

- `visual_tags` / `visual_confidence` / `visual_signal_score` / `visual_reason`  
- 挂在 **内存** `GatedCandidateForLayering`，**不写入** `UserImage.detectionScoreJson`

## 7. 与 P7.5 的边界（禁止混用）

| | 旧 `PEIMA_PREVIEW_VISUAL_ENHANCE_*` | 新 `PEIMA_ONBOARDING_VISION_*` |
|---|-----------------------------------|--------------------------------|
| 池 | `PreviewPool` | `OnboardingPhotoPreviewPool` |
| 持久化 | 内存 `visualEnhance` → 仅影响当次 generate | `detectionScoreJson.vision` |
| 标签体系 | `visual_tags`（LLM JSON 字段名） | `photoVisualTags`（封闭中文词表 V1） |
| 默认 | OFF | OFF（设计） |
| r1 云 API | 已有 LLM 路径（可选） | **不接** |
| 扩展策略 | **冻结 / 不扩展** | P7.5 唯一入口 |

---

## 8. 建议（给运维 / 开发）

1. **不要**为 onboarding 第一印象池配置 `PEIMA_PREVIEW_VISUAL_ENHANCE_*`。  
2. 若仅需旧 **PreviewPool**（`/preview-pool`）实验视觉序，见 P6 文档；默认保持 **ENABLED=0**。  
3. P7.5 实施时只新增 **`PEIMA_ONBOARDING_VISION_*`**（r1 再更新 `.env.example`）。  
4. 代码搜索时区分：`visual-signal-enhance-stub`（旧）vs `onboarding-vision`（新，r1+）。
