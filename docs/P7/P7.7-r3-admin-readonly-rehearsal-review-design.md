## 2. Why this Admin design is needed

| Milestone | Delivers |
|-----------|----------|
| [P7.10-r6d](./P7.10-r6d-dedicated-rehearsal-sidecar-schema-design.md) | Table `p76_canonical_writer_rehearsal_meta` shape |
| [P7.10-r6e](./P7.10-r6e-rehearsal-sidecar-migration-design-review.md) | SQL, CHECK constraints, indexes |
| [P7.10-r6f](./P7.10-r6f-insert-only-rehearsal-writer-design.md) | Insert-only writer gates |

Before migration or writer land, PM/Ops need a **read-only** surface to review rehearsal evidence without risking product writes.

### 2.1 Admin goals

| # | Goal |
|---|------|
| 1 | Review **baseline vs proposed** candidate per `MatchResult` row |
| 2 | See `guardrailReason`, `eligible`, `wouldChangeCandidate`, `scoreDeltaBand` |
| 3 | Confirm **`appliedToMatchResult === false`** on every row |
| 4 | Confirm rehearsal rows are **not** consumed by GET / worker / FinalMatchPage |
| 5 | Filter by `auditRunId`, cohort, environment, eligibility |
| 6 | Export audit evidence (JSON/CSV) |
| 7 | Design note / supersede hooks for later — **no Apply** |

### 2.2 Non-goals

- Apply to `MatchResult`
- Change `candidateUserId`, `finalScore`, or display
- Trigger worker or disable PreviewPool
- Promote rehearsal to production canonical write

## 4. Target Admin page

### 4.1 Route (suggestion)

Align with existing P7.6 Admin style:

| Item | Value |
|------|-------|
| **Route** | `/admin/p76/canonical-rehearsal` |
| **Component (future)** | `P76CanonicalRehearsalReviewPage.jsx` |
| **Nav link** | Beside `/admin/p76/allowlist-apply-meta` in `router/index.jsx` footer/admin links |

**Alternative:** `/admin/p76/canonical-writer-rehearsal` — same semantics; prefer **`canonical-rehearsal`** (shorter, matches table prefix).

### 4.2 Page chrome

| Element | Text |
|---------|------|
| **Title** | P7.6 Canonical Writer Rehearsal Review |
| **Subtitle** | Read-only review of canonical writer rehearsal rows (shadow compare). |
| **Primary banner** | `SHADOW REHEARSAL ONLY — NOT APPLIED TO MATCHRESULT` |
| **Secondary banner** | This row is not read by GET `/matching/result`, worker, or FinalMatchPage. Sidecar apply meta is a separate table. |
| **Footer note** | Link to [Allowlist Apply Meta](/admin/p76/allowlist-apply-meta) for Route C sidecar evidence. |

Mirror [`P76AllowlistApplyMetaPage.jsx`](../../apps/web/src/pages/P76AllowlistApplyMetaPage.jsx) audit banner pattern:

```text
Sidecar written is audit metadata only. It is not production apply ...
```

Rehearsal banner must be **stronger** (all-caps primary line) because `wouldChangeCandidate=true` could be misread as “live.”

## 7. Detail view

### 7.1 Layout sections

**1. Summary**

- `id`, `sourceVersion`, `pipelineVersion`, `auditRunId`, `generatedAt`, `environment`
- `appliedToMatchResult` (locked display: **false**)
- `rehearsalMode` (`sidecar_rehearsal`)

**2. Baseline vs proposal**

| Field | Display |
|-------|---------|
| Baseline candidate | `baselineCandidateUserId` |
| Proposed candidate | `proposedCandidateUserId` |
| Would change | `wouldChangeCandidate` |
| Baseline score | `baselineFinalScore` |
| Proposed score | `proposedScore` |
| Score band | `scoreDeltaBand` |

Side-by-side diff highlight when `wouldChangeCandidate=true`.

**3. Guardrails**

- `eligible`, `guardrailReason`
- `shadow.guardrails` + `shadow.notes[]` from payload (sanitized)

**4. Provenance**

- `allowlistApplyMetaId` → link to `/admin/p76/allowlist-apply-meta/:id` if exists
- `readPathSourceVersion`
- `sourceType` (`p76_canonical_writer_shadow`)
- Related allowlist sidecar status (read-only fetch if id present)

**5. Sanitized payload**

- Collapsible JSON tree · max height · **bounded** (first 8 KB display)
- Forbidden keys stripped server-side before response
- No raw image / prompt fields

**6. Safety banner (repeat)**

```text
This row is not read by GET, worker, or FinalMatchPage.
Rehearsal does not update MatchResult or matchInsights.
```

### 7.2 Cross-links (read-only)

| Link | Target |
|------|--------|
| Open allowlist sidecar | `/admin/p76/allowlist-apply-meta/:allowlistApplyMetaId` |
| Open MatchResult (future) | Admin read-only match inspect if exists — **not found** dedicated page today; defer or deep-link internal tool |

## 9. API design

**Prefix:** `/admin/p76/canonical-rehearsal`  
**Guards:** `JwtAuthGuard`, `RbacGuard` (mirror [`p76-admin-allowlist-apply-meta.controller.ts`](../../apps/api/src/modules/matching/p76-admin-allowlist-apply-meta.controller.ts))  
**Permission (proposed):** `VIEW_P76_CANONICAL_REHEARSAL` → `view_p76_canonical_rehearsal` in `packages/shared/constants/p5-rbac.ts` — **not found today**

### 9.1 `GET /admin/p76/canonical-rehearsal`

| Query param | Type | Description |
|-------------|------|-------------|
| `auditRunId` | string? | |
| `sourceVersion` | string? | |
| `readPathSourceVersion` | string? | |
| `environment` | string? | |
| `eligible` | boolean? | |
| `guardrailReason` | string? | |
| `wouldChangeCandidate` | boolean? | |
| `appliedToMatchResult` | boolean? | default filter false |
| `activeOnly` | boolean? | default true |
| `viewerUserId` | string? | |
| `matchResultId` | string? | |
| `generatedAtFrom` | string? | ISO |
| `generatedAtTo` | string? | ISO |
| `limit` | number | default 50 · max 100 |
| `cursor` | string? | keyset (`generatedAt`, `id`) |

**Response `200`:**

```json
{
  "schemaVersion": "p7.7-r3-admin-canonical-rehearsal-list-v1",
  "rows": [ "/* P76CanonicalRehearsalAdminListItem */" ],
  "aggregate": "/* P76CanonicalRehearsalAdminAggregateV1 */",
  "pagination": { "nextCursor": "...", "hasMore": false }
}
```

**Prisma:** `findMany` on `p76CanonicalWriterRehearsalMeta` only — **no** `matchResult.update`.

### 9.2 `GET /admin/p76/canonical-rehearsal/aggregate`

Same query filters as list; returns counts:

- `totalRows`, `eligibleCount`, `wouldChangeCandidateCount`
- `appliedToMatchResultTrueCount` (must be 0)
- `reasonCounts`, `environmentCounts`
- `latestAuditRunIds[]` (top 10)

Optional: merge aggregate into list response only (allowlist pattern supports both).

### 9.3 `GET /admin/p76/canonical-rehearsal/:id`

**Response `200`:**

| Block | Content |
|-------|---------|
| `row` | Denormalized columns |
| `shadow` | Sanitized `shadowPayload` |
| `summary` | `summary` JSON |
| `derived` | `rehearsalStatus: "shadow_only"`, `productApplyStatus: "not_applied"` |
| `links` | `allowlistApplyMetaAdminUrl?`, artifact paths |

**404** if not found.

### 9.4 Optional future (not v1 implementation)

| Method | Path | Notes |
|--------|------|-------|
| `POST` | `/admin/p76/canonical-rehearsal/:id/supersede` | Sets `supersededAt` only · rehearsal row |
| `POST` | `/admin/p76/canonical-rehearsal/export` | Async export job |

**Do not design:**

- `POST /admin/p76/canonical-rehearsal/:id/apply`
- Any `PATCH` on `match_results`

## 11. Derived status semantics (Admin UI labels)

Mirror allowlist derived statuses ([`p76AllowlistApplyMetaLabels.mjs`](../../apps/web/src/utils/p76AllowlistApplyMetaLabels.mjs)) but **rehearsal-specific**:

| Derived field | Values | Meaning |
|---------------|--------|---------|
| `rehearsalStatus` | `shadow_only` | Always in v1 |
| `productApplyStatus` | `not_applied` | Never canonical write |
| `mainChainApplyStatus` | `none` \| `violation_detected` | `violation_detected` if `appliedToMatchResult` true |
| `violationStatus` | `ok` \| `p0_applied_to_match_result` | P0 if flag true |

**Do not reuse** `sidecarStatus: written` from allowlist — rehearsal rows are **always** compare-only inserts.

## 12. Security / RBAC / privacy

| Control | Design |
|---------|--------|
| Authentication | `JwtAuthGuard` |
| Permission | `VIEW_P76_CANONICAL_REHEARSAL` (new) assigned to admin/ops roles in `p5-rbac.ts` |
| Response sanitization | Strip forbidden keys ([r6a list](../../apps/api/src/modules/matching/p76-canonical-writer-shadow-audit-json.ts) + [r6f](./P7.10-r6f-insert-only-rehearsal-writer-design.md)) |
| No public routes | Admin prefix only |
| Export | Same permission · audit log who exported |
| Production data | Table should only contain `dev`/`staging` per CHECK; Admin still filters |

**Viewer ID display:** Internal Admin may show full `viewerUserId` (consistent with allowlist page). **Exports** may offer `redactViewerIds=true` for external sharing.

## 13. Comparison: Allowlist Apply Meta vs Canonical Rehearsal

| Dimension | Allowlist apply meta Admin | Canonical rehearsal Admin |
|-----------|--------------------------|---------------------------|
| Table | `p76_allowlist_apply_meta` | `p76_canonical_writer_rehearsal_meta` |
| Purpose | Route C apply evidence | Shadow compare snapshot |
| GET reads? | Read path may use sidecar | **Must not** be read by GET |
| `applied` semantics | `applied` = sidecar row written | N/A; use `appliedToMatchResult=false` |
| Apply button | **None** (r8g2) | **None** |
| Rollback | `rolledBack` on allowlist row | `supersededAt` on rehearsal row |
| Cardinality | 1 row / viewer / cohort | Many rows / match / audit run |

## 17. Risk register
