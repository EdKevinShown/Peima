## 2. Why this design exists

[P7.7-r4.1](./P7.7-r4.1-canonical-match-result-sidecar-writer-readonly-api-implementation-closeout.md) 已实现只读 API（`GET /admin/p76/canonical-sidecar`），但 **尚无 Web Admin 页面**。

PM / Ops / Admin 需要只读界面审查 `p76_canonical_match_result_meta` 行，包括：

- `dryRunPayload` / `stageSummary` / `guardrails` / `safeFallbackMeta`
- `promotionStatus` 与 `appliedTo*` 安全标志
- `auditRunId` / `sourceVersion` / 候选 `selectedCandidateId` / `score`

该页面 **不是 Apply 页面**，不改变用户可见的 `MatchResult`、GET `/matching/result`、worker 或 FinalMatchPage。

## 5. API client design

**Future file:** `apps/web/src/api/p76CanonicalSidecarAdmin.js`

Mirror [`p76CanonicalRehearsalAdmin.js`](../../apps/web/src/api/p76CanonicalRehearsalAdmin.js) — **GET only**.

| Function | HTTP |
|----------|------|
| `listP76CanonicalSidecarAdmin(query)` | `GET /admin/p76/canonical-sidecar` |
| `getP76CanonicalSidecarAggregate(query)` | `GET /admin/p76/canonical-sidecar/aggregate` |
| `getP76CanonicalSidecarDetail(id)` | `GET /admin/p76/canonical-sidecar/:id` |

**Query builder** must map UI filters to r4.1 API params (booleans as `"true"` / `"false"` query strings; `generatedAtFrom`/`To` → API `createdAt` range).

**Error handling:**

| Status | UI message |
|--------|------------|
| **404** (feature disabled) | `Sidecar Admin API is disabled. Enable PEIMA_P76_CANONICAL_SIDECAR_ADMIN_ENABLED=1 locally.` |
| **401** | 登录已失效，请重新登录 |
| **403** | 无权限：需要 `VIEW_P76_CANONICAL_REHEARSAL` |
| **500** / other | 显示 API 返回 message 或通用错误 |
| Network | `网络异常，请稍后重试` |

Detect disabled via message containing `sidecar admin api is disabled` or `peima_p76_canonical_sidecar_admin_enabled` (same pattern as rehearsal page `isApiDisabledError`).

## 9. Detail drawer

Right-side drawer (or modal) — `getP76CanonicalSidecarDetail(id)`.

### Sections

**A. Basic info**

- `id` (full + copy), `createdAt`, `updatedAt`, `environment`, `schemaVersion`, `sourceType`

**B. Candidate / score**

- `viewerUserId`, `selectedCandidateId`, `score`, `reasonSummary`

**C. Source / audit**

- `auditRunId`, `sourceVersion`, `matchResultId` (nullable)

**D. Promotion**

- `promotionStatus`, `promotionTargetMatchResultId`
- `rollbackTokenPresent` (boolean only — **never** show token string)
- `previousSnapshotHashPresent` (boolean only)

**E. Applied flags**

- `appliedToMatchResult`, `appliedToFinalScore`, `appliedToWorkerRanking` with safe/warning labels

**F. Safety flags** (from `row.safety`)

| Flag | Expected in normal ops |
|------|------------------------|
| `isSidecarOnly` | `true` when `mode=sidecar` && `promotionStatus=not_promoted` |
| `notAppliedToMatchResult` | `true` |
| `notAppliedToFinalScore` | `true` |
| `notAppliedToWorkerRanking` | `true` |
| `readByGetPath` | **`false` (constant)** |
| `readByWorker` | **`false` (constant)** |

**G. Signoff**

- `pmSignoffStatus`, `opsSignoffStatus`

**H. Lifecycle**

- `supersededAt`, `deletedAt`, `rolledBack`

**I. JSON previews** (read-only `<pre>` or collapsible, max ~8KB truncate in UI)

- `stageSummary`, `safeFallbackMeta`, `guardrails`, `dryRunPayload` — already sanitized by API

**J. Cross-links** (from `detail.links`)

- Rehearsal admin: `links.rehearsalAdminPath`
- Allowlist apply meta: `links.allowlistApplyMetaAdminPath` (when `matchResultId` set)

Drawer footer: repeat mini banner — read-only, no Apply.

## 11. Export visible JSON

Button: **Export visible JSON**

- Serializes **current in-memory `items` array** only (visible loaded pages after Load more)
- Filename: `p76-canonical-sidecar-${Date.now()}.json`
- Does **not** fetch extra pages server-side
- Export payload is API list items (already sanitized at detail level; list items have no raw JSON blobs)
- Client must **not** add rollback tokens or re-fetch detail secrets
- Optional: strip `safety` duplication only — no transformation that re-introduces forbidden keys

| **401** | Login prompt |
| **403** | Permission panel naming `VIEW_P76_CANONICAL_REHEARSAL` |
| **Generic API error** | Red inline alert with message |
| **Aggregate only / empty items** | Cards still render; table shows empty state |
| **Detail error** | Error inside drawer |
| **Detail loading** | Spinner in drawer |

## 13. No-write UI safety

The page must **not** include:

| Forbidden control |
|-------------------|
| Apply / Promote / Rollback / Delete / Update buttons |
| Worker trigger / rerun matching |
| PreviewPool enable/disable |
| Percent rollout slider |
| Bulk select + bulk action |
| Inline edit on table cells |

**Allowed controls only:**

| Allowed |
|---------|
| Query / Reset filters / Refresh |
| Load more (cursor) |
| Copy ID |
| Export visible JSON |
| Open detail drawer |
| Navigate cross-links (read-only routes) |

Code review grep (r4.3): page source must not contain `Apply`, `Promote`, `Rollback`, `DELETE`, `POST`, `PATCH` as action labels (except in banner negation text).
