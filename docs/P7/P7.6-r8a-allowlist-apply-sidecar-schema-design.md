## 1. 一句话结论

P7.6-r8a **仅设计** allowlist apply **sidecar schema**：新增独立表 **`p76_allowlist_apply_meta`**，用于保存 P7.6 Route C `finalShadow` 的 allowlist apply 元数据。该表**不改** `MatchResult`、**不改** `finalScore`、**不改** worker、**不接** display，仅作为 apply sidecar / audit / rollback 记录。本轮**只做 schema 设计**，**不创建** migration、**不写** DB、**不实现** writer。

## 5. 约束设计

### 5.1 建议约束与索引

| 类型 | 定义 |
|------|------|
| **UNIQUE** | `(viewerUserId, sourceVersion)` — 同一 viewer + cohort 版本仅一行活跃 meta |
| **INDEX** | `viewerUserId` |
| **INDEX** | `selectedCandidateId` |
| **INDEX** | `applied` |
| **INDEX** | `rolledBack` |
| **INDEX** | `createdAt` |
| **INDEX** | `sourceVersion` |

### 5.2 红线（DB + writer）

| 字段 | 规则 |
|------|------|
| `appliedToMatchResult` | 默认 **`false`** · writer **不得**设为 `true` |
| `appliedToFinalScore` | 默认 **`false`** · writer **不得**设为 `true` |
| `appliedToWorkerRanking` | 默认 **`false`** · writer **不得**设为 `true` |
| 检测到上述为 `true` | **P0 violation** · audit 告警 |

可选 CHECK（migration 实现时考虑）：`applied_to_match_result = false AND applied_to_final_score = false AND applied_to_worker_ranking = false` — **r8a 不创建**。

## 7. Prisma model 草案

**仅文档草案** — **不**写入 `schema.prisma` · **不**生成 migration。

```prisma
model P76AllowlistApplyMeta {
  id                              String   @id
  viewerUserId                    String
  selectedCandidateId             String
  sourcePipeline                  String   @default("p7.6_route_c")
  schemaVersion                   String
  sourceVersion                   String
  routeCArtifactPath              String?
  stage1SelectedCandidateIds      Json
  stage2Top2CandidateIds          Json
  selectedBy20DOnlyCandidateId    String?
  selectedByRrmCandidateId        String?
  finalShadowSelectedCandidateId  String
  allowlistMatched                Boolean  @default(false)
  pmSignoffStatus                 String   @default("pending")
  opsSignoffStatus                String   @default("pending")
  applied                         Boolean  @default(false)
  appliedToPool                   Boolean  @default(false)
  appliedToMatchResult            Boolean  @default(false)
  appliedToFinalScore             Boolean  @default(false)
  appliedToDisplay                Boolean  @default(false)
  appliedToWorkerRanking          Boolean  @default(false)
  dryRun                          Boolean  @default(true)
  appliedAt                       DateTime?
  appliedBy                       String?
  rolledBack                      Boolean  @default(false)
  rolledBackAt                    DateTime?
  rolledBackBy                    String?
  rollbackReason                  String?
  rollbackToken                   String?
  auditNotes                      Json?
  createdAt                       DateTime @default(now())
  updatedAt                       DateTime @updatedAt

  @@unique([viewerUserId, sourceVersion])
  @@index([viewerUserId])
  @@index([selectedCandidateId])
  @@index([applied])
  @@index([rolledBack])
  @@index([createdAt])
  @@index([sourceVersion])
  @@map("p76_allowlist_apply_meta")

```

**实现备注（r8b）：** `id` 建议 `cuid()` / `uuid()`；`Json` 列存 `string[]` 时需与 Prisma 序列化约定一致。

## 8. Writer 边界（r8a 不实现 · 仅设计）

### 8.1 Writer 只能

| 动作 | 说明 |
|------|------|
| `create` sidecar row | 从 Route C artifact 填充 |
| `update` `dryRun` / `auditNotes` | audit-first |
| `update` rollback 字段 | §10 |
| `update` `applied=false` metadata | 签核状态 · allowlistMatched |

### 8.2 Writer 不能

| 动作 | 级别 |
|------|------|
| `update` `MatchResult` | **禁止** |
| `update` `finalScore` | **禁止** |
| `update` worker ranking | **禁止** |
| `update` `displayCandidateUserId` | **禁止** |
| `appliedToMatchResult = true` | **P0** |
| `appliedToFinalScore = true` | **P0** |
| `appliedToWorkerRanking = true` | **P0** |
| 非 allowlist viewer 写行 | **P0** |

**默认 posture（与 [r8](./P7.6-r8-allowlist-only-apply-design.md) env）：** `dryRun=true` · `applied=false` · 主链 flags 全 `false`。

## 10. Rollback 设计

sidecar rollback **只改 sidecar**：

| 字段 | 值 |
|------|-----|
| `rolledBack` | `true` |
| `rolledBackAt` | now |
| `rolledBackBy` | operator / job |
| `rollbackReason` | 自由文本 |
| `rollbackToken` | 关联 id |

**不需要恢复：** `MatchResult` · `finalScore` · worker — 因 r8 从未写入主链。

可选：rollback 后将 `applied=false` · `dryRun=true` · 保留历史行（audit）。

---

## 11. Audit / violation 查询

实现阶段（r8b/r8c）须支持：

| 查询 | 用途 |
|------|------|
| `applied = true` | 已写 sidecar |
| `dryRun = true` | dry-run 记录 |
| `rolledBack = true` | 已回滚 |
| `appliedToMatchResult = true` | **P0 violation** |
| `appliedToFinalScore = true` | **P0 violation** |
| `appliedToWorkerRanking = true` | **P0 violation** |
| `allowlistMatched = false` AND `applied = true` | non-allowlist **P0** |

建议视图 / dev-cli（r8c）：`p76:r8c-allowlist-sidecar-violation-audit`（**r8c 再设计**）。
