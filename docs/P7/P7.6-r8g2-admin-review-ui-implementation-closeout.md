## 4. API client 摘要

| 函数 | 方法 | 路径 |
|------|------|------|
| `listP76AllowlistApplyMeta(query)` | GET | `/admin/p76/allowlist-apply-meta` |
| `getP76AllowlistApplyMetaAggregate(query)` | GET | `/admin/p76/allowlist-apply-meta/aggregate` |
| `getP76AllowlistApplyMetaDetail(id)` | GET | `/admin/p76/allowlist-apply-meta/:id` |

- 鉴权：`authHeaders()` Bearer token  
- 403 / 401：中文错误提示（依赖 API RBAC）  
- Query：`viewerUserId` · `applied` · `rolledBack` · `sourceVersion` · `violationOnly` · `limit`（默认 50）· `cursor`

---

## 5. UI 功能摘要

### 5.1 Aggregate cards

调用 `getP76AllowlistApplyMetaAggregate`（与列表同 filter，不含 limit/cursor）。

展示：`totalSidecarRows` · `writtenRows` · `dryRunRows` · `rolledBackRows` · `violationCount` · `mainChainViolationCount` · 四个 `appliedTo*TrueCount`。

规则：

- `violationCount > 0` → 卡片红色高亮  
- `mainChainViolationCount > 0` → 顶部 **P0 warning**  
- `rolledBackRows > 0` → **warning**（非 P0）

### 5.2 Filter / list

默认 `limit=50`；排序由 API `createdAt desc`。

表格含 derived 列 + View detail；`allowlistMatched=false` 行标 **P0**。

### 5.3 Detail drawer

调用 `getP76AllowlistApplyMetaDetail`；顶部固定 audit banner（英文，与设计一致）。

展示 row 字段、derived statuses、`stageSummary`；主链 flag 或 `allowlistMatched=false` 时显示 P0 alert。

---

## 6. Derived status / violation 展示规则

| 字段 | UI 文案 |
|------|---------|
| `sidecarStatus=written` | **Sidecar written**（禁止「上线成功」等） |
| `productApplyStatus=not_applied` | **Not product-applied** |
| `violationStatus=ok` | 正常 badge |
| `p0_main_chain_flag` | 红色 / P0 |
| `rolled_back` | warning |
| `artifact_missing` / `stale_source_version` | warning |
| `allowlistMatched=false` | 红色 **no (P0)** |

主链任一 `appliedToMatchResult/FinalScore/WorkerRanking/Display=true` → 详情 **「P0: main-chain apply flag detected.»**
