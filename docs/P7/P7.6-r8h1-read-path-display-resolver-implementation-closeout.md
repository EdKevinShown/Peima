## 4. Resolver / fallback 摘要

**顺序：**

1. `resolveMatchResultDisplayCore` — 现有 RRM / pairwise / legacy 逻辑（**不变**）  
2. `applyP76ReadPathDisplayOverlay` — P7.6 只读 overlay  

**核心函数：**

- `readP76ReadPathEnv()`
- `resolveP76AllowlistSidecarDisplayCandidate(prisma, input, env?)`
- `validateP76SidecarReadEligibility(row, env)`
- `deriveP76ReadPathFallbackReason(...)`
- `buildP76ReadPathDisplayOverlay(row, env)`
- `applyP76ReadPathDisplayOverlay(prisma, input)`

**必须 safe fallback (baseline display)：**

- env disabled · not allowlisted · missing sidecar · stale `sourceVersion`  
- `rolledBack=true` · `allowlistMatched=false` · sidecar not `written`  
- PM/Ops signoff 未 approved · 主链 `appliedTo*` 任一为 true  
- `violationStatus !== ok`（strict block）  
- candidate user 不存在 · **exception**（不 bubble）

**语义：** DB `applied=true` 仅表示 **sidecar written**，**不**作为 read path 唯一门控；须 `sidecarStatus=written` + signoff + violation ok。
