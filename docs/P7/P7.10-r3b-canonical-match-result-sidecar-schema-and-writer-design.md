## 2. Why this design exists

[P7.10-r3](./P7.10-r3-p76-canonical-writer-design.md) 选择 **Option B first**：先持久化 **`p76_canonical_match_result_meta`** sidecar，再在独立门禁下 **promotion** 到 `MatchResult`（Option A）。

[P7.10-r3a](./P7.10-r3a-canonical-writer-dry-run-payload-builder-closeout.md) 已实现纯函数 **`P76CanonicalWriterDryRunPayloadV1`** builder（`mode=dry_run` · 全 `appliedTo* = false` · 无 DB）。r3a 回答「计划长什么样」，但**没有** sidecar 表、sidecar writer、promotion 边界。

**P7.10-r3b** 设计：

1. 未来 sidecar **表 / 索引 / CHECK** 草案；
2. 未来 **sidecar writer** 输入输出契约（基于 r3a payload）；
3. 与 **`p76_canonical_writer_rehearsal_meta`** 的职责分界；
4. **Promotion → `MatchResult`** 前置条件与写入范围（设计 only）；
5. **Safe fallback** 与 GET 在 promotion 前后的交互。

为 **r3c**（migration 设计）、**r3d–r3f**（writer / smoke / Admin 只读）提供可评审规格。

## 5. DB constraints design

**Future migration (r3c) — not implemented in r3b:**

| CHECK / rule | Intent |
|--------------|--------|
| `mode IN ('dry_run','sidecar','promoted')` | Allowed lifecycle modes |
| `promotionStatus IN ('not_promoted','promoted','rolled_back','blocked')` | Promotion state machine |
| `appliedToMatchResult = false OR promotionStatus = 'promoted'` | Main-chain flag only after promotion |
| `appliedToWorkerRanking = false` | Until explicit worker integration milestone |
| `appliedToFinalScore = false` OR gated by future `PEIMA_P76_CANONICAL_*` | No silent score mutation early |
| `environment IN ('dev','staging')` OR `environment IS NULL` | If column used — **block production** until r9e3 + r7 gates (mirror rehearsal) |
| `rolledBack = true` → `promotionStatus IN ('rolled_back','blocked')` | Consistency |
| `deletedAt IS NOT NULL` → no promotion | Soft-deleted rows ineligible |

**Uniqueness (choose one in r3c review):**

| Option | Definition |
|--------|------------|
| **A** | `@@unique([viewerUserId, sourceVersion, mode])` WHERE `deletedAt IS NULL AND supersededAt IS NULL` (partial unique — DB-specific) |
| **B** | `@@unique([auditRunId, viewerUserId, sourceVersion])` when `auditRunId` required per writer run |
| **C** | `@@unique([viewerUserId, sourceVersion])` + application enforces supersede before re-insert |

**Recommendation:** **B** for idempotent CLI smoke (aligns rehearsal `@@unique([matchResultId, auditRunId, pipelineVersion])` pattern).

## 7. Sidecar writer contract

**Module name (future):** e.g. `p76-canonical-match-result-sidecar-writer.ts` — **not found in this workspace**.

### 7.1 Input

| Input | Source |
|-------|--------|
| `P76CanonicalWriterDryRunPayloadV1` | Built by [r3a](./P7.10-r3a-canonical-writer-dry-run-payload-builder-closeout.md) `buildP76CanonicalWriterDryRunPayloadV1` |
| `viewerUserId` | Payload field |
| `selectedCandidateId` | Payload (non-null when `guardrails.eligible`) |
| `sourceVersion` | Payload + env `PEIMA_P76_CANONICAL_SIDECAR_WRITER_SOURCE_VERSION` |
| PM/Ops signoff states | Columns `pmSignoffStatus` / `opsSignoffStatus` — writer may **copy** from allowlist meta or artifact, not invent |
| Allowlist gate | Env `ALLOWLIST_VIEWER_IDS` + payload `guardrails` |
| `guardrails.eligible` | **Must be true** to create `mode=sidecar` row (else no-op or `mode=dry_run` artifact only) |
| `matchResultId` | Optional baseline link |
| `auditRunId` | Optional idempotency key |

**Must NOT accept:** PreviewPool output · `computeStyleScore` · random candidate · unapproved `sourceVersion`.

### 7.2 Output (single row create)

| Action | Value |
|--------|-------|
| Creates | `P76CanonicalMatchResultMeta` row |
| `appliedToMatchResult` | **false** |
| `appliedToFinalScore` | **false** |
| `appliedToWorkerRanking` | **false** |
| `promotionStatus` | **`not_promoted`** |
| `mode` | **`sidecar`** (when DB write enabled) or no row when env `ALLOW_DB_WRITE=0` |
| `dryRunPayload` | Full r3a payload JSON snapshot |
| Mutates `MatchResult` | **never** |
| Mutates `matchInsights` | **never** |

### 7.3 Writer flow (future)

```text
buildInput → buildP76CanonicalWriterDryRunPayloadV1 → assert appliedTo* false
  → read sidecar env gates
  → if !ALLOW_DB_WRITE: return payload only (artifact)
  → if !guardrails.eligible: return blocked (no row or mode=dry_run row per policy)
  → prisma.p76CanonicalMatchResultMeta.create({ ... })
```

## 8. Writer env gates

**Design-only env (not implemented in r3b):**

```bash
PEIMA_P76_CANONICAL_SIDECAR_WRITER_ENABLED=0
PEIMA_P76_CANONICAL_SIDECAR_WRITER_DRY_RUN=1
PEIMA_P76_CANONICAL_SIDECAR_WRITER_ALLOW_DB_WRITE=0
PEIMA_P76_CANONICAL_SIDECAR_WRITER_ALLOWLIST_VIEWER_IDS=
PEIMA_P76_CANONICAL_SIDECAR_WRITER_SOURCE_VERSION=p7.10-r3b-canonical-sidecar-v1
PEIMA_P76_CANONICAL_SIDECAR_WRITER_KILL_SWITCH=0
```

| Env | Default | Meaning |
|-----|---------|---------|
| `ENABLED` | `0` | Master switch |
| `DRY_RUN` | `1` | Build payload / log; prefer no durable sidecar |
| `ALLOW_DB_WRITE` | `0` | When `0`, writer never calls Prisma create |
| `ALLOWLIST_VIEWER_IDS` | empty | Blast radius |
| `SOURCE_VERSION` | `p7.10-r3b-canonical-sidecar-v1` | Cohort label |
| `KILL_SWITCH` | `0` | `1` = emergency stop (fail-closed) |

**Orthogonal to:**

- `PEIMA_P76_CANONICAL_WRITER_*` ([r3 §6](./P7.10-r3-p76-canonical-writer-design.md) — future canonical writer)
- `PEIMA_P76_READ_PATH_*` (display overlay)
- `PEIMA_P76_CANONICAL_WRITE_*` ([r7b](./P7.10-r7b-admin-apply-canonical-write-design.md) — Admin Apply)

## 10. Promotion to MatchResult

**Design only — not implemented in r3b.** Aligns [P7.10-r7](./P7.10-r7-canonical-write-readiness-design.md) · [r7b](./P7.10-r7b-admin-apply-canonical-write-design.md).

### 10.1 Preconditions

| # | Gate |
|---|------|
| 1 | Sidecar row **active**: `deletedAt` null · `supersededAt` null · `rolledBack=false` |
| 2 | `promotionStatus=not_promoted` |
| 3 | `guardrails.eligible=true` (frozen in JSON) |
| 4 | PM/Ops signoff **approved** |
| 5 | `rollbackToken` generated and stored |
| 6 | Baseline `MatchResult` snapshot hash matches `previousSnapshotHash` expectation |
| 7 | [P7.10-r7](./P7.10-r7-canonical-write-readiness-design.md) gates 12–20 PASS for production; **local-only** gate for dev |
| 8 | r9e3 **`NEED_MORE_PROD_REVERIFY`** cleared before **production** promotion |
| 9 | Safe fallback not masking a broken canonical row (no active `safe_fallback_required` on sidecar) |
| 10 | `PEIMA_P76_CANONICAL_WRITE_*` / Admin Apply env (future) — **not** sidecar writer env alone |

### 10.2 Promotion writes (future)

| Target | Field |
|--------|-------|
| `MatchResult` | `candidateUserId` ← `selectedCandidateId` |
| `MatchResult` | `finalScore` ← canonical `score` (or projection policy in r7) |
| `matchInsights` | `p76CanonicalWriterMeta` block (provenance · stage refs · `sourceVersion`) |
| Sidecar | `promotionStatus=promoted` |
| Sidecar | `appliedToMatchResult=true` |
| Sidecar | `promotionTargetMatchResultId` set |
| Sidecar | `mode=promoted` |

**Still forbidden in early promotion:** `appliedToWorkerRanking=true` · worker batch re-run · PreviewPool regeneration.

### 10.3 Rollback (design)

- Set sidecar `rolledBack=true` · `promotionStatus=rolled_back`
- Restore `MatchResult` from `previousSnapshotHash` / stored snapshot (r7b)
- **Do not** delete rehearsal rows

## 11. Safe fallback interaction

| Phase | GET / display |
|-------|---------------|
| **Before sidecar exists** | Baseline from legacy worker `MatchResult` · `matching_pending` / `no_result` per [r2](./P7.10-r2-legacy-terminology-replacement-and-safe-fallback-plan.md) |
| **Sidecar exists, not promoted** | **GET ignores** canonical sidecar by default; read-path overlay (`p76_allowlist_apply_meta`) unchanged; safe fallback = baseline / pending / no_result |
| **After promotion** | GET reads **`MatchResult`** as today; `resultState` ∈ `ready` \| `safe_fallback` \| `matching_pending` \| `no_result` |
| **Promotion failed / rolled back** | Last **stable P7.6** promoted row if any → else pending → else no_result |
| **Forbidden** | Fallback to PreviewPool · `computeStyleScore` · legacy photo matching writer |

Sidecar `safeFallbackMeta` from r3a is **audit-only** until a future GET gate explicitly consumes canonical sidecar.
