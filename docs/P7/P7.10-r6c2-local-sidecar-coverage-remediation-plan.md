## 4. Root-cause hypotheses

### 4.1 SourceVersion mismatch

| | |
|---|---|
| **Status** | **Unlikely as primary cause** (aligned in local env) |
| **Evidence** | r6a runner loads sidecar via `readP76ReadPathEnv().sourceVersion` (`p710-r6a-canonical-writer-shadow-audit-runner.ts` L66–72). Default = `p7.6-r7j3-staging-cohort-v1`. r6c1 artifact and DB count both use same cohort; **5** DB sidecar rows match **5** artifact rows with sidecar. |
| **How to verify** | Compare `PEIMA_P76_READ_PATH_SOURCE_VERSION` / `PEIMA_P76_ALLOWLIST_POOL_SOURCE_VERSION` in `.env` with `p76_allowlist_apply_meta.sourceVersion` histogram (read-only SQL or future r6c2c runner diagnostics). |
| **Remediation** | Document env checklist in r6c2b runbook; fail fast if env cohort ≠ sidecar cohort before audit. |

### 4.2 Recent MatchResult sample not allowlist-aligned

| | |
|---|---|
| **Status** | **Confirmed — primary cause** |
| **Evidence** | r6a default query: `matchResult.findMany({ orderBy: updatedAt desc, take: limit })` with **no** viewer allowlist filter (`p710-r6a-canonical-writer-shadow-audit-runner.ts` L48–54). Local DB: **80** `MatchResult` rows vs **5** sidecar rows. [P7.6-r7j1](./P7.6-r7j1-route-c-data-gap-inventory-closeout.md): most users lack Route C pool / sidecar; allowlist cohort is a **small** subset. |
| **How to verify** | Read-only: count distinct `MatchResult.userId` vs count `p76_allowlist_apply_meta` for cohort (r6c1: 6 vs 5 in recent-50 slice). |
| **Remediation** | Define **target cohort** for audits (§5–§6): allowlist-only viewer set or explicit `--viewerUserId` / env allowlist; do not use unfiltered recent-50 as rehearsal gate sample. |
