## 3. Preview payload

`P76CanonicalApplyPreviewPayloadV1` (`sourceVersion`: `p7.10-r7d-canonical-apply-preview-v1`, `mode`: `preview`):

| Field | Purpose |
|-------|---------|
| `canApply` | `true` only when **all** gates pass |
| `blockedReasons` | Failed gate reason codes |
| `sidecar` | Normalized sidecar snapshot (no raw PII expansion) |
| `currentMatchResult` | Live baseline snapshot (`hasMatchInsights` flag only) |
| `proposedChange` | `candidateWouldChange`, `scoreWouldChange`, `reasonSummaryWouldChange`, `displayWouldChange` |
| `gateResults` | Per-gate `{ id, pass, blockedReason? }` |
| `rollbackPreview` | `snapshotAvailable`, `rollbackTokenRequired`, `rollbackTokenPreview: "redacted"` |
| `safety` | Immutable no-write flags (§5) |
| `previewedAt` / `previewRequestedBy` | Audit metadata |

**Invariant:** `canApply === true` does **not** authorize writes — builder never mutates data.

## 4. Gate model

| `blockedReason` | Trigger |
|-----------------|---------|
| `missing_sidecar` | No sidecar input |
| `missing_sidecar_id` | Empty sidecar `id` |
| `missing_match_result` | Missing / mismatched `matchResultId` vs `currentMatchResult` |
| `viewer_mismatch` | `viewerUserId` ≠ `MatchResult.viewerUserId` |
| `missing_selected_candidate` | Empty `selectedCandidateId` |
| `score_missing` | Non-finite `score` |
| `sidecar_already_promoted` | `promotionStatus === "promoted"` |
| `sidecar_rolled_back` | `rolledBack === true` |
| `sidecar_deleted` | `deletedAt` set |
| `sidecar_superseded` | `supersededAt` set |
| `sidecar_applied_to_worker_ranking` | `appliedToWorkerRanking === true` |
| `sidecar_applied_to_match_result` | `appliedToMatchResult === true` |
| `sidecar_applied_to_final_score` | `appliedToFinalScore === true` |
| `unsafe_environment` | Production-like `environment` |
| `gate12_not_final` | `gate12Status` ∉ `{ PASS, GATE12_PASS, FINAL, SIGNED_OFF }` |
| `grafana_blocked` | Grafana status contains `BLOCKED` or r9e3f2 constant |
| `pm_signoff_missing` | PM signoff required but not `approved` |
| `ops_signoff_missing` | Ops signoff required but not `approved` |
| `incident_active` | `incidentActive === true` |
| `percent_rollout_active` | `percentRolloutActive === true` |
| `worker_deploy_active` | `workerDeployActive === true` |
| `production_write_blocked` | `productionWriteRequested === true` |
