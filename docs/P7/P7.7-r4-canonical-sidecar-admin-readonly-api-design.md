## 2. Why this design exists

[P7.10-r3f3](./P7.10-r3f3-canonical-match-result-sidecar-writer-local-insert-smoke-closeout.md) 已证明 `p76_canonical_match_result_meta` 可通过 r3f2 insert-only writer 在本地写入、`appliedTo*` 全为 false、并按 `auditRunId` cleanup。

下一步需要 **Admin 只读审查能力**，让 PM/Ops 能查看：

- sidecar row 身份（`auditRunId` / `viewerUserId` / `selectedCandidateId` / `sourceVersion`）
- 候选与分数（`score` / `reasonSummary`）
- 漏斗证据（`stageSummary` / `guardrails` / sanitized `dryRunPayload`）
- 推广与安全标志（`promotionStatus` / `appliedTo*` / `rolledBack`）

这不是 Apply，也不改变用户可见的 `MatchResult` / GET / worker 结果。

## 4. Proposed API surface

**Base path:** `GET /admin/p76/canonical-sidecar`

| Route | Method | Purpose |
|-------|--------|---------|
| `/admin/p76/canonical-sidecar` | `GET` | List + inline aggregate |
| `/admin/p76/canonical-sidecar/aggregate` | `GET` | Aggregate only (same filters as list) |
| `/admin/p76/canonical-sidecar/:id` | `GET` | Detail by sidecar row `id` |

**只读。** 禁止 `POST` / `PATCH` / `PUT` / `DELETE`。

**实现时复用 rehearsal Admin 结构**（已落地）：

- `JwtAuthGuard` + `RbacGuard` + `@RequirePermission(...)`
- Feature flag → `NotFoundException`（404），**不查询 DB**
- `List*QueryDto` + `to*ListQuery` + service `buildWhere` + keyset cursor
- `derive.ts`：list item mapping、aggregate、recursive sanitize

建议 Nest 文件命名（r4.1）：

| File | Role |
|------|------|
| `p76-canonical-sidecar-admin-env.ts` | `PEIMA_P76_CANONICAL_SIDECAR_ADMIN_ENABLED` |
| `p76-canonical-sidecar-admin.types.ts` | DTO contracts |
| `p76-canonical-sidecar-admin.derive.ts` | map / aggregate / sanitize / cursor |
| `dto/list-p76-canonical-sidecar-admin-query.dto.ts` | Query validation |
| `p76-canonical-sidecar-admin.service.ts` | Prisma `findMany` / `findUnique` only |
| `p76-canonical-sidecar-admin.controller.ts` | HTTP routes |
| `p76-canonical-sidecar-admin.module.ts` | Module registration |

Prisma surface（r4.1）：**仅** `prisma.p76CanonicalMatchResultMeta.findMany` / `findUnique` / `count`（aggregate 可用 `findMany` + in-memory derive，与 rehearsal Admin 一致）。**禁止** `create` / `update` / `delete` / `upsert`；**禁止** `prisma.matchResult.*`。

## 6. Permission model

| Option | Permission | Pros | Cons |
|--------|------------|------|------|
| **A (recommended short-term)** | Reuse `Permission.VIEW_P76_CANONICAL_REHEARSAL` | No shared RBAC change; same Ops cohort as rehearsal review | Name says “rehearsal” but covers canonical writer evidence family |
| **B (long-term)** | New `VIEW_P76_CANONICAL_SIDECAR` → `view_p76_canonical_sidecar` | Clear separation rehearsal vs production sidecar | Requires `p5-rbac.ts` + role map + web copy (r4.2+) |

**本轮（r4）不实现权限。** r4.1 默认采用 **Option A**，与 rehearsal controller 一致；若 PM 要求分权，在 r4.2 UI 前切 Option B。

## 7. Query filters

List / aggregate 共享 query（class-validator DTO + `toP76CanonicalSidecarAdminListQuery`）：

| Query param | Maps to column / semantics |
|-------------|---------------------------|
| `auditRunId` | `auditRunId` exact |
| `environment` | `environment` |
| `viewerUserId` | `viewerUserId` |
| `matchResultId` | `matchResultId` |
| `selectedCandidateId` | `selectedCandidateId` |
| `sourceVersion` | `sourceVersion` |
| `mode` | `mode` (e.g. `sidecar`) |
| `promotionStatus` | `promotionStatus` |
| `appliedToMatchResult` | boolean; see default below |
| `appliedToFinalScore` | boolean |
| `appliedToWorkerRanking` | boolean |
| `rolledBack` | boolean |
| `activeOnly` | `supersededAt IS NULL` when true |
| `includeDeleted` | when false: `deletedAt IS NULL` |
| `generatedAtFrom` / `generatedAtTo` | **`createdAt`** range (ISO-8601); name matches rehearsal Admin UX |
| `cursor` | keyset on `(createdAt desc, id desc)` |
| `limit` | page size |

**Defaults（与 rehearsal Admin 对齐，并贴合 r3f3 smoke 不变量）：**

| Param | Default |
|-------|---------|
| `limit` | `50` (max `100`) |
| `activeOnly` | `true` |
| `includeDeleted` | `false` |
| `appliedToMatchResult` | `false` when query param **omitted** |
| `appliedToFinalScore` | no default filter (omit = any) |
| `appliedToWorkerRanking` | no default filter (omit = any) |

Rationale: r3f3 证明正常 sidecar 行 `appliedToMatchResult=false`；默认过滤违规探测行，Ops 可显式 `appliedToMatchResult=true` 做审计。

**Cursor encoding:** base64 JSON `{ createdAt: ISO, id: string }` — same pattern as `encodeP76RehearsalAdminListCursor` but field `createdAt` (sidecar table has no `generatedAt`).

## 8. List item DTO

`schemaVersion`: `p7.7-r4-admin-canonical-sidecar-list-v1`

```ts
type P76CanonicalSidecarAdminListItem = {
  id: string;
  auditRunId: string;
  environment: string;
  viewerUserId: string;
  matchResultId: string | null;
  selectedCandidateId: string;
  sourceType: string;
  sourceVersion: string;
  schemaVersion: number;
  mode: string;
  score: number | null;
  promotionStatus: string;
  appliedToMatchResult: boolean;
  appliedToFinalScore: boolean;
  appliedToWorkerRanking: boolean;
  rolledBack: boolean;
  pmSignoffStatus: string;
  opsSignoffStatus: string;
  createdAt: string;   // ISO
  updatedAt: string;   // ISO
  supersededAt: string | null;
  deletedAt: string | null;
  safety: {
    isSidecarOnly: true;              // derived: mode === "sidecar" && !promoted
    notAppliedToMatchResult: boolean; // derived: appliedToMatchResult === false
    notAppliedToFinalScore: boolean;
    notAppliedToWorkerRanking: boolean;
    readByGetPath: false;             // constant until wired (must stay false)
    readByWorker: false;              // constant until wired (must stay false)
  };
};
```

List response envelope (mirror rehearsal):

```ts
{
  schemaVersion,
  featureEnabled: true,
  items: P76CanonicalSidecarAdminListItem[],
  pageInfo: { limit, nextCursor, totalCount },
  aggregate: P76CanonicalSidecarAdminAggregateV1,
}
```

## 10. Aggregate DTO

`schemaVersion`: `p7.7-r4-admin-canonical-sidecar-aggregate-v1`

```ts
type P76CanonicalSidecarAdminAggregateV1 = {
  totalVisible: number;
  sidecarOnlyCount: number;           // mode=sidecar && promotionStatus=not_promoted
  promotedCount: number;              // promotionStatus=promoted (if any rows)
  blockedCount: number;               // guardrails.eligible=false in dryRunPayload when parseable, else rolledBack
  rolledBackCount: number;
  appliedToMatchResultViolationCount: number;
  appliedToFinalScoreViolationCount: number;
  appliedToWorkerRankingViolationCount: number;
  promotionStatusCounts: Record<string, number>;
  modeCounts: Record<string, number>;
  sourceVersionCounts: Record<string, number>;
  environmentCounts: Record<string, number>;
  latestAuditRunIds: string[];        // up to 10 distinct, recent-first
};
```

### P0 violation rules (aggregate + per-row derived flags)

| Rule | Condition | Severity |
|------|-----------|----------|
| V1 | `appliedToWorkerRanking === true` | P0 |
| V2 | `appliedToMatchResult === true` && `promotionStatus !== "promoted"` | P0 |
| V3 | `appliedToFinalScore === true` && `promotionStatus !== "promoted"` | P0 |
| V4 | `safety.readByGetPath === true` (if ever added) | P0 |
| V5 | `safety.readByWorker === true` (if ever added) | P0 |

r3f3 local smoke expects V1–V3 counts **0** for normal cohorts. Aggregate exposes `appliedTo*ViolationCount` so Ops dashboards match rehearsal Admin `appliedToMatchResultViolationCount`.

## 11. Privacy / sanitize

Reuse forbidden-key list from [r3f1 sidecar writer privacy](../apps/api/src/modules/matching/p76-canonical-match-result-sidecar-writer-privacy.ts) (same as rehearsal writer list):

- `rawPrompt`, `fullPrompt`, `transcript`, `imageFeatures`, `rawImage`, `rawVisionResponse`, `DATABASE_URL`, `secrets` (+ snake_case aliases)

**Detail endpoint** must recursively sanitize:

- `dryRunPayload`
- `stageSummary`
- `guardrails`
- `safeFallbackMeta`

Implementation: `sanitizeP76CanonicalSidecarAdminJson()` — copy pattern from `sanitizeP76RehearsalAdminJson` in `p76-canonical-rehearsal-admin.derive.ts`, import `P76_CANONICAL_MATCH_RESULT_SIDECAR_WRITER_FORBIDDEN_JSON_KEYS` or shared constant.

**Never return** raw `rollbackToken` / full secrets. Use `rollbackTokenPresent: boolean` only.
