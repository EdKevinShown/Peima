## 4. Old-new comparison 规则实现

| 函数 | 模块 |
|------|------|
| `computeWouldChange20DWinner` | comparison |
| `computeWouldChangeLegacyMatchResult` | comparison |
| `computeWouldChangeDisplayCandidate` | comparison |
| `computeWouldChangeWorkerWinner` | comparison |
| `computeWouldChangeM6Top2` | comparison |
| `computeDifferenceStage` | comparison |
| `hasLegacyComparisonContext` | comparison |
| `buildComparisonReasonSummary` | comparison |

**`differenceStage` 枚举：**

| 值 | 含义 |
|----|------|
| `no_change` | funnel 与可用 legacy 对照一致 |
| `photo_pool` | Stage1 集合与 legacy preview pool 不同 |
| `twenty_d_ranking` | worker winner ∈ Top2 但 ≠ final |
| `rrm_selector` | `wouldChange20DWinner === true` |
| `legacy_mismatch` | 与 MatchResult/worker 不同且非 RRM 改写 20D |
| `unknown` | 无 final 或无 legacy 上下文 |

**推导顺序（与 r6 design §6.2 一致）：** `rrm_selector` → `twenty_d_ranking` / `legacy_mismatch` → `photo_pool` → `no_change`；无 legacy → `unknown`。
