## 4. API 设计

> **本轮仅设计 API 契约，不实现。**

### 4.1 列表 — `GET /admin/p76/allowlist-apply-meta`

**Query 参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `viewerUserId` | string? | 精确筛选 |
| `applied` | boolean? | DB 原始字段 · **不推荐单独用于 UI**；优先用 `sidecarStatus` |
| `rolledBack` | boolean? | rollback 筛选 |
| `sourceVersion` | string? | cohort 版本 |
| `violationOnly` | boolean? | 仅返回 `violationStatus != ok` |
| `sidecarStatus` | enum? | `not_created` \| `dry_run` \| `written` \| `rolled_back` |
| `limit` | number | 默认 50 · 最大 200 |
| `cursor` | string? | keyset pagination（`createdAt` + `id`） |

**Response `200`：**

```json
{
  "schemaVersion": "p7.6-r8g-admin-allowlist-apply-meta-list-v1",
  "rows": [ "/* P76AllowlistApplyMetaAdminRowV1 */" ],
  "aggregate": "/* P76AllowlistApplyMetaAggregateV1 */",
  "pagination": { "nextCursor": "...", "hasMore": false }
}
```

### 4.2 详情 — `GET /admin/p76/allowlist-apply-meta/:id`

**Response `200`：**

| 区块 | 内容 |
|------|------|
| `sidecar` | 表行全字段（只读） |
| `stageSummary` | stage1 count · top2 · 20D winner · RRM winner |
| `artifact` | `routeCArtifactPath` · 解析摘要 · `artifactMissing` |
| `derived` | `sidecarStatus` · `productApplyStatus` · `mainChainApplyStatus` · `violationStatus` |
| `evidenceLinks` | r7g artifact 路径 · r8e writer artifact · violation SQL 模板 |

**Response `404`：** 行不存在。

### 4.3 聚合 — `GET /admin/p76/allowlist-apply-meta/aggregate`

可选独立端点（或与列表内联 `aggregate`）；供 Admin 首页卡片。字段见 §8。

### 4.4 未来写操作（**r8g1+ · 本设计不实现**）

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/admin/p76/allowlist-apply-meta/:id/notes` | PM/Ops review note → `auditNotes` |
| `POST` | `/admin/p76/allowlist-apply-meta/:id/rollback-request` | 审批流 · 非直接执行 |
| `POST` | `/admin/p76/allowlist-apply-meta/:id/rollback` | Ops/Eng 执行 rollback |

**禁止端点：** 任何修改 `MatchResult` / `finalScore` / `displayCandidateUserId` / percent env。

### 4.5 隐私 / 安全

- **Admin-only** · Bearer / session RBAC（§10）
- Response **不得**含 `imageUrl` · `detectionScoreJson` · vendor raw · prompt
- 与 [r8b](./P7.6-r8b-allowlist-apply-writer-implementation-closeout.md) `assertP76AllowlistApplyResultPrivacySafe` 对齐

## 5. Derived Status 设计

**禁止**将 DB `applied=true` 直接展示为「已上线 / 已 Apply」。

### 5.1 `sidecarStatus`

| 值 | 派生规则 |
|----|----------|
| `not_created` | 无行 |
| `dry_run` | 无行或 `dryRun=true` 且未有效写入 |
| `written` | `applied=true` · `dryRun=false` · `rolledBack=false` |
| `rolled_back` | `rolledBack=true` |

### 5.2 `productApplyStatus`

| 值 | 含义（r8g 当前） |
|----|------------------|
| `not_applied` | 默认 · 全 cohort |
| `proposed` | 未来：PM 提议进入 read path（未实现） |
| `blocked` | 显式 block production apply |
| `future_enabled` | **reserved** · 须 r9 + signoff |

### 5.3 `mainChainApplyStatus`

| 值 | 规则 |
|----|------|
| `none` | 全部 `appliedTo*` = false |
| `violation_detected` | 任一 `appliedToMatchResult/FinalScore/WorkerRanking/Display` = true |

### 5.4 `violationStatus`

| 值 | 规则 |
|----|------|
| `ok` | 无 P0 条件 |
| `p0_main_chain_flag` | 主链 flag true |
| `non_allowlist` | `allowlistMatched=false` 且 sidecar 有效 |
| `artifact_missing` | `routeCArtifactPath` 文件不存在 |
| `stale_source_version` | `sourceVersion` ≠ 当前 cohort |
| `rolled_back` | 信息性 · `rolledBack=true`（可与 `sidecarStatus` 并列展示） |

派生逻辑在 **API 层** 计算（r8g1），**不**新增 DB 列。
