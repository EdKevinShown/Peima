## 常见误配：BASE_URL 缺少 /chat/completions

当前 `ZhipuCloudVisionAdapter` 会将 `PEIMA_ONBOARDING_VISION_BASE_URL` **原样**作为 `fetch` URL，**不会**自动追加 `/chat/completions`。

**错误配置**：

```env
PEIMA_ONBOARDING_VISION_BASE_URL=https://open.bigmodel.cn/api/paas/v4
```

**正确配置**：

```env
PEIMA_ONBOARDING_VISION_BASE_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
```

**影响**：如果只配置到 `/api/paas/v4`，live HTTP 可能返回非 2xx，并在 audit / vision `fallbackReason` 中表现为：

- `cloud_zhipu_http_404`
- `cloud_zhipu_http_400`
- 或旧版本中的 `cloud_zhipu_http_error`

**处理**：修改 `.env` 后**必须重启 API 进程**，例如：

```bash
pnpm dev:api
```

**边界**：本修正只影响 Cloud Vision live HTTP endpoint 配置；**不改** worker / MatchResult / finalScore / RRM；**不启** APPLY_TO_POOL / percent。
