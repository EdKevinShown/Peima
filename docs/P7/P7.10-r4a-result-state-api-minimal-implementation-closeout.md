## 3. Feature flag behavior

| `PEIMA_P76_RESULT_STATE_CONTRACT_ENABLED` | No `MatchResult` row | Has row |
|:---:|:---|:---|
| unset / `0` | **404** `No match result` (unchanged) | Full legacy payload, **no** `resultState` |
| `1` | **200** `matching_pending` or `no_result` + `queue` / `noResult` | Full legacy payload **+** `resultState` / `contractVersion` / … |

**No-row derivation** uses existing `getStatusForUser`:

- `waiting` \| `processing` \| `ready` (queue matched, row not yet visible) → `matching_pending`
- `not_queued` → `no_result`

**Row derivation:**

- `resultState: ready` — baseline display, read path not engaged (`p76ReadPathMeta.enabled !== true`)
- `resultState: safe_fallback` — read path **enabled** but `p76ReadPathMeta.fallbackUsed === true`
