- **5** viewers  
- 每 viewer **≥6** candidates  
- 通过正常 onboarding / preview 路径（非 `dev-p76-*` pool）

### 7.1 判定依据

| 检查 | 结果 |
|------|------|
| 合格 viewer 素材（§4） | **4** 人（需 **5**） |
| 合格 candidate 素材（§5） | **4** 人（需 **≥30** 去重槽位，且 gate 互斥） |
| 已有 `pool ≥6` viewer | **0** |
| `recommendedForRouteC` | **0** |
| 不依赖 synthetic pool | r7d 三 viewer **已排除** |

### 7.2 结论

**`C_A_NOT_FEASIBLE`**

| 枚举 | 是否 |
|------|------|
| `C_A_FEASIBLE` | **否** |
| `C_A_PARTIAL` | **否**（不足 5 viewer · 不足 6×5 候选槽位 · 同集仅 4 user） |
| `C_A_NOT_FEASIBLE` | **是** |

**说明：** 若未来通过**产品 onboarding** 新增大量真实 user，可**重新**跑 §3 SQL 再评估；**以当前库快照** C-A **不可行**。

| # | 要求 |
|---|------|
| 1 | **5–10** staging viewer |
| 2 | 每 viewer **6–10** candidate |
| 3 | 全员 **image / Cloud Vision / 20D / preference** |

| 5 | **batch match** 生成 `MatchResult`（禁止手写） |
