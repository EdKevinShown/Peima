## 3. API surface

**Base:** `GET /admin/p76/canonical-rehearsal`

| Route | Purpose |
|-------|---------|
| `GET /admin/p76/canonical-rehearsal` | List + inline aggregate |
| `GET /admin/p76/canonical-rehearsal/aggregate` | Aggregate only |
| `GET /admin/p76/canonical-rehearsal/:id` | Detail + sanitized `shadowPayload` |

**Auth:** `JwtAuthGuard` + `RbacGuard`

**Permission (r3.1):** reuses `Permission.VIEW_P76_ALLOWLIST_APPLY_META` (same Ops/Admin cohort as allowlist review). Dedicated `VIEW_P76_CANONICAL_REHEARSAL` deferred to shared RBAC migration.

**Feature flag:** `PEIMA_P76_REHEARSAL_ADMIN_ENABLED=1` required; otherwise **404** (no DB query).
