## 3. Pure function 实现摘要

| 函数 | 模块 |
|------|------|
| `computeAtoBPhotoVisualFit` | scoring |
| `computeBtoAPhotoVisualFit` | scoring |
| `computeMutualPhotoVisualFit` | scoring |
| `harmonicMeanMutualPhotoVisualFit` | scoring（可选导出，builder 未使用） |
| `sortPhotoVisualPairs` | scoring |
| `buildIneligibleReasons` | eligibility |
| `evaluatePhotoVisualPairEligibility` | eligibility |
| `buildPhotoFirstMutualMatchingShadowV1` | shadow |

**说明：**

- 评分基于已有 `tagJaccard`（`visual-ranking-shadow-scoring.ts`），无第三套 overlap 算法
- 分数 clamp 到 `[0, 1]`
- `mutual = 0.5 * AtoB + 0.5 * BtoA`
- `visualImbalancePenalty` r3a 固定为 `0`
- 排序：`mutualPhotoVisualFit` **降序** → `AtoBPhotoVisualFit` **降序** → `candidateUserId` **升序**

---

## 4. Eligibility 规则

**固定检查顺序**（可多码并存）：

1. `SELF`
2. `GENDER_GATE`
3. `PREFERENCE_GATE`
4. `USER_BLOCKED`
5. `MISSING_PROFILE`
6. `REVIEW_BLOCKED`
7. `DETECTION_UNAVAILABLE`
8. `VIEWER_VISION_MISSING`
9. `VISION_NOT_OK`
10. `EMPTY_PHOTO_VISUAL_TAGS`
11. `MISSING_STYLE_TAGS`

**说明：**

- `eligible = ineligibleReasons.length === 0`
- ineligible 可多码并存
- candidate `styleTags` 空 → **不**直接 ineligible，仅 `BtoA = 0`
- viewer 与 candidate `styleTags` **都**为空 → `MISSING_STYLE_TAGS`
- viewer vision 缺失或 `photoVisualTags` 空 → `VIEWER_VISION_MISSING`
- candidate vision 缺失或 `visionStatus !== "ok"` → `VISION_NOT_OK`
- candidate vision ok 但 `photoVisualTags` 空 → `EMPTY_PHOTO_VISUAL_TAGS`
