# P7.5-r4 Final Closeout

## 1. 一句话结论

**P7.5-r4** 已完成：Account 结构化、匹配偏好可选、照片风格偏好单源、demo candidate 文件夹导入与 seed 修复、**preview pool funnel audit**、**active pool audit**、**candidateUserId** 与 **sourceImageKey（r4h）** 去重，以及 **本地 male viewer 预览池链路签收**。**`APPLY_TO_POOL` 未启用**，仍作为后续里程碑后置；**正式匹配主链、worker、MatchResult、旧 PreviewPool** 均未纳入本阶段改造。

## 2. 阶段范围

本阶段聚焦 **onboarding 第一印象预览池（photo preview pool）** 的 **稳定性、可观测性与 dev 数据链**，**不是**正式匹配主链升级。

**包含**

- Account 表单结构化与中国本地化（省市区、学历、职业等）
- 匹配偏好 **完全可选**；空值语义为 **不限制**
- **`styleTags` 单一数据源**；`/account` **不再**编辑照片风格偏好
- **Candidate image folder import**（r4-h）及 **demo seed / mapping / per-user 去重** 修复
- **Funnel audit**（r4-m）：拆解候选数量与门控漏斗
- **Active pool audit**（r4-o2）：对当前 **active** 池做隐私安全审计
- **Gender gate** 与 **demo mapping** 人工对齐（无 AI 判性别）
- **candidateUserId** 跨 tier 全局唯一；**sourceImageKey** 同池去重（dev r4h 场景）
- **本地手测签收**（r4-o3）

**不包含**

- **`APPLY_TO_POOL`**（未实现、未启用）
- **Worker** / **`finalScore`** / **`MatchResult`**
- **云视觉 API**、**AI 判性别**、**AI 美化 / AI 头像**、人脸比对、身份认证、颜值评分
- **新 DB migration**（本阶段原则不上 schema 变更）

## 4. 当前稳定规则

### Account

- **性别**：必填 **`male` / `female`**（与预览池二元门控一致）。
- **地区**：按 **中国省级地区** 体系选择（见 r4-j1）。
- **学历 / 职业**：按 **中国学历 / 职业** 体系（见 r4-j1）。
- **匹配偏好**：**完全可选**；空偏好 = **不限制**。
- **年龄 / 身高**：可 **只填一侧**，也可都留空。
- **`/account`**：**不再**编辑 **`styleTags`**（照片风格偏好）。

### Photo preference

- **`styleTags` 唯一编辑入口**：`/onboarding/photo-preference`。
- **整体气质 + 照片感觉** 写入 **`UserPreference.styleTags`**（单源）。
- **优先关注** 等若存在 UI 采集，**不入库**或与主字段分离（以产品为准，见 r4-k）。

### Preview pool（onboarding photo preview）

- **Male viewer**：仅 **`female`** candidate（`User.gender` 经规范化后与门控一致）。
- **Female viewer**：仅 **`male`** candidate。
- **`unknown` / 非二元性别** candidate：**不入池**。
- **Viewer 本人**：**不入池**。
- **6 个 `candidateUserId`**：全局 **唯一**。
- **6 个 `sourceImageKey`（展示用）**：在可解析 r4h slug 时 **必须互异**；dev 下多用户可共用源文件，但 **同一 active 池内** 不重复同源展示。
- **候选不足**：**不允许**用重复 candidate 或重复图源 **凑满 6**；继续 **`BadRequestException`（候选不足）** 语义。

## 5. 数据与导入规则（`dev-assets/test-user-images`）

- **`mapping.json`**：仅用于 **dev / staging** 测试种子；**须 demo-safe**（`userId` / `demo-r4h*` phone 约定，见 r4-n2）。
- **Import**：会合并 **demo** 用户上的 **`User.gender`**、**`UserProfile` / `relationProfile`**、**`UserImage`**（见 r4-h / merge 逻辑）。
- **Per-user image dedup**：**`userId` + slug** 子串，避免同一用户重复插入同一源图（r4-n1）。
- **Preview pool**：在 **6 槽** 选人时排除已占用的 **`sourceImageKey`**，避免 **同池** 重复展示（r4-o2）。
- **素材结构**：当前 **female 多、male 少**；**male viewer** 可完整验证 **6 人池**；**female viewer** 若 **仅依赖** 本文件夹 **可能不足 6 名 male** —— **dev 素材限制**，非门控逻辑缺陷。

## 6. Funnel audit（`p75:r4-m-preview-pool-funnel`）

**用途**

- 将「预览池候选不足 / 当前约 0 位」拆解为：**总用户量**、**有图**、**关系画像**、**偏好硬门**、**异性二元门控** 等 **漏斗计数**。
- **不输出** phone、email、`reviewNote`、完整 `detectionScoreJson`（隐私约定见 r4-m 文档）。

**r4-o3 签收基线（示例 viewer）**

- **`viewerUserId`**：`cmp70ft7a001e6znksjb2jo03`
- **`viewer_gender_normalized`**：`male`
- **`after_opposite_gender_gate_final`**：**≥ 6**
- **Female 侧**可用候选：**充足**（用于 male viewer 生成完整池）

---

## 7. Active pool audit（`p75:r4-o2-preview-pool-active-audit`）

**用途**

- 针对 viewer **最新 active** onboarding photo preview pool（最多 **6** 条 item）输出 **隐私安全** JSON。
- 字段包含：**candidate 性别**、**duplicate candidate**、**duplicate source image**、**是否 viewer 本人**、**是否违反异性门控**、以及可从 r4h slug 反查的 **`mapping_file` / `mapping_gender`**（见 r4-o2）。

**签收条件（6 条 item 均应满足）**

- `duplicate_candidate_user_id`：**全 `false`**
- `duplicate_image_source_key`：**全 `false`**
- `violates_opposite_gender_gate`：**全 `false`**
- `is_viewer_self`：**全 `false`**
- **`source_image_key`**：**两两可区分**（同池互异）

## 8. 本地手测签收

**权威文档**：[P7.5-r4-o3-preview-pool-local-signoff.md](./P7.5-r4-o3-preview-pool-local-signoff.md)

**路径摘要**

1. **`pnpm --filter @peima/api run build`**
2. **`p75-r4-h-import-candidate-images`**（`dryRun=false`，必要时 `debugBlockedRows`）
3. **`p75:r4-m-preview-pool-funnel`**（指定 viewer）
4. 页面 **`/onboarding/photo-preview?userId=...`** → **「重新生成预览池」**
5. **`p75:r4-o2-preview-pool-active-audit`**

**结论（male viewer 基线）**

- 可生成 **完整 6 人池**；不再出现 **「当前符合条件的候选用户不足」**（在 funnel 满足前提下）。
- **`candidateUserId` 不重复**；**`sourceImageKey` 不重复**；**不展示 viewer 自己**。

## 9. 已知限制

- **Demo 素材**：**female 多、male 少**；**female viewer** 若 **只依赖** 本包，**可能不足 6 名 male** candidate。
- **视觉 vs DB**：个别图 **视觉上** 与 **`User.gender`** 可能不一致 —— 归类为 **demo 数据质量**；**本阶段不使用** AI / 人脸识别 / **自动**性别判断或改写 DB。
- **Source 去重**：解决 **同池同源重复展示**；**不保证** dev 小素材库下的 **视觉多样性**。
- **`APPLY_TO_POOL`**：**仍未**进入实现与默认开启。
