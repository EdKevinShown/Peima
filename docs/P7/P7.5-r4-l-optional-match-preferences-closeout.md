# P7.5-r4-l：匹配偏好可选与空偏好「不限制」（closeout）

## 本轮目标

- 将 **匹配偏好** 从「至少填一项可匹配维度」改为 **完全可选**。
- 空保存（`{}` 或全空数组 / 年龄身高未选）表示 **不限制**，不得再触发「必须至少一项维度」类错误。
- **硬门槛**（`preference-hard-gate`）：无配置维度时 **放行**；有配置时仍按白名单与区间过滤；支持 **年龄 / 身高单边**（仅 min 或仅 max）。
- **第一印象预览池**：viewer 无匹配偏好时，不因 preference 维度为空而筛掉全员；仍依赖性别门闸、自排除、照片等逻辑。

## 为什么改为可选

- 产品：用户可先完善资料与照片，再逐步填写匹配条件；不应在 `/account` 保存偏好时被强制阻断。

## 空偏好语义：不限制

- `preferredCities: []`、`educationPreferences: []` 等：**不限制**对应维度。
- `minAge` / `maxAge` / `minHeight` / `maxHeight` 均为 **null**：**不限制**年龄 / 身高。
- 与「未创建 `UserPreference` 行」在门闸上等价：无约束维度时 `preferenceGateDenominator === 0` → **pass-through**。

## 年龄 / 身高范围（可选 + 单边）

| 状态 | 语义 |
|------|------|
| min、max 皆空 | 不限制 |
| 仅 min | `candidate.age >= min`（`age` 为空则不过闸） |
| 仅 max | `candidate.age <= max` |
| min、max 皆有 | `min <= age <= max`，且 **min > max** 时 API 仍 **400** |
| 身高 | 与年龄对称（`>=` / `<=` / 区间） |

## 后端：`PreferencesService`

- **移除** `assertHasPreferenceScoreDenominator` 及对 `preferenceGateDenominator` 的依赖。
- **删除**英文文案：`Preferences must include at least one matchable dimension...`（正常情况下不再抛出）。
- **保留**：区间校验（`minAge > maxAge`、`minHeight > maxHeight` → 400）、各列表 **白名单** 校验、`styleTags` 白名单（onboarding / 其它调用方仍可用）。

## `preference-hard-gate` 与 `preference-score`（shared）

- `packages/shared/matching/preference-hard-gate.ts`：`passesPreferenceHardGate` 支持单边年龄 / 身高；`preferenceGateDenominator` 与之一致（单边也计 1 维）。
- `packages/shared/matching/preference-score.ts`：`computePreferenceScore` 与 gate **对齐**（单边计分）；**未改** worker `matching-score.ts`（边界要求）。

## Account 页面行为

- 说明：**均为可选**；不选表示不限制；可只填一侧年龄 / 身高。
- 保存时年龄 / 身高四个字段 **始终提交**（空下拉 → **`null`**），以便清除数据库里旧的下限 / 上限（此前省略字段会导致无法清空）。

## 第一印象预览池

- `passesPreferenceHardGate` 在 **零约束** 时全员通过该层；生成失败仍仅可能因 **候选不足 6 人**、性别未填、未完成审美步骤等，而非「无 preference 维度」。
