## 3. CLI usage

From `apps/api` (after `pnpm run build`):

```bash
# Dry-run (default) — no DB insert
pnpm run p710:r6f3:rehearsal-writer -- --dryRun=true

# Local insert + verify + cleanup (default cleanup=true on insert)
pnpm run p710:r6f3:rehearsal-writer -- --insert=true --auditRunId=r6f3-local-smoke-001
```

| Flag | Default | Notes |
|------|---------|-------|
| `--artifact` | `../../artifacts/p76/r6c2a/canonical-writer-shadow-audit-targeted.json` | r6a / r6c2a audit JSON |
| `--auditRunId` | auto `r6f3-<uuid>` | Shared by all rows in batch |
| `--environment` | `dev` | `dev` \| `staging` only |
| `--dryRun` | `true` | No `create` |
| `--insert` | `false` | Sets writer env gates + `insertOnlyP76...` |
| `--cleanup` | `true` when `--insert` | `deleteMany` by `auditRunId` |
| `--verify` | `true` when inserting | Count rows; `appliedToMatchResult` must be 0 |
| `--includeBlocked` | `true` | Skip ineligible when `false` |
