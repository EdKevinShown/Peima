# P7.4-r1d-e2 — reviewStatus 接入 Onboarding 后端 Closeout

## 本轮目标

`GET /onboarding/photo/status` 的 `hasPassingPhoto` / `nextStep` 同时考虑 **detectionStatus + reviewStatus**；新增 gate 字段供 e3 前端提示。仅后端 + 类型同步，不改前端 UI。

## passing 规则表（单张 `isUserImagePassingForOnboarding`）

| reviewStatus | detection | passing |
|--------------|-----------|---------|
| approved / appeal_approved | * | true |
| rejected / needs_reupload / appeal_rejected / appealed | * | false |
| pending_review / not_required | passed / skipped | true |
| pending_review / not_required | failed / pending | false |

**用户维度**：`hasPassingPhoto = ∃` 至少一张 passing。

实现：`apps/api/src/modules/onboarding/onboarding-photo-passing.ts`

## nextStep 影响

状态机未改顺序，仅 **`hasPassingPhoto` 数据源** 变更：

1. 无 passing → `photo_upload`
2. 有 passing + 未审美 → `photo_preference`
3. 已审美 + 未 preview ack → `photo_preview`
4. 已 preview ack → `questionnaire`

典型：仅 rejected/needs_reupload → `photo_upload`；rejected + approved → 可继续；skipped + pending_review → 可继续且 `hasPhotoUnderReview=true`。

## 新增 status 字段

| 字段 | 说明 |
|------|------|
| `hasBlockedPhoto` | 是否存在阻断性 review 图 |
| `blockingPhotoReviewStatus` | rejected / needs_reupload / appealed / appeal_rejected / null |
| `photoGateMessageKey` | 仅当无 passing 时有值 |
| `photoGateReasonCodes` | 来自阻断图 `reviewReasonCodes`（无 reviewNote） |
| `passingPhotoCount` | passing 张数 |
| `blockedPhotoId` / `passingPhotoId` | 主阻断 / 最新 passing 图 id |
| `photoReviewStatusSummary` | 扩展：none / pending_review / blocked_* |
