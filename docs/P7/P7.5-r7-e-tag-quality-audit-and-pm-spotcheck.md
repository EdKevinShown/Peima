**r7-e PASS** 已满足；[P7.6-r1](./P7.6-r1-legacy-matching-dependency-audit.md) 已完成（仍 shadow-first，不启 APPLY / percent）。

**P7.6 正确 pipeline**（[设计稿](./P7.6-bidirectional-mutual-matching-system-plan.md)）：

```text
PhotoVisual First Pool  →  20D Bidirectional Ranking  →  RRM Top2 Final Selector
```

**不是** 20D + PhotoVisual + RRM **并列加权 aggregator**。

| Stage | r7-e 交付物 |
|-------|-------------|
| **Stage 1 PhotoVisual Pool** | 确认 `styleTags` ↔ `photoVisualTags` overlap 语义合理、稳定、无违禁 |
| **Stage 2 20D** | r7-e **不验收** 20D；仅确认照片侧不阻塞 |
| **Stage 3 RRM** | r7-e **不验收** RRM |
