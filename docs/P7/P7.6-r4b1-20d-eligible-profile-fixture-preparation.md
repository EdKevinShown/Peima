## 6. 推荐方案：dev-only seed fixture

| 原则 | 说明 |
|------|------|
| **dev-only** | 仅本地 / staging；不跑生产 |
| **可回滚** | seed 前 `SELECT` 快照；提供 `UPDATE … SET col = NULL` 或删除 `user_preferences` 行 |
| **不影响生产** | 不启 `APPLY_TO_POOL` / percent |
| **不改主链** | 不写 worker / `MatchResult` / `finalScore` / RRM |
| **不删旧照片匹配** | 与 P7.6 总 plan 一致 |

**建议写入内容**：

1. 对 6 个 `user_profile`：**UPDATE** 20 个 G1-R `Float` 列（范围建议 **0.0–1.0**，与问卷刻度一致）。  
2. 对 6 个用户：**INSERT** `user_preferences`（`minAge`/`maxAge`、`preferredCities` 等与 `users` 人口字段可互命中，便于 `computePreferenceScore` > 0）。  
3. **不**复制 viewer 的完全相同向量；每人一组有差异的数值。  
4. **不**写入 `dimensionBranchChatHints` / `effectiveProfileChatOverlayV1`（非 r4b 所需；且 audit stdout 隐私检查会拒绝敏感 JSON）。
