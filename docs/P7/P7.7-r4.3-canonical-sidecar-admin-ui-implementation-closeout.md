## 4. UI behavior

- **Sticky safety banner:** `CANONICAL SIDECAR ONLY — NOT APPLIED TO MATCHRESULT` + Chinese explanation + bullets (No Apply, No MatchResult write, No worker/GET, No production rollout).
- **Header:** P7.6 Canonical Sidecar Review; permission hint `VIEW_P76_CANONICAL_REHEARSAL`.
- **Filters:** auditRunId, environment, viewerUserId, matchResultId, selectedCandidateId, sourceVersion, mode, promotionStatus, appliedTo* flags, rolledBack, activeOnly, includeDeleted, generatedAtFrom/To, limit. Defaults: `activeOnly=true`, `includeDeleted=false`, `appliedToMatchResult=false`, `limit=50`.
- **Summary cards:** totalVisible, sidecarOnlyCount, promotedCount, blockedCount, rolledBackCount, three `*ViolationCount` fields; red P0 banner when any violation count &gt; 0.
- **Table:** createdAt, environment, auditRunId (truncate+copy), sourceVersion, viewerUserId, matchResultId, selectedCandidateId, score, mode, promotionStatus, applied flags, rolledBack, safety badge, Detail.
- **Pagination:** cursor **Load more**.
- **Detail drawer:** GET `/:id` — basic info, candidate/score, source/audit, promotion, applied flags, safety flags, signoffs, lifecycle, JSON previews (reasonSummary, stageSummary, safeFallbackMeta, guardrails, sanitized dryRunPayload); `rollbackTokenPresent` boolean only.
- **Export visible JSON:** current list `items` only (no extra detail fetch; no token).
- **States:** loading, empty, feature-disabled 404, 401, 403, generic API error.
