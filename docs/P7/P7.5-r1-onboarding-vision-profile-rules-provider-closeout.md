# P7.5-r1 — OnboardingVisionProfileV1 + rules/stub provider Closeout

## 本轮目标

新增 onboarding vision 的 **TypeScript schema、封闭词表、env reader、rules/stub provider、纯函数单测**；**不写 DB**、不写 `detectionScoreJson.vision`、不改 3+2+1 pool、不接云 API。

设计依据：`docs/P7/P7.5-onboarding-vision-design.md`

## 新增 schema

`OnboardingVisionProfileV1`（`onboarding-vision-v1`）：

| 字段 | 说明 |
|------|------|
| `schemaVersion` | 固定 `onboarding-vision-v1` |
| `sourceVersion` | 如 `p7.5-r1-rules` / `p7.5-r1-stub` |
| `photoVisualTaxonomyVersion` | `p7.5-v1` |
| `provider` | `rules` \| `stub` \| `zhipu`（r1 不调用 zhipu） |
| `visionStatus` | `ok` \| `skipped` \| `failed` |
| `fallbackUsed` | boolean |
| `photoVisualTags` | 封闭中文词表，env `MAX_TAGS` 截断 |
| `qualitySignals` / `faceSignals` | 弱信号 |
| `confidence` | 0.15–0.85 |
| `warnings` | 短码 |
| `rawProviderMeta` | r1 不写入 |

## 词表 p7.5-v1

- **18** 个固定中文 tag（12 审美题 + 6 扩展）
- `PHOTO_VISUAL_TAXONOMY_VERSION = "p7.5-v1"`
- `normalizePhotoVisualTags` / `isKnownPhotoVisualTag` 丢弃未知 tag

## env reader

`readOnboardingVisionEnv()` — 前缀 `PEIMA_ONBOARDING_VISION_*`

| 变量 | 默认 |
|------|------|
| `ENABLED` | **false** |
| `PROVIDER` | `rules` |
| `TIMEOUT_MS` | 8000 |
| `CACHE_TTL_MS` | 86400000 |
| `MAX_TAGS` | 6 |
| `SHADOW_ENABLED` | true |
| `APPLY_TO_POOL` | **false** |

`provider=zhipu` → `isOnboardingVisionExternalProviderSupported === false`（r1 不发起外部请求）。

**未改** `.env` / `.env.example`（r2 再落盘注释示例）。

## rules provider

`buildVisionProfileFromRules(input, env?)`：

- 输入：`detectionScoreJson` + 可选 `viewerStyleTags`
- 解析：`quality.meanLuma` / `laplacianVariance` / `face` / `warnings`
- 规则：亮/暗/清晰度/居中人脸/多人脸 warning → tag 权重 + confidence 调整
- 无可用信号 → `visionStatus=skipped`, `fallbackUsed=true`
- **不读** DB / reviewStatus

## stub provider

`buildVisionProfileFromStub` — 固定 `["生活感","简约干净","清爽自然"]`, `confidence=0.5`, `sourceVersion=p7.5-r1-stub`

## service

`OnboardingVisionService`：

- `buildVisionProfileFromRules` / `buildVisionProfileFromStub` / `buildVisionProfile`
- `ENABLED=false` → skipped + `ONBOARDING_VISION_DISABLED`
- **未注册**到 `OnboardingModule`（r2 再接线）
