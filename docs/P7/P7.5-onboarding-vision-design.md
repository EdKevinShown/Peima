# P7.5 — Onboarding 视觉风格标签 / 审美排序增强（设计）

> **状态**：设计确认稿 + **P7.5-r0** 旧配置审计（2026-05-15）  
> **基线**：P7.4-r1 照片治理 + staging signoff 已完成  
> **本轮 r0**：仅文档 / 审计；不改业务代码、migration、依赖；不接云 API

---

## 1. 一句话结论

**P7.5 在不动 3+2+1 槽位结构、不改 finalScore / MatchResult / worker 的前提下，为每张 UserImage 旁路生成版本化 `OnboardingVisionProfileV1`（封闭 `photoVisualTags` + 弱信号），先写入 `detectionScoreJson.vision` 并做 shadow 对比；待验证后再小流量影响 onboarding 池内排序与「为什么推荐这张」解释——与旧 `PEIMA_PREVIEW_VISUAL_ENHANCE_*`（仅服务旧 `PreviewPool`）严格分离，由 `PEIMA_ONBOARDING_VISION_*` 承载。**

---

## 2. P7.5 目标与边界

### 2.1 要解决什么

| 目标 | 说明 |
|------|------|
| 更准确理解用户喜欢什么照片 | `UserPreference.styleTags`（审美题）↔ 候选 **`photoVisualTags`** 对齐 |
| 更准确选 **aesthetic_fit（3 clear）** | 增强 `pickByStyleScore`：视觉标签重叠 + 置信度 |
| 更准确选 **style_similar（2 blurred）** | **修正语义**：viewer **passing 主图** `photoVisualTags` ↔ 候选相似（现网该 tier 实际走 `computePreferenceScore`，与命名不符） |
| **视觉解释** | `reasonTags` / 轻文案（如「与你选的清爽自然接近」） |
| **不影响正式匹配** | 仅 `OnboardingPhotoPreviewPool`；零 worker / finalScore / MatchResult / 旧 `PreviewPool` |

### 2.2 现网 3+2+1 锚点（`onboarding-photo-preview-v1`）

| 槽位 | 现逻辑 | P7.5 意图 |
|------|--------|-----------|
| 3 × aesthetic_fit / clear | `computeStyleScore(viewer.styleTags, candidate.firstImage.styleTags)` | **photoVisualTags** 匹配 |
| 2 × style_similar / blurred | `computePreferenceScore`（年龄/城市/学历…） | **本人照片 visualTags 相似** |
| 1 × reflow / hidden | `pickOldest` | 保持探索，视觉仅 tie-break |

实现：`apps/api/src/modules/onboarding/onboarding-photo-preview-pool.service.ts`

### 2.3 明确不做什么

- 不做 AI 美化、不生成 AI 头像、不做人脸比对、不做身份认证、不做颜值评分  
- 不输出种族 / 年龄 / 性别等敏感属性  
- 不改变 3+2+1 **数量**与 tier / displayMode 名  
- 不替换正式匹配候选池、不改 Admin Photo Review、不改 P7.4 onboarding gate

## 3. 视觉标签体系（photoVisualTags）

### 3.1 原则

- 与 onboarding 审美题 **同源中文**（`OnboardingPhotoPreferencePage` 三组 tag）  
- 描述 **画面气质 / 场景**，不描述「此人是谁」  
- Taxonomy 版本化：`photoVisualTaxonomyVersion: "p7.5-v1"`

### 3.2 词表 V1（18）

**与审美题对齐（12）**

| 组 | 标签 |
|----|------|
| 整体气质 | 清爽自然、甜美可爱、酷感个性、成熟稳重、文艺温柔、运动阳光 |
| 照片感觉 | 生活感、精致感、松弛感、氛围感、简约干净、有个性 |

**扩展（6）**

| 标签 | 用途 |
|------|------|
| 都市精致 | 都市场景、穿搭精致 |
| 高级感 | 光影/构图偏质感 |
| 户外感 | 自然/户外光 |
| 社交感 | 聚会/互动场景（非身份） |
| 室内日常 | 家居/室内生活场景 |
| 证件感弱 | 弱负向：证件照构图（降权，非拒绝） |

### 3.3 数量 / 语言 / 版本 / 映射

| 项 | 建议 |
|----|------|
| 每张图标签数 | **3–6**（硬上限 8，由 `PEIMA_ONBOARDING_VISION_MAX_TAGS` 约束） |
| 语言 | **中文为主**（UI 一致）；`styleSignals` 可用内部英文 snake_case |
| 版本 | `photoVisualTaxonomyVersion` + `schemaVersion` |
| vs `UserPreference.styleTags` | **不等同**：preference = 主观偏好；photoVisualTags = 画面客观气质；打分用映射表，不直接复制 |

### 3.4 vs `UserImage.styleTags`

- DB 字段保留；P7.5 **优先** `detectionScoreJson.vision.photoVisualTags`  
- Fallback：`UserImage.styleTags` → rules stub

## 4. 数据结构建议（detectionScoreJson.vision）

### 4.1 三方案对比

| 维度 | ① `detectionScoreJson.vision` | ② `UserImage.visualTags[]` | ③ `UserImageVisualProfile` 表 |
|------|------------------------------|----------------------------|--------------------------------|
| migration | **无** | 需要 | 需要新表 |
| 查询 | 随 UserImage 一次读出 | 数组索引友好 | 最好 |
| 版本 / shadow | JSON 内嵌版本最易 diff | 需额外列 | 最正规 |
| **r1 推荐** | **是** | r5+ 可选投影 | 非 r1 |

### 4.2 推荐落点（r1–r3）

```typescript
// detectionScoreJson（概念，与 P7.4 共存）
{
  quality: { ... },
  face: { ... },
  primaryFace?: { ... },
  warnings: string[],
  pipeline: { ... },
  vision?: OnboardingVisionProfileV1   // P7.5 新增，可选
}
```

**P7.5-r5+（可选）**：migration 增加 `UserImage.photoVisualTags String[]`，由 vision 块投影，便于按 tag 筛选。

## 5. 是否接外部视觉 API

| 方案 | 成本 | 延迟 | 隐私 | onboarding 同步 |
|------|------|------|------|-----------------|
| **1. rules / 映射** | 零 | &lt;5ms | 最好 | **r1–r2 默认** |
| **2. GLM / 智谱等** | 按张 | 1–8s | 需传图 | **仅 async**；超时 fallback |
| **3. 其它云 VL** | 中–高 | 类似 | 类似 | r4+ 可选 |
| **4. 本地轻量** | GPU | 100–500ms | 好 | 中长期 |

**结论**

- **P7.5-r1～r3**：不接云 API；`PROVIDER=rules|stub`  
- **P7.5-r4+**：可开 `zhipu` 等，**异步**补 vision，**不阻塞**上传 / 生成池  
- **禁止**复用 `PEIMA_PREVIEW_VISUAL_ENHANCE_*` 作为 P7.5 入口（见 §14）

## 6. 新 env 设计：`PEIMA_ONBOARDING_VISION_*`

> **r0 仅文档示例**；**不修改** `.env` / `.env.example`（r1 再落盘 example）。

```bash
# --- P7.5 Onboarding photo vision（与 PREVIEW_VISUAL_ENHANCE 分离）---
PEIMA_ONBOARDING_VISION_ENABLED=0
PEIMA_ONBOARDING_VISION_PROVIDER=rules
PEIMA_ONBOARDING_VISION_BASE_URL=
PEIMA_ONBOARDING_VISION_API_KEY=replace_me
PEIMA_ONBOARDING_VISION_MODEL=
PEIMA_ONBOARDING_VISION_TIMEOUT_MS=8000
PEIMA_ONBOARDING_VISION_CACHE_TTL_MS=86400000
PEIMA_ONBOARDING_VISION_MAX_TAGS=6
PEIMA_ONBOARDING_VISION_SHADOW_ENABLED=1
PEIMA_ONBOARDING_VISION_APPLY_TO_POOL=0
```

| 变量 | 说明 |
|------|------|
| `ENABLED` | 总开关；`0` 完全不调用 |
| `PROVIDER` | r1：`rules` / `stub`；r4+：`zhipu` 等 |
| `SHADOW_ENABLED` | `1` 写 `visualRankingShadow`，**不改** pool items |
| `APPLY_TO_POOL` | `1` 且验收通过后，才改 `generate()` 排序 |
| `API_KEY` | **仅 env**；仓库与 `.env.example` 仅 `replace_me` |

## 7. 视觉分析输入与 OnboardingVisionProfileV1

### 7.1 输入

| 项 | 建议 |
|----|------|
| 图像 | 优先 **upload buffer**；或短时签名 URL；不传 reviewNote / 手机号 |
| 裁剪 | 默认 **全图**；可选 primaryFace bbox 扩边 crop 作辅助 |
| 用户审美 | `viewerStyleTags[]` 仅作 **封闭词表 prompt 上下文** |
| 禁止 | 生图、美化、颜值、身份、种族/年龄/性别 |

**rules（r1）**：不读图；从 `quality` / `face` / `primaryFace` / `warnings` 规则映射 tags。

### 7.2 输出 schema：`OnboardingVisionProfileV1`

```typescript
type OnboardingVisionProfileV1 = {
  schemaVersion: "onboarding-vision-v1";
  sourceVersion: string;              // e.g. "p7.5-r1-rules"
  photoVisualTaxonomyVersion: "p7.5-v1";
  provider: "rules" | "stub" | "zhipu";
  model?: string | null;
  generatedAt: string;                // ISO
  visionStatus: "ok" | "skipped" | "failed";
  fallbackUsed: boolean;

  photoVisualTags: string[];          // 3–6，封闭中文词表

  styleSignals?: string[];             // 可选内部 key
  qualitySignals?: {
    clarity?: "low" | "medium" | "high";
    lighting?: "dark" | "normal" | "bright";
    composition?: "centered_face" | "half_body" | "busy_bg";
  };
  faceSignals?: {
    faceCount?: number;
    primaryFaceAreaRatio?: number;
    multipleFacesWarning?: boolean;
  };

  confidence: number;                 // 0–1，排序加权
  warnings?: string[];

  rawProviderMeta?: {                  // 小对象，禁止存 provider 全文
    requestId?: string;
    latencyMs?: number;
    tokenUsage?: { prompt?: number; completion?: number };
  };
};
```

**不保存**：完整 LLM 回复、原始 HTML、用户 PII。

## 8. 如何增强 3+2+1

### 8.1 打分（概念）

| Tier | shadow / r4+ 视觉分 | Fallback |
|------|---------------------|----------|
| **aesthetic_fit** | `overlap(viewerStyleTags, candidate.photoVisualTags) × confidence` | `computeStyleScore` |
| **style_similar** | `overlap(viewerPassingPhoto.photoVisualTags, candidate.photoVisualTags)` | 现网 `computePreferenceScore` |
| **reflow** | `0.4 + ε × diversity` | `pickOldest` |

`reasonTags` 示例：`vision:aesthetic_overlap:清爽自然`、`vision:style_similar:文艺温柔`。

### 8.2 应用节奏

| 阶段 | 行为 |
|------|------|
| r2–r3 | 只写 shadow；**items 不变** |
| r4 | `APPLY_TO_POOL=1` 灰度；`sourceVersion` 可升 `onboarding-photo-preview-v2` |
| 始终 | 不影响 worker / MatchResult |

### 8.3 前端解释

- clear：「符合你选择的气质」+ 1–2 匹配 tag  
- blurred：「气质相近」  
- 不展示 provider / confidence 数值

## 9. readonly / shadow 策略

```typescript
type VisualRankingShadowV1 = {
  schemaVersion: "visual-ranking-shadow-v1";
  generatedAt: string;
  viewerUserId: string;
  baselineSourceVersion: "onboarding-photo-preview-v1";
  shadowSourceVersion: "onboarding-photo-preview-v1-vision-shadow";
  slots: Array<{
    rankInPool: number;
    tier: string;
    baselineCandidateId: string;
    shadowCandidateId: string;
    wouldChange: boolean;
    reason: string;
    baselineScore?: number;
    shadowScore?: number;
  }>;
  summary: { changedSlots: number; changedTiers: string[] };
};
```

**存储**：`OnboardingPhotoPreviewPool.metadataJson.visualRankingShadow`（或等价 JSON 列）；**r4 前不改** `candidateUserId`。

## 10. fallback 策略

| 条件 | 行为 |
|------|------|
| API 不可用 / 超时 / 非 JSON | `visionStatus=failed`, `fallbackUsed=true`, `photoVisualTags=[]` |
| 图不可读 | `skipped` |
| 无 primaryFace | 仍可全图 rules；`faceSignals` 缺省 |
| review 阻断 / 无 passing 图 | 不算 viewer 主图 vision；style_similar 走现网 fallback |
| `ENABLED=0` | 不写 vision 或 `skipped` 占位 |

**不阻断** onboarding；**不阻断** `generate()`。

## 11. 隐私与安全

- 仅照片 + 封闭词表；不传 reviewNote、问卷全文、聊天  
- 不做人脸 **识别** / 比对；primaryFace 仅几何  
- 禁止模型输出敏感人口属性与颜值  
- API key 仅 env；日志脱敏；用户 DTO 不含 `rawProviderMeta`

## 14. 新旧 env 边界（P7.5-r0 审计结论）

### 14.1 旧：`PEIMA_PREVIEW_VISUAL_ENHANCE_*`

| 结论 | 说明 |
|------|------|
| **服务谁** | **仅旧 `PreviewPool`**（`PreviewPoolService.generate` → `preview_pools` 表） |
| **不服务** | **OnboardingPhotoPreviewPool**（`onboarding_photo_preview_*`）；**零**代码引用 |
| **默认** | **关闭**：`ENABLED` 须为 `1`/`true`/`yes` 才执行 |
| **外部 API** | `PROVIDER=llm` 且配齐 `BASE_URL`+`API_KEY` 时走 `LlmPreviewVisualEnhanceClient`（HTTP）；否则 **stub** |
| **与 P7.4 / P7.5** | **无交叉**；P7.4 检测块不读这些 env；P7.5 使用新前缀 |
| **风险** | 命名易被误认为 onboarding vision；**禁止**在 P7.5 中扩展此前缀 |

详见：`docs/P7/P7.5-r0-preview-visual-env-audit.md`

### 14.2 新：`PEIMA_ONBOARDING_VISION_*`

| 结论 | 说明 |
|------|------|
| **服务谁** | 仅 **P7 onboarding** 照片 vision（`detectionScoreJson.vision` + 未来 pool shadow） |
| **默认** | **关闭**（`ENABLED=0`） |
| **r1–r3** | `rules` / `stub`；**不接云** |
| **r4+** | 可选 `zhipu` 等；**async** + fallback |
| **密钥** | 不进仓库；example 仅 `replace_me` |
