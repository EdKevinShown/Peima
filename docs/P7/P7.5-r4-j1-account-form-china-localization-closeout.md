# P7.5-r4-j1 — Account form 中国与省级地区 closeout

## 本轮目标

在 **P7.5-r4-j 结构化表单** 基础上，将 **`User.city` / `UserPreference.preferredCities`** 的含义从澳大利亚城市枚举改为 **中国省级地区词表**，并收紧 **学历 / 职业** 为 **中国语境** 选项；不做 DB migration，字段名不变。

## 为什么从「城市」改为「省级地区」

- MVP 产品与数据以 **中国区划 + 本地化文案** 为主；地级市自由文本易导致硬门槛与城市字段无法对齐。
- 省级 / 直辖市层级的 **封闭枚举** 更利于 **`preference-hard-gate` 等价匹配**（仍按字符串集合比较）。
- 「广州」「深圳」「Sydney」等城市级取值 **应从白名单中剔除**，后端 **拒绝入库**。

## 省级地区选项列表（与用户端展示一致）

`packages/shared/constants/p75-r4-j-account-form.ts` 中的 **`ACCOUNT_REGION_OPTIONS`**（经 **`ACCOUNT_CITY_VALUES`** 别名沿用历史导出名）；含 **直辖市、省、自治区、特别行政区** 及 **`海外` / `其他`**。

完整列表：**北京 / 天津 / 上海 / 重庆**；**冀晋辽吉黑江浙皖闽鲁豫鄂湘琼川贵滇陕甘青台**；**内蒙古 / 广西 / 西藏 / 宁夏 / 新疆**；**香港 / 澳门**；**海外 / 其他**。

## 中国学历列表（Account）

初中及以下 · 高中 · 中专 · 职高 · 技校 · 大专 · 本科 · 硕士 · 博士 · 其他。

移除澳洲语境：**TAFE / Diploma**、「本科在读」等不再作为合法枚举。

## 中国职业列表（Account）

与学生、互联网/IT、金融证券、财务会计、医疗健康、教育培训、设计传媒、市场商务、法律公共、制造工程、房地产建筑、餐饮服务、自由职业、创业者、暂不方便透露、其他等大类枚举（详见 constants 文件）。

## 前端文案

- 「城市」→ **「所在地（省/直辖市）」**（仍为 `city` select）。
- 「倾向城市」→ **「偏好地区（省/直辖市）（多选）」**。
- 「职业大类」→ **「职业」**；偏好侧 **「职业偏好（多选）」**。
- Chip / select 数据来自 **`ACCOUNT_CITY_VALUES`**（= 省级选项）。

## 后端白名单

- **`UpdateUserProfileDto.city`**：`@IsIn(ACCOUNT_CITY_VALUES)`。
- **`PreferencesService.assertStructuredPreferenceLists`**：`preferredCities` 与 **同一省级词表**。
- **`CreateOrUpdatePreferenceDto`**：**不**对 `preferredCities` 每元素 `@IsIn`（保持与 r4-j 一致），**服务端**在 upsert 时统一校验非法值。
- **`UpdateUserProfileDto.education` / `occupation`**：`@IsIn` 与各 `ACCOUNT_*_VALUES` 同步。
