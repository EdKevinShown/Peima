### 4.2 Incident / rollback 操作顺序

1. **立即 disable** §4.1 全部 mutation env（API + service 双层）。
2. **不要** 在 incident 中启用 `production` / `customer_production` environment。
3. 使用已有 snapshot + **rollback token**（仅从安全存储读取，**不得**粘贴到 ticket/chat/log）。
4. 调用 hidden Rollback route **或** `rollbackP76CanonicalApply`（仅 staging/dev，env 显式开启）。
5. 验证 MatchResult 恢复至 snapshot `before*` 字段；sidecar `rolled_back`；snapshot `rollback_completed`。
6. Post-incident：确认 `finalRowsForAuditRunId=0` 或记录残留 synthetic 行。

| 禁止项 |
|--------|
| 启用 customer production Apply/Rollback |
| 启用 percent rollout |
| 在 r11 之前删除 legacy photo matching 代码 |
| 将 rollback token 写入 Slack/email/artifact/docs |
