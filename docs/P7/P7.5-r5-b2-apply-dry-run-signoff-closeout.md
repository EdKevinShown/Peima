### 3.1 `pnpm` script 与 `DATABASE_URL_missing`（说明）

- **`pnpm … run p75:r5-b2-apply-dry-run-signoff`** 底层仅为 `node dist/dev-cli/...`，**不会**自动加载仓库根目录 `.env`。
- 若 shell 中未预先导出 **`DATABASE_URL`**，进程内 `process.env.DATABASE_URL` 为空，runner 会输出 **`{"error":"DATABASE_URL_missing"}`** 并 **exit 1**。
- **原因**：缺省 env 注入，**不是** runner 业务逻辑失败。
- **本机签收推荐命令**（已跑通）：在 **`apps/api`** 下使用 **dotenv-cli** 指向根 `.env`：

```bash
cd C:\Users\34713\Desktop\peima\apps\api

npx dotenv-cli -e ../../.env -- node dist/dev-cli/p75-r5-b2-apply-dry-run-signoff-runner.js --viewerUserId=cmp70ft7a001e6znksjb2jo03 --mappingPath=../../dev-assets/test-user-images/mapping.json
```

- **exit 0**：`summary.allPass === true`
- **exit 1**：任一 Case FAIL 或 `appliedToPool !== false`

## 4. `generate()` 与 shadow 时序（r5-b2 依赖）

`onboarding-photo-preview-pool.service.ts` 中 `generate()` 在创建 pool 后对 `computeShadow` 使用 **`await`**（仍 **catch** 吞错），保证 runner 在 `generate()` 返回后即可 `findUnique` 读到 shadow 行（**不改变** v1 items 与 bundle 语义）。
