# P7.4-r1d-e3 — reviewStatus Onboarding 前端提示 Closeout

## 本轮目标

在 **不改后端** 的前提下，让 onboarding 上传页根据 `GET /onboarding/photo/status`（e2 字段）展示中文 gate 提示；上传成功后按 `nextStep` / `hasPassingPhoto` 决定是否跳转。不暴露 `reviewNote` 或 Admin 字段。

设计依据：`docs/P7/P7.4-r1d-e-review-status-onboarding-gate-design.md` §5。

## 新增工具模块

`apps/web/src/utils/onboardingPhotoGateMessages.js`

| 导出 | 用途 |
|------|------|
| `PHOTO_GATE_MESSAGES` | `photoGateMessageKey` → 主文案 |
| `getPhotoGateMessage` | 无 passing 时主提示 |
| `getPhotoUnderReviewMessage` | `hasPhotoUnderReview && hasPassingPhoto` 黄条 |
| `getPartialBlockedPhotoHint` | 有 passing 但仍有 blocked 图 |
| `shouldShowBlockedPhotoGate` | `hasBlockedPhoto && !hasPassingPhoto` |
| `getBlockedPhotoReviewBanner` | 上传页红色阻断 banner（含 reason hints） |
| `mapReviewReasonCodeToHint` | 白名单 reason → 中文副文案 |

**不返回**：`reviewNote`、审核人 id 等。

## 修改页面

### `OnboardingPhotoUploadPage.jsx`

- 加载时并行 `listUserImages` + `getOnboardingPhotoStatus`，保存 `photoStatus`。
- **红色 banner**（`role="alert"`）：`getBlockedPhotoReviewBanner` — 仅当无 passing 且有阻断 review。
- **黄色 banner**（`role="status"`）：审核中可继续（有 passing + `hasPhotoUnderReview`）。
- **灰色轻提示**：有 passing 但存在 blocked 图（`getPartialBlockedPhotoHint`）。
- **上传后**：重新 `getOnboardingPhotoStatus`；若 `nextStep === photo_upload` 或 `!hasPassingPhoto` 则留在本页；否则按 `nextStep` 跳转 preference / preview / questionnaire。
- **继续审美偏好**：需 `hasPassingPhoto`；再次拉 status 后 `navigateByStatus`。
- 修复误引入的 `motionDiv` 辅助组件与错配的闭合标签，统一为普通 `<div>`。

## 文案对照（`photoGateMessageKey`）

| key | 中文 |
|-----|------|
| `photo_rejected` | 这张照片暂时无法用于匹配，请上传一张更清晰的本人照片。 |
| `photo_needs_reupload` | 请重新上传一张清晰的本人照片，以继续完成匹配流程。 |
| `photo_appealed` | 这张照片正在复核中，请先上传一张新的清晰本人照片。 |
| `photo_appeal_rejected` | 这张照片复核未通过，请上传一张新的清晰本人照片。 |

非阻断：`照片正在审核中，你可以先继续完成资料。`

## 手工验收建议

| # | 条件 | 期望 UI / 路由 |
|---|------|----------------|
| 1 | 仅 rejected，无 passing | 上传页红条；问卷入口 → 上传页 |
| 2 | needs_reupload，无 passing | 红条 + 对应 key 文案 |
| 3 | passing + pending_review | 黄条，可点「继续审美偏好」 |
| 4 | passing + 另有 rejected | 灰条轻提示，可继续 |
| 5 | 上传后仍无 passing | 留上传页，不跳转 |
| 6 | 上传后 `nextStep=photo_preference` | 自动进偏好页 |
