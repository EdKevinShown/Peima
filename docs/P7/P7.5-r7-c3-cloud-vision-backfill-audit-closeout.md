## 3. Backfill 参数

**命令**（与 r4-f 相同脚本）：

```bash
cd apps/api
pnpm --filter @peima/api run p75:r4-backfill-vision -- --provider=cloud --dryRun=true
npx dotenv-cli -e ../../.env -- node dist/dev-cli/p75-r4-f-backfill-onboarding-vision-runner.js --provider=cloud --limit=50 --dryRun=true
```

| 参数 | 默认 | 说明 |
|------|------|------|
| `--limit` | `100`（rules/stub）；**`50`（cloud/zhipu 未显式指定时）** | 最多处理 eligible 条数 |
| `--provider` | `rules` | `rules` \| `stub` \| `cloud` \| `zhipu` |
| `--dryRun` | **`true`** | `true`：只 audit，**不** `update` |
| `--onlyMissingVision` | `true` | 跳过已有 `vision` |
| `--includeBlocked` | `false` | `false` 时跳过 blocked review |
| `--userId` | — | 单用户过滤 |
| `--imageIds` | `[]` | 逗号分隔 image id allowlist |
| `--userIds` | `[]` | 逗号分隔 user id allowlist |

**cloud 输出**：`p7.5-r7-c3-cloud-vision-backfill-v1` audit JSON（非 r4-f `sampleTags` 报告）。

## 4. 默认 dryRun / 默认不发 HTTP

| 项 | 默认 |
|----|------|
| CLI `--dryRun` | **`true`**（不写 DB） |
| `PEIMA_ONBOARDING_VISION_CLOUD_DRY_RUN` | **`true`**（registry → mock，无 HTTP） |
| `PEIMA_ONBOARDING_VISION_CLOUD_HTTP_ENABLED` | **`false`** |
| `PEIMA_ONBOARDING_VISION_ENABLED` | **`false`**（未显式开启时 vision 逻辑仍由 CLI 强制 `enabled=true` 仅作用于本次 backfill env 覆盖） |

## 5. Provider 行为

| Provider | 写库 | HTTP | 报告 |
|----------|------|------|------|
| **rules** | `dryRun=false` 时 merge `vision` | 无 | r4-f `p7.5-r4-f-vision-backfill-v1` |
| **stub** | 同上 | 无 | r4-f |
| **cloud** / **zhipu** | 同上；**仅** `detectionScoreJson` | 仅 `real-zhipu` gate + `imageRef` | r7-c3 audit JSON |
| cloud + gate mock/dry-run | 可写 mock/dry-run vision | **跳过**（`cloudHttpSkippedCount`） | 含 `sourceVersionDistribution` |
| cloud + live + allowlist | 可写 zhipu vision | mocked/live **async facade** | `cloudHttpSuccessCount` / `Failed` |

**文件缺失** / 非本地 `imageUrl`：`skipped`，**不 throw**（`image_file_missing` / `image_url_not_local`）。

## 6. Audit 输出字段

`buildCloudVisionBackfillAuditReport` 顶层字段：

| 字段 | 说明 |
|------|------|
| `scannedImages` | 扫描行数 |
| `eligibleImages` | 通过分类的行数 |
| `skippedImages` | 跳过行数 |
| `updatedImages` | `dryRun=false` 且成功 `update` 数 |
| `dryRun` | CLI dryRun |
| `provider` | `cloud` / `zhipu` |
| `sourceVersionDistribution` | 如 `p7.5-r7-cloud-dry-run-v1`、`p7.5-r7-cloud-zhipu-v1` |
| `visionStatusDistribution` | `ok` / `skipped` / `failed` |
| `fallbackReasonDistribution` | 如 `cloud_live_requires_async`、`cloud_zhipu_*` |
| `photoVisualTagDistribution` | 标签计数 |
| `qualityTagDistribution` | 同上 |
| `sceneTagDistribution` | 同上 |
| `unknownTagDroppedCount` | `VISION_CLOUD_UNKNOWN_TAG` 次数 |
| `cloudHttpAttemptedCount` | live zhipu 尝试次数 |
| `cloudHttpSkippedCount` | gate mock / 无 HTTP |
| `cloudHttpSuccessCount` | live 成功（非 fallback zhipu source） |
| `cloudHttpFailedCount` | live 尝试但 fallback |
| `skipReasonDistribution` | `image_file_missing`、`existing_vision` 等 |

另含 `input.*` 元数据；**不含** `imageUrl`、apiKey、prompt、base64、原始 `detectionScoreJson`。

## 7. imageRef（backfill）

- 从 `UserImage.imageUrl` 解析 `/uploads/user-images/{filename}`。
- 在 `UPLOAD_DIR`（默认 `uploads/user-images`）读文件 → `{ kind: "bytes", mimeType, buffer }`。
- **不**持久化 buffer / base64。

---

## 8. Gate / fallback

- **Gate**：与 c0/c1 相同 `resolveCloudVisionAdapter`（dry-run、HTTP enabled、vendor、apiKey、**env allowlist**）。
- **Fallback**：facade 内 rules merge；`fallbackReasonDistribution` 统计；失败 **不** 中断整批 backfill。
- **review / detectionStatus**：update **仅** `detectionScoreJson`；**不** 改 `reviewStatus`、`detectionStatus`、`User.gender`。
