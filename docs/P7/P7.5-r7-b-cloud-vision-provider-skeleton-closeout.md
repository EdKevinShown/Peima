## 1. 一句话结论

**P7.5-r7-b** 在 `apps/api/src/modules/onboarding/vision/` 落地 **Cloud Vision Provider 骨架**：`provider=cloud` 与 legacy `zhipu` 均走 **MockAdapter + Normalizer + Facade**（`CLOUD_DRY_RUN` 默认 **1**），写入扩展后的 `detectionScoreJson.vision`；失败 **fallback rules**，**不 throw** 到上传主链。**未接**真实云 API。

## 3. 行为摘要

| Provider | r7-b 行为 |
|----------|-----------|
| **rules** | **不变**（启发式 + `p7.5-r2-rules`） |
| **stub** | **不变**（固定三标签） |
| **cloud** | MockAdapter → Normalizer → `visionStatus=ok`；`sourceVersion=p7.5-r7-cloud-dry-run-v1` |
| **zhipu** | **legacy**：路由到 **同一** mock/dry-run facade；`provider` 字段仍为 `zhipu` |

**Fallback**：mock `empty` / `refusal` / `timeout`（异常）→ `buildVisionProfileFromRules` + `fallbackUsed=true` + `fallbackReason`。

**敏感字段**：`beautyScore`、`genderGuess`、`faceEmbedding` 等 **不会** 进入 `detectionScoreJson.vision`（strip + 单测断言）。

**上传主链**：facade **catch** 所有异常；`detectionStatus` / `reviewStatus` **不由 cloud 修改**。

## 4. Env 默认值

| 变量 | 默认 |
|------|------|
| `PEIMA_ONBOARDING_VISION_ENABLED` | `false` |
| `PEIMA_ONBOARDING_VISION_PROVIDER` | `rules` |
| `PEIMA_ONBOARDING_VISION_CLOUD_VENDOR` | `mock` |
| `PEIMA_ONBOARDING_VISION_CLOUD_DRY_RUN` | **`1`（true）** |
| `PEIMA_ONBOARDING_VISION_CLOUD_ASYNC` | `1`（true，r7-b 未接线异步队列） |
| `PEIMA_ONBOARDING_VISION_CLOUD_MAX_CONCURRENCY` | `4` |
| `PEIMA_ONBOARDING_VISION_CLOUD_MOCK_SCENARIO` | `normal` |
| `PEIMA_ONBOARDING_VISION_TIMEOUT_MS` | `8000` |

**安全**：未显式配置时 **不会** 注册真实 HTTP adapter；`CLOUD_DRY_RUN=0` 时 facade 仍 **强制** mock 并打 `VISION_CLOUD_DRY_RUN_FORCED`。
