## 1. 一句话结论

P7.6-r1 只做 **legacy matching dependency audit**：梳理旧照片匹配、**两套** Preview Pool（onboarding vs batch）、20D scoring、RRM Top2、`MatchResult` / `finalScore` / worker 主链边界，为后续 **PhotoVisual First Pool → 20D Bidirectional Ranking → RRM Top2 Final Selector** 的 **shadow** 实现做准备。本轮**不改代码**、**不实现 scorer**、**不删除**旧逻辑。

## 4. 当前 PreviewPool / candidate pool 依赖

### 4.1 Onboarding pool 生成（`generate` 摘要）

**入口**：`OnboardingPhotoPreviewPoolService.generate(viewerUserId)`  
**流程**：

1. 硬门控：审美完成、≥1 图、二元 gender、≥6 gated candidates

## 5. 当前 20D scoring 依赖

### 5.1 算法文件

| 文件 | 函数 | 方向 |
|------|------|------|
| `apps/worker/src/jobs/matching-score.ts` | `computeProfileScore` | **单向**：viewer profile ↔ candidate profile（20 轴平均相似度） |
| 同上 | `computePreferenceScore` | **单向**：viewer `UserPreference` → candidate 人口统计字段 |
| 同上 | `computeStyleScore` | **单向**：viewer `styleTags` ↔ candidate `UserImage.styleTags` |
| 同上 | `computeFinalScoreV1` | 加权：`0.35·preview + 0.30·pref + 0.15·style + 0.20·profile` |
| `apps/worker/src/jobs/relationship-profile-score-v2.ts` | `computeRelationshipProfileScoreV2` | 20 轴 V2（bands/caps） |
| `apps/api/src/modules/matching/matching-relationship-profile-score-v2.ts` | API 投影 | 只读 GET |

**`apps/` 内无** `AtoB20DFit` / `BtoA20DFit` / `mutual20DFit` / `bidirectional` 实现（仅 P7.6 设计稿）。

### 5.2 输入来源

| 输入 | 来源 |
|------|------|
| 20 维画像 | `UserProfile`（问卷 G1-R 轴） |
| 择偶偏好 | `UserPreference` |
| 照片风格（v1 style 项） | `UserImage.styleTags`（worker 取候选首张/最新图） |
| Pool 项 | `PreviewPoolItem.baseScore` + `rankInPool`（legacy） |

### 5.3 `scoreShadowV2` 与 `finalScore`

| 字段 | 写入 | 是否决定 worker 赢家 |
|------|------|----------------------|
| `MatchResult.finalScore` | `computeFinalScoreV1` 的 `finalScore` | **是** |
| `matchInsights.scoreShadowV2` | `buildWorkerMatchInsightsForBestMatch` | **否**（shadow/展示） |
| `matchInsights.top2ScoreSnapshot` | 同上 | **否** |

### 5.4 不可改（P7.6 初期）

- `computeFinalScoreV1` 权重与 worker 排序逻辑  
- `MatchResult.finalScore` / `candidateUserId` 写入语义  
- 现有 `scoreShadowV2` 契约（可 **新增** 并行 shadow 字段，不替换）

### 5.5 P7.6 Stage 2 建议接入点

在 **PhotoVisual pool shadow 的候选集内**，新增：

- `AtoB20DFit`：viewer preference + profile 需求 vs candidate `UserProfile`  
- `BtoA20DFit`：反向  
- `mutual20DFit`：harmonic mean 或 0.5/0.5 − penalty  

**挂载位置**：新 `PhotoFirstMutualMatchingShadowV1.stage2TwentyD`；或扩展 `matchInsights` 新 key（`appliedToFinalScore: false`）。**不要**直接改 `computeFinalScoreV1` 直到 allowlist apply 阶段。
