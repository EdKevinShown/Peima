## 3. Shadow payload 可评估字段

以下字段来自 **r2 contract** 与 **r3 实现**，可用于离线聚合（**分母定义见 §4**）：

| 字段路径 | 用途 |
|----------|------|
| **`shadow.decision`** | **`same_as_baseline` / `switch_to_top2_candidate` / `no_shadow_decision`** 分布。 |
| **`shadow.reasonCode`** | 细因直方图、与 **`blockReasons`** 交叉分析。 |
| **`comparison.sameAsBaseline`** | 与 **`decision`** 一致性校验、冗余展示指标。 |
| **`comparison.switchSuggested`** | 与 **`switch_to_top2_candidate`** 对齐观测。 |
| **`comparison.top2GapBand`** | Top2 分差带分布（**`small` / `medium` / `large` / `unknown`**）。 |
| **`comparison.scoreDeltaBand`** | r3 多为 **`unknown`**；后续若补充 V2 delta 可再用。 |
| **`comparison.riskFlags`** | 扩展风险标签（r3 多为空数组）。 |
| **`guardrails.blocked`** | 是否进入 guardrail 阻断路径。 |
| **`guardrails.blockReasons`** | 阻断原因多重集合（闭集见 **r2 §7**）。 |
| **`inputPresence.scoreShadowV2`** | 合规 V2 是否存在（观测数据完整度）。 |
| **`inputPresence.rrmV2Top2Selector`** | Selector blob 是否存在。 |
| **`inputPresence.selectedTop2`** | Top2 数组是否存在且非空语义由生成器定义。 |
| **`inputPresence.scoreShadowV1LegacyPresent`** | **仅**历史字段观测；**不参与** pass/fail，**不作为**质量打分输入。 |
| **`generatedAt`** | 时间序列、按批次切片。 |

**明确：** **`scoreShadowV1LegacyPresent`** 只用于确认 **旧行残留比例**；**不得**用于「shadow 质量好坏」的自动判定。

## 4. 核心指标定义

以下比例均在 **某一评估样本集合 S** 上定义（例如：一段时间内的 **`MatchResult`** 行，或一次本地 batch 运行产生的行）。记 **`N = |S|`**， **`N_shadow`** = **`S`** 中存在非空 **`matchInsights.rrmDecisionShadow`** 的行数。

| 指标 | 定义 |
|------|------|
| **`shadowCoverageRate`** | **`N_shadow / N`**。若只统计 flag 打开时期，**分母**可收窄为「预期应写 shadow 的队列」— **r6** 需固定口径。 |
| **`validShadowRate`** | **`decision ∈ { same_as_baseline, switch_to_top2_candidate }`** 的行数 / **`N_shadow`**（在 **`N_shadow > 0`** 时；否则记 **0** 或 **N/A**，**r6** 固定）。 |
| **`noShadowDecisionRate`** | **`decision === no_shadow_decision`** 的行数 / **`N_shadow`**。 |
| **`sameAsBaselineRate`** | **`decision === same_as_baseline`** 行数 / **`max(1, N_valid)`** 其中 **`N_valid`** = 有效 shadow 行数（同 **`validShadowRate`** 分子）；或 / **`N_shadow`** — **r6** 选一种并全链路一致。 |
| **`switchSuggestedRate`** | **`decision === switch_to_top2_candidate`** 行数 / **`max(1, N_valid)`**（或 / **`N_shadow`**，与上同口径）。 |
| **`blockedRate`** | **`guardrails.blocked === true`** 行数 / **`N_shadow`**。 |
| **`missingInputRate`** | **`blockReasons`** 与 **`{ missing_score_shadow_v2, missing_rrm_v2_top2_selector, empty_selected_top2 }`** 交集非空的行数 / **`N_shadow`**。 |
| **`contextBlockedRate`** | **`blockReasons`** 与 **`{ has_low_band, has_strong_conflict_band, any_below_suggested_floor, top2_gap_large }`** 交集非空的行数 / **`N_shadow`**。 |
| **`invalidSelectorRate`** | **`blockReasons`** 与 **`{ invalid_selector_payload, parse_error, reason_not_ok, eligible_not_true }`** 交集非空的行数 / **`N_shadow`**。 |
| **`unexpectedExceptionRate`** | **`blockReasons`** 含 **`unexpected_exception`** 的行数 / **`N_shadow`**。 |
| **`v1LegacyPresenceRate`** | **`inputPresence.scoreShadowV1LegacyPresent === true`** 行数 / **`N`**（或 / **`N_shadow`**）；**仅**用于历史残留观测。 |

**注意：** 多标签 **`blockReasons`** 可同时命中多个「率」分子；总占比可 **>100%** 若按行重复计数 — **r6** 可改为「每行只计主 **`reasonCode`**」或「每 **`blockReason` 维度独立计数**」；**r5** 只定义语义。

## 5. 指标解释方式

| 观察 | 解读 |
|------|------|
| **`sameAsBaselineRate` 高** | **RRM Top2 视角**与当前 **worker winner** 一致度高 → **对账风险低**；亦可能表示 **Top2 与主排序强对齐**、**可切换增益有限**。 |
| **`switchSuggestedRate` 高** | **RRM** 经常在 Top2 内指向 **与 baseline 不同** 的候选 → **仅提示**潜在差异；**必须**人工 / 离线评审；**不可**直接作为上线或改 **`candidateUserId`** 的依据。 |
| **`blockedRate` 高`** | **Guardrails** 频繁触发 → **selector 输入质量**、**池子风险结构**或 **阈值策略**需优化；**不是**「shadow 坏了」，而是 **安全面收紧**。 |
| **`missingInputRate` 高`** | **Shadow 前置数据**（**V2** / **selector** / **Top2**）不完整 → **优先修数据链路**与 **worker 写入条件**，而非扩决策。 |
| **`contextBlockedRate` 高`** | **风险 contextFlags** 占比高 → **候选池**或 **profile 可用性**、**V2 分数分布**需运营 / 产品侧复盘。 |
| **`invalidSelectorRate` 高`** | **解析 / 版本 / eligible-reason** 类问题多 → **契约对齐**、**版本漂移**或 **异常池**需工程排查。 |
| **`unexpectedExceptionRate` > 0`** | **稳定性问题** → **最高优先级**修复生成器 / 运行时异常路径（**r3** 承诺不 throw 主流程，但 payload 仍可能暴露 **`unexpected_exception`**）。 |
| **`v1LegacyPresenceRate`** | 仅确认 **历史 v1** 残留比例；**不**参与质量决策。 |

## 8. Gating rule for future decision pilot

在考虑任何 **「RRM decision pilot」**（shadow **升格**为可执行或半执行策略）之前，建议 **同时**满足：

| 门槛 | 说明 |
|------|------|
| **`unexpectedExceptionRate = 0`** | 在固定样本窗内 **零** **`unexpected_exception`**。 |
| **`missingInputRate` ≤ 阈值** | 阈值由产品 / 数据共同定义（例如 **低于 5%**）；**r6** 给实测建议值。 |
| **`invalidSelectorRate` ≤ 阈值** | 契约类错误应接近 **0**；偶发需有 **根因** 说明。 |
| **`blockedRate` 可解释** | 高阻断需有 **业务解释**（池子结构 / 阈值 / 季节性），而非未知噪声。 |
| **`switchSuggestedRate` 不得单独作为上线依据** | **必须**经过 **人工 / 离线** 对 **`switch_to_top2_candidate`** 案例的 **分层审查**（质量、合规、用户体验）。 |
| **至少一轮真实 DB / 生产等价 batch evaluation** | 在 **可控环境** 复跑 **r6** 类流程，形成 **可复现报告**。 |
| **Feature flag 默认仍关闭** | **`PEIMA_M6_RRM_DECISION_SHADOW_ENABLED`** 与任何未来 **pilot flag** **默认 off**；**显式**灰度与回滚方案。 |

**强调：** **r5 / 本文档阶段不进入 decision pilot**；**不**将 **`switch_to_top2_candidate`** 写回 **`MatchResult.candidateUserId`**。
