- `withScoreShadowV1Legacy` 与 `inputPresence.scoreShadowV1LegacyPresentTrue` 属于不同层级统计：
  - `withScoreShadowV1Legacy` 表示历史 `matchInsights` 顶层 legacy `scoreShadow` 字段是否存在。
  - `inputPresence.scoreShadowV1LegacyPresentTrue` 表示 `rrmDecisionShadow` 内部 `inputPresence` 观测字段。
  - 二者均不代表新链路依赖 scoreShadow v1。
