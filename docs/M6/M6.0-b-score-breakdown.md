## 3. `scoreBreakdown` 形状（viewer-safe）

```ts
{
  previewPoolScore: number | null;
  preferenceScore: number | null;
  styleScore: number | null;
  profileScore: number | null;
  source: "reason_summary_v1" | "missing" | "parse_failed";
}
```

- **`source: "reason_summary_v1"`**：四数均在 **[0, 1]** 且整句匹配成功。  
- **`"missing"`**：`reasonSummary` 为 **null** 或 **空**（trim 后）。  
- **`"parse_failed"`**：有文本但 **无法按 v1 句式解析** 或 **数值越界 / 非有限数**；四数均为 **`null`**。  
- 响应中 **不包含** `reasonSummary` 原文的副本（仅数值与 `source` 枚举）。
