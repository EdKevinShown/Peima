## 5. Flag off/on 语义确认

### Flag off

- `PEIMA_M6_RRM_BOUNDED_DECISION_ENABLED` 未设置 / `"0"` / `"true"` / `"TRUE"` 时均不启用 read-layer true bounded decision。
- resolved projection 保持 M6.5/M6.6 既有行为路径。
- 不应出现 `rrm_bounded_decision_read_layer` 作为 resolved/decision source。

### Flag on

- 仅 `PEIMA_M6_RRM_BOUNDED_DECISION_ENABLED="1"` 且 gates 全通过时才激活。
- valid activation（source 切换、targets 切换、owner mismatch warning 保留）已由 `matching-result-display-candidate.spec.ts` 覆盖。
- 多种 fallback 分支（含 malformed、guardrail、missing input presence、target invalid、user/profile missing）已由测试覆盖并验证“不崩 + 回退”。

### Fallback

- flag on 但任一 gate 不满足时，保持旧 projection 并进入 fallback 路径。
- fallback 不应导致接口抛错到页面层。

### Rollback

- 关闭 flag 即回旧路径。
- 不需要 DB rollback。
- `candidateUserId` / `finalScore` 持久化不变。
- observation script / admin summary API 继续可用于观测。
