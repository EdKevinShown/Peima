# M6.10-C2 — Resolved Final Score Projection

## 1. 本轮目标

- 让 `resolvedCandidateUserId` 在 API projection 层拥有自己的 `resolvedFinalScore`。
- 复用 M6.10-C1 新增的 `matchInsights.top2ScoreSnapshot`。
- 本轮仅改 API projection/类型，不改 UI。

## 2. 修改文件

- `apps/api/src/modules/matching/matching-result-display.ts`
- `apps/api/src/modules/matching/matching.service.ts`
- `apps/api/test/matching-result-display-candidate.spec.ts`
- `apps/web/src/api/matching.ts`
- `docs/M6/M6.10-C2-resolved-final-score-projection.md`

## 3. 新增 API 字段

在 `GET /matching/result/:userId` projection 中新增：

- `resolvedFinalScore: number | null`
- `resolvedScoreOwnerCandidateUserId: string | null`
- `resolvedScoreSourceType: string | null`
- `scoreProjectionFallbackUsed: boolean`
- `scoreProjectionFallbackReason: string | null`

## 4. Projection 逻辑

新增 `applyResolvedScoreProjection(...)`（read-layer helper）：

- 输入：`resolvedCandidateUserId`、`baselineCandidateUserId`、`baseline finalScore`、`matchInsights`
- 优先尝试从 `top2ScoreSnapshot.items` 找到 `resolvedCandidateUserId` 对应项
- 命中且 `finalScore` 有效时：
  - `resolvedFinalScore = snapshot item.finalScore`
  - `resolvedScoreOwnerCandidateUserId = snapshot owner/candidate`
  - `resolvedScoreSourceType = "top2_score_snapshot"`
  - `scoreProjectionFallbackUsed = false`
  - `scoreProjectionFallbackReason = null`
- 未命中或异常时回落到 baseline `finalScore`，并标记 fallback

## 5. Fallback 行为

本轮使用闭集 fallback reasons：

- `top2_score_snapshot_missing`
- `resolved_candidate_missing`
- `resolved_candidate_not_in_top2_snapshot`
- `resolved_score_missing`
- `malformed_top2_score_snapshot`
- `unexpected_exception`

所有分支均不 throw 到页面层。

## 6. Score owner 行为

- 成功命中 snapshot 且 resolved score 可用时：
  - `scoreOwnerCandidateUserId` 更新为 resolved score owner；
  - 若 owner 与 `resolvedCandidateUserId` 一致，不再保留 `score_owner_mismatch`。
- fallback 时：
  - `scoreOwnerCandidateUserId` 保持 baseline；
  - 当 resolved candidate 与 baseline owner 不一致时，保留 `score_owner_mismatch`。

## 7. 不变性确认

- 不改 `candidateUserId`
- 不改 `finalScore`
- 不改 worker
- 不改 RRM resolver
- 不改 schema / migration
- 不改 UI
- 不恢复 / 不依赖 scoreShadow v1
