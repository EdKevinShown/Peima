## 7. 当前最终链路结论

当 RRM 最终展示对象为 B 时：

- `resolvedCandidateUserId = B`
- API 可从 `top2ScoreSnapshot` 找到 B 的分数
- `resolvedFinalScore = B` 的分数
- FinalMatchPage 主展示优先使用 `resolvedFinalScore`

同时保持：

- `candidateUserId` 仍是 baseline 持久化值
- `finalScore` 仍是 baseline 持久化值
- 回滚仍可通过关闭 RRM read-layer flag 完成
