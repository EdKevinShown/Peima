# M6.8-C1 — True Bounded Decision Read-layer Activation

## 1. 本轮目标

- 在 API read-layer（`GET /matching/result/:userId`）接入 bounded decision override。
- 仅当 flag 与 gates 全通过时，切换 `resolvedCandidateUserId` 与 chat/timeline/feedback targets。
- 不改持久化 winner，不改 `finalScore`，不改 worker。

## 2. 修改文件

- `apps/api/src/modules/matching/matching-result-display.ts`
- `apps/api/src/modules/matching/matching.service.ts`
- `apps/api/test/matching-result-display-candidate.spec.ts`
- `docs/M6/M6.8-C1-true-bounded-decision-read-layer-activation.md`

## 3. Feature flag

- 开关：`PEIMA_M6_RRM_BOUNDED_DECISION_ENABLED`
- 规则：仅字面量 `"1"` 开启；未设置 / `"true"` / `"TRUE"` / `"yes"` / `"0"` 均关闭。
- flag off：完全保持 M6.5/M6.6 既有 resolved projection，不写额外 fallback 状态。

## 4. Activation gates

当前实现仅在以下条件全满足时激活：

- flag on
- `matchInsights.rrmBoundedDecision` 存在且可解析
- `schemaVersion=1`
- `sourceType="rrm_bounded_decision"`
- `sourceVersion="m6.3-rrm-bounded-decision-v1"`
- `mode="dry_run"`
- `decision="would_switch_to_rrm"`
- `wouldSwitch=true`
- `fallbackUsed!==true` 且 `fallbackReason==null`
- `guardrails.blocked!==true`
- `inputPresence.scoreShadowV2===true`
- `inputPresence.rrmDecisionShadow===true`
- `inputPresence.rrmV2Top2Selector===true`
- `inputPresence.selectedTop2===true`
- `boundedRef.id` 存在
- bounded target 不等于 baseline
- bounded target 在 `rrmV2Top2Selector.selectedTop2` 闭包内
- bounded target 对应 `User` / `UserProfile` 均存在

## 5. Output behavior

激活成功时：

- `decisionCandidateUserId = bounded target`
- `decisionSourceType = "rrm_bounded_decision_read_layer"`
- `resolvedCandidateUserId = bounded target`
- `resolvedSourceType = "rrm_bounded_decision_read_layer"`
- `chatTargetUserId` / `timelineTargetUserId` / `feedbackTargetUserId = bounded target`
- `fallbackUsed = false`
- `fallbackReason = null`
- `consistencyWarnings` 追加 `rrm_bounded_read_layer_active`（info）

并保持：

- `candidateUserId`（DB 行）不变
- `finalScore` 不变
- `scoreOwnerCandidateUserId` 保持 baseline
- 若 resolved 与 owner 不一致，确保保留 `score_owner_mismatch` / `explanation_owner_mismatch`

## 6. Fallback behavior

flag on 但任一 gate 失败时：

- 不 throw 到页面
- 保持既有 resolved projection
- 若原 projection 未 fallback：设置 `fallbackUsed=true` 且写闭集 `fallbackReason`
- 追加 warning：`rrm_bounded_read_layer_fallback`（info）

fallback reason 闭集实现：

- `bounded_decision_missing`
- `bounded_decision_malformed`
- `incompatible_mode`
- `decision_not_switch`
- `would_switch_false`
- `bounded_target_missing`
- `bounded_target_user_missing`
- `bounded_target_profile_missing`
- `guardrail_blocked`
- `bounded_fallback_reason_present`
- `missing_score_shadow_v2`
- `missing_rrm_decision_shadow`
- `missing_rrm_v2_selector`
- `missing_selected_top2`
- `target_same_as_baseline`
- `target_outside_top2`
- `unexpected_exception`

## 7. 不变性确认

- 不改 `MatchResult.candidateUserId`
- 不改 `finalScore`
- 不改 worker winner / ranking
- 不改 batch-match 主决策
- 不改 RRM resolver
- 不改 Prisma schema / migration
- 不恢复 / 不依赖 scoreShadow v1
- 不输出 raw `matchInsights` / raw selectedTop2 IDs 到 API response
