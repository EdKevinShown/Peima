# M6.0-J — relationshipProfileScore v2 产品要求（用户可见基础适配指数）

> **定位**：**`relationshipProfileScore` v2** 是面向用户的 **0–100 基础关系画像适配指数**（**`displayScore100`**），与当前 worker/API 中 **0–1 区间、偏温和** 的 **`relationshipProfileScore` / `profileScore`（v1）** 目标不同。  
> **关联**：**M6.0-G3**（五态压力观测）、**M6.0-Q2**（30 canonical）、**M6.0-D**（finalScore v2 shadow 规划）、**M6.0-C/B**（scoreBreakdown / shadow 字段）。  
> **本轮边界（实现约束）**：v2 **先走 shadow**，**不替换** **`MatchResult.finalScore`**，**不改** worker 胜者排序、**不改** **`candidateUserId` / `displayCandidateUserId`**、**不改** RRM。

---

## 1. 总目标

- **用户可见**：最终展示为 **0–100** 的 **基础适配指数**，文案与色带可围绕分段含义展开。  
- **拒绝「全员温和带」**：v2 **不能** 长期挤在 **~0.75–0.90（0–1 语义）** 或等价窄带；**不能** 仅等于 **20 维均值相似度** 一类单一平滑量，而无冲突与红线张力。

---

## 2. 分布与校准目标（设计验收口径）

v2 在 **理论上有义务** 覆盖 **0–100 全区间**（不要求单次样本集必占满，但 **映射与规则** 须允许出现）：

| 目标 | 说明 |
|------|------|
| **全区间可达** | **0–100** 任一段在 **合适输入** 下 **可出现**（含极端构造验收）。 |
| **高度适配** | 高度适配样本应能达到 **90–100**。 |
| **普通适配** | 普通适配样本大致落在 **65–85**。 |
| **明显不适配** | 明显不适配样本应能落到 **40–65**（与下表 **40–60** 段衔接；细段可在实现稿中微调，但须保留「中低段可区分」）。 |
| **强冲突 / 红线 / 多核心轴冲突** | 应能落到 **0–40**。 |

**压力测试样本（当前约定）**：**All-A / All-B / All-C / All-D** **暂不直接等同**「低质量答卷」，但须作为 **评分系统压力测试**，用于观察 **分数是否被充分拉开**、**校准是否过饱和或过扁**。**Normal** 与 **混合态** 作为对照，**不得** 单独由直线卷定义「好用户」。

---

## 3. 双轨分数模型（必须区分）

| 名称 | 范围 | 含义 |
|------|------|------|
| **`rawCompatibilityScore`** | **0–1** | **原始**关系画像适配分：保留 **可解释、可微调的连续量**（例如多轴惩罚、权重、缺口后的合成），供调试与 shadow 对齐。 |
| **`displayScore100`** | **0–100** | **用户展示分**：由 **`rawCompatibilityScore`** 经 **calibration / 分段映射（piecewise）** 等得到；**不要求** **`displayScore100 = raw × 100`** 的简单线性缩放。 |

**实现提示**：允许 **logistic、分段线性、cap/floor、冲突加罚后的再归一** 等；须在 **设计文档 / ADR** 中写清 **单调性或分段单调性**、**边界行为** 与 **反例**（避免同一展示分对应 wildly different raw）。

---

## 4. 用户可见分数段含义（文案与 UI 锚点）

以下分段为 **产品语义锚点**（实现时可 **±2** 微调边界，但 **须保留五档语义** 与 **0–40 强警示**）：

| 分段 | 含义（用户向） |
|------|----------------|
| **0–40** | **强冲突 / 不建议**（红线、多核心轴不可调和、或模型定义的强负向组合）。 |
| **40–60** | **低适配 / 谨慎**（明显错配或高不确定）。 |
| **60–75** | **中等适配**。 |
| **75–88** | **较好适配**。 |
| **88–100** | **高度适配**。 |

**与 §2 的对应关系**：**明显不适配 40–65** 主要落在 **40–60** 上沿与 **60–75** 下沿的衔接区；**普通 65–85** 主要落在 **60–75** 与 **75–88**；**高度 90–100** 落在 **88–100** 上沿（实现校准表时统一即可）。

---

## 5. 落地与闸门（与主链隔离）

1. **Shadow 先行**：v2 写入 **`matchInsights.scoreShadow`**（或等价 shadow 字段路径），**不写入** **`MatchResult.finalScore`**，**不改变** worker 排序与 **`candidateUserId`**，**不触碰** RRM。  
2. **前端主分数切换（M6.0-H）**：可在 **方案层** 约定「默认展示 **`displayScore100`**、保留 v1 为次要/调试」等，**须** 与本篇 §3–§4 一致。  
3. **回归**：延续 **G3** 类 **All-A/B/C/D + Normal** 用例，验收 **展示分跨度** 与 **分段占比** 是否满足 §2，而非仅看 raw。
