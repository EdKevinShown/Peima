# M6.2-r1 — RRM Decision Shadow Batch Evaluation Plan

## 1. 本轮目标

- **M6.1** 已完成：**`rrmDecisionShadow`** **payload** 设计（**r1–r2**）、worker **shadow-only** 写入（**r3**）、**回归矩阵**（**r4**）、**评估指标**（**r5**）、本地 DB **smoke**（**r6 / r6b**，其中 **r6b** **`sampleSize=1`** 且 **`rrmDecisionShadow`** 落库验证通过）、以及 **push prep** 汇总（**r7**）。
- **M6.2** 目标：在 **更大样本** 上对 **`matchInsights.rrmDecisionShadow`** 做 **批量评估** 与 **只读聚合**，为后续 **离线报告**、**运营 / 工程观测** 做准备。
- **M6.2-r1（本文）**：**仅**输出 **评估计划**（样本、指标、分母、分布、脚本方向、**pilot 门槛**）；**不写代码**、**不实现**聚合器。
- **不进入** **RRM decision pilot**；**不让** **`switch_to_top2_candidate`** 在产线**生效**（仍为 **观测 / 落库** 侧车）。

## 3. 评估目标

**M6.2** 批量评估要回答的问题（**均为观测性问题**；**答案不足时记录「样本不足」**，**不虚构结论**）：

| 问题 | 说明 |
|------|------|
| **`shadowCoverageRate` 是否足够高？** | 在固定样本 **`S`** 上，**`N_shadow / N_total`** 是否接近预期（例如 flag 打开批次内应接近 **1.0**）；偏低则优先查 **队列 / flag / 写入条件**。 |
| **`sameAsBaselineRate` 是否稳定？** | **RRM Top2** 视角与 **worker baseline** 一致比例；**高**降低对账风险，**也可能**表示 Top2 与主排序强对齐 — **需结合** **`switchSuggestedRate`** 与业务语境。 |
| **`switchSuggestedRate` 是否异常偏高？** | **仅提示** Top2 内与 baseline **不一致** 的频率；**不可**单独作为改 **`candidateUserId`** 或上线依据。 |
| **`blockedRate` 是否可解释？** | **`guardrails.blocked`** 占比是否与 **池子结构**、**阈值**、**风险带**一致；需 **人工归因**（非自动 pass/fail）。 |
| **`missingInputRate` 是否说明数据链路不完整？** | **V2 / selector / Top2** 缺失类 **`blockReasons`** 是否集中爆发。 |
| **`invalidSelectorRate` 是否说明 selector payload 不稳定？** | **解析 / eligible / reason** 类原因是否异常。 |
| **`unexpectedExceptionRate` 是否为 0？** | **稳定性** 门槛：**>0** 必须优先工程排查（见 **§8**）。 |
| **`v1LegacyPresenceRate` 是否仍有历史残留？** | **仅**确认旧行 **`scoreShadowV1LegacyPresent`**；**不参与** shadow「质量」门槛（见 **§5**）。 |
| **RRM shadow 是否具备进入 bounded decision pilot 的前提？** | **综合** **§8** 门槛 + **样本量** + **可解释性**；**M6.2-r1 不给出**「可以 pilot」的结论，只定义 **收集证据** 后再评审的流程。 |

## 4. 样本来源计划

| 来源 | 说明 |
|------|------|
| **本地 DB 新生成 `MatchResult`** | **`batch_match_queue` `waiting`** → **`PEIMA_M6_RRM_DECISION_SHADOW_ENABLED=1`** → **worker `batch-match`**（与 **r6b**、**`m6-r6b-shadow-smoke.mjs`** 同类流程）；**推荐**作为 **可控**、**可复现** 主来源。 |
| **历史 `MatchResult` 中带 `rrmDecisionShadow` 的行** | **只读**扫描 **`match_insights`** JSON；**时间窗** / **`createdAt`** / **`since`** 由 **M6.2-r2** 脚本参数固定；**注意** flag 未开时期 **不应**出现新写入 — 若存在需核对 **数据来源**（迁移 / 手工 / 环境混用）。 |
| **真实 ID** | **评估报告与脚本 stdout**：**不写** **`userId` / `matchResultId` / `conversationId`**；仅 **计数、比例、时间窗、环境、schemaVersion**。 |

### 4.1 推荐最小样本（可调整）

| 阶段 | **`N_total`（`|S|`）** | 用途 |
|------|-------------------------|------|
| **Smoke** | **`N >= 1`** | 链路通（**M6.1-r6b** 已满足 **smoke**）。 |
| **Local batch** | **`N >= 10`** | **分布初探**、**分母稳定**、发现 **长尾 `reasonCode` / `blockReasons`**。 |
| **Pre-pilot evaluation** | **`N >= 50`**（或后续再定） | **门槛评审**前更可信的 **率** 与 **稳定性** 观测。 |

**原则：** 若本地 **无法** 凑够目标 **`N`**，**必须**在报告中写 **「样本不足」** 与 **原因**（无队列、无 active pool、环境不可用等），**不得**用单点 smoke **外推**大样本结论。

## 5. 指标定义

**沿用 **M6.1-r5** 核心指标**；**M6.2** 在全链路固定下列 **符号与分母**（与 **r6b** 文档口径对齐，便于对比）。

### 5.1 符号

| 符号 | 定义 |
|------|------|
| **`S`** | 评估样本集合（由 **§4** 定义的筛选条件确定的一族 **`MatchResult`** 行）。 |
| **`N_total`** | **`N_total = |S|`**（**`sampleSize`** 在 summary JSON 中可与 **`N_total`** 同义）。 |
| **`N_shadow`** | **`S`** 中 **`matchInsights.rrmDecisionShadow`** **存在且非空**（按实现可细化：对象存在且含 **`schemaVersion`/`sourceType`**）的行数。 |
| **`N_validShadow`** | **`N_shadow`** 的子集：**`shadow.decision ∈ { same_as_baseline, switch_to_top2_candidate }`** 的行数。 |

### 5.2 指标与分母（**M6.2 固定口径**）

| 指标 | 分子 | 分母 | 备注 |
|------|------|------|------|
| **`sampleSize`** | — | **`N_total`** | 报告主表 **`N`**。 |
| **`shadowCoverageRate`** | **`N_shadow`** | **`N_total`** | 若收窄为「flag 打开批次」，**须在报告中声明** **`S`** 定义。 |
| **`validShadowRate`** | **`N_validShadow`** | **`N_shadow`**；若 **`N_shadow=0`** 记 **`N/A`** 或 **0**（**r2 实现时二选一并写死**）。 |
| **`noShadowDecisionRate`** | **`decision === no_shadow_decision`** 行数 | **`N_shadow`** | |
| **`sameAsBaselineRate`** | **`decision === same_as_baseline`** 行数 | **`N_shadow`**（与 **r6b** 一致，便于 **`N` 小** 时解读） | **可选**附录再给 **`/ max(1, N_validShadow)`** 版本，**不得**混用而不声明。 |
| **`switchSuggestedRate`** | **`decision === switch_to_top2_candidate`** 行数 | **`N_shadow`**（同上） | |
| **`blockedRate`** | **`guardrails.blocked === true`** 行数 | **`N_shadow`** | |
| **`missingInputRate`** | **`blockReasons`** 与 r5 集合 **`{ missing_score_shadow_v2, missing_rrm_v2_top2_selector, empty_selected_top2 }`** 交集非空 | **`N_shadow`** | 多标签可导致与其他「率」分子重叠。 |
| **`contextBlockedRate`** | **`blockReasons`** 与 r5 **context** 集合交集非空 | **`N_shadow`** | 同上。 |
| **`invalidSelectorRate`** | **`blockReasons`** 与 r5 **invalid** 集合交集非空 | **`N_shadow`** | 同上。 |
| **`unexpectedExceptionRate`** | **`blockReasons`** 含 **`unexpected_exception`** | **`N_shadow`** | |
| **`v1LegacyPresenceRate`** | **`inputPresence.scoreShadowV1LegacyPresent === true`** | **`N_total`** | **仅历史残留观测**；**不作为**质量门槛或 pilot 硬条件。 |

## 6. 分布统计

建议在 **M6.2-r2** 聚合输出中包含（**匿名计数**）：

### 6.1 **`decision` distribution**

- **`same_as_baseline`**
- **`switch_to_top2_candidate`**
- **`no_shadow_decision`**

### 6.2 **`reasonCode` distribution**

- 对 **`shadow.reasonCode`**（或契约等价字段）做 **频次表**；输出 **Top-K**（例如 **K=10**），**余桶**合并为 **`other`**。

### 6.3 **`blockReasons` distribution**

- 对 **`guardrails.blockReasons`** 做 **多重集** 展开后 **按 tag 频次**；输出 **Top-K**；**同一行** 可贡献多个 tag（与 **r5** 一致：**行级率**可 **>100%** 若误用行重复计数 — **脚本应明确**「按行」vs「按 tag 次」两种视图）。

### 6.4 **`inputPresence`**

- **`scoreShadowV2`**：**true / false** 计数
- **`rrmV2Top2Selector`**：**true / false** 计数
- **`selectedTop2`**：**true / false** 计数
- **`scoreShadowV1LegacyPresent`**：**true / false** 计数（**legacy 观测**）

## 7. 只读聚合脚本建议（**M6.2-r2 实现**，**r1 不编码**）

为 **M6.2-r2** 预留脚本方向（**文件名 r2 再最终确认**）：

| 候选路径 | 说明 |
|----------|------|
| **`packages/database/scripts/m6-r2-shadow-evaluation-summary.mjs`** | 与 **M6.2** 里程碑对齐。 |
| **`packages/database/scripts/m6-rrm-decision-shadow-eval.mjs`** | 与 **M6.1** 命名延续。 |

**语义（要求）：**

- **只读 DB**（**`SELECT`** / Prisma **`findMany`**）；**不写 DB**、**不调用** LLM、**不改** **`MatchResult`**。
- 查询 **`match_insights`** 中带 **`rrmDecisionShadow`** 的 **`MatchResult`**（筛选条件：**`since` / `limit` / flag 时段** 等在 r2 定义）。
- **stdout**：**匿名 JSON summary**（计数、比例、`schemaVersion` 分布、`sourceVersion` 分布）；**不输出**完整 **`userId` / `matchResultId` / `conversationId`**。
- **可接受 CLI 参数（建议）**：**`--limit`**、**`--since`**（ISO 或 epoch）、**`--json`**（纯 JSON 一行）、**`--pretty`**（缩进）。

**运行方式：** 与 **`m6-r6b-shadow-smoke.mjs`** 类似，推荐 **`node --env-file=.env ...`** 或 **`pnpm exec dotenv -e ../../.env -- node ...`**（以仓库惯例为准）。

## 8. 决策门槛建议（**future bounded decision pilot**）

以下 **不是**「自动批准 pilot」；**是** **工程 / 产品评审前** 的 **最低证据门槛**建议：

| 门槛 | 建议 |
|------|------|
| **`unexpectedExceptionRate`** | **必须为 0**（在 **`N_shadow >= 10`** 的本地 batch 上复测）；**>0** → **阻塞** pilot 讨论直至修复。 |
| **`invalidSelectorRate`** | **必须很低**（具体阈值 **M6.2 报告**中给出观测值后再定；**原则**：无持续 **parse / eligible** 类系统性错误）。 |
| **`missingInputRate`** | **必须可解释**（偶发 vs 结构性缺失；结构性 → **先修数据链路**）。 |
| **`blockedRate`** | **必须可解释**（与 **guardrail** 设计一致，而非随机异常）。 |
| **`switchSuggestedRate`** | **不得**单独作为上线或改 **`candidateUserId`** 依据；**须**结合人工 / 离线评审。 |
| **样本量** | **至少一轮** **`N_total >= 10`** 本地 batch；**更理想** **`N_total >= 50`** pre-pilot。 |
| **Feature flag** | **默认保持关闭**；任何试点 **必须**可 **一键关闭** shadow 写入。 |
| **Fallback** | **关闭 flag** 后行为与 **M6.1 前**一致（**无** **`rrmDecisionShadow`** 新写入路径 **不影响**主匹配）。 |
| **不变性（直至单独 bounded decision 阶段）** | **不改** **`finalScore`**、**不改** **`MatchResult.candidateUserId`**；**bounded decision** 若未来存在，**须**独立里程碑与评审，**不在 M6.2-r1 展开**。 |
