## 5. M6 功能链路最终确认（文档 + 代码口径）

- **RRM V2 readonly display**：在 **`readM6RrmV2SelectorDisplayEnv()`** 之后；仅当 **`PEIMA_M6_RRM_V2_SELECTOR_DISPLAY_ENABLED === "1"`** 时走只读展示 resolver（**`apps/api/src/modules/matching/matching-m6-rrm-v2-selector-display-env.ts`**）。
- **`displaySourceType`**：M6 只读成功路径为 **`rrm_top2_v2_selector_readonly`**（与 R6/R8 文档一致）。
- **Feature flag 默认**：未设置或非 **`"1"`** → **`enabled: false`**（**默认关闭**；**`"TRUE"`** 等字符串**不**开启，与测试一致）。
- **Fallback**：flag off、invalid payload、**`scoreShadowV2` missing**、selector 不合规等 → **不**进入 M6 readonly 路径，回退既有 **pairwise / primary** 等行为（由 **`matching-result-display`** 与单测锁定）。
- **scoreShadow v1**：**仅 v1** 不满足 M6；**v1 缺失** **不**作为进入 **`rrm_top2_v2_selector_readonly`** 的条件（**v2 required**）。
- **Worker 新行**：**不再写入** **`matchInsights.scoreShadow`**（v1）；**仍写入** **`scoreShadowV2`**（R10）。
- **`relationshipProfileScore`**：优先 **`scoreShadowV2`** 合法投影，否则 **reasonSummary / breakdown**；**不再**从 **v1 shadow** 读（R10）。
- **FinalMatchPage**：依据 **`result.displaySourceType`** 等 API 字段分支；代码注释明确 **不解析** **`matchInsights` / `scoreShadow`**（R8）。
