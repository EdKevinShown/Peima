# M6.0-r8 — FinalMatchPage RRM V2 Readonly Display Surface

## 1. 本轮目标

- **M6.0-r6**：后端在 **`resolveMatchResultDisplay`** 中已接入 **`PEIMA_M6_RRM_V2_SELECTOR_DISPLAY_ENABLED`** 条件下的只读展示解析，可返回 **`displaySourceType: rrm_top2_v2_selector_readonly`**（见 `docs/M6/M6.0-r6-rrm-v2-selector-readonly-display-resolver.md`）。
- **M6.0-r7**：parser / resolver 回归与记录（见 `docs/M6/M6.0-r7-rrm-v2-selector-readonly-display-regression.md`）。
- **M6.0-r8（本轮）**：仅在 **FinalMatchPage** 上**轻量展示**后端已返回的 **`displaySourceType`**（及可选 **`fallbackUsed`** 若未来 API 提供）；**不**让前端计算 RRM、**不**解析 **`matchInsights.rrmV2Top2Selector`**、**不**为 M6 路径读取 **`scoreShadowV2` / `scoreShadow` v1**。

## 4. 前端展示行为

| 条件 | 用户可见主区域 |
|------|------------------|
| **`displaySourceType === "rrm_top2_v2_selector_readonly"`** | 蓝色信息框：说明「RRM V2 只读候选选择器辅助排序」、**只影响展示说明**、主结果与主候选人未改写；引导展开「技术来源说明」 |
| **`fallbackUsed === true`**（且非上一行；当前 API 多未返回） | 单行：**当前展示使用稳定基线路径。** |
| **`match_result_original` 或缺省 `displaySourceType`** | **展示来源：稳定基线** |
| **`static_final` / `pairwise_final` / `static_fallback` / `rrm_top2_bounded_selector`** | **展示来源：已有增强展示路径**（一句澄清不改库主结果） |

**技术区（折叠「技术来源说明」）**

- 始终有 **`展示来源类型：<code>`**（原有）。
- 若传入布尔 **`displayResolverFallbackUsed`**，显示 **`displayResolver fallbackUsed`**。
- 当 **`rrm_top2_v2_selector_readonly`** 时，增加一段 **M6 readonly display** 说明（**不**展示 `selectedTop2`、**不**展示 raw **`rrmV2Top2Selector`**、**不**展示 **`scoreShadow`** 原文）。

## 5. 不变性确认

- **未改** `finalScore` / **`MatchResult.candidateUserId`** 的语义与计算；页面仍使用 API 返回值。
- **未改** worker、batch-match、RRM resolver、Prisma schema / migration、**后端** `resolveMatchResultDisplay`。
- **FinalMatchPage** **不**计算 RRM、**不**读取 **`scoreShadow` v1/v2** 用于 M6 只读路径判定、**不**解析 **`selectedTop2`**（M6 路径仅读 **`displaySourceType`** 等顶层字段）。
