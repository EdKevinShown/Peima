## 3. 新增字段（响应顶层）

| 字段 | 说明 |
|------|------|
| **`baselineCandidateUserId`** | 等于 **`MatchResult.candidateUserId`**（**trim**）。 |
| **`displayCandidateUserId`** | 与 **display resolver** 一致（与既有 **`...display`** 同值）。 |
| **`decisionCandidateUserId`** | 本轮固定 **`null`**（**true bounded** 未接线）。 |
| **`resolvedCandidateUserId`** | **有** **`displayCandidateUserId`** 则用其；**否则** **baseline**；**resolver 抛错** 时 **baseline**。 |
| **`resolvedSourceType`** | 通常 **= `displaySourceType`**；**fallback baseline** 时为 **`match_result_original`**。 |
| **`decisionSourceType`** | 本轮固定 **`null`**。 |
| **`fallbackUsed`** | **resolver catch** 或 **display id 缺失** 时为 **`true`**；否则 **`false`**。 |
| **`fallbackReason`** | **`display_resolver_failed` / `display_missing` / `null`**。 |
| **`scoreOwnerCandidateUserId`** | 本轮固定 **= `baselineCandidateUserId`**。 |
| **`explanationOwnerCandidateUserId`** | 本轮固定 **= `baselineCandidateUserId`**。 |
| **`chatTargetUserId` / `timelineTargetUserId` / `feedbackTargetUserId`** | **= `resolvedCandidateUserId`**。 |
| **`consistencyWarnings`** | **`display` ≠ `baseline`** 时附加 **info/warning**；**resolver fallback** 时含 **`resolved_fallback_to_baseline`**。 |

---

## 4. 行为说明

| 场景 | 行为 |
|------|------|
| **Baseline only** | **`display` = baseline`** → **`resolved`** = baseline；**`consistencyWarnings`** 为空数组。 |
| **Display ≠ baseline**（如 **M6.0 readonly**） | **`resolved`** = **display**；**chat/timeline/feedback** 跟 **`resolved`**；**score/explanation owner** 仍为 **baseline**，并发出 **`score_owner_mismatch` / `explanation_owner_mismatch` / `display_candidate_differs_from_candidate_user_id`**。 |
| **Display resolver 抛错** | **catch** 后 **display** 回退为 **baseline slice**；**`fallbackUsed=true`**，**`fallbackReason=display_resolver_failed`**，**`resolved_fallback_to_baseline`** **warning**。 |
| **True bounded** | **未接线**；**不**解析 **`rrmBoundedDecision`**；**`wouldSwitch` / `switch_to_top2_candidate`** **不生效**。 |
