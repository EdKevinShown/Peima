# M6.0-r10 — scoreShadow v1 Removal

## 1. 本轮目标

- **R9**（`M6.0-r9-score-shadow-v1-dependency-audit.md`）已完成 **scoreShadow v1** 依赖审计。
- **R10** 在**运行时代码**中删除 **v1 的持续生成**与 **API 对 v1 的 required 读取**；M6 后续主线只依赖 **`scoreShadowV2`** 与既有 **`reasonSummary` / breakdown** fallback。
- **不删除**历史 docs 中「v1/v2 曾并存」等**事实记录**（R5–R9 等文档正文不改写为「从未存在 v1」）。
- **不改**最终匹配决策：**`finalScore`**、**`MatchResult.candidateUserId`**、**worker winner / ranking`**、**batch-match 主决策**、**RRM resolver**、**Prisma schema / migration**、**FinalMatchPage** 算法逻辑。

---

## 2. R9 审计结论摘要

| 结论 | 说明 |
|------|------|
| Worker | R9 时 **仍写入** `matchInsights.scoreShadow`（v1）；R10 **已停止**新行写入 v1，**保留** `scoreShadowV2`。 |
| API | R9 时 **`matching-relationship-profile-score.ts`** 仍可从 **合规 v1** 推导 **`relationshipProfileScore`**；R10 **已改为**优先 **v2 shadow**，否则 **breakdown**。 |
| R6 | **不依赖** v1（只要求 **`scoreShadowV2` + selector**）。 |
| R8 | **不读取** raw v1 用于展示决策。 |
| 结论 | **v1 removal** 可进入 **runtime cleanup**（本轮）。 |

## 4. Runtime removal 行为

- **Worker**：**不再**向新生成的 `matchInsights` 写入 **`scoreShadow`（v1）**；**仍生成并写入** **`scoreShadowV2`**（及既有 **`rrmV2Top2Selector`** 路径）。
- **API**：**不再**从 **v1** 推导 **`relationshipProfileScore`**；有**合规** **`scoreShadowV2`** 时 **`source = match_insights_score_shadow_v2`** 且 **score = displayScore100/100**；否则走 **`reasonSummary` 分解的 `profileScore`**（**`score_breakdown_profile_score`**）或 **`missing`**。
- **R6 readonly display**：**仍只要求** **`scoreShadowV2`**；**v1 缺失**不会触发 **fallback**（与 R9/R6 设计一致）。

## 5. 测试迁移

- **删除**：对 **`tryReadRelationshipProfileScoreFromScoreShadow`**（v1 读路径）的整段 **`describe`**。
- **更新**：**`resolveRelationshipProfileScoreShadow`** 用例改为 **v2 优先**、**无效 v2 + 历史 v1 字段 → 仍走 breakdown**（证明 v1 不被消费）。
- **Worker**：**batch-match-match-insights** / **rrm-v2-top2-selector-shadow** 中 **v1 存在性**断言改为 **`scoreShadow` 未定义** + **v2 仍存在**。
- **`worker-score-shadow-m60.spec.ts`**（位于 **`apps/api/test/`**）：第二用例从合并 **`scoreShadow`** 改为合并 **`scoreShadowV2`**；**`buildScoreShadowM60` 形状单测保留**（函数仍在 **`matching-score.ts`**，供历史/工具链使用）。
- **未改** **`matching-rrm-v2-selector-readonly-display.spec.ts`**、**`matching-result-display-candidate.spec.ts`** 中「仅 v1 不满足 M6」类负例（仍覆盖 **v2 required**）。
