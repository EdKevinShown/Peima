# M6.6-C1 — ChatPage `finalMatchPeerUserId` Handoff

## 1. 本轮目标

- **`FinalMatchPage`** 已在跳转聊天 / 时间线时在 URL 中附带 **`finalMatchPeerUserId`**（与 **M6.5-C3** 的 **chat / timeline** target 链一致）。
- **`ChatPage`** 本轮开始从 query 读取该参数，计算 **`expectedPeerUserId`**，并与当前 **`getConversation`** 返回的会话 **`candidateUserId`**（**actualConversationPeerUserId**）比对。
- **仅**做 **warning / debug** 展示与 **沟通洞察**区说明文案；**不**改 **`ChatService.createOrReuseConversation`**、**不**改发消息、**不**改会话成员、**不**调 **Copilot** API 或模型 prompt。

## 3. 行为说明

| 项 | 行为 |
|----|------|
| **URL** | **`expectedPeerUserId`** = **`searchParams.get("finalMatchPeerUserId")?.trim() || null`**；缺失时保持旧路径。 |
| **actual** | **`conversation.candidateUserId`**（trim 非空）；无会话或字段不可用 → **`null`**。 |
| **`handoffPeerMatched`** | **`!expectedPeerUserId || !actualConversationPeerUserId || expected === actual`** → **`true`**；二者均存在且不等 → **`false`**（与需求一致：缺任一侧视为「未证伪」对齐）。 |
| **mismatch** | 普通 UI 显示黄色提示：「当前聊天对象与最终匹配入口传入对象不一致，本页仍按当前会话继续。」**不**禁用发送、**不**自动建连 / 切会话。 |
| **debug=1** | 无 handoff：「无最终匹配 handoff」；已对齐且两侧 ID 可用：「最终匹配 handoff 已对齐」；有 expected 无 actual：candidate 未就绪说明；**mismatch**：一行 **脱敏** expected / actual。 |
| **沟通洞察** | 默认：「沟通建议基于当前会话生成。」**mismatch** 时：「最终匹配入口传入对象与当前会话对象不一致，沟通建议仍基于当前会话。」 |
