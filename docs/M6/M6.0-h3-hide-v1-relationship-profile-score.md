# M6.0-H3 — Hide V1 relationship profile score from FinalMatchPage

> **范围**：**FinalMatchPage** 主流程中 **不再** 以醒目卡片展示 **`relationshipProfileScore` v1 / v1 shadow 对照**；v1 读数 **仅** 在 **「技术来源说明」** 内以 **弱文案、默认折叠** 保留，供 **审计 / fallback 排障**。  
> **不改**：**API** 响应字段、**worker**、**`MatchResult.finalScore`**、**`candidateUserId` / `displayCandidateUserId`**、**RRM**、Prisma schema、migration；**不做** low-effort detection。  
> **依据**：**`M6.0-h2-final-match-v2-primary-score-feature-flag.md`**、**`M6.0-g5-final-match-v2-primary-score-manual-run-record.md`**、**`M6.0-k1-scoring-v2-rollout-and-closure-plan.md`**。

---

## 1. 一句话结论

**H3** 移除主流程 **绿色「关系画像适配度」v1 对照卡片**（含 **「v1 shadow 对照，刻度与主视觉 V2 不同」** 等用户向文案）。**保留**：**H2** V2 主视觉 **feature flag**、**legacy `finalScore` v1** fallback 与 Hero、**「匹配分数构成」**（**`scoreBreakdown`**）、**「V2 关系画像适配度（实验）」** 折叠区、**RRM / `displaySourceType`** 说明；**`GET /matching/result`** 仍返回 **`relationshipProfileScore`**，前端在技术区以 **「旧版 relationshipProfileScore v1（仅技术审计）」** 折叠展示。

| 区域 | H3 后 |
