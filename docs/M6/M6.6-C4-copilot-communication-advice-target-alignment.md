# M6.6-C4 — Copilot / Communication Advice Target Alignment

## 1. 本轮目标

- **Copilot** = 当前 **AI 助手 / 沟通建议**（**`getCopilotInsights(conversationId)`**，**`CopilotPage` / `ChatPage`** 嵌入区）。
- **M6.6-C4** 明确：**沟通建议归因 = 当前会话中的聊天对象**（**`conversation.candidateUserId`**），**不**把 **Final Match handoff** 的 **`finalMatchPeerUserId`** 当作 Copilot 的「另一套」目标对象。
- **handoff mismatch** 时仅 **warning / debug**；**不**改 **Copilot** 后端、**prompt**、**request shape**、**provider / model**。

## 3. Target 规则

| 概念 | 规则 |
|------|------|
| **copilot 归因 peer** | 等于 **`actualConversationPeerUserId`**（**`GET /chat/conversations/:id`** 的 **`candidateUserId`**）。 |
| **expectedPeerUserId** | URL **`finalMatchPeerUserId`**（**Final Match** handoff）。 |
| **mismatch** | 二者均存在且不等 → 琥珀色 warning；**建议内容仍**基于 **conversationId** 当前会话（**不**把 **expected** 当作 Copilot 目标）。 |
| **无法推导 actual** | **`getConversation`** 失败或 **candidate** 为空 → 仅展示「基于当前 **conversationId** 对应会话」类说明。 |

---

## 4. ChatPage 行为

- 沟通洞察区：**默认**「沟通建议基于当前会话生成。」；**`handoffPeerMismatch`** 时与 **M6.6-C1** 一致的 **warning** 句。
- **debug=1**：一行脱敏 **actual**（即 **copilot 归因**）与 **handoff expected**。
- **「完整沟通建议」链接**：**`/copilot?...`** 附带 **`finalMatchPeerUserId`**（当当前页 URL 已带该参数时）。

---

## 5. CopilotPage 行为

- 读 **`finalMatchPeerUserId`**；**不**改 **`getCopilotInsights(conversationId)`** 调用。
- **peerLookup**：**`getConversation`** 仅用于 **UI 归因说明**与 **handoff** 比对。
- **导航**：**chat / timeline / copilot** 自链保留 **`finalMatchPeerUserId`**，避免在子页丢失 handoff。
- **归因卡片**：无法推导 **actual** → 固定 fallback 句；**mismatch** → warning；否则默认句；**debug** → 脱敏 **expected / actual**。

---

## 6. Copilot API / prompt 不变性

- **未**改 **后端** **copilot** 实现、**prompt**、**provider / model**。
- **未**改 **`getCopilotInsights`** 请求形状（仍 **`conversationId`**）。
- **未**新增 **API**。

- **debug=1** 使用 **`maskPeerIdForDebug`**（前 4 + `…` + 后 4）。
