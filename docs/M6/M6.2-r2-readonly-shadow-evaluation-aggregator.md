# M6.2-r2 — Read-only Shadow Evaluation Aggregator

## 1. 本轮目标

- **M6.2-r1** 已定义 **RRM decision shadow** 批量评估计划（样本、分母、分布、门槛）。
- **M6.2-r2（本轮）** 新增 **只读 DB 聚合脚本**：扫描 **`match_results.match_insights`**，统计 **`rrmDecisionShadow`** 相关指标与分布，输出 **匿名 JSON summary**。
- **不写 DB**、**不改** worker / API **runtime 业务逻辑**；**不进入** **decision pilot**。

## 3. 脚本命令

**仓库根目录：**

```bash
node --env-file=.env packages/database/scripts/m6-r2-shadow-evaluation-summary.mjs --limit 20 --pretty
```

**当前支持的 CLI 参数：**

| 参数 | 说明 |
|------|------|
| **`--limit <n>`** | 扫描 **`MatchResult`** 的最大行数（**`createdAt` 降序**，最新优先）。**默认 `500`**（未传或非法时回退为 **500**）。 |
| **`--since <date>`** | 可选。**ISO 字符串**或 **`YYYY-MM-DD`**；过滤 **`createdAt >=`** 该 UTC 日零点（**`YYYY-MM-DD`** 解析为 **`T00:00:00.000Z`**）。 |
| **`--pretty`** | **缩进 JSON** 输出到 **stdout**。 |
| **`--json`** | **单行 JSON**（与 **`--pretty`** 互斥时以 **`--json`** 为准得到单行）。**两者都不传**时默认 **缩进输出**（便于人工阅读）。 |

**不输出** **`userId` / `matchResultId` / `conversationId`**；**不**在 stdout 打印数据库主键。

## 4. 输出指标与分母口径

与 **M6.2-r1 §5** 对齐：

| 字段 | 含义 |
|------|------|
| **`sampleSize`** | **`N_total`**：本次查询返回并参与扫描的 **`MatchResult`** 行数（受 **`--limit` / `--since`** 约束）。 |
| **`shadowCount`** | **`N_shadow`**：**`matchInsights.rrmDecisionShadow`** 为非空 **对象** 的行数（含 **结构异常** 的 **JSON 对象**，此类计入 **`shadowMalformedCount`** / **`unknown`** **decision**）。 |
| **`validShadowCount`** | **`N_validShadow`**：**`decision ∈ { same_as_baseline, switch_to_top2_candidate }`** 的行数。 |
| **`rates.*`** | 分母：**`shadowCoverageRate` = `N_shadow / N_total`**（**`N_total=0`** 时为 **0**）；**`v1LegacyPresenceRate`** = **`inputPresence.scoreShadowV1LegacyPresent === true`** 行数 / **`N_total`**；其余 **`*Rate`**（除 **`v1LegacyPresenceRate`**）分母为 **`N_shadow`**，**`N_shadow=0`** 时为 **`null`**（JSON 中为 **`null`**）。 |
| **`decisionDistribution`** | **`same_as_baseline` / `switch_to_top2_candidate` / `no_shadow_decision` / `unknown`** 计数。 |
| **`reasonCodeDistribution`** | **`shadow.reasonCode`** → 频次（缺失为 **`unknown`**）。 |
| **`blockReasonDistribution`** | **`guardrails.blockReasons`** 展开后的 **tag** 频次。 |
| **`inputPresenceSummary`** | 在 **`N_shadow`** 行上 **`true`** 计数：**`scoreShadowV2True`** 等。 |
| **`malformedInsightsCount`** | **`matchInsights`** 非 **plain object** 的行数。 |
| **`shadowMalformedCount`** | **`rrmDecisionShadow`** 存在但非 **object** 的行数。 |
| **`parseErrorCount`** | **`shadowMalformed`** 行数 + **`decision === "unknown"`** 的 **`has_shadow`** 行数。 |
| **`malformedCount`** | **`malformedInsightsCount + shadowMalformedCount`**（便于与 **r1** 文案对齐）。 |
| **`generatedAt`** | Summary 生成时间（**ISO**）。 |

**顶层 JSON 契约：** **`schemaVersion: 1`**，**`sourceType: "rrm_decision_shadow_evaluation_summary"`**，**`sourceVersion: "m6.2-rrm-decision-shadow-eval-v1"`**。

## 5. 本地执行结果

**命令：**

`node --env-file=.env packages/database/scripts/m6-r2-shadow-evaluation-summary.mjs --limit 20 --pretty`

**摘要（匿名，无 ID）：**

| 项 | 值 |
|----|-----|
| **`sampleSize` (`N_total`)** | **20** |
| **`shadowCount` (`N_shadow`)** | **1** |
| **`validShadowCount`** | **1** |
| **`decisionDistribution`** | **`same_as_baseline: 1`**；其余为 **0** |
| **`blockedRate` / `unexpectedExceptionRate`** | **0**（**`blockReasonDistribution`** 为空） |
| **`v1LegacyPresenceRate`** | **0**（**`scoreShadowV1LegacyPresentTrue: 0`**） |
| **`malformedCount` / `parseErrorCount`** | **0** |

**说明：** 在最近 **20** 条 **`MatchResult`** 中仅 **1** 条含 **`rrmDecisionShadow`**，属 **小窗口** 扫描；**不代表**全库覆盖率。**样本不足**时应在 **M6.2-r3** 报告中显式写出 **`N_total` / `N_shadow`** 与采集策略。

**`pnpm --filter @peima/database build`：** 本轮执行 **失败**（**Windows `EPERM`**：Prisma **`query_engine-windows.dll.node`** 重命名被系统/锁占用）。脚本仅依赖已生成的 **`@prisma/client`**；**与 r2 脚本逻辑无关**。可在关闭占用进程后重试 **`pnpm --filter @peima/database build`**。
