# M6.8-C3 — Controlled Local Activation Fixture / Smoke

## 1. 本轮目标

- 为 M6.8-C1 read-layer activation 构造受控本地样本。
- 通过本地 DB fixture 验证 `would_switch_to_rrm` 观测路径可出现。
- 该路径仅用于 dev/local smoke，不是生产决策路径。

## 2. 修改文件

- `packages/database/scripts/m6-r8-c3-controlled-activation-fixture.mjs`
- `docs/M6/M6.8-C3-controlled-local-activation-fixture-smoke.md`

## 3. Fixture 脚本行为

新增脚本：`m6-r8-c3-controlled-activation-fixture.mjs`

- 子命令：
  - `inspect`：只读扫描，输出匿名摘要，不写 DB。
  - `apply`：显式执行才写；一次最多修改 1 条 `MatchResult.matchInsights.rrmBoundedDecision`。
- 安全限制：
  - 默认不写（必须 `apply`）。
  - 不输出真实 ID / userId / candidateUserId / conversationId。
  - 不输出 raw `matchInsights`。
  - 仅输出匿名统计与 before/after 摘要。
  - 写入范围仅 `matchInsights.rrmBoundedDecision`，不改 `candidateUserId` / `finalScore`。

## 4. 执行结果

### inspect

命令：

```bash
node --env-file=.env packages/database/scripts/m6-r8-c3-controlled-activation-fixture.mjs inspect
```

结果（匿名）：

- `ok = true`
- `scannedRows = 2`
- `selectedTop2Count = 2`
- `boundedTargetAvailable = true`
- `boundedDecisionBefore.decision = would_use_baseline`

### apply

命令：

```bash
node --env-file=.env packages/database/scripts/m6-r8-c3-controlled-activation-fixture.mjs apply
```

结果（匿名）：

- `ok = true`
- `modifiedRows = 1`
- `dbWrite = true`
- `changedFields = ["matchInsights.rrmBoundedDecision"]`
- before: `decision = would_use_baseline`, `wouldSwitch = false`
- after: `decision = would_switch_to_rrm`, `wouldSwitch = true`
- after 仍保持：
  - `mode = dry_run`
  - `fallbackUsed = false`
  - `fallbackReason = null`
  - `guardrailsBlocked = false`
  - `inputPresence` required flags 均为 `true`
