## 5. Rollout checklist

### Flag default

- `PEIMA_M6_RRM_BOUNDED_DECISION_ENABLED` 默认关闭。
- 仅字面量 `"1"` 开启。
- 非 `"1"` 视为关闭。

### Rollout preconditions

上线前应满足：

- API tests passed
- Web build passed
- Worker tests passed
- observation script / admin observation summary API 可用
- admin/debug observation 可查
- fallback reason 可观测
- no schema migration required
- no `candidateUserId` write
- no `finalScore` recompute
- manual API smoke 若具备 token 可补，但不是本轮阻塞项

### Monitoring points

- 持续观察 `boundedDecision.would_switch_to_rrm` / `would_use_baseline` / `fallback_baseline` 分布；
- 持续观察 quality 指标（`malformedCount` / `parseErrorCount` / `unexpectedExceptionCount`）是否稳定；
- 通过 admin/debug summary 与脚本交叉核对观测一致性。

### Rollback

- 关闭 flag 即回旧 resolved projection。
- 无需 DB rollback。
- 不影响 `MatchResult.candidateUserId` / `finalScore`。
- observation API/script 持续可用。
