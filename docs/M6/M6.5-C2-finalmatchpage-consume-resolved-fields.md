# M6.5-C2 — FinalMatchPage Consume Resolved Fields

## 1. 本轮目标

- **M6.5-C1** 已在 **`GET /matching/result/:userId`** 上提供 **resolved projection**（`resolvedCandidateUserId`、`chatTargetUserId`、`timelineTargetUserId`、`feedbackTargetUserId`、owner 字段、`consistencyWarnings`、顶层 **`fallbackUsed` / `fallbackReason`** 等）。
- **M6.5-C2** 让 **`FinalMatchPage`** 与 **`FinalMatchTechnicalDetails`** **优先消费**上述字段，并在缺失时 **回退** 到既有 **`displayCandidateUserId` / `candidateUserId`** 链（与 C1 合同及旧 GET 兼容）。
- **不**改变正式匹配结果语义：**不**改 **`MatchResult.candidateUserId`**、**`finalScore`**、worker winner、RRM resolver；**不**接 **`PEIMA_M6_RRM_BOUNDED_DECISION_ENABLED`**；**不**解析 raw **`rrmDecisionShadow` / `rrmBoundedDecision`**。

---

## 2. 修改文件

| 文件 | 变更 |
|------|------|
| **`apps/web/src/pages/FinalMatchPage.jsx`** | 计算 **`resolvedCandidateUserId`**（`resolved` → `display` → `candidate`）、**`chatTargetUserId`**、**`timelineTargetUserId`**、**`feedbackTargetUserId`**、**`explanationTargetUserId`**；主展示 **`effectiveDisplayCandidateId`** = **`resolvedCandidateUserId`**；**Start Chat** / **时间线** 与 **`postMatchReviewAi`** 分别锚定 **`chatTargetUserId`**、**`timelineTargetUserId`**、**`explanationTargetUserId`**；**`consistencyWarnings`** 与 **resolved fallback** 轻量提示；footer **`data-m65-feedback-target-user-id`** 预留 C3。 |
| **`apps/web/src/components/final-match/FinalMatchTechnicalDetails.jsx`** | 折叠区 **「M6.5-C2 · resolved 投影」**：展示与主路径一致的 resolved / targets / owners、**`fallbackReason`**（API **`fallbackReason`**）、**`consistencyWarnings`** JSON。 |
| **`docs/M6/M6.5-C2-finalmatchpage-consume-resolved-fields.md`** | 本文档。 |

**未改（本轮）：** **`apps/web/src/api/matching.ts`**（C1 已含类型）、API service、worker、Prisma、ai-pairwise 指定文件。

## 3. 消费字段

| 字段 | 页面用途 |
|------|----------|
| **`resolvedCandidateUserId`** | 与 **`displayCandidateUserId`、`candidateUserId`** 组成 **`resolvedCandidateUserId` 计算链**；驱动 **`effectiveDisplayCandidateId`**。 |
| **`resolvedSourceType`** | 传入技术详情展示（主路径不分支 true bounded）。 |
| **`chatTargetUserId`** | **Start Chat** 入口： **`result.chatTargetUserId \|\| resolvedCandidateUserId`**。 |
| **`timelineTargetUserId`** | **时间线** 入口：**`result.timelineTargetUserId \|\| resolvedCandidateUserId`**。 |
| **`feedbackTargetUserId`** | 计算 **`result.feedbackTargetUserId \|\| resolvedCandidateUserId`**；footer **`data-m65-feedback-target-user-id`**；**C3** 将把反馈入口与此对齐。 |
| **`scoreOwnerCandidateUserId` / `explanationOwnerCandidateUserId`** | 技术详情展示；**`explanationTargetUserId`** = **`explanationOwnerCandidateUserId \|\| resolvedCandidateUserId`**（旧 API 无 owner 时回退）。 |
| **`consistencyWarnings`** | 主区轻量 **`severity`** 分区（**blocking / warning / info**）。 |
| **`fallbackUsed` / `fallbackReason`** | 主区在 **`display_resolver_failed` / `display_missing`** 时提示「本次结果已回退到稳定基线展示。」；技术区已有 **`displayResolver fallbackUsed`** 与 **`projection fallbackReason`**。 |

---

## 4. 行为说明

| 能力 | 行为 |
|------|------|
| **Start Chat** | 依赖 **`chatTargetUserId`**；缺失则按钮禁用且不发起建连；**`createConversation`** 仍只传 **`matchResultId`**（不改 DTO）。 |
| **时间线** | 导航目标为 **`timelineTargetUserId`**；缺失则禁用。 |
| **Feedback** | 本轮仅 **`feedbackTargetUserId`** 变量 + **`data-m65-feedback-target-user-id`**；**M6.5-C3** 做 Chat / Timeline / **Feedback** 对齐与回归。 |
| **warnings / fallback** | **`consistencyWarnings`** 非空时主区列表展示；**`fallbackUsed`** 且 reason 为 **`display_resolver_failed` / `display_missing`** 时基线回退文案。 |
| **技术详情** | **`FinalMatchTechnicalDetailsContent`** 接收 **与页面 memos 一致** 的 **`resolvedCandidateUserId` / `chatTargetUserId` / `timelineTargetUserId` / `feedbackTargetUserId`**（旧 GET 无顶层 **`resolved*`** 时与主路径一致）。 |

---

## 5. 不变性确认

- **未**改 **`MatchResult.candidateUserId`**（仍展示、仍传 API 原字段）。
- **未**改 **`finalScore`** 展示与 **`resolvePrimaryMatchScore`** 逻辑。
- **未**改 worker、**RRM resolver**、Prisma、migration。
- **未**接 **`PEIMA_M6_RRM_BOUNDED_DECISION_ENABLED`**。
- **未**解析 raw **`matchInsights`** 内 RRM meta 作为本页决策依据（与 **M6.5-r4** 一致）。
