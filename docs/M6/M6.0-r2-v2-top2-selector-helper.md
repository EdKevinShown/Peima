# M6.0-R2 / R2B — V2 Top2 selector pure helper

## Scope

This milestone implements **only** a pure function helper:

- `selectV2Top2Candidates` in `apps/worker/src/jobs/rrm-v2-top2-selector.ts`
- Unit tests in `apps/worker/test/rrm-v2-top2-selector.spec.ts`

There is **no** wiring to RRM resolvers, batch-match persistence, Prisma, HTTP APIs, or the web app.

## R2B product rule (always-on RRM)

**The selector does not decide whether RRM should run.** It **only** selects a stable **V2 Top2** from the candidate list using valid `scoreShadowV2` rows.

- If there are **at least two** distinct candidates with **legally shaped** V2 shadow payloads, **`eligible === true`** and **`reason === "ok"`**. RRM is expected to **arbitrate display between exactly these two** (`top1CandidateUserId` / `top2CandidateUserId`); **RRM must not pick someone outside this V2 Top2.**

Signals that used to block RRM in early R2 are **hints only**, exposed on **`contextFlags`** (and echoed thresholds on **`thresholds`**):

| Flag | Meaning |
|------|--------|
| `top2GapLarge` | Top1 − Top2 &gt; `thresholds.largeGapThreshold` (default **12**; hint only) |
| `hasLowBand` | Either selected row has `band === "low"` |
| `hasStrongConflictBand` | Either selected row has `band === "strong_conflict"` |
| `anyBelowSuggestedFloor` | Either selected `displayScore100` &lt; `thresholds.suggestedFloorDisplayScore100` (default **65**; hint only) |

Optional constructor-style overrides: `suggestedFloorDisplayScore100`, `largeGapThreshold` on **`RrmV2Top2SelectorOptions`** — they **only** affect flags and **`thresholds`** in the result, **not** who is selected.

## What is still filtered (invalid data only)

A row is **valid** only if `scoreShadowV2` satisfies:

- `scoringVersion === "m6.0-relationship-profile-score-v2-shadow"`
- `source` is `profile_v2_shadow` or `insufficient_profile`
- `displayScore100` is a finite number in **\[0, 100\]**
- `band` is one of: `high`, `good`, `medium`, `low`, `strong_conflict`

Missing shadow, wrong version/source, non-finite or out-of-range scores, or unknown bands are **dropped** from the pool. **`invalid_score_shadow_v2`** is returned when every input row carried a non-null shadow **object** and **none** parsed (diagnostic).

## Unchanged by design

- **`MatchResult.finalScore`** and **worker winner / ranking** are untouched.
- **`candidateUserId`**, **`displayCandidateUserId`**, and **RRM resolver** code paths are **not** modified by this helper (it is pure; callers wire it later).
