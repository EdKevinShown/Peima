# M6.0-R2 — V2 Top2 selector pure helper

## Scope (this round)

This milestone implements **only** a pure function helper:

- `selectV2Top2Candidates` in `apps/worker/src/jobs/rrm-v2-top2-selector.ts`
- Unit tests in `apps/worker/test/rrm-v2-top2-selector.spec.ts`

There is **no** wiring to RRM, batch-match, Prisma, HTTP APIs, or the web app.

## Purpose

The helper decides whether a candidate list has a **V2-consistent Top2** pair (by `relationshipProfileScoreV2` shadow / `matchInsights.scoreShadowV2`) that is **safe for future RRM gating**: tight enough score gap, high enough scores, and bands that are not `low` or `strong_conflict` (by default).

- It **only** answers: “Is there an eligible V2 Top2 subset for RRM to consider?”
- It **does not** call RRM.
- It **does not** choose final `displayCandidateUserId` or `candidateUserId`.
- It **does not** read or write `MatchResult.finalScore` or worker legacy ranking.

## Defaults

| Option                 | Default |
| ---------------------- | ------- |
| `minDisplayScore100`   | `65`    |
| `maxTop2Gap`           | `12`    |
| `allowBands`           | `["medium", "good", "high"]` |

## Next steps (not R2)

**M6.0-R3** and later milestones will integrate this helper with RRM Top2 V2 shadow behavior, resolvers, and display paths as defined in `M6.0-r1-rrm-v2-integration-scan-plan.md` and related J1C / K1 docs.
