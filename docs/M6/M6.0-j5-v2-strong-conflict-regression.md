## 1. 一句话结论

**J5 合成回归通过**：**`strongConflictCount` / `redFlagConflictCount`** 可按阈值触发；**`capApplied`** 在多规则并存时取 **最严上界的最小值**（实测可稳定为 **0.68**）；**`displayScore100` 可落入 0–40** 且 **`band === strong_conflict`**（**全轴反向 0 vs 1** 样本）；**中等红线冲突**（如 **婚姻预期 0/1**、其余轴 **0.7 对齐**）可落入 **`band === low`**、**display 约 40–60**。**在仅触发 `capApplied = 0.68` 且 `raw` 仍较高时**，**display 下限约 57**（**分段映射**所致），**不能**单靠「cap 到 0.68」就把分压到 **&lt;40** — **0–40** 依赖 **`cappedRawScore` &lt; 0.55**（通常需 **高 penalty + 低 weightedBase** 或极端差异）。**若产品要求「中度冲突即 &lt;40」**，建议另开 **M6.0-J6** 调 **penalty 上限 / cap 档位 / 映射**，**不在 J5 改算法**。

## 3. 合成样本设计

| # | 场景 | 构造要点 | 预期计数 / cap |
|---|------|----------|----------------|
| 1 | 单 **strong** | 一核心轴 **diff &gt; 0.60**（如 `attachmentStyle` **0 vs 1**），其余 **0.5 对齐** | **`strongConflictCount ≥ 1`**，**`capApplied ≤ 0.82`** |
| 2 | 多 **core**（无 strong） | 两核心轴 **0 vs 0.55**（**diff = 0.55**） | **`coreConflictCount ≥ 2`**，**`capApplied ≤ 0.78`** |
| 3 | 三 **core** | 三核心轴 **0 vs 0.55** | **`capApplied ≤ 0.72`** |
| 4 | **redFlag** | **`marriageExpectation` 0 vs 1`**（红线轴 **diff &gt; 0.60**） | **`redFlagConflictCount ≥ 1`**，**`capApplied ≤ 0.68`** |
| 5 | 强冲突低分 | **`fullProfile(0)` vs `fullProfile(1)`** | **`displayScore100 &lt; 40`**，**`band === strong_conflict`** |
| 6 | 低适配（非极端） | 全轴 **0.7** 对齐，仅 **`marriageExpectation` 0 vs 1** | **`band === low`** 或 **display 40–60** |
| 7 | 非冲突高适配 | **完全相同** `fullProfile(0.62)` | **`band === high`**，**`displayScore100 ≥ 88`** |
| 8 | **cap 取最严** | **4** + **3** 叠加（红线 + 多 core + 单轴 strong） | **`capApplied === 0.68`**（**`min(0.82,0.78,0.72,0.68)`**） |

## 5. 是否触发 cap / strong / redFlag

- **`strongConflictCount`**：**是**（单轴 **0 vs 1**、全反向、及 **8** 叠加样本）。  
- **`redFlagConflictCount`**：**是**（**`marriageExpectation` 0 vs 1** 等）。  
- **`capApplied`**：**是**；多规则时取 **`Math.min`**，最低档为 **0.68**（**J2 当前表**）。

---

## 6. 是否进入 low / strong_conflict

- **`strong_conflict`**：**是**（**全 0 vs 全 1**，**`displayScore100 &lt; 40`**）。  
- **`low`**：**是**（**§3 样本 6**：红线 + 高对齐基底）。  
- **`medium`**：J5 未强制单独断言；**G4** 已在真实问卷五态下覆盖 **medium / good**。

---

## 7. 是否需要 J6 调参

**当前 J2 参数下**：  
- **0–40** 与 **`strong_conflict`** **可达**（需 **极端合成** 或 **`cappedRawScore` 足够低**）。  
- **仅**依赖 **`capApplied = 0.68`** 而 **`raw` 仍 ~0.86** 时，**`cappedRawScore = 0.68`** → **display 约 57**（**映射 `[0.55,0.72] → [40,62]`**），**不会**进入 **&lt;40**。  
**若产品要**：中度冲突即可 **&lt;40** 或 **`cap` 低于 0.68**，属 **J6**（**penalty 上限、cap 档位、分段映射**）范畴；**J5 不改公式**。
