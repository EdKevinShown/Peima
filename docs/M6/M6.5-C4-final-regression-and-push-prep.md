# M6.5-C4 — Final Regression and Push Prep

## 1. 本轮目标

- **M6.5-C1** 已完成：**`GET /matching/result/:userId`** 增加 **resolved projection**（targets / owners / warnings / fallback 等）。

## 3. C1–C3 功能摘要

### C1

- API 新增 **`resolvedCandidateUserId`**、**`chatTargetUserId` / `timelineTargetUserId` / `feedbackTargetUserId`**、**`scoreOwnerCandidateUserId` / `explanationOwnerCandidateUserId`**、**`consistencyWarnings`**、**`fallbackUsed` / `fallbackReason`** 等投影字段。
- **未**改 **`MatchResult.candidateUserId`**、**`finalScore`**、worker、**RRM resolver**。

### C2

- **`FinalMatchPage`** 消费 **resolved** 与 **targets**；主展示与 **`effectiveDisplayCandidateId`** 对齐 resolved 链。
- **`FinalMatchTechnicalDetails`** 折叠展示 resolved 投影与 **warnings**。
- **warnings / fallback** 主路径轻提示。

### C3

- **`resolveTargetId`** 统一三条 target fallback：**API 专用 target 字段** → **`resolvedCandidateUserId`** → **`displayCandidateUserId`** → **`candidateUserId`**。
- **chat / timeline / feedback** 均经上述链；**`finalMatchPeerUserId`** 写入 **chat / timeline** 跳转 query。
- 仅 **`severity === "blocking"`** 的 **`consistencyWarnings`** 阻断「进入聊天」「时间线」按钮。
