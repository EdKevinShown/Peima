# M6.0-r6 — RRM V2 Selector Readonly Display Resolver（后端最小接线）

## 本轮目标

在 **Final Match / matching result 的展示解析路径**（`resolveMatchResultDisplay`）中，增加由环境变量 **`PEIMA_M6_RRM_V2_SELECTOR_DISPLAY_ENABLED`** 控制的只读分支：开启时从 **`MatchResult.matchInsights`** 尝试解析并校验 **`rrmV2Top2Selector`**；全部通过则返回 **`displaySourceType: "rrm_top2_v2_selector_readonly"`** 与对应 **`displayCandidateUserId`**。任何失败 **不抛错**，**回退** 到既有逻辑（pairwise 展示路径或 **`match_result_original`**）。

**明确不是**：接入 RRM 决策、改 worker、改 batch-match、改 RRM resolver、改 **`finalScore`**、改 **`MatchResult.candidateUserId`** 或主决策字段。

## Feature flag

| 变量 | 语义 |
|------|------|
| `PEIMA_M6_RRM_V2_SELECTOR_DISPLAY_ENABLED` | **仅当值为字面量 `"1"`** 时开启；未设置或其它值均为关闭 |

读取辅助：`readM6RrmV2SelectorDisplayEnv()` → `{ enabled: boolean }`。

默认关闭；关闭时 **完全不读取** M6 分支，行为与改前一致。

## 接线路径（优先级）

`resolveMatchResultDisplay` 顺序：

1. **M5** `PEIMA_M5_RRM_TOP2_ENABLED` + `matchResultRrmTop2DisplayMeta` 冻结侧车（不变）
2. **M6** `PEIMA_M6_RRM_V2_SELECTOR_DISPLAY_ENABLED === "1"` → `tryParseRrmV2SelectorReadonlyDisplayFromMatchInsights` + `user` / `userProfile` 存在性只读查询
3. **Pairwise** finalize meta（不变）
4. **`match_result_original`**（不变）

## Parser / 校验规则（`tryParseRrmV2SelectorReadonlyDisplayFromMatchInsights`）

- **`matchInsights.scoreShadowV2`** 必须存在且 **`scoringVersion === "m6.0-relationship-profile-score-v2-shadow"`**（**v2 为必需**；不读取、不要求 **`scoreShadow` v1**）。
- **`rrmV2Top2Selector.version`** 必须等于与 **`packages/shared/types/match-p1.ts`** 中 **`MATCH_INSIGHTS_RRM_V2_TOP2_SELECTOR_SHADOW_VERSION`** 相同的字符串（API 内用本地常量持有该字面量）。
- 若 payload 上存在 **`schemaVersion`** 数字字段，则必须为 **`1`**。
- **`eligible === true`**，**`reason === "ok"`**。
- **`contextFlags`**：`top2GapLarge`、`hasLowBand`、`hasStrongConflictBand`、`anyBelowSuggestedFloor` 均 **不得为 `true`**（仅接受 `false` / 缺失视为非高风险路径的宽松对象校验以 `!== true` 为准）。
- **`selectedTop2`**：数组，长度 **1–2**；每项非空 **`candidateUserId`** 字符串。
- **Rank**：若任一项带 **`rank`**，则每项均须带 **`rank`**，且数值唯一；无 **`rank`** 时以数组顺序为准，且若存在非空 **`top1CandidateUserId`**，须与 **`selectedTop2[0].candidateUserId`** 一致。

成功时 **`displayUserId`** = **`selectedTop2[0].candidateUserId`**（与 **`top1CandidateUserId`** 对齐时即 Top1 展示人）。

Resolver 层额外要求：**`user`** 与 **`userProfile`** 行存在，否则回退。

## Fallback

触发回退（含 try/catch 吞掉异常）的情形包括但不限于：flag 非 `"1"`、解析返回 `null`、用户或画像不存在、任意运行时异常。回退后继续 **pairwise** 或 **`match_result_original`**，**不写库**。

## v2-only / v1 非阻塞

- **必须**有合规 **`scoreShadowV2`** 才走 M6 展示路径。
- **`scoreShadow`（v1）缺失或 `v1LegacyPresent` 等字段** — 本轮 **不实现、不检查**；**不因 v1 缺失而回退**。
- **仅 v1、无 v2** → 解析失败 → 回退。
