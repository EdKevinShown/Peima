# M6.0-r7 — RRM V2 Selector Readonly Display Regression

## 1. 本轮目标

- **M6.0-r6** 已完成：在 **`PEIMA_M6_RRM_V2_SELECTOR_DISPLAY_ENABLED === "1"`** 条件下，从 **`MatchResult.matchInsights`** 只读解析 **`rrmV2Top2Selector`** + **`scoreShadowV2`**，通过 **`resolveMatchResultDisplay`** 返回 **`displaySourceType: rrm_top2_v2_selector_readonly`**；失败则 **fallback**，不写主库、不改 **`finalScore`** / **`candidateUserId`**。
- **M6.0-r7** 只做 **回归验证与记录**：自动化测试、`tsc`、本地 API 启动验证、场景矩阵与不变性确认。
- **R7 不扩展功能**；**不改** worker、batch-match、RRM resolver、**`finalScore`**、**`MatchResult.candidateUserId`**、Prisma schema / migration、README、FinalMatchPage、R4/R5 文档。

## 5. 回归场景矩阵

以下 **Case 1–10** 本轮 **均未做真实 DB 手工回归**；结果列均为 **parser / resolver 单测（`mockPrisma`）自动化覆盖**。

| Case | 场景 | 期望 | 结果 | 备注 |
|------|------|------|------|------|
| 1 | Flag off（未设置 / 非 `"1"`） | 不走 M6；`displaySourceType` **不为** `rrm_top2_v2_selector_readonly`；`candidateUserId` / `finalScore` 不变 | **通过** | `matching-result-display-candidate`：flag 删除、`"TRUE"`；未执行真实 DB 手动验证，本轮由 parser/resolver 单测覆盖 |
| 2 | Flag on + 合法 payload + user + userProfile | `rrm_top2_v2_selector_readonly`；展示人来自 Top1；行上主字段不变；不写 DB | **通过** | 同上 |
| 3 | Flag on + 无效 payload（如错误 `version`） | Fallback；不 throw | **通过** | R7 **新增** resolver 单测 |
| 4 | `eligible === false` | Fallback（`null`） | **通过** | parser 单测 |
| 5 | `reason !== "ok"` | Fallback | **通过** | parser 单测 |
| 6 | `selectedTop2` 为空 | Fallback | **通过** | parser 单测 |
| 7 | `contextFlags` 任一为 `true` | Fallback | **通过** | parser：`top2GapLarge` 及 **hasLowBand / hasStrongConflictBand / anyBelowSuggestedFloor**（R7 补全 `it.each`） |
| 8 | 缺少 `scoreShadowV2` | Fallback | **通过** | resolver + parser |
| 9 | 无 v1、仅有 v2 + 合法 selector | **不因** v1 缺失 fallback；可走 M6 | **通过** | resolver：`no scoreShadow v1 + v2 present` |
| 10 | Top1 **userProfile** 或 **user** 缺失 | Fallback；不 500 | **通过** | resolver：`missing user profile`；R7 **新增** `user` 行缺失 |

## 6. 不变性确认

- **`finalScore`**：resolver 单测断言输入行未被改写。
- **`MatchResult.candidateUserId`**：单测断言保持不变。
- **worker / batch-match / RRM resolver**：R7 未改代码路径（仅测与文档）。
- **Prisma schema / migration**：未改。
- **FinalMatchPage**：未改。
- **scoreShadow v1**：不参与 M6 required pass/fail（parser 不读 v1；v1-only 时因缺 v2 而 fallback 属 **v2 必需**，非 v1 惩罚）。

## 7. 当前风险 / 后续注意

- R7 仍是 **readonly display regression**，**不是** RRM 决策接入。
- 前端 **尚未** 针对 **`rrm_top2_v2_selector_readonly`** 做专门展示（见 **M6.0-r8**）。
- **M6.0-r8**：FinalMatchPage **轻量**展示 `displaySourceType` /（若后续 API 扩展）`fallbackUsed` / `reasonSummary`；**不得**在前端计算 RRM、**不得**解析 `scoreShadow` / `selectedTop2`。
- **v1 removal** 不在 R7；后续 **R9/R10** 等里程碑单独处理。
