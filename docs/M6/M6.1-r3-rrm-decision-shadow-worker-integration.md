# M6.1-r3 — RRM Decision Shadow Worker Integration

## 1. 本轮目标

- **M6.1-r1 / r2** 已完成 **shadow mode 设计** 与 **payload contract**（**`sourceType: rrm_decision_shadow`**、**`sourceVersion: m6.1-rrm-decision-shadow-v1`**、**`schemaVersion: 1`**）。
- **M6.1-r3（本轮）** 在 **worker** **`matchInsights`** 组装阶段，在 **`PEIMA_M6_RRM_DECISION_SHADOW_ENABLED === "1"`** 时生成并写入 **`matchInsights.rrmDecisionShadow`**，供后续离线评估。
- **不改变** 正式匹配决策：**`finalScore`**、**`MatchResult.candidateUserId`**、**worker winner / ranking**、**batch-match 主逻辑**、**RRM resolver**、**FinalMatchPage**。

## 3. Feature flag

| 变量 | 语义 |
|------|------|
| **`PEIMA_M6_RRM_DECISION_SHADOW_ENABLED`** | **默认关闭**；**仅**字面量 **`"1"`** 为 **`enabled: true`**。**`"0"`、`"true"`、`"TRUE"`、未设置** → **关闭**。 |
| **作用域** | **只控制** **`rrmDecisionShadow`** 的生成与写入；**不**影响正式匹配结果。 |

---

## 4. Payload 行为

| 场景 | 行为 |
|------|------|
| **Flag off** | **不写入** **`rrmDecisionShadow`**（对象上 **无该键**）。 |
| **Flag on + 输入合法 + baseline 与 `selectedTop2[0]` 一致** | 写入 **`decision: "same_as_baseline"`** 等完整 payload。 |
| **Flag on + 输入合法 + baseline 与 `selectedTop2[0]` 不一致** | 写入 **`decision: "switch_to_top2_candidate"`**（**仅观测**，**不**改 **`candidateUserId`**）。 |
| **Flag on + 任一 guardrail / 缺输入** | 写入 **`decision: "no_shadow_decision"`**，**`guardrails.blocked: true`**，**`blockReasons`** 按 **r2** 闭集填充。 |
| **`scoreShadow` v1** | **`inputPresence.scoreShadowV1LegacyPresent`** 仅观测；**不参与** eligibility。 |
| **异常** | 外层 **try/catch** → **`no_shadow_unknown`** + **`unexpected_exception`**；**不向主流程 throw**。 |

---

## 5. 不变性确认

- **`finalScore`**：**未**改计算逻辑；仅 **读取**用于 **`finalScoreBand`**。
- **`MatchResult.candidateUserId`**：**未**改；processor 仍写 **`best.item.candidateUserId`**。
- **Worker winner / ranking**、**batch-match 主决策**：**未**改。
- **RRM resolver**：**未**改（仍为 **selector shadow** 与既有计分）。
- **`scoreShadow` v1**：**未**恢复写入；**不**依赖 v1 生成 shadow。
- **`scoreShadowV2`**：**保留**。
- **Prisma schema / migration**：**未**改（**JSON** 字段增键）。
- **FinalMatchPage / API**：**本轮未**改。
