## 1. 本轮目标

- **M6.3-r1 / r2** 已完成 **bounded decision** **安全合同**与 **写入策略**（**方案 B**：**`matchInsights.rrmBoundedDecision`** **dry-run meta**）。
- **M6.3-r3（本轮）** 在 **worker** **`matchInsights`** 组装阶段，**behind** **`PEIMA_M6_RRM_BOUNDED_DECISION_DRY_RUN_ENABLED`** 写入 **`rrmBoundedDecision`**（**仅审计 / 观测**）。

## 4. Payload 行为

| 条件 | 行为 |
|------|------|
| **Dry-run flag off** | **不写** **`rrmBoundedDecision`**（**`null`**，不合并）。 |
| **Dry-run on + 无 `rrmDecisionShadow`** | **`fallback_baseline`**，**`fallbackReason: missing_shadow`**（便于观测）。 |
| **Dry-run on + `same_as_baseline`** | **`would_use_baseline`**，**`wouldSwitch: false`**。 |
| **Dry-run on + 有效 `switch_to_top2_candidate`**（门控通过） | **`would_switch_to_rrm`**，**`wouldSwitch: true`**，**`boundedRef`** 指向 **Top2[0]**（**runtime** 可含 **id**；**本文档不写真实生产 ID**）。 |
| **Dry-run on + `no_shadow_decision`** | **`fallback_baseline`**，**`shadow_not_switch`**。 |
| **`guardrails.blocked` / 非空 `blockReasons`**（在 **switch** 路径上） | **`fallback_baseline`**，**`guardrail_blocked`**。 |
| **缺 `scoreShadowV2`** | **`missing_score_shadow_v2`**。 |
| **`contextFlags`** 高风险 | **`context_flags_high_risk`**。 |
| **`sourceVersion` 与 `m6.1-rrm-decision-shadow-v1` 不一致** | **`source_version_mismatch`**。 |
| **畸形 `rrmDecisionShadow`** | **`malformed_shadow`**；**`unexpected_exception`** 走 **catch** 分支。 |
| **`scoreShadow` v1 缺失** | **不阻塞**；**`inputPresence.scoreShadowV1LegacyPresent`** 仅 **观测**。 |
