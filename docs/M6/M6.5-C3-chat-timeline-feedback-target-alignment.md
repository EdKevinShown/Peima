# M6.5-C3 — Chat / Timeline / Feedback Target Alignment

## 1. 本轮目标

- **M6.5-C1** 在 **`GET /matching/result/:userId`** 上提供 **resolved projection** 与各 **target** 字段。
- **M6.5-C2** 已在 **`FinalMatchPage`** 消费 **resolved** 与轻量 **warnings / fallback** 提示。
- **M6.5-C3** 对 **Start Chat**、**时间线**、**反馈归因锚点** 做**最小**前端对齐：统一 **`resolveTargetId`** fallback 链，**禁止**动作入口**仅**依赖 **`candidateUserId`**；**不**改正式匹配结果写入语义。
- **不**解析 raw **`rrmBoundedDecision` / `rrmDecisionShadow`** 作为客户端决策依据。

---

## 2. 修改文件

| 文件 | 变更 |
|------|------|
| **`apps/web/src/pages/FinalMatchPage.jsx`** | 新增 **`resolveTargetId`**；**chat / timeline / feedback / explanation（复审 AI）** 使用显式 **API 字段顺序** fallback；**blocking** 级 **`consistencyWarnings`** 时禁用进入聊天与时间线；导航增加可选 query **`finalMatchPeerUserId`**（handoff）；footer **data 属性** + 注释；**debug=1** 下输出各 target 锚点。 |

---

## 3. Target fallback chains

| 入口 | 链（前者优先，依次回退） |
|------|---------------------------|
| **Chat** | **`chatTargetUserId`** → **`resolvedCandidateUserId`** → **`displayCandidateUserId`** → **`candidateUserId`** |
| **Timeline** | **`timelineTargetUserId`** → **`resolvedCandidateUserId`** → **`displayCandidateUserId`** → **`candidateUserId`** |
| **Feedback（页内锚点）** | **`feedbackTargetUserId`** → **`resolvedCandidateUserId`** → **`displayCandidateUserId`** → **`candidateUserId`** |

**主展示 / 侧车** 用的 **`resolvedCandidateUserId`** 计算与上表中间三段一致（**无**单独的「只猜 baseline」路径）。

---

## 4. 行为说明

| 项 | 行为 |
|----|------|
| **Start Chat** | **`createConversation`** 仍只传 **`matchResultId`**（若存在）；**按钮禁用**条件：**无 `userId`**、**链上无 chat target**、或存在 **`severity === "blocking"`** 的 **`consistencyWarnings`**。跳转 **`/chat`** 的 query 附带 **`finalMatchPeerUserId=<chat 链结果>`**（供后续页面渐进消费；**不**替代服务端会话成员解析）。 |
| **时间线** | 同上，**`finalMatchPeerUserId=<timeline 链结果>`** 附在 **`/chat/timeline`**。 |
| **Feedback** | 本页**无**独立 feedback **POST**；**`data-m65-feedback-target-user-id`** 与代码注释标明 **`feedbackTargetUserId`** 链，供 **C4+** 或自动化对齐。 |
| **target 缺失** | 对应按钮禁用；沿用既有 **`setError`** 建连失败路径。 |
| **info / warning** | **不**因一致性提示单独禁用聊天 / 时间线（与 **M6.5-r4 §10** 中 **blocking** 可阻断主路径一致）。 |
