# M6.0-R3B-F1 — Shared types Node runtime import 修复

## 问题性质

**不是** RRM-V2 算法问题，也**不是** batch-match 业务逻辑缺陷。

Worker 执行 `node dist/main.js --batch-match` 时，Node 解析 **`@peima/shared/types`** 到 `package.json` 的 **`exports["./types"]` → `./types/index.ts`**（源码入口）。`batch-match-match-insights.ts` 使用了**值导入**：

`import { MATCH_INSIGHTS_RRM_V2_TOP2_SELECTOR_SHADOW_VERSION } from "@peima/shared/types"`  

这会在 **runtime** 执行整个 `types/index.ts` barrel，进而加载 **`./match-p1`**。在 **Node ESM** 下，该相对路径**无扩展名**时无法解析到磁盘文件（既不会命中 `match-p1.ts`，也不会自动映射为 `.js`），于是报错：

`ERR_MODULE_NOT_FOUND: Cannot find module '.../match-p1'`

若仅把 barrel 改为 `from "./match-p1.js"`，则 Node 会查找 **`match-p1.js` 实体文件**；仓库中仅有 **`match-p1.ts`**、且当前 **未**将 `types/` 编译成 `dist/types/*.js`，问题仍会表现为模块找不到。

## Root cause（归纳）

1. **`@peima/shared/types` 的 exports 指向 TypeScript 源码**，Node 会直接执行该 TS（在支持/半支持 TS 的环境下）。
2. **Barrel 对子文件的 extensionless 相对路径**不符合 Node ESM 解析规则。
3. **Worker 对 shared types 做了值导入**，强制触发上述 runtime 加载链。

## 修复方式（本轮采用）

**最小、与业务无关的修复**：在 **`apps/worker/src/jobs/batch-match-match-insights.ts`** 中：

- 将 `@peima/shared/types` 改为 **`import type { ... }` 仅类型导入**（编译后从 emit 中擦除，**runtime 不再加载** `packages/shared/types/index.ts`）。
- 将 **`MATCH_INSIGHTS_RRM_V2_TOP2_SELECTOR_SHADOW_VERSION`** 以 **本地 `const`** 声明，字面量与 **`packages/shared/types/match-p1.ts`** 中导出的常量**保持一致**，并在注释中写明「须与 shared 保持同步」。

仓库内 **仅 worker** 对 `@peima/shared/types` 存在值导入；`match-insights-placeholder.ts` 已是 `import type`。因此该改动能消除 worker batch-match 的 **ERR_MODULE_NOT_FOUND**，而**无需**立刻引入「编译整个 types 包到 `dist/types`」或改动 `package.json` exports 的大范围重构。

**未改动**：`MatchResult.finalScore`、worker winner / ranking、`candidateUserId`、`displayCandidateUserId`、RRM resolver、打分与 selector 算法。

## 验证

```bash
pnpm --filter @peima/shared build
pnpm --filter @peima/worker build
cd apps/worker
node --env-file=..\..\..env dist\main.js --batch-match
```

预期：**不再**因 `match-p1` / shared types barrel 而 `ERR_MODULE_NOT_FOUND`；有 waiting 队列时应能跑完 batch；无队列时应正常退出而非模块崩溃。

## 后续（可选加固）

若未来仍有代码对 `@peima/shared/types` 做**值导入**，可择一加固：

- 为 `types/` 增加 **`tsc` 产出 `dist/types/*.js` + `.d.ts`**，并将 `exports["./types"]` 的 **runtime** 指向 `dist`；或  
- 将版本常量等 runtime 值迁到 **`@peima/shared/constants`** 等已有 **JS 构建产物** 包，types 包仅保留类型。
