# M6.2-r4 — Shadow Batch Evaluation Report

## 1. 本轮目标

- **M6.2-r1**：定义 **RRM decision shadow** **batch evaluation** 计划（样本、分母、分布、门槛）。
- **M6.2-r2**：新增 **只读 DB 聚合器** **`m6-r2-shadow-evaluation-summary.mjs`**。
- **M6.2-r3**：完成 **本地 batch evaluation run**（baseline → **queue prep + batch-match** → final aggregator）。
- **M6.2-r4（本文）**：基于 **r3** 的匿名指标与分布，撰写**正式评估报告**——说明**能支持**与**不能支持**的结论、是否需扩样本、以及是否可进入下一阶段 **bounded decision contract** 的**设计准备**（**非 implementation**）。
- **r4** **不继续造样本**；**不进入** **decision pilot**；**不让** shadow **switch** 生效。

## 6. Interpretation

### 6.1 稳定性

- **`unexpectedExceptionRate = 0`**、**`malformedCount = 0`**、**`parseErrorCount = 0`**。
- **本窗口内** **shadow payload** 可被聚合器稳定消费，**无**解析崩溃与异常标签 — **支持**「**工程链路在受控本地 batch 下可用**」的结论。

### 6.2 输入完整性

- **`missingInputRate = 0`**、**`invalidSelectorRate = 0`**。
- **`scoreShadowV2` / `rrmV2Top2Selector` / `selectedTop2`** 在 **13** 条 **shadow** 行上 **`inputPresence`** 均为 **true** — **支持**「**在该生成路径下前置输入齐备**」的结论（**仅限**本数据集）。

### 6.3 RRM 与 baseline 一致性

- **`sameAsBaselineRate = 1.0`**，**`switchSuggestedRate = 0`**。
- 在**同质样本**（同一池、同一主排序结果反复落库）下，**RRM shadow** 与 **worker baseline** **完全一致** — **不**支持「产线全局 RRM 与主排序总一致」或「永不建议 switch」类结论（见 **§7**）。

### 6.4 风险与 guardrails

- **`blockedRate = 0`**，**`blockReasonDistribution`** 为空。
- **本窗口内** **未** 观测到 **low / conflict / floor / gap** 等 **guardrail** 触发 — **不**支持「真实候选池永无风险面」的结论。

### 6.5 **`scoreShadow` v1**

- **`v1LegacyPresenceRate = 0`**（本窗 **`N_total`** 口径）。
- **新 shadow 样本** **不依赖** **v1**；**未恢复** **v1** 写入路径。

---

## 7. Limitations

- **样本来自本地 DB**，**不代表**生产流量、地域、时段或运营策略下的分布。
- **同质性高**：**12** 轮扩充来自**同一 eligible active preview pool** 路径与**同一 viewer** 的重复 **`batch-match`**。
- **`sameAsBaselineRate=1.0`** **不代表** **RRM** 在广泛场景下**永不**与 baseline 分歧。
- **`switchSuggestedRate=0`** **不代表** **RRM** 无潜在**切换**提示或**无**产品增益空间。
- **`blockedRate=0`** **不代表**真实多池、多风险结构下 **guardrails** 不会被触发。
- **`sampleSize=50` / `shadowCount=13`** 属于 **local batch** 证据量级；**不是** **M6.2-r1** 所述 **pre-pilot（如 N≥50 全为 shadow 或多样场景）** 的充分样本。
- **不应**基于本轮结论**直接进入** **bounded decision pilot**。
