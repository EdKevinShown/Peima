# M6.7-C3 — Read-only RRM Observation Summary API

## 1. 本轮目标

- 新增一个 admin/debug 用只读 API summary endpoint。
- 返回与 C1 snapshot script 对齐的匿名 RRM observation 聚合字段。
- 不改变任何正式匹配结果，不接 true bounded decision flag。

## 3. Endpoint

- 路径：`GET /admin/rrm-observation/summary`
- Query：
  - `limit`（可选）
- limit 规则：
  - 默认 `50`
  - 最大 `200`
  - 非法值回退默认 `50`
- 鉴权 / admin 行为：
  - 复用现有 `@UseGuards(JwtAuthGuard)` + `AdminService.assertCanRunAiSimulationV1(userId)`
  - 非登录返回 `401`
  - 非 admin 返回现有 admin gate 拒绝（按 `AdminService` 既有行为）
- 错误处理：
  - DB/聚合异常统一返回安全错误 `failed_to_build_rrm_observation_summary`
  - 不向客户端泄露数据库内部细节

## 4. 返回字段

匿名 response shape：

- `sampleSize`
- `coverage`
  - `withScoreShadowV2`
  - `withScoreShadowV1Legacy`
  - `withRrmV2Top2Selector`
  - `withRrmDecisionShadow`
  - `withRrmBoundedDecision`
  - `withResolvedProjectionUnavailableInDbNote`（恒为 `true`）
- `decisionShadow`
  - `same_as_baseline`
  - `switch_to_top2_candidate`
  - `no_shadow_decision`
  - `blocked`
  - `unexpected_exception`
- `boundedDecision`
  - `would_use_baseline`
  - `would_switch_to_rrm`
  - `fallback_baseline`
  - `fallbackReasonDistribution`
- `inputPresence`
  - `scoreShadowV2True`
  - `rrmV2Top2SelectorTrue`
  - `selectedTop2True`
  - `scoreShadowV1LegacyPresentTrue`
- `quality`
  - `malformedCount`
  - `parseErrorCount`
  - `unexpectedExceptionCount`
- `notes`
- `limit`
- `generatedAt`

## 5. Privacy / security

- admin/debug only。
- 不输出 `id` / `userId` / `candidateUserId` / `conversationId`。
- 不输出 raw `matchInsights`。
- 不输出 raw `selectedTop2` IDs。
- 不提供 user-level drilldown。
- limit capped（默认 50，最大 200）。
- 只读查询；不写 DB。

## 6. Aggregation logic

- 在 API 侧新增纯函数聚合器，字段口径与 C1 script 对齐：
  - coverage / decisionShadow / boundedDecision / inputPresence / quality / notes。
- 对 malformed 行逐条容错：
  - 单行异常不影响整体输出；
  - `malformedCount` / `parseErrorCount` / `unexpectedExceptionCount` 分层统计。
- legacy `scoreShadow` 仅做 presence 观测，不作为新链路必需依赖。
