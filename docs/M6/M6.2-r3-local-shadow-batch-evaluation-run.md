- **M6.2-r2** 已提供只读聚合器 **`m6-r2-shadow-evaluation-summary.mjs`**。

## 7. 解读

- **`shadowCoverageRate`（最近 50 行 = 0.26）**：在**当前本地库**与**固定预览池 + 同一 viewer 重复 batch** 设定下，**`N_shadow=13`** 已 **≥ 10**，可作为 **M6.2-r1** 定义的 **local batch** 量级证据；**全库**仅 **57** 条 **`MatchResult`** 时，**更大 `--limit`** 不会增加 **`shadowCount`**（旧行无 shadow）。
- **same / switch**：**全部为 `same_as_baseline`**，**`switchSuggestedRate=0`** — 符合**同一池、同一 winner 路径**下的预期；**不能**外推到多样池 / 多样 profile 产线分布。
- **blocked / missing / invalid / unexpected**：均为 **0**，**稳定性与输入完整性**在本窗口内**良好**。
- **`v1LegacyPresenceRate=0`**：最近窗口内 **无** **`scoreShadowV1LegacyPresent`** 为 **true** 的 shadow 行（**不**讨论历史非 shadow 行）。
- **M6.2-r4**：**具备**进入 **「Shadow Batch Evaluation Report」** 的条件（**`N_shadow ≥ 10`** + **无异常率**）；**仍为观测报告**，**不作** **bounded decision pilot** 结论。
