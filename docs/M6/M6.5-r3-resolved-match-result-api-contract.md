# M6.5-r3 — Resolved Match Result API Contract

## 1. 本轮目标

- **M6.5-r2** 已定义 **`resolvedCandidate`**、**各 owner** 与 **target consistency**（**FinalMatchPage / chat / timeline / feedback / explanation / score** 应围绕谁一致）。
- **M6.5-r3（本文）**：定义 **`GET /matching/result/:userId`**（与 **`apps/web/src/api/matching.ts`** 中 **`getMatchingResult`** 一致的实际路径）**未来**应返回的 **`resolved*`** 及关联字段，使**前端不必**自拼 **RRM** 逻辑。
- **r3** **只**做 **API contract** 文档；**不**改 **API 实现**、**不**改 **`MatchingResultResponse`** 运行时行为。

---

## 2. 当前 API 问题

**现状（简化）：** **`MatchingResultResponse`** 已含 **`candidateUserId`**、**`displayCandidateUserId?`**、**`displaySourceType?`**、**`fallbackUsed?`**、**`finalMatchDecisionMeta?`**、**`multiSourceFinalDecision?`** 等（见 **`apps/web/src/api/matching.ts`**）；服务端通过 **`resolveMatchResultDisplay`**（**`matching-result-display.ts`**）解析 **display**。

**未来风险：**

| 问题 | 后果 |
|------|------|
| **仅**暴露 **`candidateUserId`** | 客户端易默认「匹配对象 = **baseline**」，与 **display** 分叉。 |
| **`displayCandidateUserId`** 来自 **display resolver** | 正确用于 **Hero**，但若 **chat** 仍手写 **`candidateUserId`** → **A/B 分裂**。 |
| **未来 `decisionCandidateUserId`**（**true bounded**） | 再多一轨，**前端**若自行 **`if (meta...)`** → **展示 / chat / explanation** 不一致。 |
| **`matchInsights`** 仍出现在响应中 | 诱导客户端解析 **`rrmDecisionShadow` / `rrmBoundedDecision`**（**M6.5-r2 §12** 禁止）。 |

**结论：** **API** 应**显式**返回 **`resolvedCandidateUserId`**（及 **owner / target** 字段），**单一权威**；**前端** **不**根据 **raw meta** 推断 **switch**。

---

## 3. Top-level response fields 草案

以下字段为 **`MatchingResultResponse` 顶层**（或**逻辑等价**的嵌套 **`resolved`** 对象内）的**未来扩展**。**r3 不实现**。

| 字段 | 含义 | 可空？ | Legacy / Canonical |
|------|------|--------|---------------------|
| **`candidateUserId`** | **`MatchResult` 持久化**主候选（**baseline**）。 | **否** | **Legacy + 长期保留**（对账、旧客户端）。 |
| **`baselineCandidateUserId`** | 显式 **baseline**；通常 **= `candidateUserId`**。 | **可**缺省（缺省时 **= `candidateUserId`**） | **Canonical**（新客户端推荐读）。 |
| **`displayCandidateUserId`** | **Display resolver** 输出（**已存在**，可选）。 | **可**缺省 | **Legacy + Canonical**（与 **M3.8–M6.0** 兼容）。 |
| **`decisionCandidateUserId`** | **未来** **true bounded** **meta** 选中对象（**Top2**）。 | **可**缺省；无 **true** 时 **应缺省或 = baseline** | **Canonical**（未来）。 |
| **`resolvedCandidateUserId`** | **用户体验**默认锚点（**M6.5-r2**）。 | **否**（**应**始终给出；失败时 **= baseline**） | **Canonical**（**FinalMatchPage** 主路径推荐）。 |
| **`resolvedSourceType`** | **`resolvedCandidate`** 为何被解析为该人（**§6** 枚举子集）。 | **否** | **Canonical**。 |
| **`displaySourceType`** | **已存在**；**display slice** 来源。 | **可**缺省 | **Legacy + Canonical**。 |
| **`decisionSourceType`** | **bounded / baseline / fallback** 等（**审计**）。 | **可**缺省 | **Canonical**（未来）。 |
| **`fallbackUsed`** | **已存在**（可选）；是否与 **resolved** 一致须在实现中统一。 | **可**缺省 | **Legacy + Canonical**。 |
| **`fallbackReason`** | **闭集**字符串（**§7**）。 | **`null`** 当未 fallback | **Canonical**。 |

## 4. Owner fields 草案

| 字段 | 含义 | 默认 |
|------|------|------|
| **`scoreOwnerCandidateUserId`** | **`finalScore` / relationship 分数**解释归属。 | **= `resolvedCandidateUserId`** |
| **`explanationOwnerCandidateUserId`** | **`primaryConclusion` / matchExplanation / matchReview / reasonSummary`** 绑定对象。 | **= `resolvedCandidateUserId`** |
| **`chatTargetUserId`** | **发起会话**对象。 | **= `resolvedCandidateUserId`** |
| **`timelineTargetUserId`** | **时间线**归属对象。 | **= `resolvedCandidateUserId`** |
| **`feedbackTargetUserId`** | **反馈**归因对象。 | **= `resolvedCandidateUserId`** |

**若任一 owner ≠ `resolvedCandidateUserId`：**

- **必须**返回 **`ownerMismatchReason`**（**string**，闭集或自由文本由 **M6.5-r4** 定）**和/或** **`consistencyWarnings`**（**§8**）；
- **禁止**依赖前端猜测；
- **`severity: "blocking"`** 时：**建议** **UI** 阻止依赖错误 **owner** 的主动作（**具体 UX** **M6.5-r4**）。

## 5. `resolvedCandidate` object

**未来**可返回嵌套对象（**可选优化**，减少多次按 **userId** 查 profile）：

```typescript
// 伪类型 — r3 不落地到仓库
resolvedCandidate?: {
  userId: string;
  profile?: unknown;   // 与现有 GET 嵌套 profile 形状对齐，由 OpenAPI 定义
  images?: unknown;
  tags?: unknown;
  sourceType: string;   // 与 resolvedSourceType 或 display 子类型对齐
};
```

| 说明 |
|------|
| **r3** **不要求**当前实现该对象。 |
| **建议**未来 **FinalMatchPage** **优先**消费 **`resolvedCandidate` / `resolvedCandidateUserId`**，**避免**仅依赖 **`displayCandidateUserId` + 自行拼 baseline**。 |
| **不**鼓励客户端从 **`matchInsights`** 反推 **profile** 用于主路径。 |

## 6. Source type taxonomy（response 级）

| `resolvedSourceType`（示例值） | **changes `resolvedCandidate`?** | **changes `candidateUserId`?** | **affects chat/timeline?** | **Notes** |
|--------------------------------|-----------------------------------|---------------------------------|----------------------------|-----------|
| **`match_result_original`** | **否**（= baseline） | **否** | **跟随 baseline** | 默认安全态。 |
| **`pairwise_finalize`**（或与 **`displaySourceType`** 成对出现） | **可能**（= **finalize** 选中） | **否** | **应**随 **resolved** | 与现有 **pairwise** 合同一致。 |
| **`rrm_top2_v2_selector_readonly`** | **可能**（= **display**） | **否** | **应**随 **resolved** | **M6.0**；**非** true decision。 |
| **`rrm_decision_shadow`** | **否**（**meta** 不自动改 **resolved**） | **否** | **否**（除非上层显式引用） | **侧车**；**默认**不提升为 **resolved**。 |
| **`rrm_bounded_decision_dry_run`** | **否** | **否** | **否** | **仅观测**；**`wouldSwitch`** 不生效。 |
| **`rrm_true_bounded_decision_read_layer`** | **是** | **否** | **是** | **Strategy A**；须 **§7 fallback**。 |
| **`rrm_true_bounded_decision_enabled`** | **是** | **可能**（**Strategy C**） | **是** | **须** **full** consistency。 |
| **`fallback_baseline`** | **强制**回 **baseline** | **否** | **回 baseline** | **`fallbackUsed=true`**。 |

**说明：** **`displaySourceType`** 仍可使用 **`matching-result-display.ts`** 中既有枚举；**`resolvedSourceType`** 为**更粗**或**正交**的「**用户动作锚点**」标签，**二者映射表**在 **实现** 时由 **resolver** 维护（**r3** 只要求**不矛盾**）。

## 7. Fallback fields

| 字段 | 类型 | 说明 |
|------|------|------|
| **`fallbackUsed`** | **boolean** | **true** 时 **`resolvedCandidateUserId`** **应** = **`baselineCandidateUserId`**。 |
| **`fallbackReason`** | **string \| null** | 闭集建议见下表。 |
| **`fallbackSourceType?`** | **string** | 发生 fallback 时 **resolver** 最终采用的来源标签（如 **`match_result_original`**）。 |
| **`fallbackFromSourceType?`** | **string** | **失败前**尝试的来源（如 **`rrm_true_bounded_decision_read_layer`**）。 |

**`fallbackReason` 建议闭集：**

| 值 | 方向 |
|----|------|
| **`missing_resolved_candidate`** | 无法确定 **resolved** 目标。 |
| **`missing_profile`** | **profile** 缺失导致无法安全展示/动作。 |
| **`owner_mismatch`** | **owner** 与 **resolved** 无法对齐且未授权双轨。 |
| **`malformed_decision_meta`** | **meta** 不可解析。 |
| **`source_version_mismatch`** | **`schemaVersion` / `sourceVersion`** 不匹配。 |
| **`guardrail_blocked`** | **guardrails** 拦截。 |
| **`true_flag_off`** | **true** 功能关闭或未 rollout。 |
| **`explanation_not_ready`** | **解释**未与 **resolved** 绑定。 |
| **`chat_target_unavailable`** | **会话**目标不可用。 |
| **`timeline_target_unavailable`** | **时间线**目标不可用。 |
| **`unexpected_exception`** | 捕获异常，**不** **500**。 |

---

## 8. Consistency warnings

**可选**字段：

```typescript
consistencyWarnings?: Array<{
  code: string;
  severity: "info" | "warning" | "blocking";
  message: string; // 用户可见文案由 i18n 映射更好；r3 仅合同
}>;
```

**`code` 示例：**

| `code` | 典型含义 |
|--------|-----------|
| **`score_owner_mismatch`** | **score** 与 **resolved** 不一致风险。 |
| **`explanation_owner_mismatch`** | **解释**仍绑定非 **resolved**。 |
| **`chat_target_mismatch`** | **chat** 目标 ≠ **resolved**。 |
| **`timeline_target_mismatch`** | **timeline** 目标 ≠ **resolved**。 |
| **`display_candidate_differs_from_candidate_user_id`** | **读层** 与 **持久化** 分叉（**信息性**常见）。 |
| **`resolved_fallback_to_baseline`** | **resolved** 已回退 **baseline**。 |

## 9. Backward compatibility

- **保留** **`candidateUserId`**（**持久化**语义不变）。
- **保留** **`displayCandidateUserId` / `displaySourceType`**（现有 **FinalMatchPage** 路径）。
- **新增** **`resolved*` / owner / target / warnings`**：缺省时旧客户端行为**不变**。
- **迁移期**：旧前端可继续读 **`candidateUserId` + `displayCandidateUserId`**；**新** **FinalMatchPage** **应**迁移到 **`resolvedCandidateUserId`**（及 **`chatTargetUserId`** 等）。
- **不**删除 **`matchInsights`** 字段本身（若当前有）→ **但** **合同**上 **主路径 UI** **禁止**依赖其 **RRM** 子树（**M6.5-r2**）。

## 10. Frontend consumption contract

| 区域 | 使用字段 |
|------|-----------|
| **FinalMatchPage 主资料 / Hero** | **`resolvedCandidate`**（若有）或 **`resolvedCandidateUserId`** + 既有 profile 加载键 |
| **Chat 按钮** | **`chatTargetUserId`** |
| **Timeline 按钮** | **`timelineTargetUserId`** |
| **Feedback** | **`feedbackTargetUserId`** |
| **Explanation 区块** | **`explanationOwnerCandidateUserId`**（及既有解释字段，**须**后端对齐 **owner**） |
| **Score 区块** | **`scoreOwnerCandidateUserId`** |
| **禁止** | **`FinalMatchPage`** **解析** raw **`rrmDecisionShadow` / `rrmBoundedDecision`** |

## 11. Backend resolver responsibility

**Resolver**（**`resolveMatchResultDisplay`** 及 **`GET /matching/result`** 组装层）**未来**须：

- 读取 **baseline**（**`MatchResult`**）。
- 读取 **display meta**（**现有** **M5/M6** 链）。
- 读取 **未来 bounded / true meta**（**版本化**）。
- **校验** **`sourceVersion` / `schemaVersion`**。
- **计算** **`resolvedCandidateUserId`** 与 **`resolvedSourceType`**。
- **计算** **各 owner / target**；**不一致**时填 **warnings** / **`ownerMismatchReason`**。
- **Fallback** → **baseline**；**`fallbackUsed` / `fallbackReason`**。
- **不 throw** 到用户页。
