# P2.5 联调与验收清单

面向研发：**可重复执行的手动联调命令 + 验收勾选**。非产品说明；自动化测试不在范围内。

**相关文档**：模块级结论与历史口径见 [P2-validation-summary.md](./P2-validation-summary.md)；范围边界见 [P2-scope-notes.md](./P2-scope-notes.md)。

## 1. 当前已完成能力范围（P2-MVP + P2.5 收口）

| 域 | 能力要点 |
|----|----------|
| **Summary** | `GET` 优先持久化行否则内联规则摘要；`POST .../summary/generate` 落库快照；ChatPage「生成并更新摘要」|
| **Feedback** | `POST /feedback`、`GET /feedback/mine`；ChatPage 快捷反馈 |
| **Profile suggestion** | `GET /profile-suggestions/mine`、`POST .../accept|dismiss`；ChatPage 列表 + 待处理操作 + 已处理折叠 |
| **Behavior signal** | `POST /behavior-signals`、`GET /behavior-signals/mine` |
| **Analytics** | `GET /analytics/p2-overview/mine` 任意登录用户；`GET /analytics/p2-overview` **仅** env 白名单用户（否则 **403**）|
| **Copilot** | `GET /copilot/conversations/:id/insights`；ChatPage 卡片；**CopilotPage** `/copilot?conversationId=` 独立页 + `basedOn` 展示 |
| **DB** | P2 四表见 migration `20260405100000_p2_persistence_mvp`（空库 `migrate deploy` 可复现）|

## 2. 环境前置条件

- Node / pnpm 按仓库要求；**PostgreSQL** 可用，`DATABASE_URL` 已配置。
- 已执行：`pnpm install`；`pnpm --filter @peima/database db:migrate`（或 `migrate deploy`）与 `prisma generate`；API 可 `nest build` / `pnpm dev:api`。
- 至少一名测试用户已 **登录** 取得 JWT；具备 **conversationId**（会话参与者为该用户）。
- Web（可选）：`pnpm dev:web`，默认 API `VITE_API_BASE_URL` 指向同一后端。

## 3. 占位变量（请先替换）

在下列命令中替换：

| 占位符 | 含义 |
|--------|------|
| `$BASE` / `%BASE%` | API 根，如 `http://localhost:3000` |
| `$TOKEN` | `Authorization: Bearer` 后的 JWT |
| `$USER_ID` | 与 token 一致的 `userId`（`sub`） |
| `$CONV_ID` | 该用户参与的 `conversationId` |
| `$SUGGESTION_ID` | `GET .../profile-suggestions/mine` 返回的某条 `id`（pending） |

## 4. 关键联调命令

### 4.1 登录取 Token（示例）

**curl（bash / Git Bash）**

```bash
BASE=http://localhost:3000
curl -s -X POST "$BASE/auth/login" -H "Content-Type: application/json" \
  -d '{"phone":"YOUR_11_DIGIT_PHONE"}'
```

从 JSON 取 `token` 字段作为 `$TOKEN`（与 `POST /auth/login` 响应一致）。

**PowerShell**

```powershell
$BASE = "http://localhost:3000"
$r = Invoke-RestMethod -Method Post -Uri "$BASE/auth/login" `
  -ContentType "application/json" `
  -Body '{"phone":"YOUR_11_DIGIT_PHONE"}'
$TOKEN = $r.token
```

---

### 4.2 Chat summary

**GET（bash）**

```bash
curl -s -H "Authorization: Bearer $TOKEN" \
  "$BASE/chat/conversations/$CONV_ID/summary"
```

**POST generate（bash）**

```bash
curl -s -X POST -H "Authorization: Bearer $TOKEN" \
  "$BASE/chat/conversations/$CONV_ID/summary/generate"
```

**PowerShell**

```powershell
$h = @{ Authorization = "Bearer $TOKEN" }
Invoke-RestMethod -Uri "$BASE/chat/conversations/$CONV_ID/summary" -Headers $h
Invoke-RestMethod -Method Post -Uri "$BASE/chat/conversations/$CONV_ID/summary/generate" -Headers $h
```

---

### 4.3 Feedback

Body 须满足 DTO：`userId` 与 token 一致；`subjectKind` ∈ `match|conversation|suggestion|copilot|other`；`sourceType` ∈ `rule_based|template_based|placeholder|hybrid`。

**curl**

```bash
curl -s -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  "$BASE/feedback" \
  -d "{\"userId\":\"$USER_ID\",\"subjectKind\":\"conversation\",\"subjectId\":\"$CONV_ID\",\"sourceType\":\"rule_based\",\"sourceVersion\":\"p2.5-check\"}"
curl -s -H "Authorization: Bearer $TOKEN" "$BASE/feedback/mine"
```

**PowerShell**

```powershell
$h = @{ Authorization = "Bearer $TOKEN"; "Content-Type" = "application/json" }
$body = @{
  userId = $USER_ID
  subjectKind = "conversation"
  subjectId = $CONV_ID
  sourceType = "rule_based"
  sourceVersion = "p2.5-check"
} | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri "$BASE/feedback" -Headers $h -Body $body
Invoke-RestMethod -Uri "$BASE/feedback/mine" -Headers @{ Authorization = "Bearer $TOKEN" }
```

---

### 4.4 Profile suggestion

**列出我的建议**

```bash
curl -s -H "Authorization: Bearer $TOKEN" "$BASE/profile-suggestions/mine"
```

**创建 pending（示例 patch，实际键需与白名单维度一致）**

```bash
curl -s -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  "$BASE/profile-suggestions" \
  -d "{\"userId\":\"$USER_ID\",\"sourceType\":\"rule_based\",\"sourceVersion\":\"p2.5-check\",\"proposedPatch\":{\"socialEnergy\":0.5}}"
```

**accept / dismiss**

```bash
curl -s -X POST -H "Authorization: Bearer $TOKEN" \
  "$BASE/profile-suggestions/$SUGGESTION_ID/accept"
curl -s -X POST -H "Authorization: Bearer $TOKEN" \
  "$BASE/profile-suggestions/$SUGGESTION_ID/dismiss"
```

### 4.5 Behavior signal

```bash
curl -s -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  "$BASE/behavior-signals" \
  -d "{\"userId\":\"$USER_ID\",\"eventType\":\"p2.check\",\"sourceType\":\"rule_based\",\"sourceVersion\":\"p2.5-check\",\"conversationId\":\"$CONV_ID\"}"
curl -s -H "Authorization: Bearer $TOKEN" "$BASE/behavior-signals/mine"
```

### 4.6 Analytics（mine vs global）

**我的统计（应 200）**

```bash
curl -s -o /dev/null -w "%{http_code}\n" -H "Authorization: Bearer $TOKEN" \
  "$BASE/analytics/p2-overview/mine"
```

**全局统计**

- 当 **`P2_ANALYTICS_GLOBAL_OVERVIEW_USER_IDS` 未包含** 当前 `userId`：应 **403**。
- 当 env **包含** 当前 `userId` 并重启 API：应 **200**。

```bash
curl -s -o /dev/null -w "%{http_code}\n" -H "Authorization: Bearer $TOKEN" \
  "$BASE/analytics/p2-overview"
```

PowerShell：`Invoke-WebRequest` 看 `StatusCode`，或 `(Invoke-WebRequest ...).StatusCode`。

## 5. 手动验收 Checklist

勾选前请确认已满足 [§2 环境前置](#2-环境前置条件)。

- [ ] **Summary GET**：`GET .../summary` 返回 JSON，含 `summary`、`generatedAt`；有持久化时 `persisted: true` 且再次 GET 与 generate 后一致（见历史 bug 修复）。
- [ ] **Summary POST generate**：`POST .../summary/generate` 返回 200，字段完整；再 GET 仍为持久化快照。
- [ ] **Feedback POST + GET**：`POST /feedback` 201/200；`GET /feedback/mine` 含刚写入条目。
- [ ] **Profile mine + accept/dismiss**：`mine` 列出建议；对 **pending** 执行 accept 或 dismiss 成功；非 pending 再操作应失败（4xx）。
- [ ] **Behavior POST + GET**：写入成功；`mine` 可见新记录（顺序为倒序列表语义）。
- [ ] **Analytics mine**：任意登录用户 **200**。
- [ ] **Analytics global**：白名单外用户 **403**；白名单内 **200**（需配置 env 并重启 API）。
- [ ] **Copilot API**：参与者 **200**，响应含 `relationshipState`、`communicationAdvice`、`riskHints`、`suggestedTopics`、`basedOn` 等（以实际 JSON 为准）。
- [ ] **ChatPage**：登录后进 `/chat?conversationId=&userId=`：摘要区、生成按钮、Copilot 卡片、完整 Copilot 链接、画像建议区（待处理/已处理折叠）、反馈快捷操作可测；发消息仍正常。
- [ ] **CopilotPage**：`/copilot?conversationId=`（可带 `userId`）加载 insights；「返回聊天」链回正确；loading/错误/缺参提示合理。
