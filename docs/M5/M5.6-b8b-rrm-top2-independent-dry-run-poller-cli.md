# M5.6-B8-B — Independent Dry-run Poller CLI

## Summary

This milestone implements an **independent dry-run poller CLI** for manual or future CI / scheduled runs: read up to **N** pending `MatchResultRrmTop2DisplayHookJob` rows and emit **aggregate-safe JSON** using the **shared apply service** dry-run path.

| Item | Detail |
|------|--------|
| **Runner** | `apps/api/src/dev-cli/m56-b8-rrm-top2-hook-job-dry-run-poller.ts` |
| **CLI entry** | `apps/api/src/dev-cli/m56-b8-rrm-top2-hook-job-dry-run-poller-cli.ts` |
| **Shared service** | `processRrmTop2HookJobsDryRunAggregate` from `rrm-top2-hook-job-apply.service.ts` |
| **npm script** | `pnpm --filter @peima/api run m56-b8:rrm-top2-hook-job-dry-run-poller` (after `nest build`) |

## Behavior

- **`NODE_ENV=production`**: refused (JSON + non-zero exit), same spirit as other M5 dev-clis.
- **Dry-run only**: refuses `--apply`, `--mode=apply`, and `--confirmControlledApply` (apply-semantic flags).
- **`--limit=<N>`**: default **5**, clamped **1–10**.
- **`--once`**: accepted for CLI symmetry; this build **always** runs a single round and JSON includes **`once: true`**.
- **`--pretty`**: pretty-printed JSON.
- **Output**: `refused` **or** success envelope with `mode: "dry_run"`, `once: true`, `sourceVersion: m5.6-b8-rrm-top2-hook-job-dry-run-poller-v1`, counts, and **`items[]`** with only `index` / `wouldProcess` / `wouldSkip` / `noOpReasonCode` (no job / match / candidate ids in items).

## Explicit non-goals

- **No** GET `/matching/result` or other HTTP wiring.
- **No** `apps/worker/src/main.ts` registration; **no** automatic interval poller.
- **No** `--apply` or apply writer path (`dryRun: false` not used by this CLI).
- **No** HookJob `mark*` status updates.
- **No** `MatchResultRrmTop2DisplayMeta` writes; **no** `matchInsights` summary writes.
- **No** Prisma schema / migration changes.
- **No** change to `MatchResult.candidateUserId` or `finalScore`.
