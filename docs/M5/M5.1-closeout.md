## 1. 一句话结论

M5.1 **三层轨道**（Core / Signal Adapter / Consumer）已在 API 层落地：**唯一 Core** 仍为 RRM-Sim；新增 **Observed / Assistant / Timeline** 只读 Adapter 与 **Eval** 脱敏聚合 Consumer；**全部** HTTP 路径 `appliedToMatchResult: false`，**不**改写 `MatchResult` / `finalScore` / worker 主排序。  
本轨道 **不**包含 Pairwise Comparator 实现变更（已有 [M5.1-pairwise-comparator-spec](./M5.1-pairwise-comparator-spec.md) 文档 + `rrm-shared` 注册）。

**命名说明**：仓库内另有较早里程碑 **「M5.1 readonly multi-source final decision sidecar」**（`multiSourceFinalDecision` on `GET /matching/result`）。本文档收口的是 **「M5.1-r1～r12 三层架构轨道」**，二者并存、职责不同。

## 3. 交付物矩阵

### 3.1 模块与 `sourceVersion`

| 模块 | 路径 | `sourceVersion` | 跑 Core 分段公式？ |
|------|------|-----------------|-------------------|
| **RRM-Sim** | `ai-simulation-v1/` | `rrm-sim-v1` | **是**（唯一正式 Core） |
| **RRM-Observed** | `rrm-observed/` | `rrm-observed-v1` | 否（v1 仅 signal summary） |
| **RRM-Assistant** | `rrm-assistant/` | `rrm-assistant-v1` | 有条件（推进草稿 → ActionFit） |
| **RRM-Timeline** | `rrm-timeline/` | `rrm-timeline-v1` | 有条件（推进窗口 → `RFI_t`） |
| **RRM-Eval** | `rrm-eval/` | `rrm-eval-v1` | 否（cohort 聚合） |
| **Pairwise** | `ai-pairwise-decision/` | `rrm-lite-pairwise-decision-v1` | 否（Comparator） |

### 3.2 HTTP（只读）

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| GET | `/chat/conversations/:id/rrm-observed-summary` | JWT 会话参与方 | Observed 趋势信号 |
| POST | `/chat/conversations/:id/rrm-assistant-draft-assessment` | JWT 参与方 · body `{ draft }` | ActionFit band；无 raw 标量 |
| GET | `/chat/conversations/:id/rrm-timeline-summary` | JWT 参与方 | 趋势 + 推进窗口 `rhythmBand` |
| GET | `/admin/rrm-eval/aggregate?limit&sinceDays` | Admin observability 权限 | 脱敏 cohort 指标 |

**统一红线**：响应含 `appliedToMatchResult: false`（及 finalScore / worker 同类字段）；**不**自动发消息；**不**暴露 raw RFI / 公式向量给终端用户（Eval 为 admin 聚合）。

## 4. 架构不变量（收口重申）

- **生产匹配漏斗**：Photo → 20D Top2 → **Pairwise**（Comparator）· P7.6 RRM Top2 仍为 **shadow / 受控 display** 路径，见 [P7.6](../P7/P7.6-bidirectional-mutual-matching-system-plan.md) §1–2。  
- **禁止** `w1·20D + w2·Photo + w3·RRM` 类并列加权.display。  
- Adapter **不得** 使用 `rrm-sim-v1` 作为 `sourceVersion`（`assertAdapterSourceVersionNotCoreSim`）。  
- Chat / Timeline / Observed **不得** 冒充 Sim 载荷写入 matching 主链。  
- **未实现**（明确推迟）：`RFI_obs`、Observed 推进事件 Core 路径、贝叶斯 Core v2、Eval 自动调参上线 — 见 [future recommendations](./M5.1-future-core-formula-update-recommendations.md)。
