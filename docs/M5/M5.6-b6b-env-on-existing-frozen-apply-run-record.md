## 3. 环境：`PEIMA_M5_RRM_TOP2_META_WRITE_ENABLED=1`

**目的**：使 B5 apply 路径中的 `writeRrmTop2DisplayMetaForMatchResult` **不再**在入口处即返回 `writer_disabled`，从而能执行到 **frozen 侧车** 检查。

**PowerShell 示例**（仅作用于当前 shell；**勿**将 `.env` 全文或密钥写入版本库或本文档正文）：

```powershell
$env:PEIMA_M5_RRM_TOP2_META_WRITE_ENABLED = "1"
```

**本轮实测**：B5 controlled apply 在 **已设置** `PEIMA_M5_RRM_TOP2_META_WRITE_ENABLED=1` 的 shell 中执行；观测到 **`existing_meta_frozen`**（见 §5），**不是** B5-C 中 env off 下的 **`writer_disabled`** 早退。
