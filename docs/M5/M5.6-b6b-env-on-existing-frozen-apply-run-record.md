**目的**：让 B5 apply 路径中的 `writeRrmTop2DisplayMetaForMatchResult` **不再**在入口处即返回 `writer_disabled`，从而能执行到 **frozen 侧车** 检查。

```powershell

```

## 4. 创建新的 pending hook job（B3，**本地占位符**）

**命令模板**（将 `<LOCAL_*>` 替换为本地非生产 id；**勿**将替换后的命令粘贴进公开文档）：

```bash
cd apps/api
node --env-file=..\\..\\.env dist\\dev-cli\\m56-b3-rrm-top2-hook-job-cli.js ^
  --matchResultId=<LOCAL_MATCH_RESULT_ID> ^
  --viewerUserId=<LOCAL_VIEWER_USER_ID> ^
  --top2CandidateUserIdA=<LOCAL_TOP2_A> ^
  --top2CandidateUserIdB=<LOCAL_TOP2_B> ^
  --top2Fingerprint=local-dev-fixture-b6b ^
  --guardrailsStatus=pass ^
  --pretty --apply
```

**设计意图**：

- 使用 **新** `top2Fingerprint=local-dev-fixture-b6b`，避免与历史 hook job 行的 **`@@unique(matchResultId, top2Fingerprint, sourceVersion)`** 冲突。  
- 目标 `MatchResult` 必须 **已存在 frozen** `MatchResultRrmTop2DisplayMeta`（与 B6-A Case 1 一致）。

**本地执行后应核对（字段级，无 id）**：

| 检查项 | 预期 |
|--------|------|
| `created` | `true`（首次创建）或 `false`（幂等命中）；以本地 CLI JSON 为准 |
| `status`（hook job） | `pending` |
| `candidateUserIdUnchanged` | `true` |
| `finalScoreUnchanged` | `true` |

### 4.1 本轮自动化会话说明

**未**在本 Cursor 自动化会话中执行上述 B3 apply（缺少由操作者提供的 `<LOCAL_*>` 占位符替换值）。因此 **无法**在此文档写入「本次实测 `created` / `status`」的布尔结论；操作者完成 §4 后，应以 **本地 CLI 输出** 为准。

|------|------|
