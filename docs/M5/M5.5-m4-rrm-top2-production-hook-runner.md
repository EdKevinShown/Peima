# M5.5-M4 — Controlled RRM Top2 Production Hook Runner

## 概述

本轮提供 **受控 production hook runner**（`m55-m4`），用于在 **本地 / dev / staging** 基于真实 `MatchResult` 行验证 **M5.5-M2** `writeRrmTop2DisplayMetaForMatchResult` 的写入与 no-op 行为。

**不是**最终自动 production hook；**不**接 `GET /matching/result`、**不**接 worker 主流程、**不**接 simulation completion 自动调用、**不**全库扫描。

## 行为

| 项 | 说明 |
|----|------|
| **`NODE_ENV=production`** | **拒绝运行**（立即退出）。 |
| **默认** | **dry-run**（`writeRrmTop2DisplayMetaForMatchResult` 的 `dryRun: true`），不写 summary / meta。 |
| **`--apply`** | `dryRun: false`；仅在 **`PEIMA_M5_RRM_TOP2_META_WRITE_ENABLED`** 等条件满足时由 writer 落库。 |
| **`--mergeSummary`** | 使用 **M5.5-M0.1** fixture 形状合并 viewer-safe summary；**apply** 路径需 **`PEIMA_M5_RRM_SIM_READONLY_SUMMARY_WRITE_ENABLED=1`**，否则 **no-op `summary_write_disabled`**（runner 前置拒绝，不强行写）。 |
| **Static Top2** | **本轮仍由 CLI 参数传入**（与 M5.5-M2 runner 一致），用于受控验证；**M5.5-M5+** 再从 **冻结 DB 来源**读取（见 `M5.5-m3-rrm-top2-writer-production-hook-plan.md` §5）。 |
| **输出** | **viewer-safe JSON**（`mode`、`dryRun`、`ok`、`noOpReasonCode`、`wroteSummary`、`wroteMeta`、`sourceVersion`、不变量、`nextVerificationHint` 等）；**不**打印 raw prompt / transcript / score 向量 / token / key。 |

## 环境变量

- **`PEIMA_M5_RRM_TOP2_META_WRITE_ENABLED`** — meta 写入总闸（与 M5.5-M2 一致）。
- **`PEIMA_M5_RRM_SIM_READONLY_SUMMARY_WRITE_ENABLED`** — `--mergeSummary` 且 **`--apply`** 时需要。

输出中会带 **`metaWriteEnvOn` / `summaryWriteEnvOn`** 布尔快照，便于确认闸门（不含敏感值）。

## 构建与运行

在 `apps/api` 下执行 `pnpm exec nest build` 后：

```bash
pnpm --filter @peima/api run m55-m4:rrm-top2-production-hook -- \\
  --matchResultId=<local_match_result_id> \\
  --top2CandidateUserIdA=<id> --top2CandidateUserIdB=<id> \\
  --rrmWinnerCandidateUserId=<id> --top2Fingerprint=<fingerprint> \\
  [--guardrailsStatus=pass] [--mergeSummary] [--apply] [--pretty]
```

- **Dry-run（默认）**：不写库；可核对 `ok` / `noOpReasonCode` / `nextVerificationHint`。  
- **Apply**：显式传入 **`--apply`**；并确保上述 env 与 DB 数据满足 writer / eligibility 要求。

**请勿**将真实业务 ID、token、或 `.env` 内容粘贴进 **文档 / 公开 PR 描述**。

## 不变量

Runner 与 writer 共同保证 **不修改**：

- `MatchResult.candidateUserId`
- `MatchResult.finalScore`
- `PairwisePoolFinalizeMeta`、worker ranking、用户画像
- 不创建聊天、不改 FinalMatch / Chat 前端
