# M5.6-B2 — RRM Top2 Hook Job Service Helper

> **范围**：`MatchResultRrmTop2DisplayHookJob` 的 **最小 repository / service helper**（纯 Prisma 委托 + 错误脱敏）。**不接** GET、worker、consumer、**不调用** `writeRrmTop2DisplayMetaForMatchResult`。本文不出现真实业务 ID、token、`DATABASE_URL`。

## 1. 交付内容

| 路径 | 说明 |
|------|------|
| `apps/api/src/modules/matching/rrm-top2-hook-job.service.ts` | `createOrGetRrmTop2HookJob`、`findPendingRrmTop2HookJobs`、`markRrmTop2HookJobProcessing` / `Processed` / `Skipped` / `Failed`、`sanitizeRrmTop2HookJobError`。 |
| `apps/api/src/modules/matching/rrm-top2-hook-job.types.ts` | 增补 **`RrmTop2HookJobRow`**（与 M5.6-B1 表字段对齐；在 `prisma generate` 成功前便于 TS 编译）。 |
| `apps/api/test/rrm-top2-hook-job.service.spec.ts` | 幂等创建、pending 查询、状态迁移、脱敏、**不触碰** `MatchResult.update` / `matchResultRrmTop2DisplayMeta` / writer。 |

## 2. 行为摘要

- **`createOrGetRrmTop2HookJob`**：按 `@@unique([matchResultId, top2Fingerprint, sourceVersion])` **find → create**；新建行 **`status = pending`**；**不**做 RRM eligibility；**不**写 `MatchResult` / meta / summary。
- **`findPendingRrmTop2HookJobs`**：`status = pending`，`orderBy createdAt asc`，`limit` 默认 **10**、最大 **100**；**本轮无租约抢占**（锁在后续里程碑）。
- **状态 helpers**：`processing` 时 `lockedAt` + `attempts += 1`；`processed` / `skipped` 写 `processedAt` 并 **`lockedAt = null`**；`failed` 写 `lastErrorCode` + **sanitized** `lastErrorMessage`，`processedAt` / `lockedAt` 置空。
- **`sanitizeRrmTop2HookJobError`**：剥离 Bearer / 常见 key / `DATABASE_URL` / DB URL 片段、粗粒度 prompt/transcript 片段，**上限 500 字符**。

## 3. 红线（本轮遵守）

- **不接** `GET /matching/result`。
- **不接** worker / consumer 轮询。
- **不调用** `writeRrmTop2DisplayMetaForMatchResult`。
- **不写** `MatchResultRrmTop2DisplayMeta`、`matchInsights.rrmSimReadonlySummary`。
- **不改** `MatchResult.candidateUserId`、`finalScore`。

## 4. Prisma Client 说明

若本地 **`pnpm prisma generate`** 因 Windows `EPERM`（`query_engine` 被占用）失败，服务层使用 **`RrmTop2HookJobRow` + 窄 `RrmTop2HookJobPrisma`** 与运行时 `PrismaService` **结构兼容**；生成成功后可将类型逐步收敛到 `@peima/database` 导出的 Prisma model（可选后续清理）。
