# M5.6-B4B — RRM Top2 Hook Job Consumer Dry-run Runner (Controlled CLI)

> **范围**：**controlled dev-cli**：用 `findPendingRrmTop2HookJobs` 读取 pending hook job，对每条调用 `processRrmTop2HookJobDryRun`，输出 **聚合 JSON**（不含真实 job / match / candidate id）。**不**写 job 状态、**不**写 meta、**不**写 summary、**不**改 `candidateUserId` / `finalScore`、**不**接 worker / GET。本文不含真实业务 ID、token、`DATABASE_URL`。

## 1. 行为

| 项 | 说明 |
|----|------|
| **`NODE_ENV=production`** | **拒绝运行**（退出码非 0）。 |
| **`--apply`** | **不支持**（解析到即拒绝并退出）。 |
| **`DATABASE_URL`** | **必需**（需连库只读查询 pending）。 |
| **CLI** | `--limit=<1–100>`（默认 10）、`--pretty`。 |
| **本轮** | **无** `--recordDryRunResult`；不写 `auditMeta` / `metaWriteResult`。 |

## 2. 构建与运行

在 `apps/api` 下 `pnpm exec nest build` 后：

```bash
pnpm --filter @peima/api run m56-b4b:rrm-top2-hook-job-consumer -- --limit=20 --pretty
```

输出字段包括：`mode`（`dry_run`）、`sourceVersion`（runner 合约版本字符串）、`totalJobsRead`、`wouldProcessCount`、`wouldSkipCount`、`noOpReasonCounts`、`writerOkCount`、`writerNoOpCount`、`candidateUserIdUnchangedAll`、`finalScoreUnchangedAll`、`items`（仅 **index** + 决策字段，**无** id）。

## 3. 安全边界

- **不**调用 `markRrmTop2HookJobProcessing` / `Processed` / `Skipped` / `Failed`。  
- **不**修改 hook job `status`。  
- **不** `matchResult.update`、`matchResultRrmTop2DisplayMeta.upsert`、summary writer apply。  
- Writer 仅通过 consumer 以 **`dryRun: true`** 调用（与 M5.6-B4 一致）。
