## 1. 原则

1. **不改公式形态** 除非新 `sourceVersion`（如 `rrm-sim-v2`）、Eval 证据、回滚方案齐备。  
2. **贝叶斯更新的是信念（分布）**，不是把新数据再塞进 `RFI = S×E×A + …` 重算冒充「更新后的 Core」。  
3. **Sim → 先验**，**Observed / Feedback → 似然**，**Consumer → 后验摘要**（与 Adapter/Core/Consumer 分层一致）。

---

## 2. Core v2 候选方向（非贝叶斯）

| 方向 | 动机 | 风险 |
|------|------|------|
| 调整 RFI→0–100 映射 | 缓解 M1.3 `too_narrow` / spread 压缩 | 旧 job 解读漂移 |
| Per-scenario `C_pred` / `D_pre` | 加大候选间差异 | 复杂度高、与 v1 不可比 |
| `R_scenario` 进入越界惩罚 P | 单场景越界更重 | 需重新校准七场景 fixture |
| 诊断阈值 alone（spread&lt;8） | 不动公式，只改只读提案 | 不解决根因，但最安全 |

**准入**：M6/M5.1 RRM-Eval 表 + PM 签字 + shadow 对比 v1/v2。

## 3. 贝叶斯：Core 作为先验

### 3.1 随机变量 θ（建议先选一种）

| θ | 含义 | 先验来源 |
|---|------|----------|
| π | 「当前关系适合推进」概率 | `simulatedRhythmScore` → Beta 先验 |
| z | 连续「关系势能」 | RFI → Normal 先验 μ₀, σ₀ |

### 3.2 先验参数化（示例：Beta–Binomial）

```text
π ~ Beta(α₀, β₀)
π₀ = simulatedRhythmScore / 100
κ  = 先验强度（越大越信 Sim）
α₀ = π₀ · κ ,  β₀ = (1 − π₀) · κ
```

κ 由 Eval 调参，**不**写死在 Core 公式里。

### 3.3 似然（Observed / Feedback）

| 观测 | 似然族 |
|------|--------|
| 回复/冷场/负反馈（二值） | Binomial → Beta 后验 **加计数** |
| 合成标量 `Q_obs, S_obs` | Normal 似然 → **精度加权** 更新 μ, σ |
| Top2「i 优于 j」 | **Bradley–Terry**（Pairwise 是比较似然，不是 π 直接更新） |

### 3.4 更新公式（闭式，便于实现）

**Beta 后验（二值结果）：**

```text
α₁ = α₀ + s_success
β₁ = β₀ + s_failure
E[π | data] = α₁ / (α₁ + β₁)
```

**Gaussian 后验（标量观测 x）：**

```text
τ₀ = 1/σ₀² ,  τ_obs = 1/σ_obs²
τ_post = τ₀ + τ_obs
μ_post = (τ₀·μ₀ + τ_obs·x) / τ_post
```

**时间序列（Timeline 窗口）：** Kalman 预测/更新；窗口内 `RFI_t` 仅作观测层，不替代 Sim Core 公式。

### 3.5 输出契约（建议 `rrm-posterior-v1`）

- `priorSourceVersion: "rrm-sim-v1"`  
- `likelihoodSourceVersion: "rrm-observed-v1" | "feedback-v1"`  
- `posteriorMean`, `posteriorVariance` 或 `alphaPost`, `betaPost`  
- `appliedToFinalScore: false`（直至单独里程碑）

## 4. 与 Pairwise / 主链的边界

- **禁止**：Sim 分 + Pairwise 分 + 后验分 **加权平均** 成一个 `mutualMatchScore`。  
- **允许**：Top2 上用 Bradley–Terry，η 的先验均值来自各候选 Sim。  
- **禁止**：后验直接写 `MatchResult.candidateUserId` 而无开关与 Eval。

---

## 5. 建议落地顺序（未来里程碑）

1. RRM-Eval：π₀ vs 结果（校准 κ）。  
2. Observed v1 信号 → Beta 或 Gaussian **离线** 原型（脚本，不写主链）。  
3. 若 Top2 要吃 RRM：Bradley–Terry + shadow。  
4. 再评估 **rrm-sim-v2** 公式形态变更。
