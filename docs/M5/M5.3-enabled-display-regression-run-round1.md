## 5. 安全不变量（本轮确认）

- **`MatchResult.candidateUserId`**：resolver **不**修改行数据；测试断言输入行不变。
- **`finalScore`**：同上。
- **resolver 不写 DB**：无 `prisma.update` / create；只读侧车 + `matchInsights`。
- **GET 不运行 RRM evaluator**：仅解析已存的 `rrmSimReadonlySummary` JSON。
- **GET 不重算 Top2**：Top2 由 meta + eligibility 输入约束，无 `buildRelationshipShortlistTop2` 调用。
- **GET 不生成 RRM proposal**：无 proposal 生成逻辑。
- **`multiSourceFinalDecision`**：**不**接管 display（M5.1/M5.2 设计未变）。
- **FinalMatchPage**：本轮 **未**改。
- **`displaySourceType = rrm_top2_bounded_selector`**：仅在 **env on + 侧车 + eligible + User 存在** 时出现。
