# M5.6-B3 — RRM Top2 Hook Job Controlled Runner

> **范围**：**controlled dev-cli runner**，在本地 / dev / staging **手动**创建或幂等复用 **`MatchResultRrmTop2DisplayHookJob`** 行。**不接** GET、worker、consumer；**不调用** `writeRrmTop2DisplayMetaForMatchResult`。本文不出现真实业务 ID、token、`DATABASE_URL`。

## 1. 行为

| 项 | 说明 |
|----|------|
| **`NODE_ENV=production`** | **拒绝运行**（立即退出）。 |
| **默认** | **dry-run**：**不**打开 Nest / **不**要求 `DATABASE_URL`；**不**调用 `createOrGetRrmTop2HookJob`。 |
| **`--apply`** | 需 **`DATABASE_URL`**；启动 Nest `PrismaService`，调用 **`createOrGetRrmTop2HookJob`**（幂等）。 |
| **输出** | **viewer-safe JSON**（`mode`、`dryRun`、`apply`、`created`、`jobId`、`status`、`sourceVersion`、`top2Fingerprint`、`guardrailsStatus`、不变量、`nextStepHint` 等）；**不**打印 raw prompt / transcript / raw score / token / API key。 |

## 2. 构建与运行

在 `apps/api` 下 `pnpm exec nest build` 后：

```bash
pnpm --filter @peima/api run m56-b3:rrm-top2-hook-job -- \\
  --matchResultId=<local_match_result_id> \\
  --viewerUserId=<local_viewer_user_id> \\
  --top2CandidateUserIdA=<id> --top2CandidateUserIdB=<id> \\
  --top2Fingerprint=<fingerprint> \\
  [--sourceVersion=m5.6-b3-rrm-top2-hook-job-v1] \\
  [--rrmSourceType=controlled_runner] [--guardrailsStatus=pass|caution|block|not_evaluated] \\
  [--poolId=...] [--batchId=...] [--aiSimulationJobId=...] [--pairwiseJobId=...] \\
  [--apply] [--pretty]
```

- **Dry-run（默认）**：不写库；可核对 JSON 与 `nextStepHint`。  
- **`--apply`**：写入 **hook job 表**；**不**表示 RRM 展示已生效（仍需后续 consumer + writer 等里程碑）。

**请勿**将真实业务 ID、token、或 `.env` 内容粘贴进 **文档 / 公开 PR 描述**。
