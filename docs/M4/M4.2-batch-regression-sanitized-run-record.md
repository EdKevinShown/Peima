# M4.2 — 批量回归脱敏验收记录

本文档为 **M4.2 批量报告脚本** 在真实 DB 上跑出的 **聚合结果快照**（多轮），仅含统计字段，**不含** `viewerUserId`、`poolId`、`candidateUserId`、`pairwiseJobId`、`simulationJobId` 或 `perSample`。实现与指标定义见 [M4.2-batch-regression-and-quality-metrics.md](./M4.2-batch-regression-and-quality-metrics.md)。

**执行方式（本地）**：`cd apps/api && pnpm exec nest build` 后，在仓库根目录执行  
`node --env-file=.env packages/database/scripts/m4-2-batch-regression-report.mjs --limit 20 --json … --markdown …`。原始 JSON / 本地 Markdown 由根 `.gitignore` 忽略，**不提交**。

**说明**：`--limit` 为纳入样本的 **上限**；实际 **`sampleCount`** 取决于 DB 中满足样本定义的行数。

- **不改** `displayCandidateUserId`；**不改** **`GET /matching/result`**。
