# M4.2 — 第一阶段收口说明（closure）

本文档记录 **M4.2 批量回归与质量指标** 第一阶段的 **目标、交付与边界**，便于审计与后续 M4.3 / M4.4 分流。**不含**业务代码或 schema 变更说明；实现以代码与 [M4.2-batch-regression-and-quality-metrics.md](./M4.2-batch-regression-and-quality-metrics.md) 为准。

---

## 1. M4.2 目标

- **基于 M4.1** `MatchingDecisionComparisonService.getComparison`（四源 decision-comparison）做 **只读批量回归** 与 **质量指标统计**（脚本 `m4-2-batch-regression-report.mjs`）。  
- **只读**：不写库、不重跑 LLM、**不改变**最终匹配结果（`MatchResult`、展示候选、`GET /matching/result`、worker 主排序等）。

---

---

## 3. 关键结果

- **初始**批量纳入样本：**`sampleCount` = 1**（`pairwise_pool_finalize_meta.frozen=true` 且归属一致的 `preview_pools` 极少）。  
- **扩容后**：通过 M3 系列 pairwise + finalize，`frozen=true` 的 finalize meta **增至 5**，批量报告 **`sampleCount` = 5**。  
- **脱敏 run record** 仅含聚合字段，**不含** `viewerUserId`、`poolId`、`candidateUserId`、`pairwiseJobId`、`simulationJobId`、`perSample`。  
- **原始 JSON**、**本地 Markdown 报告**、**local run 记录**（含 cuid）**未提交**到版本库（`.gitignore` 窄规则）。
