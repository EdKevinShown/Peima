# M4.4 — Admin Observability 第一阶段收口

本文档收口 **M4.4** 只读观测：**M0 / M1 / M1B**（CLI）与 **M2**（Admin HTTP，经 [P7.11-r1 closeout](../P7/P7.11-r1-production-matching-observability-closeout.md)）。**未**进入 Admin UI 大盘、自动修复链路。详细方案见 [`M4.4-admin-observability-plan.md`](./M4.4-admin-observability-plan.md)。

---

## 1. M4.4 目标（阶段内已对齐）

- 建立 **Admin / developer 观测面**，理解 matching 侧车与旁路信号，而非替代主决策。
- 对 **fallback**、**failure**、**finalize**、**pairwise**、**simulation**、与 **batch regression（M4.2）** 相关的指标做 **只读汇总**（CLI + 文档），**不改变最终匹配结果**。

## 4. 安全边界（重申）

- **不写** `MatchResult`，**不改** `candidateUserId`、`finalScore`、`displayCandidateUserId`。
- **不改** `GET /matching/result` 语义；**不改** worker、**不改** `FinalMatchPage` 用户主路径。
- **不改** pairwise finalize 业务语义；**不改** RRM **公式 / evaluator / extractDPre**。
- **不暴露** raw prompt、LLM body、transcript、**raw `meta`**；观测输出仅安全聚合字段。
- **不提交**真实 ID 明细；本地 `*.local.*` 报告不入库。

---

## 5. 本阶段明确未做

- **未实现** Admin Web 大盘 / 页面（M4.4-M3）。
- **未实现**自动告警、自动 retry、自动 repair；脚本与文档 **无**写库副作用。
- **未让**观测结果 **自动** 影响最终匹配或 worker 排序。
