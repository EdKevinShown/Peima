# P4：体验与联动 — 手动验收清单（勾选用）

前置：已登录、具备有效会话 `conversationId` 与 `userId`（query 或 localStorage 约定）。

## 聊天页 `/chat`

- [ ] 可见「会话周边（规则层 · 只读）」区块与统一说明文案。
- [ ] 摘要加载失败时，出现 **可读错误** 与 **重试加载摘要**；重试后能恢复或再次报错一致。
- [ ] **生成并更新摘要** 成功后，提示含「沟通建议已尝试刷新」；Copilot 区域数据有变化或仍为空时行为可理解。
- [ ] 沟通建议加载失败时，有错误文案与 **重试加载沟通建议**。
- [ ] 快捷反馈 👍/😐/👎 成功后，提示含 **不通知对方**；失败时有可读错误。
- [ ] 无画像建议时，画像卡片仍展示（非整段消失），且「待处理」下为「当前没有…」类说明。
- [ ] 进入 Copilot 全页、时间线链接携带的 query 完整。

## Copilot 页 `/copilot`

- [ ] 无 `conversationId` 时，空态说明含返回 **聊天** 链接与 query 提示。
- [ ] 有 `conversationId` 时，**刷新沟通建议** 可重新拉取（仅只读 API）。
- [ ] 返回聊天链接带上 `conversationId` / `userId`。
- [ ] 接口错误时 `role="alert"` 展示信息可读。

## 回归（勿破坏）

- [ ] P0：发消息、刷新消息列表仍正常。
- [ ] P3：从聊天进入 **关系时间线** 仍正常。
- [ ] P2.5：摘要生成、建议 accept/dismiss 仍可用。

## 403 / 白名单（可选）

- [ ] 调用需白名单的接口时，403 提示与 `handleJson` 中文说明一致。
