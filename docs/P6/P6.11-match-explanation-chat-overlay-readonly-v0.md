# P6.11 — Match Explanation：聊天画像 Overlay 只读解释增强（v0）

## 目的

在 **不改变** `MatchResult.finalScore`、worker、匹配排序、预览池、问卷答案与数据库 schema 的前提下，将 **viewer** 的 `user_profile.effectiveProfileChatOverlayV1` **只读**接入 `match-explanation-ai` 的 **LLM 用户消息上下文**，用于丰富自然语言说明。

## 行为摘要

- **入口**：`GET /match-explanation-ai/match-results/:matchResultId`（与既有 P6.6 一致）。
- **读取**：解释请求处理时，对 `match_result.userId`（viewer）查询 `user_profile.effectiveProfileChatOverlayV1`（仅该字段）。
- **不向模型投喂原始 JSON**：服务端预渲染为短文本块 `chatProfileOverlaySummary`（仅存在于 prompt 拼接中，**不**作为 API 响应字段）。
- **免责声明**（固定文案）：明确为「聊天画像补充参考」、**不影响匹配分**、**不改变问卷主画像**，并要求模型 **不得**声称该段内容改变了匹配分或排序。
- **状态中文**：按轴状态生成 1～3 条短句；不输出 axisId、分支代号、权重、内部枚举名。
- **失败降级**：profile 读取或摘要生成失败时，视为无 overlay，**与 P6.6 原有解释链路一致**（含规则回退路径不受影响）。

## 实现位置

- `apps/api/src/modules/match-explanation-ai/match-explanation-chat-overlay-summary.ts` — 摘要生成。
- `apps/api/src/modules/match-explanation-ai/match-explanation-ai.service.ts` — 读库并拼接 user content。
- `apps/api/src/modules/match-explanation-ai/match-explanation-ai-model.prompt.ts` — 系统 prompt 约束与 `buildMatchExplanationUserContent` 可选参数。
- `apps/api/test/match-explanation-chat-overlay-summary.spec.ts` — 最小单测。

## Prompt 版本

`MATCH_EXPLANATION_PROMPT_VERSION` 为 **`p6.11-match-explanation-prompt-v2`**（与 `match-explanation-ai.constants.ts` 一致），真实 LLM 成功路径的 `sourceVersion` 中会体现该片段。

## 接口验收（已完成）

**边界（本轮不宣称、未改）**：`finalScore`、worker、matching 排序、schema、问卷主画像主链；P6.11 仅只读解释增强。

### 1. 单测

- 命令：`pnpm --filter @peima/api test -- match-explanation-chat-overlay-summary.spec.ts`
- 结果：`6 tests passed`（`effectiveProfileChatOverlayV1` 服务端摘要与 `buildMatchExplanationUserContent` 拼接入 prompt 有单测覆盖）。

### 2. 规则 / fallback 路径

- 条件：未启用 LLM 或 `MATCH_EXPLANATION_AI_API_KEY` 等导致走规则时。
- 请求：`GET /match-explanation-ai/match-results/:matchResultId`
- 预期响应字段：`sourceType = match_explanation_rule_based`，`sourceVersion = p6.6-match-explanation-rule-v1`（与 P6.6 规则占位一致，**P6.11 未破坏** fallback 语义）。

### 3. 真实 LLM 路径（DeepSeek 示例）

- 环境变量（示例）：
  - `MATCH_EXPLANATION_AI_ENABLED=true`
  - `MATCH_EXPLANATION_AI_BASE_URL=https://api.deepseek.com`
  - `MATCH_EXPLANATION_AI_MODEL=deepseek-chat`
  - `MATCH_EXPLANATION_AI_PROVIDER=deepseek`（与 `sourceType` 中 provider slug 一致；另需有效 API Key。）
- 请求示例：`GET /match-explanation-ai/match-results/cmoc1wqwi00026zcc8ng1eavi`（须带 viewer 的 JWT 且该 `matchResultId` 可访问。）
- 实际返回示例（验收记录）：
  - `sourceType = match_explanation_model_deepseek`
  - `sourceVersion = deepseek|deepseek-chat|p6.11-match-explanation-prompt-v2`

**结论**：P6.11 的 match-explanation-ai 真实模型路径已跑通；overlay 摘要在服务端注入，并有单测保障；与规则回退、既有边界一致。
