# P6.y — Interaction Simulation Lite（阶段完成总结）

**阶段状态：已完成收口。** 面向「初次聊天互动预判」的**只读 HTTP 切片**：在**不落库、不改 matching、不跑 worker** 的前提下，为当前用户与其某条 `MatchResult` 输出**四轴 band + oneLiner + 总评**；输入侧与 **P6.x Match Review** 同源（静态 `reviewStaticScore` + `buildMatchReviewStaticSummary` 结构化摘要）。

**本地验证（人工）**：① **模型成功路径** — DeepSeek 下 `debug.sourceType === "interaction_simulation_lite_model_deepseek"`、`debug.fallbackUsed === false`。② **模型失败 fallback 路径** — 已走规则填充同一 schema，`fallbackUsed === true`。③ **`debug.meta.reason`** — fetch / 错误 `BASE_URL` 等网络层失败已归因 **`network`**（不再落泛化 `unknown`）。自动化测试**不**依赖外网模型，见文末「最小自动化护栏」。

## 能力范围（做 / 不做）

| 做 | 不做 |
|----|------|
| **GET** 按 `matchResultId` 拉取预判；JWT 且 `tokenUserId === MatchResult.userId`（否则 403）；画像缺失 404 | 写入任何业务表、缓存命中归因、异步重算 |
| **模型主路径**（`INTERACTION_SIMULATION_LITE_ENABLED` + 有效 `API_KEY`）：OpenAI-compatible `POST …/v1/chat/completions`，解析 JSON 填入与规则相同的 DTO | 与聊天会话、Copilot、worker 批处理编排联动 |
| **规则 fallback v2**：`rawBands(v1 表) → coherencePass → verdictFromAxes → summaryComposer`；`labelFitSummary` 仅作 summary **末句 trailer** | 本阶段不扩新轴、不改接口 shape、不改 Final Match 区块位置 |
| **debug**：`sourceType` / `sourceVersion` / `fallbackUsed` / `meta`（与 P6.x 风格对齐的归因口径） | `meta.reason` 在**模型成功**响应中可不出现（见下文冒烟说明） |

## 已验证主链（工程口径）

- **规则层 v2**：与 P6.x 同源静态摘要 → 四轴 + `overall`；张力检测（含收紧后的 `PICKUP_VS_COLD`）、coherence cap、叙事顺序（见 `interaction-simulation-lite-rule.ts`、`interaction-simulation-lite-coherence.ts`）。
- **HTTP 与鉴权**：`GET /interaction-simulation-lite/match-results/:matchResultId`；403 / 404 / 200 行为与专文一致。
- **前端**：`FinalMatchPage`「初次聊天互动预判」四轴中文名固定；仅消费上述 GET。
- **模型主路径（本地）**：配置 **`INTERACTION_SIMULATION_LITE_*` + DeepSeek** 时，已确认 **`interaction_simulation_lite_model_*`**、**`fallbackUsed: false`**；与规则直出以 **`sourceType`** 区分。
- **模型失败 fallback（本地）**：已确认 **`fallbackUsed: true`**、`sourceType` 为 `interaction_simulation_lite_rule|fallback|…`、响应体仍为规则 v2 同一 DTO 形状。
- **`meta.reason`（含 `network`）**：`timeout` / `http_error` / `invalid_json` / **`network`**（`fetch` 抛错且非超时，如错误 `BASE_URL`、DNS、连接被拒）等见 `interaction-simulation-lite.service.ts` 中 `mapFailureKindToReason`；模型成功时 **`reason` 常不出现**。

## 已知限制

- **非模拟器**：不生成多轮对话、不预测具体话术；输出为**静态画像上的互动倾向**文案。
- **规则与模型文案可能不一致**：fallback 与模型成功时的 `oneLiner`/`summary` 风格不必相同；对比时应以 **`debug.sourceType`** 区分来源。
- **`fallbackUsed` 语义**：`false` 既包含「纯规则（未尝试模型）」，也包含「模型成功」；区分二者必须看 **`sourceType`**。
- **配置前缀独立**：使用 **`INTERACTION_SIMULATION_LITE_*`**，与 `MATCH_REVIEW_AI_*` 分离；需分别配置若两条链都要走模型。
- **CI / 默认回归**：仓库内自动化以**规则层与纯函数**为主，**不要求**在流水线中调用真实 DeepSeek。

## 接口

- **GET** `/interaction-simulation-lite/match-results/:matchResultId`
- **鉴权**：JWT；`tokenUserId` 必须等于该 **`MatchResult.userId`**（否则 **403**）；无行或画像缺失 **404**。
- **成功**：**200**；**不落库**。

## 环境变量（`INTERACTION_SIMULATION_LITE_*`）

与 **`MATCH_REVIEW_AI_*`** 并列，见仓库根 **`.env.example`**：

| 变量 | 说明 |
|------|------|
| `INTERACTION_SIMULATION_LITE_ENABLED` | `1` / `true` / `yes` 为开启模型路径的前置开关 |
| `INTERACTION_SIMULATION_LITE_API_KEY` | 非空才会**发起** HTTP 调用；空则规则直出 |
| `INTERACTION_SIMULATION_LITE_BASE_URL` | 可选；默认 `https://api.openai.com`（须兼容 OpenAI Chat Completions） |
| `INTERACTION_SIMULATION_LITE_MODEL` | 可选；默认 `gpt-4o-mini` |
| `INTERACTION_SIMULATION_LITE_PROVIDER` | 可选；写入 `sourceType` 中的 slug（未设则从 host 推断） |
| `INTERACTION_SIMULATION_LITE_TIMEOUT_MS` | 可选；默认 25000，上限 120000 |

## `fallbackUsed`（与 P6.x Match Review 一致）

定义见 **`apps/api/src/modules/interaction-simulation-lite/interaction-simulation-lite.constants.ts`** 内 **`INTERACTION_SIMULATION_LITE_FALLBACK_USED_DOC`**：

- **`false`**：**未尝试模型**的规则直出（`ENABLED=0` 或未配 Key），**或**模型成功且 JSON 校验通过。
- **`true`**：**已尝试**调用模型，因超时 / HTTP / **网络层（`meta.reason: network`）** / 空内容 / JSON 无效等回退为**规则填充同一 schema**。

因此仅凭 `fallbackUsed === false`**不能**断言走了模型；必须结合 **`sourceType`**。

## 最小 LLM 冒烟（确认走模型而非规则）

### 代码是否具备模型调用通路

是。`apps/api/src/modules/interaction-simulation-lite/interaction-simulation-lite.service.ts` 在 `ENABLED` 且 `API_KEY` 非空时调用 `chatClient.complete`，成功则返回 **`parseInteractionSimulationLiteModelJson`** 映射后的 `axes` / `overall`。

### 需要开启的环境变量

在 **`.env`**（或运行 API 时的环境）中至少：

```bash
INTERACTION_SIMULATION_LITE_ENABLED=1
INTERACTION_SIMULATION_LITE_API_KEY=<你的供应商 Key>
# DeepSeek 示例：
# INTERACTION_SIMULATION_LITE_BASE_URL=https://api.deepseek.com
# INTERACTION_SIMULATION_LITE_MODEL=deepseek-chat
```

重启 **API** 进程使 env 生效。

### 操作建议（验证不是 rule）

1. 使用已登录用户，取一条属于自己的 **`MatchResult.id`**。
2. 调用 **GET** `/interaction-simulation-lite/match-results/:matchResultId`（带 JWT）。
3. 对比响应 **`debug`**：
   - **模型成功**：`debug.sourceType` 形如 **`interaction_simulation_lite_model_<slug>`**（已验证：`interaction_simulation_lite_model_deepseek`）；**`debug.fallbackUsed === false`**；**`debug.meta`** 通常含 **`provider`**、**`model`**，**不一定带 `reason`**。
   - **纯规则（未调模型）**：`debug.sourceType === "interaction_simulation_lite_rule"`，`fallbackUsed === false`，**`debug.meta.reason`** 为 **`disabled`** 或 **`missing_config`**。
   - **调模型后失败回退**：`debug.fallbackUsed === true`，`debug.sourceType` 形如 **`interaction_simulation_lite_rule|fallback|<reason>`**；**`debug.meta.reason`** 为 `timeout` / `http_error` / `invalid_json` / **`network`** 等与失败类型对齐的值（坏 `BASE_URL` 等 → **`network`**）。

### 重点看的字段

| 字段 | 模型成功（期望） | 纯规则 | 模型失败 fallback |
|------|------------------|--------|-------------------|
| **`sourceType`** | `interaction_simulation_lite_model_*` | `interaction_simulation_lite_rule` | `interaction_simulation_lite_rule|fallback|...` |
| **`fallbackUsed`** | `false` | `false` | `true` |
| **`meta.reason`** | 通常**无**（未设置） | `disabled` 或 `missing_config` | `timeout` / `http_error` / `invalid_json` / **`network`**（如错误 `BASE_URL`、DNS、连接被拒等 fetch 层失败）/ … |

## 最小自动化护栏（测试建议）

**目标**：在**零外网 LLM** 的前提下，锁住规则层 v2 的**成功路径**与关键不变量，避免回归时「接口还在、叙事/verdict  silently 崩坏」。

**推荐落点**：`apps/api/test/interaction-simulation-lite-rule-path.spec.ts`（已实现）。

| 护栏类型 | 内容 | 是否调 DeepSeek |
|----------|------|------------------|
| **常量** | `INTERACTION_SIMULATION_LITE_RULE_SOURCE_VERSION === p6.y-interaction-lite-rule-v2` | 否 |
| **规则 payload** | 对固定 `reviewStaticScore` + `MatchReviewStaticSummaryPayload` 调用 `buildInteractionSimulationLiteRulePayload`，断言四轴 `band` 合法、`verdict` 枚举、`summary` 非空、`oneLiner` 非空 | 否 |
| **高风险 → pause** | 高 cold / 高 mis 等输入下 `verdict === "pause"` | 否 |
| **`labelFitSummary` trailer** | 非空摘要时 `summary` 含 `画像摘要补充：` 且该前缀出现在**文末附近**（与 v2「仅末句 trailer」一致） | 否 |
| **张力收紧** | `detectTensions`：`pickup high + cold high` 才含 `PICKUP_VS_COLD`；仅 `medium` 不触发 | 否 |

**刻意不做（本轮）**：对 `InteractionSimulationLiteService` 做端到端 HTTP + 真实 Key 的 Jest；对 `parseInteractionSimulationLiteModelJson` 可做**fixture JSON** 单测（可选后续加），仍无需网络。
