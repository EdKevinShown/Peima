## 1. 本轮完成项

### 1.1 P6.8 最小闭环

- **ChatPage** 提供「根据本轮对话生成画像建议」，调用 **`POST /chat/conversations/:conversationId/profile-completion-suggestion`**；成功后在 **`GET /profile-suggestions/mine`** 可见 **pending** 建议。
- 建议走既有 **profile-suggestions** 审阅闭环：**accept / dismiss**；生成接口**不**自动写 **`UserProfile`**。
- **accept** 后按既有 accept 路径写入，作为**补充维度信号**参与画像聚合；**不以单次聊天强改主标签**为产品目标，侧重点是 **layer1 / 维度类信号的微调**（与 P6.8 白名单与专文一致）。
- **dismiss** **不**写入画像，仅状态流转。

### 1.2 P6.10 最小收口（Chat 内按钮）

- **事前**：按钮**最小禁用态** + **单行说明**（可推导条件与 **`docs/P6/acceptance/P6.10-*`**、**`P6.9-*`** 专文对齐）；**已有待处理**（pending + 约定 `sourceVersion`）时禁用并提示。
- **事后**：**ChatPage** 对生成失败按 **`ProfileCompletionSuggestionRequestError.status`** 分支展示固定中文；**`apps/web/src/api/chat.ts`** 对 **401 / 403** 另有固定文案，其余携带服务端 **`message`** 或 **`detail`**。具体状态码与文案以专文及当前 `ChatPage` / `chat.ts` 为准。

### 1.3 会话 URL 自愈

- **`/chat`**、**`/copilot`**、**`/chat/timeline`**：在 **`resolveUserId`** 能拿到 **`userId`**、URL **无 `conversationId`** 时，前端调用 **`createConversation(userId)`**，成功后 **`replace`** 回写 **`conversationId` + `userId`**（`apps/web/src/hooks/useEnsureConversationInUrl.js`）。
- Bootstrap 中展示 **「正在准备会话…」**，避免误报「缺少 conversationId」；失败则展示创建会话错误。
- 三页顶栏互跳仍只依赖 URL 中已有参数；**`ConversationContextBar`** 仅展示，逻辑未改。

### 1.4 Final match 主链（规则 / 占位版）

- 已跑通：**preview-pool → matching enqueue → batch-match → final result**；**当前 final result 仍为规则层 + 占位洞察**，**不是**最终「AI 模拟匹配」产品版。

### 1.5 profile-suggestions 列表可读（基础设施）

- **`GET /profile-suggestions/mine`** 与 ChatPage「画像更新建议」区在 **schema 与 migrations 对齐** 后**可读**（历史上曾因 **`profile_update_suggestions` 缺列** 导致 500，已通过迁移与库对齐解决）。
